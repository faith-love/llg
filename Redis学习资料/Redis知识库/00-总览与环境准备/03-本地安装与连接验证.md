# 本地安装与连接验证

## 安装方式

本地学习推荐三种方式：

- Docker：隔离简单，便于切换版本。
- Linux 包管理器：贴近服务器环境。
- Windows 环境下使用 WSL：比旧版 Windows 移植包更接近真实 Redis。

Docker 示例：

```bash
Docker run --name Redis学习资料-lab -p 6379:6379 -d Redis学习资料:7
Docker exec -it Redis学习资料-lab Redis学习资料-cli
```

## 基础连接

进入 `Redis学习资料-cli` 后先验证连通性：

```bash
PING
SET hello Redis学习资料
GET hello
DEL hello
```

返回 `PONG` 代表服务可访问。`SET` 和 `GET` 能成功，代表读写链路正常。

## 常用启动参数

```bash
Redis学习资料-服务端 /path/to/Redis学习资料.conf
Redis学习资料-cli -h 127.0.0.1 -p 6379
Redis学习资料-cli -a your-password
Redis学习资料-cli --raw
```

`--raw` 对中文值更友好。生产环境不要把密码直接写在 shell 历史里，可以通过环境变量、配置中心或客户端配置管理。

## 环境检查清单

- `Redis学习资料-服务端 --version` 能看到服务端版本。
- `Redis学习资料-cli ping` 返回 `PONG`。
- `INFO 服务端` 能看到运行时间、版本和模式。
- `CONFIG GET dir` 和 `CONFIG GET 未译66984filename` 能确认持久化文件位置。
- 学习环境和生产环境的数据库不要混用。

## 推荐练习流程

每次新建环境后，按固定顺序验证：

```bash
PING
INFO 服务端
INFO 客户端s
INFO memory
CONFIG GET dir
CONFIG GET appendonly
SET lab:env:check ok EX 60
GET lab:env:check
TTL lab:env:check
```

这些命令能同时验证连接、读写、过期、内存信息和持久化目录。以后排查生产问题时，也可以把这个顺序作为只读检查的起点。

## Docker 数据持久化

如果希望Docker删除后数据还在，需要挂载数据目录：

```bash
Docker run --name Redis学习资料-lab -p 6379:6379 -v Redis学习资料-数据:/数据 -d Redis学习资料:7 Redis学习资料-服务端 --appendonly yes
```

这条命令会启用 AOF，并把数据目录放到 Docker 未译27462lume 中。学习时可以用它观察 AOF 文件增长、重启恢复和配置变更。

## 常见问题

- 连接被拒绝：服务没启动、端口没映射或防火墙拦截。
- 认证失败：配置了密码但 `Redis学习资料-cli` 没带 `-a` 或 `AUTH`。
- 中文显示异常：使用 `Redis学习资料-cli --raw`。
- Docker重启后数据丢失：没有挂载 `/数据` 或没有启用持久化。

## 练习

- 用 Docker 启动一个 Redis 7 实例。
- 使用 `Redis学习资料-cli` 完成 `PING`、`SET`、`GET`、`TTL`。
- 重启Docker后验证数据是否还在。
- 记录本地环境的版本、端口、数据目录和持久化配置。
