# Redis 知识库

Redis 是以内存为核心的数据存储系统，常用于缓存、分布式锁、计数器、排行榜、限流、消息流和会话存储。学习 Redis 时不要只背命令，还要理解数据结构、内存成本、持久化风险、高可用切换、客户端连接和业务缓存策略。

## 版本基线

这套知识库以 Redis 7.x/8.x 的通用能力为主。Redis 8 将 Redis Stack 的能力并入 Redis Open Source，包含更多数据结构和搜索能力；实际生产选型仍应以公司镜像源、客户端兼容性、许可证策略和官方 release notes 为准。

## 学习检查

- 能解释每种数据类型的典型业务场景和不适用场景。
- 能设计有命名规范、过期策略和容量边界的 Key。
- 能说清 未译25173DB/AOF 的恢复路径和数据丢失窗口。
- 能根据业务选择缓存更新策略，并说明一致性取舍。
- 能从慢查询、延迟、内存、连接数、复制延迟定位 Redis 问题。
