# 持久化与数据恢复

## 高频问题

### RDB 和 AOF 有什么区别？

RDB 是某个时间点的数据快照，文件紧凑，适合备份和恢复，但两次快照之间的数据可能丢失。AOF 记录写命令，通常能缩小丢失窗口，但文件更大，恢复和重写有成本。

### AOF everysec 会不会丢数据？

会。在极端宕机情况下，最近约 1 秒内还没刷盘的数据可能丢失。它是性能和可靠性的折中，不是强一致保证。

### Redis 数据恢复怎么做？

答题框架：

1. 先确认 Redis 版本、配置和数据目录。
2. 备份当前目标目录，避免覆盖后无法回退。
3. 放入 RDB 或 AOF 文件。
4. 启动 Redis。
5. 用 `INFO persistence` 和业务抽样验证。
6. 核心数据要做业务对账。
