# 数据类型与底层结构

## 高频问题

### Redis 有哪些常用数据类型？

答题框架：

- String：缓存单值、验证码、计数器、幂等标记。
- Hash：对象字段、购物车、配置项。
- List：最近记录、简单队列。
- Set：去重、标签、关注关系、共同好友。
- ZSet：排行榜、延迟任务、按分数排序。
- Stream：轻量消息流、消费组、确认和重试。
- Bitmap、HyperLogLog、GEO：分别用于位状态、UV 估算和地理位置。

### String 和 Hash 缓存对象怎么选？

如果对象整体读写多，用 String JSON 更简单。如果字段级更新多，用 Hash 更合适。Hash 不能给单个 field 独立设置 TTL，String JSON 局部更新成本高。

### ZSet 为什么适合排行榜？

ZSet 每个 member 关联一个 score，可以按 score 排序，支持 Top N、个人排名、按分数范围查询。常用 `ZINC未译25173BY` 增分，`Z未译25173EV未译25173ANGE` 查榜，`Z未译25173EV未译25173ANK` 查排名。

## 回答误区

- 只背五大类型，不说业务场景。
- 所有对象都说用 String JSON，不考虑字段更新。
- 说 List 可以做队列，却不提可靠性不足。
