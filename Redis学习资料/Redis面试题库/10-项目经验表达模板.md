# 项目经验表达模板

## 总模板

## 商品详情缓存示例

```text
我们在商品详情接口使用 Redis 降低数据库压力。
Key 是 mall:product:{id}:detail，value 使用 JSON，TTL 30 分钟并加随机抖动。
读接口先查缓存，未命中回源数据库并写缓存。
更新商品时先更新数据库，再删除缓存，删除失败通过消息重试。
热点商品使用逻辑过期和后台刷新，避免击穿。
监控命中率、回源次数、重建耗时和慢查询。
Redis 异常时返回基础字段，关闭推荐模块。
```

## 短信验证码示例

```text
我们用 Redis 保存短信验证码和限流计数。
验证码 Key 是 auth:sms:code:{phone}，TTL 5 分钟。
发送频率用分钟级计数器控制，错误次数也用计数器限制。
验证码成功后删除，失败次数过多会短暂锁定。
Redis 不可用时拒绝发送验证码，避免绕过风控。
```

## 排行榜示例

```text
我们用 ZSet 做文章热榜。
Key 按 rank:article:daily:{date} 设计，member 是文章 ID，score 是热度分。
阅读、点赞、评论按不同权重调用 ZINC未译25173BY。
查询 Top N 用 Z未译25173EV未译25173ANGE，个人排名用 Z未译25173EV未译25173ANK。
历史榜单设置 TTL，并监控 ZSet 大小和写入 QPS。
```

## 分布式锁示例

```text
我们在定时任务中用 Redis 锁防止多实例重复执行。
加锁使用 SET lock:作业:{name} uuid NX EX 300。
释放锁使用 Lua 校验 uuid 后删除。
任务本身做幂等，锁过期或 Redis 切换时不会造成重复写坏数据。
```
