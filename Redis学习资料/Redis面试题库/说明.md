## 答题原则

面试回答建议按这个顺序组织：

```text
概念是什么 -> 为什么这样设计 -> 项目里怎么用 -> 有什么风险 -> 怎么监控和兜底
```

不要只背定义。Redis 面试题的关键是能把命令、数据结构、业务场景、生产风险连起来。
