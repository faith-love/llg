# String 命令

## 常用命令

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `SET` | 写入字符串 | `SET 用户:1:name Ada` |
| `GET` | 读取字符串 | `GET 用户:1:name` |
| `MGET` | 批量读取 | `MGET key1 key2` |
| `MSET` | 批量写入 | `MSET k1 v1 k2 v2` |
| `SETNX` | 不存在时写入 | `SETNX lock:1 uuid` |
| `SETEX` | 写入并设置过期 | `SETEX code:phone 300 123456` |
| `INCR` | 自增 1 | `INCR counter:article:1` |
| `INCRBY` | 增加指定值 | `INCRBY stock:sku:1 -1` |
| `DECR` | 自减 1 | `DECR stock:sku:1` |
| `STRLEN` | 查看字符串长度 | `STRLEN 缓存:value` |

## 推荐写法

写缓存：

```bash
SET 缓存:product:1 "{...}" EX 1800
```

写幂等标记：

```bash
SET idem:支付:req-001 done NX EX 600
```

写锁：

```bash
SET lock:order:1001 request-uuid NX EX 30
```

## 风险提示

- `SETNX` 单独使用没有过期时间，不适合作为完整锁实现。
- `INCR` 要求 value 是整数格式。
- 大 JSON String 每次读写都是整体传输，字段频繁变化时考虑 Hash。
- `MGET` 虽然减少网络往返，但一次读取太多 Key 仍会造成大响应。

## 常见场景

- 验证码：`SET auth:sms:code:{phone} code EX 300`。
- 计数器：`INCR article:{id}:views`。
- 幂等：`SET idem:{biz}:{requestId} 1 NX EX 600`。
- 简单缓存：`SET 缓存:{biz}:{id} value EX ttl`。

## 练习

- 用 `INCR` 实现阅读数。
- 用 `SET NX EX` 实现一个 10 分钟幂等 Key。
- 说明为什么锁释放不能直接 `DEL`。
