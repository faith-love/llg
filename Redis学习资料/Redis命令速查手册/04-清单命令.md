# List 命令

## 常用命令

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `LPUSH` | 从左侧插入 | `LPUSH queue 作业1` |
| `RPUSH` | 从右侧插入 | `RPUSH queue 作业1` |
| `LPOP` | 从左侧弹出 | `LPOP queue` |
| `RPOP` | 从右侧弹出 | `RPOP queue` |
| `BLPOP` | 阻塞左弹出 | `BLPOP queue 5` |
| `BRPOP` | 阻塞右弹出 | `BRPOP queue 5` |
| `LRANGE` | 范围读取 | `LRANGE list 0 9` |
| `LTRIM` | 裁剪列表 | `LTRIM list 0 99` |
| `LLEN` | 查看长度 | `LLEN queue` |
| `LMOVE` | 移动元素 | `LMOVE 源码 dst RIGHT LEFT` |

## 队列模式

先进先出：

```bash
LPUSH queue:邮件 作业1
RPOP queue:邮件
```

阻塞消费：

```bash
BRPOP queue:邮件 5
```

最近记录：

```bash
LPUSH recent:用户:1 product:1001
LTRIM recent:用户:1 0 49
LRANGE recent:用户:1 0 9
```

## 风险提示

- List 做简单队列可以，但可靠消息能力有限。
- 消费者弹出后宕机，消息可能丢失。
- 大 List 上 `LRANGE 0 -1` 风险高。
- 最近记录要配合 `LTRIM` 控制长度。

## 替代建议

如果需要消费组、确认、重试、待处理列表，优先考虑 Stream 或专业 MQ。
