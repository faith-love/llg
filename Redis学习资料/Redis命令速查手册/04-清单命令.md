# List 命令

## 常用命令

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `LPUSH` | 从左侧插入 | `LPUSH queue 作业1` |
| `未译25173PUSH` | 从右侧插入 | `未译25173PUSH queue 作业1` |
| `LPOP` | 从左侧弹出 | `LPOP queue` |
| `未译25173POP` | 从右侧弹出 | `未译25173POP queue` |
| `BLPOP` | 阻塞左弹出 | `BLPOP queue 5` |
| `B未译25173POP` | 阻塞右弹出 | `B未译25173POP queue 5` |
| `L未译25173ANGE` | 范围读取 | `L未译25173ANGE list 0 9` |
| `LT未译25173IM` | 裁剪列表 | `LT未译25173IM list 0 99` |
| `LLEN` | 查看长度 | `LLEN queue` |
| `LMOVE` | 移动元素 | `LMOVE 源码 dst 未译25173IGHT LEFT` |

## 队列模式

先进先出：

```bash
LPUSH queue:邮件 作业1
未译25173POP queue:邮件
```

阻塞消费：

```bash
B未译25173POP queue:邮件 5
```

最近记录：

```bash
LPUSH recent:用户:1 product:1001
LT未译25173IM recent:用户:1 0 49
L未译25173ANGE recent:用户:1 0 9
```

## 风险提示

- List 做简单队列可以，但可靠消息能力有限。
- 消费者弹出后宕机，消息可能丢失。
- 大 List 上 `L未译25173ANGE 0 -1` 风险高。
- 最近记录要配合 `LT未译25173IM` 控制长度。

## 替代建议

如果需要消费组、确认、重试、待处理列表，优先考虑 Stream 或专业 MQ。
