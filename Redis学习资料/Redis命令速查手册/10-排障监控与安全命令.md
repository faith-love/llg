# 排障、监控与安全命令

## 信息查看

| 命令 | 用途 |
| --- | --- |
| `INFO 服务端` | 服务端版本和运行信息 |
| `INFO 客户端s` | 客户端连接 |
| `INFO memory` | 内存状态 |
| `INFO stats` | 统计信息 |
| `INFO commandstats` | 命令统计 |
| `INFO replication` | 复制状态 |
| `INFO persistence` | 持久化状态 |

## 慢查询与延迟

```bash
SLOWLOG LEN
SLOWLOG GET 20
SLOWLOG RESET
LATENCY LATEST
LATENCY DOCTOR
```

慢查询只统计命令执行时间，不包含网络、排队和客户端等待连接。

## 客户端命令

```bash
CLIENT LIST
CLIENT INFO
CLIENT KILL ip:port
```

`CLIENT KILL` 属于高风险操作，必须确认目标连接。

## 内存命令

```bash
MEMORY USAGE key
MEMORY STATS
OBJECT ENCODING key
```

用于观察单 Key 内存、整体内存结构和对象编码。

## ACL 命令

```bash
ACL LIST
ACL WHOAMI
ACL SETUSER app-用户 on >password ~app:* +@read +@write -@dangerous
```

生产中应用账号应限制 Key 前缀和命令类别。

## 风险提示

- 排障时不要用 `KEYS *`。
- 不要频繁执行高成本观察命令。
- 不要在日志里输出密码、token、验证码。
- `CONFIG SET`、`FLUSHALL`、`SHUTDOWN` 必须严格限制权限。

## 练习

- 用 `INFO` 找出当前连接数和内存使用。
- 用 `SLOWLOG GET` 查看慢查询。
- 设计一个只允许访问 `app:*` 的应用账号。
