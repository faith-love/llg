## 使用原则

- 在线上执行命令前，先判断复杂度和返回数据量。
- 能按 Key 精确访问，就不要全量扫描。
- 能用 `SCAN` 分批，就不要用 `KEYS`。
- 删除大 Key 优先使用 `UNLINK`。
- 排障命令也要控制频率，避免把排障变成新的压力来源。
