# 排行榜与热度统计

## 场景

排行榜常用于文章热榜、商品销量榜、用户积分榜、活动贡献榜。Redis ZSet 适合按分数排序，并能快速查询 Top N 和个人排名。

## Key 设计

| 榜单 | Key | 类型 | 说明 |
| --- | --- | --- | --- |
| 日榜 | `rank:article:daily:{yyyyMMdd}` | ZSet | 每日热榜 |
| 周榜 | `rank:article:weekly:{yyyyww}` | ZSet | 每周热榜 |
| 用户积分榜 | `rank:用户:score` | ZSet | 长期榜 |
| 文章计数 | `counter:article:{id}:views` | String | 阅读数 |

## 写入流程

用户阅读、点赞、评论时，根据权重增加热度：

```bash
ZINCRBY rank:article:daily:20260514 1 article:1001
ZINCRBY rank:article:daily:20260514 5 article:1001
ZINCRBY rank:article:daily:20260514 10 article:1001
```

不同事件不要混在代码里写魔法数字，应配置权重规则。

## 查询流程

```bash
ZREVRANGE rank:article:daily:20260514 0 9 WITHSCORES
ZREVRANK rank:article:daily:20260514 article:1001
ZSCORE rank:article:daily:20260514 article:1001
```

展示榜单时通常还要批量查询文章详情缓存或数据库。

## 风险与处理

- 同分排序：需要明确是否接受字典序，或设计复合 score。
- 刷榜：对用户行为做限流和去重。
- 历史数据无限增长：日榜、周榜设置 TTL 或归档。
- 大榜单：只保留 Top N 或定期裁剪低排名。
- 热点榜单：可本地缓存 Top 结果几秒钟。

## 监控指标

- 榜单 Key 大小。
- 写入 QPS。
- 查询 QPS。
- 榜单生成耗时。
- 异常加分次数。
- Top 榜单缓存命中率。

## 练习任务

为文章热榜设计一套热度公式：阅读 +1、点赞 +5、评论 +10、收藏 +20。写出 Key、命令、历史清理策略和防刷策略。
