# Java 注解知识库

这套知识库用于系统学习 Java 注解。目标不是只会背 `@Override`、`@Autowired`、`@Transactional`，而是理解注解在 Java 语言、编译器、反射、框架扫描、代码生成和工程规范中的真实作用。

## 学习目标

- 能解释注解解决什么问题，以及它和注释、接口、继承、配置文件的区别。
- 能看懂注解的语法、元素类型、默认值、数组值和嵌套注解。
- 能正确选择 `@Retention`、`@Target`、`@Documented`、`@Inherited`、`@Repeatable`。
- 能定义一个运行时注解，并通过反射读取类、字段、方法和参数上的注解。
- 能理解 Spring、MyBatis、Bean Validation、JUnit、Lombok 等框架为什么大量使用注解。
- 能判断注解不生效时应该从保留策略、扫描路径、代理路径、调用方式和依赖版本排查。

## 推荐学习路线

1. 先读 `01-04`，建立语言层面的基础：注解是什么、怎么写、保留到哪个阶段、能标在哪里。
2. 再读 `05-09`，把注解和反射、编译期处理、小框架串起来。
3. 然后读 `10-14`，对照真实后端项目里最常见的注解场景。
4. 最后读 `15-16`，整理避坑、排查和面试表达。

## 一句话主线

注解本身不执行业务逻辑，它只是给代码打上结构化标记；真正执行逻辑的是编译器、注解处理器、反射代码或框架容器。
