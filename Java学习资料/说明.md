# Java 学习资料

这个目录用于存放 Java 相关学习资料、练习项目和源码示例。建议先走 Java 学习路线，再按需要进入注解专题和 Spring Boot 示例。

## 推荐入口

- [Java 详细学习路线](Java学习路线/说明.md)
- [Java 注解知识库](Java注解知识库/说明.md)
- [Spring Boot 示例项目](Spring-Boot示例/README.md)

## 使用方式

1. 先读 `Java学习路线/说明.md`，明确整体路线、版本选择和阶段目标。
2. 按阶段学习专题文档，每一阶段都要完成对应练习和验收项。
3. 学到反射、注解和 Spring Boot 前，先读 `Java注解知识库/说明.md`，理解注解语法、反射读取、编译期处理和框架用法。
4. 学到 Spring Boot 阶段后，再结合 `Spring-Boot示例` 中的示例模块拆解真实项目结构。
