# 06-阶段通过标准

## 为什么需要通过标准

没有通过标准，学习很容易变成“我感觉我学过”。但实际写项目时，可能连最基本的错误都定位不了。

通过标准的作用是把学习变成可检查的结果。

## 总体判断公式

一个知识点是否学会，可以用 4 个问题判断：

1. 我能不能用自己的话解释？
2. 我能不能写一个最小例子？
3. 我能不能改造这个例子？
4. 出错后我能不能定位问题？

如果只能看懂教程，但不能自己写，就还没过关。

## 基础阶段通过标准

你应该能做到：

- 不查资料写出 `主` 方法。
- 会使用变量、判断、循环、数组。
- 会写方法并传参。
- 能处理简单输入。
- 能写 50 行以内的控制台程序。

验收练习：

- 写一个猜数字游戏。
- 写一个成绩管理小程序。
- 写一个数组排序和查找程序。

## OOP 和核心 API 阶段通过标准

你应该能做到：

- 会设计类和对象。
- 会使用封装、继承、多态。
- 会使用 `List`、`Set`、`Map`。
- 会处理异常。
- 会使用泛型。
- 会读写文件。

验收练习：

- 写一个命令行图书管理系统。
- 数据能保存到文件。
- 输入非法时程序不会崩溃。

## JVM 和并发阶段通过标准

你应该能做到：

- 能解释堆、栈、方法区的大致作用。
- 能区分 `StackOverflowError` 和 `OutOfMemoryError`。
- 能创建线程和线程池。
- 能解释共享变量为什么可能出错。
- 能使用锁或原子类解决简单线程安全问题。

验收练习：

- 写一个多线程售票程序。
- 写一个线程池处理任务的程序。
- 写一个触发 OOM 的小实验并记录原因。

## 数据库和 HTTP 阶段通过标准

你应该能做到：

- 会写基础 SQL。
- 会用 Java 连接数据库。
- 会使用参数化查询防止 SQL 注入。
- 能解释事务。
- 能设计简单 REST API。

验收练习：

- 写一个图书 JDBC/MyBatis 小项目。
- 支持增删改查和分页。
- 借阅库存修改使用事务。

## Spring Boot 阶段通过标准

你应该能做到：

- 能创建 Spring Boot 项目。
- 能写 Controller、Service、Mapper。
- 能做统一异常处理。
- 能做参数校验。
- 能连接数据库。
- 能写基础测试。

验收练习：

- 完成一个图书馆 REST API。
- 至少包含用户、图书、借阅 3 个核心模块。
- 说明 能让别人跑起来。

## 工程化阶段通过标准

你应该能做到：

- 会执行 `mvn clean 测试`。
- 会看日志。
- 会写多环境配置。
- 会用 Docker 启动 MySQL/Redis。
- 会写项目启动说明。

验收练习：

- 项目支持 `Docker 通用pose up -d` 启动依赖。
- 核心业务有测试。
- 接口错误能在日志中定位。

## 项目毕业标准

一个能作为 Java 入门毕业项目的作品至少满足：

- 有清晰 说明。
- 有数据库表结构和初始化脚本。
- 有接口示例。
- 有统一响应和统一异常。
- 有登录或权限控制。
- 有至少 10 个关键测试。
- 有 Docker 启动说明。
- 有项目复盘文档。
