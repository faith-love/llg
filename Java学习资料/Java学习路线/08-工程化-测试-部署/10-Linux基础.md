# 10-Linux 基础命令和线上排查

## 为什么后端要会 Linux

很多 Java 后端服务最终运行在 Linux 环境。你不一定一开始就精通运维，但必须能看日志、查进程、查端口、查磁盘和定位基础问题。

## 文件和日志

| 命令 | 作用 |
| --- | --- |
| `pwd` | 查看当前目录 |
| `ls -la` | 查看文件 |
| `cat file` | 输出文件 |
| `less file` | 分页查看文件 |
| `tail -f app.日志` | 实时查看日志 |
| `grep "E未译25173未译25173O未译25173" app.日志` | 搜索错误 |

## 进程和端口

| 命令 | 作用 |
| --- | --- |
| `ps aux` | 查看进程 |
| `top` | 查看资源占用 |
| `ss -lntp` | 查看监听端口 |
| `kill` | 结束进程 |

## 磁盘和内存

| 命令 | 作用 |
| --- | --- |
| `df -h` | 查看磁盘分区 |
| `du -sh *` | 查看目录大小 |
| `free -h` | 查看内存 |

## 权限

常见权限问题：

```text
未译63149未译32146 denied
```

常见原因：

- 文件没有执行权限。
- 当前用户没有目录读写权限。
- 日志目录不可写。

## 容易出错的示例

### 错误示例：看到端口占用就直接杀进程

```text
kill -9 1234
```

### 为什么错

你可能杀掉别人的服务或系统关键进程。`-9` 也不给程序优雅退出机会。

### 正确做法

先确认进程是什么：

```text
ps -fp 1234
ss -lntp
```

确认是自己的服务后再处理。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 日志查看 | 定位错误 | 线上不能靠 IDE | `tail -f` 配合 `grep` | 重点是找关键错误 |
| 端口查看 | 判断服务是否监听 | 端口冲突常见 | `ss -lntp` | 难点是区分监听和访问失败 |
| 磁盘查看 | 排查磁盘满 | 磁盘满会导致写日志失败 | `df` 看总量，`du` 找目录 | 重点是不要乱删 |
| 权限 | 控制读写执行 | 部署常因权限失败 | 看用户和目录权限 | 难点是最小权限 |
