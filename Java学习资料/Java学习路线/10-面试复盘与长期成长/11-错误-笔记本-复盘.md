# 11-错题本和薄弱点复盘

## 错题本解决什么问题

不会的问题如果只是看一遍答案，很快会忘。错题本把“不会”变成可复习、可跟踪、可修复的条目。

## 错题模板

```markdown
# 错题：事务为什么会失效

## 我的错误回答

## 正确结论

## 原理解释

## 项目例子

## 容易混淆点

## 下次复习时间
```

## 错题分类

| 分类 | 示例 |
| --- | --- |
| 概念不清 | volatile 和 synchronized |
| 原理不懂 | HashMap 扩容 |
| 项目不会讲 | Redis 为什么用 |
| 排查不会 | CPU 高怎么定位 |
| 表达混乱 | 回答太散没有结论 |

## 薄弱点处理

发现薄弱点后不要只看文章，要补动作：

- 写一段代码验证。
- 画一张图。
- 写一个项目例子。
- 录音讲一遍。
- 一周后再答一次。

## 容易出错的示例

### 错误做法：复制标准答案

复制一大段答案，没有自己的错误原因和项目例子。

### 为什么错

下次还是不会讲，因为没有经过自己的理解和表达。

### 正确做法

写自己的错因：

```text
我只记得 ACID，但不知道事务边界应该围绕完整业务动作。
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 错因 | 找到真正问题 | 避免重复错 | 写自己的错误回答 | 重点是真实 |
| 项目例子 | 把答案落地 | 不再空背 | 每题配一个场景 | 难点是贴合 |
| 复习时间 | 防止遗忘 | 形成循环 | 1 天、3 天、7 天 | 重点是回看 |
| 输出验证 | 检查是否掌握 | 看懂不代表会 | 录音或写答案 | 难点是坚持 |

## 本节练习

- 整理 10 道错题。
- 每道题写错误原因。
- 每道题补一个项目例子。
- 一周后重答并标记掌握程度。

## 本节通过标准

- 错题不是复制答案。
- 每道题有错误原因。
- 每道题有复习记录。
- 薄弱点能逐步减少。
