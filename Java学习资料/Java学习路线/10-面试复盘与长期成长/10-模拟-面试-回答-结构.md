# 10-模拟面试和回答结构

## 模拟面试解决什么问题

很多问题你以为会了，一开口就发现讲不清。模拟面试的作用是训练表达、发现盲区和提高追问承受能力。

## 回答结构

技术问题建议：

```text
结论 -> 作用 -> 原理 -> 项目例子 -> 注意点
```

项目问题建议：

```text
背景 -> 流程 -> 方案 -> 难点 -> 结果 -> 改进
```

排查问题建议：

```text
现象 -> 影响范围 -> 排查步骤 -> 根因 -> 修复 -> 预防
```

## 模拟面试流程

1. 选 10 个问题。
2. 不看答案，录音回答。
3. 回听并记录卡顿点。
4. 修改答案。
5. 让别人追问或自己追加 2 层追问。

## 追问示例

问题：你用了事务吗？

追问：

- 事务放在哪一层？
- 保护了哪些 SQL？
- 哪些异常会回滚？
- 事务可能在哪些情况下失效？
- 你怎么测试回滚？

## 容易出错的示例

### 错误回答：只背定义

```text
事务具有 ACID，分别是原子性、一致性、隔离性、持久性。
```

### 为什么不够

定义没错，但没有说明项目里怎么用，也没有说明解决什么问题。

### 改进回答

补上业务例子和事务边界。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 录音回答 | 暴露表达问题 | 看懂不等于会讲 | 每题 2 分钟 | 重点是回听 |
| 追问训练 | 提高深度 | 面试常连续追问 | 每题追加为什么和怎么做 | 难点是诚实边界 |
| 排查结构 | 展示工程能力 | 不靠猜 | 现象到根因 | 重点是步骤 |
| 时间控制 | 避免答案过散 | 面试时间有限 | 先结论后展开 | 难点是取舍 |

## 本节练习

- 录音回答 10 个问题。
- 每个问题写 2 个追问。
- 给一个接口报错设计排查回答。

## 本节通过标准

- 能不看答案回答核心问题。
- 能承受 2 层追问。
- 能按结构讲排查过程。
- 能控制回答时间。
