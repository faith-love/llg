# 00-章节导读：面试复盘和长期提升

## 为什么面试复盘要单独成章

面试不是把八股题背完就结束。面试真正考察的是：

- 基础概念能不能讲清。
- 项目有没有真实理解。
- 出问题能不能定位。
- 技术选择有没有理由。
- 学完以后能不能继续成长。

这章的重点是把前面所有学习内容整理成可复习、可表达、可追问的材料。

## 小白先记住的主线

- 面试题不是孤立背诵，要和代码、项目、错误经历绑定。
- 项目不是罗列技术栈，要讲业务问题、方案、取舍和结果。
- 不会的问题要进入错题本，不要只看答案。
- 简历上写的每个技术点，都要能回答“为什么用、怎么用、踩过什么坑”。
- 长期提升要选方向，不要同时追所有热门技术。
