# 15-最低毕业标准和复盘模板

## Java 后端入门毕业标准

满足下面条件，可以认为 Java 后端入门路线完成：

- 写过至少 3 个 Java 小项目。
- 写过至少 1 个完整 Spring Boot 项目。
- 能解释 Java、JVM、并发、数据库、Spring 的核心问题。
- 能独立排查常见启动失败、接口报错、SQL 错误。
- 能写测试并通过 `mvn clean 测试`。
- 能用 Docker 启动应用和依赖。
- 能把项目完整讲给别人听。

## 知识验收

| 模块 | 最低要求 | 是否通过 |
| --- | --- | --- |
| Java 基础 | 集合、异常、泛型、IO 能讲清 |  |
| JVM | 内存区域、GC、OOM 排查能讲清 |  |
| 并发 | 锁、volatile、线程池、ThreadLocal 能讲清 |  |
| 数据库 | 索引、事务、锁、慢查询能讲清 |  |
| Spring | IoC、AOP、事务、MVC、自动配置能讲清 |  |
| 项目 | 能讲清背景、流程、难点和结果 |  |

## 面试前最终检查

- 简历每个技术点都能讲。
- 项目 3 分钟讲法已准备。
- 每个项目至少 2 个难点。
- 高频问题至少过 3 轮。
- 错题本最近一周复习过。
- 能手写核心 SQL。
- 能解释事务和索引。
- 能讲清部署和测试。

## 长期成长标准

入门之后继续提升，不要只看学了多少技术，要看：

- 是否能独立拆需求。
- 是否能设计清晰接口。
- 是否能发现风险。
- 是否能写测试保护业务。
- 是否能排查线上问题。
- 是否能复盘技术取舍。

## 通过标准

- 能完成一个从需求到部署的后端项目。
- 能清楚回答主要高频问题。
- 能把项目讲成业务问题和技术方案。
- 能持续用复盘推动下一阶段学习。
