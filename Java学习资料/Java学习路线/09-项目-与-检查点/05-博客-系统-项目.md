# 05-个人博客系统

## 项目定位

个人博客系统适合 Spring Boot 中期。它比图书馆系统更偏内容管理，能训练内容模型、分页搜索、缓存、文件上传、后台权限和前后端协作。

## 核心功能

- 文章发布。
- 文章编辑。
- 文章删除。
- 草稿和发布状态。
- 标签和分类。
- 评论。
- 图片上传。
- 热门文章缓存。
- 后台登录。

## 核心业务规则

- 草稿文章不能在前台展示。
- 删除分类前要检查是否有关联文章。
- 评论需要校验文章状态。
- 上传文件要限制大小和类型。
- 热门文章缓存要设置过期时间。
- 后台接口必须鉴权。

## 缓存设计

适合缓存：

- 热门文章列表。
- 首页文章摘要。
- 分类和标签列表。

不适合盲目缓存：

- 频繁变化的后台编辑数据。
- 权限强相关的私有数据。

## 容易出错的示例

### 错误示例：发布状态只靠前端隐藏

前端不展示草稿，但后端接口仍能查到草稿。

### 为什么错

用户可以绕过前端直接请求接口，导致草稿泄露。

### 正确做法

前台查询接口必须在 SQL 或 Service 中过滤：

```text
status = PUBLISHED
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 内容模型 | 管理文章、分类、标签 | 多对多关系常见 | 文章标签用中间表 | 重点是关系清楚 |
| 状态 | 区分草稿和发布 | 防止内容误展示 | 用枚举表达状态 | 难点是接口过滤 |
| 文件上传 | 支持图片内容 | 有安全和存储风险 | 限制大小和类型 | 重点是不要信任文件名 |
| 缓存 | 加速热门数据 | 降低数据库压力 | 设置过期时间 | 难点是一致性 |

## 验收标准

- 文章列表支持分页、排序、关键词搜索。
- 草稿不会出现在前台接口。
- 上传文件限制大小和类型。
- 热门文章有缓存和过期策略。
- 后台接口需要登录。
- 文章、评论、标签核心逻辑有测试。
