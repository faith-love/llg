## 小白先记住的主线

- JVM 负责运行 Java 字节码。
- 堆主要放对象，栈主要放方法调用。
- GC 负责回收不再使用的对象。
- 并发问题本质上常见于共享可变数据。
- 线程池是为了控制线程数量和任务排队，不是为了让任务无限变快。
- 性能优化必须先测量，再判断，再修改。
