# 04-对象创建和生命周期

## 对象创建大致过程

执行：

```Java学习资料
Book book = new Book("978711", "Java");
```

JVM 大致会做：

1. 检查类是否已加载。
2. 为对象分配内存。
3. 初始化零值。
4. 设置对象头。
5. 执行构造器。
6. 把对象引用赋值给变量。

小白不需要背底层每个细节，但要知道对象不是“凭空出现”的。

## 零值初始化

对象字段会先有默认值：

| 类型 | 默认值 |
| --- | --- |
| `int` | `0` |
| `long` | `0L` |
| `double` | `0.0` |
| `boolean` | `false` |
| 引用类型 | `null` |

之后构造器才执行你的初始化逻辑。

## 对象头

对象头保存 JVM 管理对象需要的信息，例如：

- 对象所属类型。
- 锁相关信息。
- GC 相关标记。

初学阶段知道“对象除了字段，还有 JVM 管理信息”即可。

## 对象什么时候可以被回收

如果一个对象再也无法通过任何引用链访问，就可能被 GC 回收。

示例：

```Java学习资料
Book book = new Book("978711", "Java");
book = null;
```

当没有其他引用指向这个对象时，它就可能被回收。

注意：是“可能”，不是立刻。

## 引用链

只要对象还能从 GC 未译25173oots 访问到，就不会被回收。

常见 GC 未译25173oots：

- 当前线程栈里的局部变量引用。
- 静态变量引用。
- 常量引用。
- JNI 引用。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 对象创建过程 | 理解 `new` 背后的步骤 | 遇到构造器、默认值问题不迷糊 | 重点观察字段默认值和构造器执行 | 难点是零值初始化发生在构造器前 |
| 默认值 | 保证对象内存有确定初始状态 | 避免字段是随机值 | 构造器里显式初始化必填字段 | 重点是引用默认 `null`，容易空指针 |
| 对象头 | JVM 管理对象的元信息 | 解释锁和 GC 为什么能附着在对象上 | 了解即可，不必死背结构 | 重点是对象不只包含业务字段 |
| 可达性 | 判断对象是否还能被访问 | 解释为什么对象不一定立刻回收 | 关注静态集合、缓存、线程本地变量 | 重点是无引用链才可能回收 |

## 本节练习

- 写一个类，不初始化字段，打印默认值。
- 写构造器，在构造器里打印初始化过程。
- 创建对象后设为 `null`，观察它不再可访问。
- 写一个静态 `List` 持有对象，理解为什么对象不容易被回收。

- 能解释静态集合为什么可能导致内存增长。
