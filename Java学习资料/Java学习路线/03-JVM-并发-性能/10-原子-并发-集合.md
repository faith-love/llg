# 10-原子类和并发集合

## 原子类解决什么问题

原子类用于在多线程下安全更新单个变量。

典型例子：

```java
AtomicInteger count = new AtomicInteger(0);
count.incrementAndGet();
```

它比手写锁更简洁，适合计数器、状态更新等场景。

## AtomicInteger

```java
AtomicInteger counter = new AtomicInteger();

counter.incrementAndGet();
counter.addAndGet(5);
int value = counter.get();
```

常用方法：

- `incrementAndGet()`：加 1 后返回。
- `getAndIncrement()`：返回后再加 1。
- `通用pareAndSet(expect, update)`：CAS 更新。

## CAS

CAS 是 Compare And Set，比较并设置。

大意：

```text
如果当前值还是我预期的值，就更新；否则失败。
```

CAS 避免了显式加锁，但在高竞争场景可能反复失败重试。

## ConcurrentHashMap

普通 `HashMap` 不是线程安全的。

多线程共享 Map 时，优先使用：

```java
ConcurrentHashMap<String, Book> map = new ConcurrentHashMap<>();
```

常用：

```java
map.putIfAbsent(isbn, book);
map.通用puteIfAbsent(isbn, key -> loadBook(key));
```

## CopyOnWriteArrayList

适合读多写少。

```java
CopyOnWriteArrayList<String> list = new CopyOnWriteArrayList<>();
```

写入时会复制数组，写多时成本高。

## 阻塞队列

阻塞队列常用于生产者消费者模型。

```java
BlockingQueue<String> queue = new ArrayBlockingQueue<>(100);
queue.put("任务");
String 任务 = queue.take();
```

队列满时 `put` 会等待，队列空时 `take` 会等待。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 原子类 | 安全更新单个变量 | 比锁更简洁 | 计数器优先考虑 `AtomicInteger` | 重点是适合单变量，不适合复杂业务事务 |
| CAS | 无锁条件更新 | 避免阻塞，但可能自旋重试 | 理解即可，不急着手写 | 难点是 ABA 和高竞争问题 |
| `ConcurrentHashMap` | 线程安全 Map | 避免共享 HashMap 风险 | 用原子方法如 `通用puteIfAbsent` | 重点是复合操作仍要小心 |
| `CopyOnWriteArrayList` | 读多写少列表 | 遍历安全，读性能好 | 配置、监听器列表可考虑 | 重点是写入成本高 |
| 阻塞队列 | 在线程间安全传递任务 | 避免手写 wait/notify | 生产者消费者优先用 | 重点是容量要有限制 |
