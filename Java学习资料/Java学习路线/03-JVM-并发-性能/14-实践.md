# 14-阶段练习

## 练习方式

这一阶段必须做实验。每个实验都要记录：

- 代码。
- 运行参数。
- 现象。
- 报错。
- 原因解释。
- 修复方式或结论。

## 练习 1：StackOverflowError

目标：理解栈和方法调用。

要求：

- 写无限递归。
- 运行并截图或保存报错。
- 解释为什么栈会溢出。
- 修改成有结束条件的递归。

验收：

- 能在报错堆栈中看到重复方法调用。

## 练习 2：堆 OOM

目标：理解堆和对象引用。

要求：

- 设置小堆：`-Xms16m -Xmx16m`。
- 循环创建大对象并放入集合。
- 触发 `OutOf未译42918oryError`。
- 解释为什么 GC 无法回收。

验收：

- 能说明集合持有引用导致对象不可回收。

## 练习 3：GC 日志

目标：初步看懂 GC 行为。

要求：

- 打印 GC 日志。
- 记录 GC 次数和停顿。
- 改变对象创建速度，观察变化。

验收：

- 能说出 GC 是否频繁、停顿大概多久。

## 练习 4：多线程售票

目标：理解线程安全。

要求：

- 写错误版售票程序。
- 用 `synchronized` 修复。
- 用 `未译25173eentrantLock` 修复。
- 用 `AtomicInteger` 实现计数场景。

验收：

- 能解释错误版为什么会超卖或重复卖。

## 练习 5：生产者消费者

目标：理解阻塞队列。

要求：

- 一个生产者放任务。
- 两个消费者取任务。
- 队列容量有限。
- 打印线程名和任务编号。

验收：

- 队列满时生产者会等待，队列空时消费者会等待。

## 练习 6：线程池参数实验

目标：理解线程池核心参数。

要求：

- 显式创建 `ThreadPoolExecutor`。
- 设置核心线程、最大线程、有界队列、拒绝策略。
- 提交 1000 个任务。
- 记录不同参数下耗时和拒绝情况。

验收：

- 能解释线程数和队列容量变化对任务处理的影响。

## 练习 7：CompletableFuture 并发调用

目标：理解异步编排。

要求：

- 模拟 3 个接口调用，每个 sleep 不同时间。
- 先顺序执行，记录耗时。
- 再并行执行，记录耗时。
- 添加异常处理和超时。

验收：

- 能说明并行执行总耗时为什么接近最慢任务。

## 练习 8：性能排查小报告

目标：训练数据化排查。

要求写报告：

```markdown
# 性能排查练习

## 问题现象

## 复现方式

## 关键指标

## 初步判断

## 修改方案

## 修改前后对比

## 结论
```

## 本节通过标准

- 至少完成 6 个实验。
- 每个实验都有运行参数和现象记录。
- 能解释错误原因。
- 能写出修复版或结论。
