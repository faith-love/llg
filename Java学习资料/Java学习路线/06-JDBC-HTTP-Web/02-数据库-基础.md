# 02-数据库基础和 Java 后端关系

## 为什么后端必须学数据库

Java 程序运行时的数据默认在内存里。程序重启后，内存数据会丢失。数据库负责长期保存业务数据。

典型后端数据：

- 用户信息。
- 图书信息。
- 借阅记录。
- 订单记录。
- 登录日志。

## Java 和数据库怎么协作

基本链路：

```text
Java 对象 -> SQL -> 数据库表 -> 查询结果 -> Java 对象
```

例如：

```text
Book 对象 -> insert into books -> books 表 -> select 查询 -> Book 对象
```

## Java 阶段要补的数据库能力

如果 SQL 基础已经在 `D:\learn\SQL学习资料` 学过，这一阶段重点补：

- JDBC 连接数据库。
- 参数化查询。
- 事务控制。
- 连接池。
- DAO/Mapper 分层。
- MyBatis 映射。
- 分页查询。
- 索引和慢查询基本排查。
