# 16-通过标准和复盘清单

## 阶段通过标准

完成这一阶段后，你应该能做到：

- 能用 JDBC 或 MyBatis 完成图书 CRUD。
- 能使用参数化 SQL，避免 SQL 注入。
- 能解释事务 ACID 和事务边界。
- 能说明连接池的作用和风险。
- 能设计基础 REST API。
- 能区分 Controller、Service、Mapper、DTO、Entity。
- 能设计统一错误响应。
- 能实现分页查询。
- 能初步排查慢查询。

## 进入下一阶段前

进入 `05-Spring Boot 主线` 前，确认：

- 你知道 Spring Boot Controller 之前，HTTP 本身是什么。
- 你知道 MyBatis 之前，JDBC 本身做了什么。
- 你知道事务不是注解装饰，而是业务一致性边界。
- 你知道 REST API 不只是路径命名，还包含状态码、响应结构和错误规范。
