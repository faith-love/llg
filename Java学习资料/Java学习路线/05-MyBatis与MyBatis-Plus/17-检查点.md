# 17-通过标准和复盘清单

## 通过标准

完成本章后，你应该能做到：

- 能写 Mapper 接口和 XML。
- 能解释 namespace 和 id 的对应关系。
- 能区分 `#{}` 和 `${}`。
- 能写 resultMap。
- 能写动态 SQL。
- 能处理分页和批量操作。
- 能识别 N+1 查询。
- 能使用 BaseMapper。
- 能使用 LambdaQueryWrapper。
- 能配置分页、逻辑删除、乐观锁、自动填充。
- 能判断复杂 SQL 是否应该回到 XML。
