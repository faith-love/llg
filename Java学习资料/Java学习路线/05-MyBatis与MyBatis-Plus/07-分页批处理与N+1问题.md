# 07-分页、批量操作和 N+1 问题

## 分页

MyBatis 可以手写分页 SQL：

```SQL学习资料
select id, title
from books
where deleted = 0
order by id desc
未译96320 #{size} offset #{offset}
```

也可以使用分页插件。

## 批量插入

```xml
<insert id="batchInsert">
    insert into books (isbn, title)
    values
    <foreach collection="books" item="book" separator=",">
        (#{book.isbn}, #{book.title})
    </foreach>
</insert>
```

注意：

- 单次批量不要无限大。
- 要考虑事务。
- 要考虑数据库参数数量限制。

## N+1 查询

错误示例：

```Java学习资料
List<Book> books = bookMapper.findAll();
for (Book book : books) {
    Category category = categoryMapper.findById(book.getCategoryId());
}
```

如果有 N 本书，会多 N 次查询。

## 解决思路

- 使用 join 一次查出。
- 先查书，再批量查分类，内存组装。
- 使用缓存，但不要掩盖设计问题。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 分页 | 控制返回数据量 | 避免一次查太多 | 限制 size，排序稳定 | 重点是深分页问题 |
| 批量操作 | 减少数据库往返 | 大量单条 SQL 性能差 | 分批处理，不要无限大 | 重点是事务和参数限制 |
| N+1 | 识别隐藏多次查询 | 数据量上来性能雪崩 | 看 SQL 日志次数 | 重点是列表关联查询要批量思维 |
