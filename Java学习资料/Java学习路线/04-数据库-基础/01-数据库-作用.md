# 01-数据库在后端中的作用

## 数据库解决什么问题

数据库负责持久化保存业务数据。Java 程序内存里的数据会随进程结束而消失，数据库里的数据可以长期保存。

后端项目常见数据：

- 用户。
- 图书。
- 借阅记录。
- 订单。
- 支付记录。
- 操作日志。

## 数据库和 Java 的关系

```text
HTTP 请求 -> Java 业务逻辑 -> SQL -> 数据库 -> 查询结果 -> Java 对象 -> JSON 响应
```

数据库不是只给 Java 存数据，它还承担：

- 唯一性约束。
- 事务一致性。
- 查询能力。
- 并发控制。
- 数据恢复。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 持久化 | 长期保存业务数据 | 内存数据重启即丢 | 关键业务数据必须落库 | 重点是数据库保存事实数据 |
| 查询能力 | 快速按条件找到数据 | 没有查询能力只能全量扫描 | 根据业务查询设计表和索引 | 重点是查询模式影响设计 |
| 约束 | 从数据库层防止脏数据 | 只靠代码校验可能漏 | 唯一、非空、外键按需使用 | 重点是数据库是最后防线 |
| 事务 | 保证多步操作一致 | 防止一半成功一半失败 | 一个业务动作一个事务边界 | 重点是数据一致性 |
