# 14-阶段项目：图书数据库设计

## 项目目标

为图书借阅系统设计一套基础数据库。

不要只画表名，要包含：

- 字段。
- 类型。
- 主键。
- 唯一约束。
- 索引。
- 初始化数据。
- 关键 SQL。
- 事务说明。

## 推荐表

```text
books
categories
用户s
borrow_records
```

## books

建议字段：

```text
id
isbn
title
author
category_id
stock
version
deleted
created_at
updated_at
```

## borrow_records

建议字段：

```text
id
book_id
用户_id
borrowed_at
due_at
returned_at
status
created_at
updated_at
```

## 必须设计的 SQL

- 新增图书。
- 按 ISBN 查询图书。
- 分页查询图书。
- 借阅时扣库存。
- 归还时更新记录。
- 查询用户当前借阅。
- 按分类统计图书数量。

## 项目知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 表设计 | 承载业务数据结构 | 表设计差会拖累后续代码 | 从业务动作反推表 | 重点是关系和约束 |
| 库存字段 | 支撑借阅可用性 | 并发扣减可能出错 | 配合事务和锁 | 重点是不能扣成负数 |
| 借阅记录 | 保存历史事实 | 不保留记录无法审计 | 状态和时间字段要完整 | 重点是历史记录不要随图书变化丢失 |
| 索引 | 支撑高频查询 | 没索引列表和查询会慢 | 为 ISBN、分类、时间设计 | 重点是结合查询 |

## 验收标准

- 至少 4 张表。
- 每张表有主键。
- ISBN 有唯一约束。
- 库存不能为负。
- 有分页查询 SQL。
- 有借阅事务说明。
- 有初始化脚本。
- 有至少 5 条测试数据。
