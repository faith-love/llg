# 16-通过标准和复盘清单

## 通过标准

完成本章后，你应该能做到：

- 能解释数据库在 Java 后端中的作用。
- 能设计基础表结构。
- 能选择常见字段类型。
- 能使用主键、唯一、非空等约束。
- 能写 C未译25173UD、JOIN、聚合和分页 SQL。
- 能解释事务 ACID。
- 能区分乐观锁和悲观锁。
- 能设计基础索引。
- 能用 `EXPLAIN` 初步分析 SQL。
- 能写初始化脚本。
