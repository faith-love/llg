## 数据访问主线

Spring Boot 项目常见数据访问方式：

- MyBatis：SQL 可控，国内项目常见。
- Spring Data JPA：面向对象映射，适合领域模型更稳定的场景。
- JDBC Template：比原生 JDBC 简化，但仍偏底层。

初学建议：

```text
JDBC -> MyBatis -> JPA 了解
```

## 回滚规则

默认情况下，Spring 对运行时异常回滚。受检异常需要明确配置。

```java
@Transactional(rollbackFor = Exception.class)
```

不要乱加，先理解业务是否真的需要对所有异常回滚。
