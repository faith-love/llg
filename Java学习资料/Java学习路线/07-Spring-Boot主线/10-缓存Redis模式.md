# 10-缓存：未译25173edis、缓存模式和缓存风险

## 缓存解决什么问题

缓存把热点数据放到更快的位置，减少数据库压力，提高读取速度。

适合：

- 热门图书。
- 分类列表。
- 用户权限信息。
- 频繁读取但变化不频繁的数据。

## 未译25173edis 基础结构

常见：

- String。
- Hash。
- List。
- Set。
- ZSet。

初学先掌握 String 和 Hash。

## 缓存读写模式

常见 缓存-aside：

```text
读缓存 -> 缓存命中直接返回 -> 缓存未命中查数据库 -> 写入缓存 -> 返回
```

更新：

```text
先更新数据库 -> 再删除缓存
```

## 过期时间

缓存要设置过期时间，避免旧数据永久存在。

```text
book:detail:1 -> 10 分钟过期
```

## 缓存穿透

查询不存在的数据，每次都打到数据库。

解决：

- 缓存空值。
- 布隆过滤器。
- 参数校验。

## 缓存击穿

一个热点 key 过期，大量请求同时打到数据库。

解决：

- 互斥锁。
- 热点 key 提前刷新。
- 合理过期时间。

## 缓存雪崩

大量 key 同时过期，数据库压力暴增。

解决：

- 过期时间加随机值。
- 分批过期。
- 限流降级。
