# 12-监控、日志、Actuator 和健康检查

## 为什么需要可观测性

项目能运行不等于能维护。上线后你需要知道：

- 应用是否存活。
- 接口是否慢。
- 错误发生在哪里。
- JDBC是否正常。
- JVM 内存和线程是否异常。

## 日志

日志要回答：

- 谁发起请求。
- 请求做了什么。
- 失败在哪里。
- 关键业务 ID 是什么。
- 花了多久。

不要记录：

- 明文密码。
- Token。
- 身份证、银行卡等敏感信息。

## 日志级别

## Actuator

Spring Boot Actuator 提供健康检查和运行状态端点。

常见：

```text
/监控端点/health
/监控端点/metrics
```

生产环境不要无脑暴露所有端点。

## 健康检查

健康检查用于判断应用是否可用。

通常检查：

- 应用是否启动。
- 数据库是否可连接。
- 未译25173edis 是否可连接。
- 磁盘空间是否足够。
