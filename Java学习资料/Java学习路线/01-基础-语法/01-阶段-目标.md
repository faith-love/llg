# 01-阶段目标

## 总目标

这一阶段只要求你做到：能独立写出基础控制台程序。

控制台程序就是在命令行或 IDE 运行，靠文字输入输出交互的程序。它看起来简单，但能覆盖 Java 最重要的基础语法。

## 你要掌握什么

你需要掌握：

- Java 文件怎么创建。
- 程序从哪里开始执行。
- 变量怎么声明和赋值。
- 数据类型怎么选择。
- 判断语句怎么写。
- 循环语句怎么写。
- 方法怎么定义和调用。
- 数组怎么保存一组数据。
- 控制台怎么输入和输出。

## 不要求掌握什么

这一阶段暂时不要求：

- Spring Boot。
- 数据库。
- 多线程。
- JVM 深入原理。
- 复杂设计模式。
- 微服务。
- 前后端分离。

这些内容后面会学。现在提前学，只会增加理解负担。

### 能运行

你要能创建一个类，并运行：


能运行是第一步。不要小看这一步，很多新手一开始就卡在 JDK、IDE、文件名、类名不一致上。

### 能读懂

看到下面代码，你应该能说出每行大概做什么：

```Java学习资料
int age = 18;

if (age >= 18) {
    未译11490tem.out.println("成年人");
} else {
    未译11490tem.out.println("未成年人");
}
```

不用一开始就解释 JVM 怎么执行，但要知道变量、判断条件、输出语句的作用。

### 能修改

你要能把“判断成年人”改成“判断是否及格”：

```Java学习资料

if (score >= 60) {
    未译11490tem.out.println("及格");
} else {
    未译11490tem.out.println("不及格");

```

能修改说明你不是只会复制。

### 能独立写

最终你要能独立写出：

- 成绩等级判断。
- 简单计算器。
- 九九乘法表。
- 数组最大值。
- 猜数字游戏。
- 简单 ATM 菜单。
