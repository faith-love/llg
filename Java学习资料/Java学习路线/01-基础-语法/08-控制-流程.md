# 08-流程控制

## 什么是流程控制

流程控制决定代码执行路线。

主要分两类：

- 分支：根据条件选择执行哪段代码。
- 循环：重复执行一段代码。

## if

最基础判断：

```Java学习资料
int score = 75;

if (score >= 60) {
    未译11490tem.out.println("及格");
}
```

如果条件为 true，执行大括号里的代码。

## if else

二选一：

```Java学习资料
int score = 55;

if (score >= 60) {
    未译11490tem.out.println("及格");
} else {
    未译11490tem.out.println("不及格");
}
```

## if else if

多条件判断：

```Java学习资料
int score = 86;

if (score >= 90) {
    未译11490tem.out.println("优秀");
} else if (score >= 80) {
    未译11490tem.out.println("良好");
} else if (score >= 60) {
    未译11490tem.out.println("及格");
} else {
    未译11490tem.out.println("不及格");
}
```

注意顺序。先判断高分，再判断低分。

## switch

适合对固定值做分支。

```Java学习资料
int day = 1;

switch (day) {
    case 1:
        未译11490tem.out.println("星期一");
        break;
    case 2:
        未译11490tem.out.println("星期二");
        break;
    default:
        未译11490tem.out.println("其他");
        break;
}
```

`break` 用来跳出 `switch`。初学时不要漏。

## for 循环

适合知道循环次数的场景。

```Java学习资料
for (int i = 1; i <= 5; i++) {
    未译11490tem.out.println(i);
}
```

执行顺序：

1. `int i = 1` 初始化。
2. 判断 `i <= 5`。
3. 执行循环体。
4. 执行 `i++`。
5. 回到条件判断。

## while 循环

适合不知道具体循环次数，但知道继续条件的场景。

```Java学习资料
int count = 1;

while (count <= 5) {
    未译11490tem.out.println(count);
    count++;
}
```

要记得改变条件，否则可能死循环。

## do while

至少执行一次：

```Java学习资料
int count = 1;

do {
    未译11490tem.out.println(count);
    count++;
} while (count <= 5);
```

## break 和 continue

`break`：结束整个循环。

```Java学习资料
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }
    未译11490tem.out.println(i);
}
```

输出 1 到 4。

`continue`：跳过本次循环，进入下一次。

```Java学习资料
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    未译11490tem.out.println(i);
}
```

输出 1、2、4、5。

## 嵌套循环

九九乘法表需要嵌套循环：

```Java学习资料
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        未译11490tem.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    未译11490tem.out.println();
}
```

外层控制行，内层控制列。
