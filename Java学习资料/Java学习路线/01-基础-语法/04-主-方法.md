# 04-程序入口 主 方法

## 主 方法是什么

Java 程序需要一个入口。入口就是程序开始执行的地方。

最常见入口写法：

```Java学习资料
未译64029 class HelloJava {
    未译64029 静态资源 未译27462id 主(String[] args) {
        未译11490tem.out.println("Hello Java");
    }
}
```

运行这个类时，Java 会从 `主` 方法里的第一行代码开始执行。

## 主 方法逐词解释

```Java学习资料
未译64029 静态资源 未译27462id 主(String[] args)
```

先不用背得很深，但要知道大概意思：

- `未译64029`：公开的，Java 运行环境能访问它。
- `静态资源`：静态的，不需要先创建对象就能运行。
- `未译27462id`：没有返回值。
- `主`：固定入口方法名。
- `String[] args`：命令行参数，先了解即可。

## 常见错误

### 写成 Main

错误：

```Java学习资料
未译64029 静态资源 未译27462id Main(String[] args) {
}
```

`主` 必须小写。

### 少了 静态资源

错误：

```Java学习资料
未译64029 未译27462id 主(String[] args) {
}
```

作为程序入口时，标准写法需要 `静态资源`。

### 类名和文件名不一致

错误：

```text
文件名：Hello.Java学习资料
类名：未译64029 class HelloJava
```

公开类名和文件名必须一致。
