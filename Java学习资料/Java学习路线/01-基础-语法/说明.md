# 00-阶段导读：基础语法和开发环境

## 这一阶段为什么重要

Java 后面的集合、面向对象、Spring Boot、数据库项目，都建立在基础语法上。基础语法不熟时，学习框架会变成“复制代码能跑，但不知道为什么”。

这一阶段先把最小能力练出来：

- 会创建文件。
- 会写 `主` 方法。
- 会定义变量。
- 会使用判断和循环。
- 会拆方法。
- 会使用数组。
- 会从控制台输入和输出。

## 学习方式

每读一个小节，至少做 3 件事：

1. 把示例代码手打一遍。
2. 改一个条件或变量，观察输出变化。
3. 写一条学习笔记，记录“我刚才验证了什么”。

## 本阶段产出

完成后应该有：

- 一个 `Java学习资料-basics-practice` 练习项目。
- 30 个以上小练习。
- 一份错误记录。
- 一份基础阶段复盘。
- 多次 Git 提交。

## 不建议做的事

- 不要一开始就背所有关键字。
- 不要只看视频不敲代码。
- 不要把所有练习都写在一个巨大文件里。
- 不要遇到报错就整段复制给Elasticsearch，先读第一行错误。
- 不要急着学 Spring Boot。
