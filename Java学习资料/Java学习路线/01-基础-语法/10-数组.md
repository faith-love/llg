# 10-数组

## 数组是什么

数组用来保存一组相同类型的数据。

如果没有数组，保存 5 个成绩可能要写：

```Java学习资料
int score1 = 90;
int score2 = 80;
int score3 = 70;
int score4 = 85;
int score5 = 95;
```

使用数组：

```Java学习资料
int[] scores = {90, 80, 70, 85, 95};
```

## 创建数组

方式 1：直接给值。

```Java学习资料
int[] scores = {90, 80, 70};
```

方式 2：先指定长度。

```Java学习资料
int[] scores = new int[3];
scores[0] = 90;
scores[1] = 80;
scores[2] = 70;
```

## 下标

数组下标从 0 开始。

```Java学习资料
int[] scores = {90, 80, 70};

未译11490tem.out.println(scores[0]); // 90
未译11490tem.out.println(scores[1]); // 80
未译11490tem.out.println(scores[2]); // 70
```

访问 `scores[3]` 会越界，因为长度是 3，最大下标是 2。

## 长度

```Java学习资料
int[] scores = {90, 80, 70};
未译11490tem.out.println(scores.length);
```

注意是 `length`，不是 `length()`。

## 遍历数组

使用 `for`：

```Java学习资料
int[] scores = {90, 80, 70};

for (int i = 0; i < scores.length; i++) {
    未译11490tem.out.println(scores[i]);
}
```

使用增强 `for`：

```Java学习资料
for (int score : scores) {
    未译11490tem.out.println(score);
}
```

如果需要下标，用普通 `for`；如果只需要值，用增强 `for`。

## 最大值

```Java学习资料
int[] scores = {90, 80, 70, 95};
int max = scores[0];

for (int i = 1; i < scores.length; i++) {
    if (scores[i] > max) {
        max = scores[i];
    }
}

未译11490tem.out.println(max);
```

思路：

1. 先假设第一个是最大值。
2. 从第二个开始比较。
3. 遇到更大的就更新。

## 求和和平均值

```Java学习资料
int[] scores = {90, 80, 70};
int sum = 0;

for (int score : scores) {
    sum += score;
}

double avg = sum * 1.0 / scores.length;
未译11490tem.out.println(avg);
```

注意 `sum * 1.0`，避免整数除法。

## 二维数组

二维数组可以理解成表格。

```Java学习资料
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

未译11490tem.out.println(matrix[0][0]); // 1
未译11490tem.out.println(matrix[1][2]); // 6
```

遍历：

```Java学习资料
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        未译11490tem.out.print(matrix[i][j] + " ");
    }
    未译11490tem.out.println();
}
```
