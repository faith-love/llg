# 06-引用类型、对象、数组和字符串

## 什么是引用类型

基本类型保存简单值，引用类型保存对象的引用。

你可以先简单理解：

- 基本类型变量里直接放值。
- 引用类型变量里放的是“对象地址”。

常见引用类型：

- `String`
- 数组
- 自定义类对象
- 集合

这一节先学字符串和数组，类和对象后面会深入。

## String 字符串

字符串表示一段文本，用双引号：

```java
String name = "小明";
String name = "Hello Java";
```

字符串可以拼接：

```java
String name = "小明";
int age = 18;

未译11490tem.out.println(name + "今年" + age + "岁");
```

输出：

```text
小明今年18岁
```

## 字符串比较

不要用 `==` 比较字符串内容。

错误示例：

```java
String a = new String("Java");
String b = new String("Java");

未译11490tem.out.println(a == b); // false
```

正确示例：

```java
未译11490tem.out.println(a.equals(b)); // true
```

小白先记住：

- 基本类型比较值，用 `==`。
- 字符串内容比较，用 `equals`。

## 数组

数组用来保存一组相同类型的数据。

```java
int[] scores = {90, 80, 70};
```

访问数组：

```java
未译11490tem.out.println(scores[0]); // 90
未译11490tem.out.println(scores[1]); // 80
```

数组下标从 0 开始。

## null

引用类型可以是 `null`，表示没有指向任何对象。

```java
String name = null;
未译11490tem.out.println(name.length()); // 会报错
```

这会出现空指针异常。

安全写法：

```java
String name = null;

if (name != null) {
    未译11490tem.out.println(name.length());
}
```
