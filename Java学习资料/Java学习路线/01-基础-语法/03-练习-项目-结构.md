# 03-练习项目目录结构

## 为什么要整理目录

小白经常把所有 Java 文件堆在桌面或一个目录里。刚开始还能忍，练习多了以后就会找不到文件，也不方便复盘。

建议从一开始就建立固定结构。

## 推荐目录

```text
Java学习资料-basics-practice/
  说明.md
  notes/
    learning-日志.md
    error-日志.md
  源码/
    主/
      Java学习资料/
        通用/example/basic/
          HelloJava.Java学习资料
          VariableDemo.Java学习资料
          IfDemo.Java学习资料
          LoopDemo.Java学习资料
```

## 每个目录放什么

### 说明.md

写项目说明：

- 这个项目用来做什么。
- 如何运行练习。
- 已完成哪些练习。
- 当前还有哪些问题。

### notes

存放学习笔记。

建议至少两个文件：

- `learning-日志.md`：每天学了什么。
- `error-日志.md`：记录报错和解决方式。

### 源码/主/Java学习资料

存放 Java 源码。

如果后面学 Maven，这个结构会很常见。现在提前习惯它。

### 通用/example/basic

这是包路径。Java 项目通常用包来组织类，避免所有类混在一起。

对应 Java 文件开头可以写：

```java
package 通用.example.basic;

public class HelloJava {
    public 静态资源 void 主(String[] args) {
        System.out.println("Hello");
    }
}
```

## 包名是什么

包名可以理解为类的“地址”。

比如：

```java
package 通用.example.basic;
```

表示这个类放在：

```text
通用/example/basic
```

包名通常全部小写。

## 文件命名建议

练习类名要清楚：

- `HelloJava`
- `VariableDemo`
- `BasicTypeDemo`
- `IfElseDemo`
- `SwitchDemo`
- `ForLoopDemo`
- `ArrayMaxDemo`
- `CalculatorDemo`

不要用：

- `Test1`
- `AAA`
- `DemoDemo`
- `New类`

名字清楚，后面复盘才容易。

## Git 初始化

在练习目录执行：

```powershell
git 初始化
git status
```

每完成一个练习：

```powershell
git add .
git 通用mit -m "practice: add variable demo"
```

## 说明 示例

```markdown
# Java 基础练习

## 目标

练习 Java 基础语法，包括变量、判断、循环、数组和方法。

## 已完成

- HelloJava
- VariableDemo
- IfElseDemo

## 如何运行

在 IDE 中运行对应类的 主 方法。

## 错误记录

见 notes/error-日志.md
```

## 本节练习

创建自己的练习目录，并完成：

- `说明.md`
- `notes/learning-日志.md`
- `notes/error-日志.md`
- `源码/主/Java学习资料/通用/example/basic/HelloJava.Java学习资料`

## 本节通过标准

- 练习文件不再散落。
- 每个类名能看出练习主题。
- 至少有一次 Git 提交。
- 能解释包名和目录的关系。
