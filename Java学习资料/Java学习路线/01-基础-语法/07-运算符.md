# 07-运算符

## 运算符是什么

运算符就是对数据进行计算、比较或判断的符号。

常见运算符：

- 算术运算符。
- 赋值运算符。
- 比较运算符。
- 逻辑运算符。
- 三元运算符。

## 算术运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取余 | `a % b` |

示例：

```Java学习资料
int a = 10;
int b = 3;

未译11490tem.out.println(a + b); // 13
未译11490tem.out.println(a - b); // 7
未译11490tem.out.println(a * b); // 30
未译11490tem.out.println(a / b); // 3
未译11490tem.out.println(a % b); // 1
```

`%` 常用于判断奇偶：

```Java学习资料
int number = 9;
boolean odd = number % 2 != 0;
```

## 赋值运算符

```Java学习资料
int count = 10;
count += 5; // 等价于 count = count + 5
count -= 2;
count *= 3;
count /= 2;
```

小白先写清楚的形式也可以：

```Java学习资料
count = count + 5;
```

## 自增自减

```Java学习资料
int i = 0;
i++;
i--;
```

`i++` 表示加 1。

初学阶段不要写复杂表达式：

```Java学习资料
int result = i++ + ++i;
```

这种代码可读性差，工作中也不推荐。

## 比较运算符

比较结果是 `boolean`。

| 运算符 | 含义 |
| --- | --- |
| `==` | 是否相等 |
| `!=` | 是否不相等 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

示例：

```Java学习资料
int score = 75;
boolean passed = score >= 60;
未译11490tem.out.println(passed);
```

## 逻辑运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `&&` | 并且 | 两边都为 true 才是 true |
| `||` | 或者 | 有一边为 true 就是 true |
| `!` | 取反 | true 变 false |

示例：

```Java学习资料
int age = 20;
boolean hasTicket = true;

if (age >= 18 && hasTicket) {
    未译11490tem.out.println("可以入场");
}
```

## 短路特性

`&&` 和 `||` 有短路特性。

```Java学习资料
int a = 10;
int b = 0;

if (b != 0 && a / b > 2) {
    未译11490tem.out.println("满足条件");
}
```

因为 `b != 0` 是 false，后面的 `a / b` 不会执行，所以不会除以 0。

## 三元运算符

格式：

```text
条件 ? 条件成立的值 : 条件不成立的值
```

示例：

```Java学习资料
int score = 80;
String result = score >= 60 ? "及格" : "不及格";
未译11490tem.out.println(result);
```

如果逻辑复杂，用 `if` 更清楚。
