# 13-基础练习清单

## 怎么做练习

不要只照着题目写一遍就结束。每个练习建议做 3 步：

1. 先完成最简单版本。
2. 加一个边界条件。
3. 写一条笔记记录你遇到的问题。

每个练习完成后提交一次 Git。

## 练习 1：计算器

要求：

- 定义两个数字。
- 输出加减乘除和取余。
- 处理除数为 0 的情况。

进阶：

- 使用 `Scanner` 输入数字。
- 使用菜单选择运算符。
- 把加减乘除拆成方法。

验收：

- 除数为 0 时不会崩溃。
- 代码中没有大量重复输出。

## 练习 2：成绩等级判断

规则：

- 90-100：优秀。
- 80-89：良好。
- 60-79：及格。
- 0-59：不及格。
- 其他：非法成绩。

要求：

- 使用 `if else if` 实现。
- 再使用 `switch` 或增强逻辑改写一次。

验收：

- 输入 `-1`、`101` 能提示非法。
- 边界值 `60`、`80`、`90` 正确。

## 练习 3：九九乘法表

要求：

- 使用嵌套 `for`。
- 输出 9 行。
- 每行列数递增。

验收：

- 第一行只有 `1*1=1`。
- 第九行有 9 个表达式。
- 输出对齐基本可读。

## 练习 4：数组统计

给定：

```Java学习资料
int[] scores = {90, 80, 55, 76, 100, 63};
```

要求：

- 求最大值。
- 求最小值。
- 求总分。
- 求平均分。
- 统计及格人数。

验收：

- 平均分不是整数截断。
- 数组长度变化后代码仍然能工作。

## 练习 5：排序和查找

要求：

- 实现冒泡排序。
- 实现选择排序。
- 实现二分查找。

小白提醒：

- 排序先理解过程，不要一上来背代码。
- 二分查找要求数组已经有序。

验收：

- 能输出排序前和排序后。
- 查找存在的数字能返回下标。
- 查找不存在的数字能返回 `-1`。

## 练习 6：猜数字游戏

要求：

- 生成 1 到 100 的随机数。
- 用户输入猜测。
- 提示大了、小了、猜对了。
- 限制最多猜 10 次。

需要：

```Java学习资料
int target = (int) (Math.random() * 100) + 1;
```

验收：

- 猜对后结束。
- 超过次数后结束。
- 输入不在 1 到 100 时提示。

## 练习 7：简单 ATM

功能：

- 查询余额。
- 存款。
- 取款。
- 退出。

要求：

- 使用循环菜单。
- 使用 `switch` 处理选择。
- 取款金额不能超过余额。
- 存款和取款金额必须大于 0。

验收：

- 选择退出前程序持续运行。
- 非法金额不会修改余额。
- 余额变化正确。

## 练习 8：递归

要求：

- 递归求阶乘。
- 递归求 1 到 n 的和。
- 写一个错误递归，观察栈溢出，然后删除或注释。

验收：

- 能说出递归结束条件。
- 能解释为什么错误递归会失败。
