# 01-阶段目标

## 总目标

这一阶段要从“会写小程序”升级为“会组织小项目”。

基础阶段你可能写了很多 `Demo` 文件，但真实项目不会把所有代码都放在一个类里。面向对象阶段的目标，就是学会把数据、行为和规则拆到合适的位置。

## 你要掌握的能力

### 设计类

你要能从需求里找出类。

例如图书管理系统：

- 图书：`Book`
- 用户：`用户`
- 菜单：`Menu`
- 图书服务：`BookService`
- 图书仓库：`Book未译25173epository`

### 创建对象

类是模板，对象是具体实例。

```Java学习资料
Book book = new Book("978711", "Java 入门", "张三");
```

这一行创建了一本具体的书。

### 管理多个对象

多个对象不能靠很多变量硬写，要用集合。

```Java学习资料
List<Book> books = new ArrayList<>();
books.add(book);
```

### 处理错误

业务错误要明确表达。

例如 ISBN 重复、图书不存在、库存不足，都不应该只打印一句话就结束。

```Java学习资料
throw new BookNotFoundException("图书不存在：" + isbn);
```

### 保存数据

程序关闭后数据不能全部丢失。基础阶段先使用文件保存，后面数据库阶段再换成 MySQL。

## 本阶段不追求什么

暂时不追求：

- 复杂设计模式。
- 企业级架构。
- Spring Boot。
- 数据库持久化。
- 并发安全。
- 分布式系统。

先把普通 Java 程序组织好。

## 学习判断标准

如果你能把一个 300 行的 `主` 方法拆成 5-10 个职责清楚的类，就说明这一阶段开始入门。

## 本节练习

拿“简单 ATM”练习，思考可以拆成哪些类：

- 账户类。
- 菜单类。
- ATM 服务类。
- 输入工具类。

先不用全部实现，写出类名和职责即可。

## 本节通过标准

- 能说出本阶段为什么要学面向对象。
- 能从一个小需求中识别 3-5 个类。
- 能理解“类是模板，对象是实例”。
- 能说明为什么集合比一堆变量更适合管理多个对象。
