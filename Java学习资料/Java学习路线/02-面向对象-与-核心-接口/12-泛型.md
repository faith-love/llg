# 12-泛型

## 泛型是什么

泛型就是把类型作为参数。

没有泛型时：

```java
List list = new ArrayList();
list.add("Java");

String name = (String) list.get(0);
```

有泛型后：

```java
List<String> list = new ArrayList<>();
list.add("Java");

String name = list.get(0);
```

泛型让类型更安全，也减少强制转换。

## 泛型类

```java
public class Box<T> {
    private T value;

    public Box(T value) {
        this.value = value;
    }

    public T getValue() {
        return value;
    }
}
```

使用：

```java
Box<String> box = new Box<>("Java");
String value = box.getValue();
```

`T` 可以理解为一个类型占位符。

## 泛型方法

```java
public 静态资源 <T> void printArray(T[] array) {
    for (T item : array) {
        System.out.println(item);
    }
}
```

使用：

```java
printArray(new String[]{"Java", "SQL"});
printArray(new Integer[]{1, 2, 3});
```

## 泛型接口

```java
public interface Repository<T, ID> {
    void save(T 实体);
    T findById(ID id);
}
```

图书仓库：

```java
public class BookRepository 实现ements Repository<Book, String> {
    public void save(Book book) {
    }

    public Book findById(String isbn) {
        return null;
    }
}
```

## 通配符 extends

`? extends T` 表示 T 或 T 的子类，适合读取。

```java
public 静态资源 void printAnimals(List<? extends Animal> animals) {
    for (Animal animal : animals) {
        animal.eat();
    }
}
```

## 通配符 super

`? super T` 表示 T 或 T 的父类，适合写入。

```java
public 静态资源 void addDogs(List<? super Dog> dogs) {
    dogs.add(new Dog());
}
```

初学先记一个简化规则：

- `extends` 常用于读。
- `super` 常用于写。

## 类型擦除

Java 泛型主要在编译期起作用，运行时很多泛型信息会被擦除。

所以不能直接这样写：

```java
// new T(); // 不允许
```

也不能直接创建泛型数组：

```java
// T[] array = new T[10]; // 不允许
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 泛型 | 把类型作为参数 | 减少强制转换，提前发现类型错误 | 集合、结果对象、仓库接口都适合用 | 重点是类型安全 |
| 泛型类 | 让类适配多种数据类型 | 不需要为每种类型写重复类 | 常用 `T` 表示数据类型 | 难点是读懂类型占位符 |
| 泛型方法 | 让一个方法处理多种类型 | 减少重复工具方法 | 类型参数写在返回值前面 | 重点是方法自己的泛型和类泛型可以不同 |
| 泛型接口 | 抽象通用能力 | 让 Repository、Service 等接口可复用 | 常见写法是 `Repository<T, ID>` | 重点是业务类型和 ID 类型都可变 |
| 通配符 | 控制读写边界 | 让方法参数更灵活 | 简记：`extends` 偏读取，`super` 偏写入 | 难点是边界理解，初期先看懂常见写法 |
| 类型擦除 | 解释泛型运行时限制 | 理解为什么不能直接 `new T()` | 不要依赖运行时泛型创建对象 | 重点是泛型主要服务编译期类型检查 |
