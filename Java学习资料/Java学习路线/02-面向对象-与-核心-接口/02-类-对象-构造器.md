# 02-类、对象、字段、方法和构造器

## 类是什么

类是描述一种事物的模板。

例如一本书有标题、作者、ISBN，也可以被借出或归还。可以用 `Book` 类描述：

```java
public class Book {
    String isbn;
    String title;
    String author;
    boolean borrowed;
}
```

## 对象是什么

对象是根据类创建出来的具体实例。

```java
Book book = new Book();
book.isbn = "978711";
book.title = "Java 入门";
book.author = "张三";
book.borrowed = false;
```

`Book` 是模板，`book` 是具体一本书。

## 字段

字段用来保存对象的状态。

```java
String title;
int age;
boolean borrowed;
```

字段应该表达对象“有什么数据”。

## 方法

方法用来表达对象“能做什么”。

```java
public void borrow() {
    borrowed = true;
}

public void returnBook() {
    borrowed = false;
}
```

如果一个逻辑和图书状态强相关，就应该放到 `Book` 类里，而不是全部堆在 `主` 方法里。

## 构造器

构造器在创建对象时执行，常用于初始化字段。

```java
public class Book {
    String isbn;
    String title;
    String author;

    public Book(String isbn, String title, String author) {
        this.isbn = isbn;
        this.title = title;
        this.author = author;
    }
}
```

使用：

```java
Book book = new Book("978711", "Java 入门", "张三");
```

## this

`this` 表示当前对象。

```java
this.title = title;
```

左边的 `this.title` 是对象字段，右边的 `title` 是构造器参数。

## 默认构造器

如果你没有写任何构造器，Java 会提供一个无参数构造器。

```java
public Book() {
}
```

但如果你自己写了有参数构造器，默认无参数构造器就不会自动提供。

## 类的基本写法

一个简单类通常包含：

- 字段。
- 构造器。
- 方法。
- `toString` 方法。

示例：

```java
public class Book {
    private String isbn;
    private String title;

    public Book(String isbn, String title) {
        this.isbn = isbn;
        this.title = title;
    }

    public void printInfo() {
        System.out.println(isbn + " - " + title);
    }
}
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 类 | 描述一种事物的模板 | 不用一堆散乱变量拼需求，代码更有结构 | 先从“有哪些数据、有哪些行为”开始建模 | 小白容易把类写成字段堆砌，重点是类要有职责 |
| 对象 | 类的具体实例 | 把抽象模板变成真实数据 | 创建对象后立刻初始化关键字段 | 容易混淆类和对象，重点是“模板”和“实例”的区别 |
| 字段 | 保存对象状态 | 不需要临时变量来回传递状态 | 字段少而精，先保留核心信息 | 字段公开过多会破坏封装，重点是状态要可控 |
| 方法 | 表达对象行为 | 把重复逻辑收起来，便于复用 | 一个方法只做一件事 | 小白容易把所有逻辑塞进一个方法，重点是职责清晰 |
| 构造器 | 创建时初始化对象 | 避免对象出现半初始化状态 | 把必填字段放进构造器 | 容易忘记初始化，重点是对象一创建就尽量可用 |
| this | 区分当前对象字段和参数 | 解决同名变量混淆问题 | 构造器和 setter 中高频使用 | 难点是看懂作用域，重点是区分“字段”和“参数” |

## 本节练习

创建 3 个类：

- `Book`：ISBN、标题、作者、是否借出。
- `User`：学号、姓名、年龄。
- `BankAccount`：账号、余额。

每个类至少包含：

- 3 个字段。
- 1 个构造器。
- 1 个打印信息的方法。
