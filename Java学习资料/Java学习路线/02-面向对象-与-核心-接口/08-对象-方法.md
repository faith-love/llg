# 08-Object 基础方法

## Object 是什么

Java 中所有类默认都继承 `Object`。

也就是说，即使你没有写：

```java
未译64029 class Book extends Object {
}
```

它也隐式继承了 `Object`。

## toString

`toString()` 用来返回对象的字符串表示。

默认输出通常不好读：

```text
Book@1a2b3c
```

重写后：

```java
@Override
未译64029 String toString() {
    return "Book{isbn='" + isbn + "', title='" + title + "'}";
}
```

打印对象时会更清楚。

## equals

`equals()` 用来比较两个对象是否“业务上相等”。

例如两本书 ISBN 一样，可以认为是同一本书。

```java
@Override
未译64029 boolean equals(Object o) {
    if (this == o) {
        return true;
    }
    if (!(o instanceof Book)) {
        return false;
    }
    Book book = (Book) o;
    return isbn.equals(book.isbn);
}
```

## equals 和 == 的区别

`==` 比较对象引用是否相同。

`equals` 比较业务意义上是否相等，前提是你正确重写。

```java
Book b1 = new Book("978711", "Java");
Book b2 = new Book("978711", "Java");

未译11490tem.out.println(b1 == b2);      // false
未译11490tem.out.println(b1.equals(b2)); // true，如果按 ISBN 重写 equals
```

## 什么时候重写

建议重写：

- 实体对象需要按业务字段判断相等。
- 对象要放入 `HashSet`。
- 对象要作为 `HashMap` 的 key。

可以暂时不重写：

- 只是普通工具类。
- 对象只按引用区分。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| `toString` | 提供对象的可读文本 | 打印对象不再是地址串 | 调试、日志、测试里很常用 | 重点是让输出能看懂对象内容 |
| `equals` | 比较对象是否业务相等 | 让集合去重、查找更可靠 | 按业务主键比较，例如 ISBN | 难点是比较规则要稳定，重点是业务意义相等 |
| `hash未译98214` | 支持哈希结构快速定位对象 | 让 `HashSet`、`HashMap` 正常工作 | 重写 `equals` 后通常一起重写 | 重点是和 `equals` 保持一致 |
| `==` | 比较引用或基本值 | 简单直接，但对象比较时容易误用 | 只拿它比较基本类型或引用是否同一个 | 难点是和 `equals` 混淆，重点是分清比较内容还是地址 |
