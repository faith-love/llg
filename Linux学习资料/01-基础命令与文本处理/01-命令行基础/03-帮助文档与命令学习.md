# 帮助文档与命令学习

## 作用

帮助文档与命令学习用于建立自查能力。Linux 命令很多，不可能全部背下来。真正重要的是看到一个陌生命令时，能快速查到它的用途、参数、示例和风险。

如果只靠Elasticsearch和复制命令，很容易复制到不适合当前发行版、当前版本或当前场景的命令。会查帮助文档，才能在服务器上自己判断。

## 痛点

- 不知道命令参数含义，只能复制教程。
- 复制来的命令在当前系统不可用，不知道如何改。
- 不会看 man 文档，觉得全是英文很难读。
- 不知道短选项和长选项在哪里查。
- 不知道命令版本不同会导致参数差异。

## 优点

- 遇到陌生命令能自己查。
- 能理解参数，不容易误用危险选项。
- 能快速确认当前系统命令是否支持某个功能。
- 能减少对单一教程的依赖。

## 常见帮助入口

### 1. `--help`

最直接：

```bash
ls --help
grep --help
systemctl --help
```

适合：

- 快速看命令用途。
- 查常见参数。
- 确认当前版本支持什么选项。

使用技巧：

```bash
grep --help | less
grep --help | grep -n "recursive"
```

### 2. `man`

查看完整手册：

```bash
man ls
man grep
man systemctl
```

man 内常用操作：

| 操作 | 作用 |
| --- | --- |
| `Space` | 下一页 |
| `b` | 上一页 |
| `/keyword` | 搜索关键字 |
| `n` | 下一个搜索结果 |
| `q` | 退出 |

示例：在 `man grep` 里搜索递归参数：

```text
/recursive
```

### 3. `tldr`

如果安装了 `tldr`，可以看更简短的示例：

```bash
tldr tar
tldr rsync
tldr journalctl
```

适合：

- 快速看常用例子。
- 学习命令组合。

注意：

- 生产服务器不一定安装。
- `tldr` 是辅助，不替代 `man` 和官方文档。

### 4. `info`

部分 GNU 工具有更详细的 info 文档：

```bash
info core工具
```

新手不必优先学，但知道它存在即可。

### 5. 服务自带检查命令

很多服务提供配置检查：

```bash
nginx -t
sshd -t
named-checkconf
```

这类命令比只看帮助更重要，因为它能验证配置是否可加载。

## 如何读帮助文档

建议按这个顺序读：

1. 看 `NAME`：命令做什么。
2. 看 `SYNOPSIS`：命令格式。
3. 看 `DESCRIPTION`：核心说明。
4. 搜索你关心的参数。
5. 看 `EXAMPLES`，如果有。
6. 执行前用测试文件或测试目录试一次。

示例：

```bash
man tar
```

你不需要读完整文档，先知道：

- `-c` 创建归档。
- `-x` 解包。
- `-t` 查看内容。
- `-z` gzip。
- `-f` 指定文件。

## 命令学习方法

### 先学场景，不先背参数

例如 `tar` 不要先背全部参数，而是学 3 个场景：

```bash
tar -czf 日志s.tar.gz 日志s/
tar -tzf 日志s.tar.gz
tar -xzf 日志s.tar.gz
```

### 先只读，再修改

学习危险命令前先使用只读模式：

```bash
find /opt/apps -name "*.日志"
```

确认结果后再考虑：

```bash
find /opt/apps -name "*.日志" -delete
```

### 先小范围，再大范围

不要一开始就在 `/` 下递归操作。

推荐：

```bash
find /tmp/Linux学习资料-lab -name "*.tmp"
```

不推荐初学时直接：

```bash
find / -name "*.tmp" -delete
```

## 版本差异

同一个命令在不同系统上可能版本不同：

```bash
grep --version
tar --version
nginx -v
systemctl --version
```

注意：

- macOS 和 Linux 命令参数可能不同。
- BusyBox 环境中的命令参数更少。
- 老系统的软件版本可能不支持新参数。

## 使用技巧

- 不懂参数先 `--help`。
- 不懂行为再 `man`。
- 想看例子可以用 `tldr`。
- 改配置前找服务的测试命令，例如 `nginx -t`。
- 复制网上命令前，先拆成命令、选项、参数理解。

## 难点

- man 文档内容多，新手容易不知道看哪里。
- 有些命令没有统一示例，需要结合场景学习。
- 不同发行版的命令版本不同，教程可能过期。
- 服务配置文件的语法检查命令比普通 help 更重要。

## 重点

- 不背全部参数，先掌握查参数的方法。
- 学命令要围绕真实场景。
- 危险操作先只读预览。
- 版本差异要用本机命令确认。

## 练习

1. 用 `man grep` 搜索 `recursive`，找到递归参数。
2. 用 `tar --help` 找出创建、查看、解压三个参数。
3. 用 `nginx -h` 或 `nginx -t` 理解 Nginx 配置检查。
4. 找一条网上命令，拆成命令、选项、参数并解释含义。
