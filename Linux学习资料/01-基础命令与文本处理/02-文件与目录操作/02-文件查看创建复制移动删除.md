# 文件查看创建复制移动删除

## 作用

文件查看、创建、复制、移动、删除是 Linux 运维最常用的文件操作能力。部署项目要创建目录、复制构建包、移动版本目录；排障要查看文件属性、确认配置是否存在；清理磁盘要删除旧文件。这个知识点重点是“会操作”和“安全操作”。

## 痛点

- 看不懂 `ls -l` 输出里的权限、属主、大小和时间。
- 创建多级目录时漏一级路径。
- 复制配置没有备份，改错后无法恢复。
- 移动文件到错误目录。
- 删除前不确认范围，误删重要文件。
- 不知道文件类型，脚本、压缩包、二进制文件混淆。

## 优点

- 能快速确认文件是否存在、大小、时间和权限。
- 能安全创建部署目录。
- 能备份配置和移动版本文件。
- 能用预览和移动待删目录降低删除风险。

## 查看文件和目录

常用命令：

```bash
ls
ls -l
ls -lah
ls -lt
ls -lhS
stat app.jar
file app.jar
```

### `ls -lah`

示例：

```text
-rw-r--r-- 1 app app 52M May 11 12:00 app.jar
```

含义：

- `-rw-r--r--`：文件类型和权限。
- `app app`：属主和属组。
- `52M`：文件大小。
- `May 11 12:00`：修改时间。
- `app.jar`：文件名。

### `stat`

查看更完整的元信息：

```bash
stat app.jar
```

适合确认：

- 文件大小。
- 权限数字。
- 最近访问、修改、状态变更时间。

### `file`

判断文件类型：

```bash
file app.jar
file deploy.sh
file archive.tar.gz
```

适合排查：

- 下载的包是不是 HTML 错误页。
- 脚本是不是文本文件。
- 压缩包格式是否正确。

## 创建目录和文件

创建单级目录：

```bash
mkdir 日志s
```

创建多级目录：

```bash
mkdir -p /opt/apps/demo-接口/shared/日志s
```

创建空文件或更新时间：

```bash
touch app.日志
```

使用技巧：

- 部署目录用 `mkdir -p`。
- 创建后马上检查权限和属主。

```bash
ls -ld /opt/apps/demo-接口/shared/日志s
```

## 复制文件和目录

复制文件：

```bash
cp app.jar app.jar.bak
```

复制目录：

```bash
cp -r 配置 配置.bak
```

保留属性复制：

```bash
cp -a 配置 配置.bak
```

配置备份建议带时间戳：

```bash
cp 应用配置.yml 应用配置.yml.bak-$(date +%F-%H%M%S)
```

注意：

- 复制到已有目录时，目标含义可能变化。
- 覆盖前确认目标文件是否重要。

## 移动和重命名

重命名：

```bash
mv old-name new-name
```

移动到目录：

```bash
mv app.jar /opt/apps/demo-接口/releases/2026-05-11-120000/
```

使用技巧：

- 同一文件系统内 `mv` 通常很快。
- 跨文件系统移动可能等价于复制后删除。
- 移动前确认目标目录存在。

## 删除文件和目录

删除文件：

```bash
rm app.日志
```

删除目录：

```bash
rm -r old-dir
```

强制递归删除：

```bash
rm -rf old-dir
```

`rm -rf` 是高风险命令，生产环境执行前必须确认：

```bash
hostname
whoami
pwd
ls -lah old-dir
```

更稳妥做法：

```bash
mkdir -p /tmp/delete-review
mv old-dir /tmp/delete-review/
```

先移动到待删除目录，确认没有问题后再删除。

## 常见场景

### 备份配置后修改

```bash
cd /etc/nginx
sudo cp nginx.conf nginx.conf.bak-$(date +%F-%H%M%S)
sudo vim nginx.conf
sudo nginx -t
```

### 创建应用日志目录

```bash
sudo mkdir -p /opt/apps/demo-接口/shared/日志s
sudo chown app:app /opt/apps/demo-接口/shared/日志s
sudo chmod 750 /opt/apps/demo-接口/shared/日志s
```

### 发布文件移动到 release

```bash
release=2026-05-11-120000
sudo mkdir -p /opt/apps/demo-接口/releases/$release
sudo mv /tmp/app.jar /opt/apps/demo-接口/releases/$release/
sudo chown -R app:app /opt/apps/demo-接口/releases/$release
```

## 使用技巧

- 改配置前先 `cp` 备份。
- 删除前先 `ls` 预览。
- 脚本中使用绝对路径。
- 目录创建后检查属主和权限。
- 对未知文件先用 `file` 判断类型。

## 难点

- 删除文件是否允许，主要看父目录权限。
- `cp` 覆盖文件通常不会提醒，除非别名或参数设置。
- `mv` 既可以移动也可以重命名，新手容易误解。
- 文件名带空格时，变量要加双引号。

## 重点

- `ls -lah` 是文件检查的基础。
- `mkdir -p` 用于多级目录。
- 配置文件改前带时间戳备份。
- `rm -rf` 前必须确认主机、用户、目录和目标。
- 生产删除优先“移动到待删除区”，不要立刻永久删除。
