# Linux 运维知识库总纲

这个知识库面向后端开发、测试、运维入门和日常服务器维护。目标不是做一本纯命令速查表，而是建立一套能落地的 Linux 运维工作流：能进入服务器、看懂目录和进程、部署项目、配置环境变量、控制文件权限、管理服务、查看日志、定位问题并保证基本安全。

## 学习目标

- 能独立登录一台 Linux 服务器，并判断系统版本、资源状态、网络状态和运行中的服务。
- 能熟练使用常见命令完成文件查看、搜索、编辑、压缩、传输、进程管理、磁盘查看和日志排查。
- 能把一个后端项目部署到 Linux 上，并完成启动、停止、重启、健康检查和回滚。
- 能正确配置环境变量、配置文件、启动参数和密钥，理解临时配置与持久配置的区别。
- 能控制文件权限、目录权限、用户组、服务用户和 SSH 登录权限，避免把系统暴露在高风险状态。
- 能用 systemd、Nginx、防火墙、定时任务、日志轮转等基础设施管理真实服务。

## 推荐学习路线

1. 先学 `01-03`：命令行、文件目录、文本查看和编辑。不会看文件、搜日志、改配置，就很难继续部署项目。
2. 再学 `04-05`：权限和环境变量。这两个是部署失败、启动失败、安全风险最常见的根因。
3. 接着学 `06-09`：安装软件、管理服务、部署项目、配置 Nginx。这是把项目真正跑起来的主线。
4. 然后学 `10-12`：网络、防火墙、日志、资源和性能。这是项目上线后定位问题的主线。
5. 最后学 `13-16`：自动化、安全加固、故障案例和工具选型，把零散操作沉淀成可复用流程。

## 常用排障顺序

遇到问题时，先按这个顺序确认：

1. 最近做过什么变更。
2. 服务是否运行：`systemctl status`、`ps`。
3. 端口是否监听：`ss -lntup`、`lsof -i`。
4. 本机健康检查是否通过：`curl http://127.0.0.1:端口/health`。
5. Nginx 是否正常：`nginx -t`、`未译12785.日志`、`access.日志`。
6. 环境变量和配置是否生效：`systemctl cat`、`EnvironmentFile`、`/proc/PID/environ`。
7. 权限是否正确：`id`、`ls -lah`、`namei -l`、`sudo -u app 测试`。
8. 资源是否耗尽：`df -h`、`free -h`、`top`、`journalctl -k`。
9. 防火墙和安全组是否放行：`ufw`、`firewall-cmd`、云控制台。
10. 修复后做健康检查、日志确认和复盘记录。

## 使用建议

- 学习时先看模块 说明，再进入小专题。
- 排障时直接按场景进入对应专题，不必从头读。
- 每次执行高风险命令前，先确认主机、用户、目录和影响范围。
- 修改配置前先备份，修改后做语法检查、服务状态检查和回滚准备。
- 安全、备份、监控类工具不是安装完就结束，必须定期验证。
