# 项目实战模板

本模块把前面的概念落到真实项目里。目标不是给一份万能模板，而是给你可以按项目改造的起点。

## 专题目录

| 文件 | 重点 |
| --- | --- |
| [11-Java项目容器化模板](11-Java项目容器化模板.md) | Spring Boot 或 Java API 的 Dockerfile 和 Compose 模板 |
| [12-前端Nginx静态站点模板](12-前端Nginx静态站点模板.md) | Node 构建、Nginx 托管、SPA 刷新和 API 代理 |
| [13-MySQL与Redis开发环境模板](13-MySQL与Redis开发环境模板.md) | 数据库、缓存、volume、端口和初始化配置 |
| [14-本地全栈联调模板](14-本地全栈联调模板.md) | 前端、后端、MySQL、Redis 的 Compose 联调结构 |

## 典型实战场景

| 场景 | 推荐方式 |
| --- | --- |
| Java 后端 API | 多阶段构建，运行镜像只保留 JRE 和 jar |
| Node 前端 | 构建阶段编译，Nginx 镜像托管静态文件 |
| MySQL | 官方镜像 + named volume + 独立密码和备份 |
| Redis | 官方镜像 + 持久化配置 + 卷挂载 |
| 本地全栈联调 | Compose 管理前后端、数据库和缓存 |

## 项目上线检查

- 镜像是否已构建并推送。
- 配置是否按环境分离。
- 数据是否挂载。
- 日志是否能采集。
- 端口是否已放行。
- 健康检查是否通过。
- 是否有回滚标签。

## 模板使用方式

1. 先确认应用的启动命令。
2. 确认构建产物的位置。
3. 确认哪些目录需要持久化。
4. 确认哪些配置要外置。
5. 按场景改造模板。
