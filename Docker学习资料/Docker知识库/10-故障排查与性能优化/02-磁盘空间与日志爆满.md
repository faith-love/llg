# 磁盘空间与日志爆满

Docker 服务器磁盘满会导致容器无法启动、数据库写入失败、镜像无法拉取，严重时影响宿主机。

## 先看磁盘

```bash
df -h
docker system df
docker system df -v
```

## 常见来源

- 容器日志过大。
- 旧镜像太多。
- 构建缓存太多。
- 停止容器堆积。
- 数据卷增长过快。

## 容器日志

查看日志路径：

```bash
docker inspect 容器名
```

如果日志无限增长，要配置日志轮转或接入日志平台。

## 安全清理顺序

1. 清理停止容器。
2. 清理悬空镜像。
3. 清理构建缓存。
4. 检查无用镜像。
5. 最后才评估无用 volume。

命令：

```bash
docker container prune
docker image prune
docker builder prune
```

## 不要直接清 volume

`docker volume prune` 可能删除未被当前容器引用但仍有价值的数据卷。生产环境执行前必须确认卷用途和备份。

## 长期修复

- 日志大小限制。
- 镜像保留策略。
- 定期容量巡检。
- 数据卷增长监控。
- 备份和清理分开执行。
