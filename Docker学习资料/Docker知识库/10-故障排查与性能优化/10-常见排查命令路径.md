# 常见排查命令路径

这是一条从现象到命令的快速路径。

## 容器起不来

```bash
docker ps -a
docker logs 容器名
docker inspect 容器名
```

重点看：

- 退出码。
- 启动命令是否正确。
- 配置文件路径是否存在。
- 挂载目录是否可读写。

## 外部访问不了

```bash
docker port 容器名
ss -lntp
docker exec -it 容器名 sh
```

重点看：

- 端口映射方向。
- 应用监听地址是否为 `0.0.0.0`。
- 防火墙和安全组。

## 容器之间不通

```bash
docker network ls
docker network inspect 网络名
docker exec -it 某容器 sh
getent hosts 目标服务名
```

重点看：

- 是否同网络。
- 主机名是否写成服务名。
- 端口是否正确。

## 数据丢失

```bash
docker inspect 容器名
docker volume ls
docker volume inspect 卷名
```

重点看：

- 是否真的挂载了卷。
- 写入路径是否正确。
- 删除容器后数据是否应该保留。

## 构建太慢

```bash
docker build --progress=plain -t app:1.0.0 .
docker history 镜像名
```

重点看：

- 哪一步缓存失效。
- 有没有复制过多无关文件。
- 依赖安装是否可以缓存。
