# 容量监控与清理策略

Docker 服务器磁盘打满通常来自四类东西：容器日志、旧镜像、停止容器、volume 数据。

## 先判断占用来源

```bash
docker system df
docker system df -v
df -h
du -sh /var/lib/docker
```

不要一上来就清理 volume。

## 清理对象

| 对象 | 检查命令 | 清理命令 |
| --- | --- | --- |
| 停止容器 | `docker ps -a` | `docker container prune` |
| 悬空镜像 | `docker images -f dangling=true` | `docker image prune` |
| 构建缓存 | `docker builder du` | `docker builder prune` |
| 未使用网络 | `docker network ls` | `docker network prune` |
| 未使用卷 | `docker volume ls` | `docker volume prune` |

## 高风险清理

```bash
docker system prune -a --volumes
```

这个命令会清理未使用镜像、容器、网络和卷，生产环境不要作为定时任务无脑执行。

## 日志增长控制

建议配置 Docker 日志大小限制，或者接入日志平台后设置保留周期。

检查容器日志路径：

```bash
docker inspect 容器名
```

## 生产策略

- 保留最近几个可回滚镜像。
- 数据 volume 不参与普通清理。
- 清理前先快照或备份关键数据。
- 容量告警阈值建议至少设置在 70%、85%、95% 三档。
