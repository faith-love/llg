# 上线检查清单

Docker 项目上线前不要只看容器能否启动，要确认镜像、配置、数据、网络、日志、安全和回滚都具备。

## 镜像检查

- 镜像标签固定。
- 镜像来源可信。
- 构建提交可追溯。
- 不使用未确认的 `latest`。
- 有上一个可回滚标签。

## 配置检查

- `.env` 或平台变量齐全。
- 数据库、Redis、外部服务地址正确。
- 生产日志级别正确。
- 密码没有写进 Dockerfile。
- 配置文件挂载路径正确。

## 数据检查

- 数据库、上传文件、缓存持久化目录已挂载。
- 备份任务可执行。
- 恢复流程已验证。
- 容器删除重建后数据仍在。

## 网络检查

- 只暴露必要端口。
- 内部服务不直接公网开放。
- Nginx 或网关转发正确。
- 防火墙和安全组规则匹配。

## 健康检查

```bash
docker compose ps
docker compose logs --tail=200 app
curl -f http://127.0.0.1:8080/health
```

上线后至少验证：

- 容器状态。
- 健康接口。
- 登录或核心业务接口。
- 依赖连接。
- 错误日志。

## 回滚准备

- 保留旧镜像标签。
- 保留旧 Compose 配置。
- 确认数据库变更是否兼容。
- 写好回滚命令。
