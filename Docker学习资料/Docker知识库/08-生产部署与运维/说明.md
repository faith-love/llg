## 生产部署前检查

- 镜像标签是否固定。
- 数据是否挂载。
- 配置是否外置。
- 容器是否用非 root 用户运行。
- 端口是否只暴露必要端口。
- 是否有健康检查。
- 是否有回滚版本。
- 是否有日志和磁盘监控。

## 目录建议

```text
/opt/docker/
  app/
    compose.yaml
    .env
    logs/
    data/
    backup/
```

建议把项目相关文件放在统一目录，方便备份、排障和迁移。

## 常用运维命令

```bash
docker compose up -d
docker compose pull
docker compose logs -f
docker compose restart
docker system df
docker image ls
docker container ls -a
```

## 升级和回滚

升级思路：

1. 拉取新镜像。
2. 更新 Compose 文件或部署配置中的镜像标签。
3. 重新启动服务。
4. 验证健康检查和业务接口。
5. 保留旧版本标签。

回滚思路：

1. 切回上一个镜像标签。
2. 保持数据卷不变。
3. 重新启动。
4. 验证日志和接口。

## 日志策略

- 优先输出到 stdout/stderr。
- 必须写文件时，挂载日志目录。
- 控制日志体积，避免把宿主机磁盘打满。
- 定期验证日志轮转策略是否生效。

## 容量和清理

- 定期查看 `docker system df`。
- 不要让无用镜像和停止容器长期堆积。
- 生产清理前先确认是否还有回滚镜像。
- 备份数据卷前先确认备份可恢复。
