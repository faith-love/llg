# 镜像拉取推送失败

## 现象

`docker push` 被拒绝，或者 `docker pull` 超时、证书报错、认证失败。

## 排查

```bash
docker login 仓库地址
docker images
docker tag 镜像名 仓库地址/项目/镜像:标签
docker push 仓库地址/项目/镜像:标签
```

重点看：

- 是否登录正确仓库。
- 镜像标签是否包含仓库地址和项目路径。
- 账号是否有对应权限。
- 网络是否可达。
- 证书是否被信任。

## 根因

常见是标签写错、登录错仓库、项目权限不足或仓库证书问题。

## 修复

- 重新打正确标签。
- 重新登录仓库。
- 让仓库管理员补权限。
- 检查仓库地址和证书。

## 长期修复

- CI/CD 固定仓库地址模板。
- 交付前自动校验镜像标签。
- 私有仓库账号最小权限化。
