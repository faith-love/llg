# 镜像构建很慢或很大

## 现象

构建耗时很长，推送也慢，镜像体积远大于预期。

## 常见原因

- 依赖安装放在后面，缓存失效频繁。
- 构建上下文太大。
- 把源码历史、测试文件、日志和本地依赖带进镜像。
- 没有使用多阶段构建。

## 排查

```bash
docker build --progress=plain -t app:1.0.0 .
docker history app:1.0.0
```

## 修复

- 优先优化 `.dockerignore`。
- 把稳定的依赖层前置。
- 使用多阶段构建。
- 只把运行期需要的产物复制到最终镜像。

## 长期修复

- 给团队统一 Dockerfile 模板。
- 定期检查镜像体积。
- 对基础镜像和依赖更新建立缓存策略。
