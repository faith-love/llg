# 权限不足导致服务启动失败

## 现象

容器启动后日志报 `permission denied`，应用无法写日志、写缓存或初始化数据库。

## 排查

```bash
docker exec -it 容器名 id
docker inspect 容器名
ls -lah /宿主机挂载目录
```

重点看：

- 容器运行用户。
- 宿主机目录属主。
- 挂载是否只读。
- 路径上级目录权限。

## 根因

容器内应用不是 root，但宿主机挂载目录归 root 所有，应用没有写权限。

## 修复

- 调整宿主机目录属主。
- 调整容器运行用户。
- 给只需要读的目录加只读挂载。

## 长期修复

- Dockerfile 中显式指定 `USER`。
- 目录规划里分离配置、数据和日志。
- 在上线前做写权限验证。
