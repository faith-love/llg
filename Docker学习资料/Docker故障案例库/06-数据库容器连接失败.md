# 数据库容器连接失败

## 现象

应用容器报数据库连接失败，Compose 已经启动完成，但接口仍然报错。

## 排查

```bash
docker compose ps
docker compose logs -f app
docker compose logs -f mysql
docker exec -it app sh
```

重点看：

- 配置里是否写了 `localhost`。
- 数据库主机名是否写成服务名。
- 数据库是否已经完成初始化。
- 端口是否正确。
- 密码是否正确。

## 根因

应用容器里的 `localhost` 指容器自己，而不是 MySQL 容器。

## 修复

- 把数据库地址改成服务名 `mysql`。
- 给数据库加健康检查。
- 给应用加连接重试。

## 长期修复

- Compose 模板统一使用服务名。
- 数据库上线后先做连接验证。
- 不把就绪状态和启动状态混淆。
