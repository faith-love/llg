# 端口映射正确但外部访问失败

## 现象

容器已经运行，`docker ps` 也能看到 `0.0.0.0:8080->8080/tcp`，但浏览器还是打不开。

## 排查顺序

```bash
docker logs 容器名
docker exec -it 容器名 sh
ss -lntp
```

重点看：

- 应用是否真的启动成功。
- 应用是否监听 `0.0.0.0`。
- 宿主机端口是否被别的进程占用。
- 防火墙和云安全组是否放行。

## 根因示例

应用只监听 `127.0.0.1`，导致 Docker 端口映射到了容器端口，但容器里的应用没有对外部网卡开放。

## 修复

把应用监听地址改成 `0.0.0.0`，然后重启容器。

## 长期修复

- 在镜像或 Compose 中写清楚监听地址。
- 加健康检查。
- 为服务提供标准健康路径。
