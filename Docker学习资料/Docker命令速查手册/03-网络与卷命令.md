# 网络与卷命令

## 网络命令

```bash
docker network ls
docker network create app-net
docker network inspect app-net
docker port web
```

## 卷命令

```bash
docker volume ls
docker volume create app-data
docker volume inspect app-data
docker volume prune
```

## 使用提示

- 容器间通信优先用自定义网络和服务名。
- 数据库和上传文件要挂卷。
- `volume prune` 只处理未使用卷，生产要先确认卷用途。
