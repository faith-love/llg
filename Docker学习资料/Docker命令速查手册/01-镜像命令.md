# 镜像命令

## 常用命令

```bash
docker images
docker pull nginx:stable
docker build -t app:1.0.0 .
docker history app:1.0.0
docker tag app:1.0.0 registry.example.com/app:1.0.0
docker push registry.example.com/app:1.0.0
docker inspect app:1.0.0
```

## 使用提示

- `pull` 拉取远程镜像。
- `build` 从 Dockerfile 构建镜像。
- `tag` 给镜像加标签或改仓库地址。
- `history` 看镜像层。
- `inspect` 看镜像元数据。

## 常见问题

- 镜像拉不下来，先看仓库地址和登录状态。
- 构建速度慢，先看 `.dockerignore` 和 Dockerfile 顺序。
- 生产部署不要只写 `latest`。
