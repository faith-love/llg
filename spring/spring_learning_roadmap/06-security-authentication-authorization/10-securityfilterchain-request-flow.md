# 10-SecurityFilterChain 请求链路

## 它在请求链路里的位置

SecurityFilterChain 位于业务 Controller 前面。

它要处理的通常包括：

- 认证入口。
- 授权判断。
- 异常转换。
- 安全上下文建立。

## 为什么这层重要

如果安全处理放到 Controller 里再做，很多事情就已经太晚了：

- 未认证请求已经进入业务代码。
- 统一失败响应更难做。
- 安全边界容易分散。

## 学习重点

你不需要一开始死记过滤器名字，但要知道：

- 请求先经过安全链。
- 成功后才进入业务层。
- 失败会在安全层被转换。

## 本节通过标准

- 能解释 SecurityFilterChain 在请求主线中的位置。
- 能说出为什么安全逻辑通常前置于 Controller。
- 能理解安全上下文不是业务层临时拼出来的。
