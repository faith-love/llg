# 11-方法级授权和表达式边界

## 为什么还需要方法级授权

URL 级保护适合入口控制，但业务里经常还需要更细粒度判断：

- 当前用户是否能操作这条数据。
- 是否拥有某个具体权限。
- 是否只允许某些角色修改状态。

## 方法级授权的价值

它更适合表达：

- 业务动作级别的限制。
- 比路径更细的权限规则。

## 边界要清楚

不要把所有复杂业务规则都写进授权表达式。

授权应该负责“能不能做”，复杂业务决策仍然放在业务层。

## 本节通过标准

- 能解释 URL 级和方法级授权的边界。
- 能知道方法级授权适合更细粒度控制。
- 能避免把复杂业务规则硬塞进授权表达式。
