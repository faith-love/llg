# 13-认证失败、授权失败和统一错误响应

## 为什么 401 和 403 必须分开

如果这两个混在一起，调用方就无法判断：

- 是没登录。
- 还是登录了但权限不足。

## 失败响应的目标

要让前端或调用方能明确知道：

- 当前状态是什么。
- 是否需要跳登录。
- 是否需要提示无权限。

## 统一处理

安全层错误最好统一处理，而不是散落在每个接口里自己返回。

这样能保持：

- 结构一致。
- 状态码一致。
- 协议边界清楚。

## 本节通过标准

- 能正确区分并处理 401 和 403。
- 能建立统一的安全失败响应结构。
- 能避免业务层随意拼装认证授权错误。
