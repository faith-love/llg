# 09-隔离级别、锁和并发读写

## 隔离级别在解决什么

隔离级别解决的是并发事务读写时的一致性问题。

你至少要知道它和这些现象相关：

- 脏读。
- 不可重复读。
- 幻读。

## 锁不是只在数据库课里有用

真实项目里，库存、余额、状态流转都可能和锁有关。

至少要有概念区分：

- 悲观锁。
- 乐观锁。
- 行锁。

## 不要脱离业务理解并发问题

例如库存扣减：

- 多个请求同时减库存。
- 一个事务还没提交，另一个事务已经读到旧值。

这类问题如果不和业务场景结合，很容易学成空概念。

## 本节通过标准

- 能说出隔离级别和并发读写问题的关系。
- 能理解乐观锁和悲观锁的基本差异。
- 能把锁问题放回业务场景理解。
