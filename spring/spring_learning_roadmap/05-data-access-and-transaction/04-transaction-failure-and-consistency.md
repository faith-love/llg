# 04-事务失效和一致性实验

## 常见失效场景

最常见的几个：

- 同类内部调用。
- `private` 方法。
- 目标对象不是 Spring Bean。
- 异常被吞掉。

这些场景如果不实验，很容易误以为“加了 `@Transactional` 就一定生效”。

## 一致性实验

建议做下面几个实验：

- 创建订单并扣减库存。
- 库存不足时回滚。
- 支付成功后更新订单并写日志。
- 人为制造异常，观察哪些操作提交了，哪些回滚了。

## 单库和分布式

单库事务能解决单数据库里的原子性问题。

跨服务、跨数据库、外部调用场景，还要补：

- 幂等。
- 补偿。
- 消息。
- 状态机。

## 本节通过标准

- 能说出几类最常见的事务失效场景。
- 能通过实验观察提交和回滚结果。
- 能区分单库事务和分布式一致性问题。
