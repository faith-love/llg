# 02-消息队列和幂等消费

## 消息适合什么场景

常见场景：

- 下单后异步通知。
- 审计日志。
- 批量任务削峰。
- 最终一致性流程。

## 消息不是发送成功就结束

你还要考虑：

- 发送确认。
- 消费失败重试。
- 死信处理。
- 顺序要求。
- 重复消费。

## 幂等为什么重要

消费者收到同一条消息多次时，结果必须可控。

典型例子：

- 重复扣库存。
- 重复发优惠券。
- 重复写日志。

幂等处理通常要依赖唯一业务键、去重表或状态机。

## 本节通过标准

- 能说明为什么消费者必须幂等。
- 能列出消息链路里的几个关键失败点。
- 能区分“同步调用”和“异步消息”的适用场景。
