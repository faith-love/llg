# 06-阶段练习和通过标准

## 阶段练习项目

基于前面的 Web 项目继续补：

- `dev/test/prod` 三套配置。
- `@ConfigurationProperties` 业务配置类。
- Actuator 端点。
- 依赖树笔记。
- 一个被排除的自动配置实验。

## 阶段自测问题

1. Starter 解决什么问题？
2. 自动配置为什么会生效？
3. `@ConditionalOnMissingBean` 的意义是什么？
4. 配置为什么可能不生效？
5. `@Value` 和 `@ConfigurationProperties` 怎么选？
6. Actuator 能做什么，不能做什么？

## 阶段通过标准

- 能解释 `@SpringBootApplication` 的组成。
- 能建立稳定的环境配置体系。
- 能通过依赖树和启动日志定位基础问题。
