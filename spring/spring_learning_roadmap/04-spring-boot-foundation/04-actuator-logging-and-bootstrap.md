# 04-Actuator、日志和启动观察

## 为什么要看启动过程

很多 Spring Boot 问题其实在启动日志里就已经给出了线索。

你至少要看：

- 应用名。
- 端口。
- 当前 Profile。
- Web 容器是否启动。
- 关键依赖是否初始化成功。

## Actuator 的位置

Actuator 提供运行时信息入口。

常见端点：

- `health`
- `info`
- `metrics`

它解决的是“服务当前状态可见”，不是完整监控系统本身。

## 日志不要只看报错最后一行

定位问题时，重点看：

- 触发点。
- 上下文参数。
- 异常链。
- 根因。

后面上线阶段，你还需要把日志和 traceId、用户 ID、请求 ID 关联起来。

## 本节通过标准

- 能打开并访问常见 Actuator 端点。
- 能从启动日志判断应用是否真的启动成功。
- 能区分“能跑”和“可观测”之间的差别。
