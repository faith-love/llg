# 14-图书 REST API 项目落地

## 最小落地范围

建议把本阶段知识压进一个小项目：

- 图书创建
- 图书更新
- 图书详情
- 图书分页
- 图书删除
- 图书状态更新

## 需要同时体现的能力

- REST 路由
- DTO
- 参数校验
- 统一异常
- 分页和筛选
- 状态码语义
- 文档和示例

## 验收视角

看这个项目时，要能回答：

- 路由是否清楚。
- 输入输出边界是否稳定。
- 错误结构是否一致。
- 分层是否清楚。

## 本节通过标准

- 能把 Spring MVC 这一阶段的核心能力组合成一个完整小项目。
- 能用这个项目支撑后续 Boot、事务和安全阶段继续扩展。
