## 小白需要先记住的结论

- 项目不是功能清单，项目是需求、设计、实现、测试、部署和复盘的组合。
- 一个能讲清楚的中等复杂度项目，比三个堆功能的半成品更有价值。
- 面试里最重要的不是“用了什么框架”，而是“为什么这么设计，出问题时怎么定位”。
