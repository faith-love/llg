## 使用方式

1. 先读 `Python学习路线/说明.md`，明确整体路线、版本选择和阶段目标。
2. 先完成 `00-总览与版本基线`，把学习目标、目录规范、每周节奏和验收标准固定下来。
3. 后续按阶段逐步展开专题文档，每个阶段都要有练习、复盘和验收记录。
4. 新增 Python 文档时优先归入对应阶段；如果形成速查、案例或项目库，再在本页新增独立分类入口。
