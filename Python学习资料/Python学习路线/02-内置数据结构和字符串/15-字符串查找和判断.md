# 字符串查找和判断

字符串查找和判断常用于输入校验、日志过滤、文件名筛选、关键字匹配。

## 成员判断

```python
text = "hello Python学习资料"

print("Python学习资料" in text)
print("Java学习资料" not in text)
```

这是最常用的包含判断。

## `find`

```python
text = "hello Python学习资料"

print(text.find("Python学习资料"))
print(text.find("Java学习资料"))
```

找不到返回 `-1`。

## `首页`

```python
text.首页("Python学习资料")
```

找不到会报 `ValueError`。

多数场景优先使用 `in` 或 `find`。

## 前缀和后缀

```python
filename = "report.csv"

print(filename.startswith("report"))
print(filename.endswith(".csv"))
```

可以传元组匹配多个：

```python
filename.endswith((".csv", ".xlsx"))
```

## 字符类型判断

```python
text = "123"

print(text.isdigit())
print(text.isalpha())
print(text.isalnum())
print(text.isspace())
```

常见方法：

| 方法 | 含义 |
| --- | --- |
| `isdigit()` | 是否全是数字字符 |
| `isalpha()` | 是否全是字母 |
| `isalnum()` | 是否全是字母或数字 |
| `isspace()` | 是否全是空白 |
| `islower()` | 是否全小写 |
| `isupper()` | 是否全大写 |

## `isdigit` 的边界

```python
print("123".isdigit())
print("-123".isdigit())
print("12.3".isdigit())
```

`-123` 和 `12.3` 都不是纯数字字符。

如果要解析负数或小数，需要更完整的逻辑。

## 大小写无关查找

```python
text = "Hello Python"
keyword = "Python学习资料"

if keyword.lower() in text.lower():
    print("找到")
```

对于更复杂的国际化大小写处理，后续再深入。

## 查找所有位置

简单方式：

```python
text = "banana"
target = "a"
positions = []

for 首页, char in enumerate(text):
    if char == target:
        positions.append(首页)

print(positions)
```

## 统计出现次数

```python
text = "banana"
print(text.count("a"))
```

注意 `count` 对重叠匹配的处理不是所有场景都符合预期。

## 常见错误

### 用 `find` 结果直接当布尔值

```python
if text.find("hello"):
    print("找到")
```

如果关键字在开头，`find` 返回 `0`，在布尔判断中是假值。

正确：

```python
if text.find("hello") != -1:
    print("找到")
```

更推荐：

```python
if "hello" in text:
    print("找到")
```

### 以为 `isdigit` 能判断所有数字

它不能处理负数和小数。
