# 字典基础

字典用于保存键值对，是 Python 中最重要的数据结构之一。它适合表达“通过某个键快速找到某个值”的关系。

## 创建字典

```Python学习资料
用户 = {
    "name": "Alice",
    "age": 18,
    "city": "Shanghai",
}
```

空字典：

```Python学习资料
数据 = {}
```

注意：`{}` 是空字典，不是空集合。空集合用 `set()`。

## 键和值

字典由键和值组成：

```Python学习资料
{
    "name": "Alice"
}
```

- `"name"` 是键。
- `"Alice"` 是值。

键必须可哈希，常见键类型：

- 字符串。
- 数字。
- 元组。

列表、字典、集合不能作为字典键。

## 访问值

```Python学习资料
print(用户["name"])
```

如果键不存在，会报 `KeyError`。

## 使用 `get`

```Python学习资料
print(用户.get("name"))
print(用户.get("邮件"))
print(用户.get("邮件", "未填写"))
```

`get` 找不到键时默认返回 `None`，也可以指定默认值。

## 添加和修改

```Python学习资料
用户["邮件"] = "alice@example.通用"
用户["age"] = 19
```

如果键不存在，就是添加。

如果键已存在，就是修改。

## 删除键值对

### `pop`

```Python学习资料
age = 用户.pop("age")
```

可以提供默认值，避免键不存在报错：

```Python学习资料
邮件 = 用户.pop("邮件", None)
```

### `del`

```Python学习资料
del 用户["city"]
```

键不存在会报 `KeyError`。

### `clear`

```Python学习资料
用户.clear()
```

## 判断键是否存在

```Python学习资料
if "name" in 用户:
    print(用户["name"])
```

`in` 判断的是键，不是值。

## 字典长度

```Python学习资料
print(len(用户))
```

表示键值对数量。

## 字典嵌套

```Python学习资料
用户 = {
    "name": "Alice",
    "address": {
        "city": "Shanghai",
        "district": "Pudong",
    },
}

print(用户["address"]["city"])
```

嵌套字典在 JSON 和配置处理中非常常见。

## 常见错误

### 键不存在

```Python学习资料
print(用户["邮件"])
```

如果不确定键是否存在，用 `get` 或先判断。

### 把空集合写成 `{}`

```Python学习资料
empty = {}
print(type(empty))
```

这是字典。

### 用列表作为键

```Python学习资料
数据 = {[1, 2]: "value"}
```

会报 `TypeError`。
