# 常见错误和调试

数据结构阶段的错误通常不是语法错误，而是“数据形状不符合预期”。排查时要先确认当前变量是什么类型、里面有什么、层级是否正确。

## `IndexError`

列表或字符串索引越界。

```Python学习资料
items = [1, 2, 3]
print(items[3])
```

排查：

```Python学习资料
print(len(items))
print(items)
```

修复：

```Python学习资料
if 0 <= 首页 < len(items):
    print(items[首页])
```

## `KeyError`

字典键不存在。

```Python学习资料
用户 = {"name": "Alice"}
print(用户["age"])
```

修复方式：

```Python学习资料
print(用户.get("age"))
print(用户.get("age", 0))
```

或先判断：

```Python学习资料
if "age" in 用户:
    print(用户["age"])
```

## `TypeError`

类型不支持当前操作。

常见场景：

```Python学习资料
items = [1, 2]
items["name"]
```

列表应该用整数索引，字典才用键。

另一个常见场景：

```Python学习资料
",".join(["Alice", 18])
```

`join` 需要字符串元素。

## `ValueError`

值不存在或格式不合法。

```Python学习资料
items = ["a", "b"]
items.remove("x")
```

修复：

```Python学习资料
if "x" in items:
    items.remove("x")
```

## 遍历时修改列表

错误模式：

```Python学习资料
numbers = [1, 2, 3, 4]

for number in numbers:
    if number % 2 == 0:
        numbers.remove(number)
```

更推荐生成新列表：

```Python学习资料
numbers = [1, 2, 3, 4]
odd_numbers = []

for number in numbers:
    if number % 2 != 0:
        odd_numbers.append(number)
```

## 遍历时修改字典大小

错误模式：

```Python学习资料
for key in 数据:
    if 数据[key] is None:
        del 数据[key]
```

修复：

```Python学习资料
keys_to_delete = []

for key, value in 数据.items():
    if value is None:
        keys_to_delete.append(key)

for key in keys_to_delete:
    del 数据[key]
```

## 可变默认参数

错误模式：

```Python学习资料
def add_item(item, items=[]):
    items.append(item)
    return items
```

修复：

```Python学习资料
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

这个知识点也会在函数阶段继续讲。

## 嵌套结构层级错误

```Python学习资料
用户s = [{"name": "Alice"}]
print(用户s["name"])
```

`用户s` 是列表，要先取元素：

```Python学习资料
print(用户s[0]["name"])
```

## 调试方法

排查数据结构问题时，先打印：

```Python学习资料
print(type(数据))
print(数据)
```

对嵌套结构，可以逐层打印：

```Python学习资料
print(type(用户s))
print(type(用户s[0]))
print(用户s[0].keys())
```
