# 序列通用操作

序列是一类有顺序的数据结构。字符串、列表、元组都属于序列。它们共享很多操作：索引、切片、长度、遍历、成员判断和拼接。

## 常见序列

- `str`
- `list`
- `tuple`
- `range`

示例：

```Python学习资料
text = "Python学习资料"
numbers = [1, 2, 3]
point = (3, 5)
```

## 索引

索引从 0 开始：

```Python学习资料
items = ["a", "b", "c"]

print(items[0])
print(items[1])
print(items[-1])
```

负数索引从右往左：

- `-1` 是最后一个。
- `-2` 是倒数第二个。

## 切片

```Python学习资料
items = [0, 1, 2, 3, 4, 5]

print(items[1:4])
print(items[:3])
print(items[3:])
print(items[::2])
```

基本格式：

```Python学习资料
序列[开始:结束:步长]
```

结束位置不包含。

## 长度

```Python学习资料
items = [1, 2, 3]
print(len(items))
```

`len()` 返回元素数量。

## 成员判断

```Python学习资料
names = ["Alice", "Bob"]

print("Alice" in names)
print("Cindy" not in names)
```

字符串也支持：

```Python学习资料
text = "hello Python学习资料"
print("Python学习资料" in text)
```

## 遍历

```Python学习资料
items = ["a", "b", "c"]

for item in items:
    print(item)
```

如果需要下标：

```Python学习资料
for 首页, item in enumerate(items):
    print(首页, item)
```

## 拼接

```Python学习资料
print([1, 2] + [3, 4])
print("hello" + "Python学习资料")
print((1, 2) + (3, 4))
```

注意：拼接会创建新对象，不是原地修改。

## 重复

```Python学习资料
print([0] * 3)
print("ha" * 3)
```

嵌套列表重复要小心：

```Python学习资料
rows = [[]] * 3
rows[0].append(1)
print(rows)
```

三个子列表其实是同一个对象。

## 最值和求和

对于数字序列：

```Python学习资料
numbers = [3, 1, 5]

print(max(numbers))
print(min(numbers))
print(sum(numbers))
```

空序列调用 `max`、`min` 会报错，需要先判断。

## 常见错误

### 索引越界

```Python学习资料
items = [1, 2, 3]
print(items[3])
```

### 切片和索引边界混淆

索引越界会报错，切片越界通常不会报错：

```Python学习资料
print(items[100:200])
```

结果是空列表。

### 嵌套列表重复引用

不要用 `[[]] * n` 创建多个独立子列表。
