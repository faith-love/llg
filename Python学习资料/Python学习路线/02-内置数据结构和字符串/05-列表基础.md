# 列表基础

列表是 Python 中最常用的可变序列。它适合保存一批有顺序、可重复、需要增删改的数据。

## 创建列表

```Python学习资料
numbers = [1, 2, 3]
names = ["Alice", "Bob", "Cindy"]
empty = []
```

列表可以包含不同类型，但实际项目中通常建议同一个列表保存同类数据。

不推荐：

```Python学习资料
items = ["Alice", 18, True, {"city": "Shanghai"}]
```

如果是一个人的信息，用字典更合适：

```Python学习资料
用户 = {"name": "Alice", "age": 18, "active": True}
```

## 访问元素

```Python学习资料
names = ["Alice", "Bob", "Cindy"]

print(names[0])
print(names[-1])
```

## 修改元素

```Python学习资料
names[1] = "Bobby"
```

列表是可变对象，可以原地修改。

## 添加元素

### `append`

在末尾添加一个元素：

```Python学习资料
names.append("David")
```

### `insert`

在指定位置插入：

```Python学习资料
names.insert(1, "Eve")
```

### `extend`

追加另一个可迭代对象里的多个元素：

```Python学习资料
names.extend(["Frank", "Grace"])
```

注意区别：

```Python学习资料
names.append(["Frank", "Grace"])
```

这会把整个列表作为一个元素追加。

## 删除元素

### `pop`

删除并返回指定位置元素，默认最后一个：

```Python学习资料
last = names.pop()
first = names.pop(0)
```

### `remove`

按值删除第一个匹配元素：

```Python学习资料
names.remove("Alice")
```

如果值不存在，会报 `ValueError`。

### `del`

按索引或切片删除：

```Python学习资料
del names[0]
del names[1:3]
```

### `clear`

清空列表：

```Python学习资料
names.clear()
```

## 查找元素

```Python学习资料
names = ["Alice", "Bob", "Alice"]

print("Alice" in names)
print(names.首页("Alice"))
print(names.count("Alice"))
```

`首页` 找不到会报 `ValueError`，使用前可以先 `in` 判断。

## 列表长度

```Python学习资料
print(len(names))
```

## 列表复制

浅复制：

```Python学习资料
new_names = names.copy()
```

也可以：

```Python学习资料
new_names = names[:]
```

嵌套列表的拷贝问题后面单独讲。

## 常见错误

### `append` 和 `extend` 混淆

```Python学习资料
items = [1, 2]
items.append([3, 4])
print(items)
```

结果是：

```text
[1, 2, [3, 4]]
```

如果想得到 `[1, 2, 3, 4]`，用 `extend`。

### `remove` 删除不存在的值

```Python学习资料
items.remove("x")
```

先判断：

```Python学习资料
if "x" in items:
    items.remove("x")
```

### 遍历时删除元素

遍历列表时直接删除可能跳过元素。后面常见错误章节会详细讲。
