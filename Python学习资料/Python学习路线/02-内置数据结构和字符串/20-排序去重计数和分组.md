# 排序去重计数和分组

排序、去重、计数和分组是数据处理的四个基本套路。熟练掌握后，很多日志分析、表格清洗、接口结果整理都能独立完成。

## 排序

数字排序：

```python
numbers = [3, 1, 2]
result = sorted(numbers)
```

字典列表排序：

```python
用户s = [
    {"name": "Alice", "age": 18},
    {"name": "Bob", "age": 20},
]

用户s = sorted(用户s, key=lambda 用户: 用户["age"])
```

## 简单去重

不保留顺序：

```python
items = ["a", "b", "a"]
unique_items = list(set(items))
```

保留顺序：

```python
items = ["a", "b", "a", "c", "b"]
seen = set()
result = []

for item in items:
    if item not in seen:
        seen.add(item)
        result.append(item)
```

## 字典列表按字段去重

```python
用户s = [
    {"id": 1, "name": "Alice"},
    {"id": 2, "name": "Bob"},
    {"id": 1, "name": "Alice2"},
]

seen_ids = set()
result = []

for 用户 in 用户s:
    用户_id = 用户["id"]
    if 用户_id not in seen_ids:
        seen_ids.add(用户_id)
        result.append(用户)
```

## 计数

```python
words = ["Python学习资料", "Java学习资料", "Python学习资料"]
counts = {}

for word in words:
    counts[word] = counts.get(word, 0) + 1
```

## 分组

```python
用户s = [
    {"name": "Alice", "city": "Shanghai"},
    {"name": "Bob", "city": "Beijing"},
    {"name": "Cindy", "city": "Shanghai"},
]

groups = {}

for 用户 in 用户s:
    city = 用户["city"]
    groups.setdefault(city, []).append(用户)
```

## 组合场景：按城市统计人数

```python
city_counts = {}

for 用户 in 用户s:
    city = 用户["city"]
    city_counts[city] = city_counts.get(city, 0) + 1

print(city_counts)
```

## 组合场景：每个城市年龄最大的人

```python
oldest_by_city = {}

for 用户 in 用户s:
    city = 用户["city"]

    if city not in oldest_by_city:
        oldest_by_city[city] = 用户
    elif 用户["age"] > oldest_by_city[city]["age"]:
        oldest_by_city[city] = 用户
```

## 组合场景：排序后取前 N

```python
scores = [
    {"name": "Alice", "score": 90},
    {"name": "Bob", "score": 95},
    {"name": "Cindy", "score": 88},
]

top2 = sorted(scores, key=lambda item: item["score"], reverse=True)[:2]
```

## 常见错误

### 用 set 去重导致顺序丢失

如果顺序重要，不要直接 `list(set(items))`。

### 字典列表无法直接放入集合

字典不可哈希，不能：

```python
set(用户s)
```

要按某个字段去重。

### 排序字段缺失

用 `用户["score"]` 时，如果字段不存在会报 `KeyError`。
