# 拷贝、浅拷贝和深拷贝

拷贝问题是 Python 初学到中级阶段的高频难点。核心问题是：你复制的是外层Docker，还是连内部对象也复制了。

## 赋值不是拷贝

```python
a = [1, 2]
b = a

b.append(3)
print(a)
```

`a` 和 `b` 指向同一个列表。

## 浅拷贝

浅拷贝会创建新的外层Docker，但内部对象仍然共享。

常见方式：

```python
items = [1, 2, 3]

copy1 = items.copy()
copy2 = items[:]
copy3 = list(items)
```

对一层列表：

```python
items = [1, 2]
new_items = items.copy()
new_items.append(3)

print(items)
print(new_items)
```

外层已经分开。

## 嵌套结构的浅拷贝问题

```python
matrix = [[1, 2], [3, 4]]
new_matrix = matrix.copy()

new_matrix[0].append(99)

print(matrix)
print(new_matrix)
```

两个矩阵的第一行都会变化，因为内部列表共享。

## 深拷贝

深拷贝会递归复制内部对象。

```python

matrix = [[1, 2], [3, 4]]

new_matrix[0].append(99)

print(matrix)
print(new_matrix)
```

## 字典拷贝

```python
用户 = {"name": "Alice", "tags": ["vip"]}
new_用户 = 用户.copy()

new_用户["tags"].append("new")
print(用户)
```

`tags` 列表仍然共享。

嵌套字典同理。

## 什么时候用浅拷贝

适合：

- 一层列表。
- 一层字典。
- 内部元素是不可变对象。
- 只想避免外层增删影响原对象。

## 什么时候用深拷贝

适合：

- 嵌套列表。
- 嵌套字典。
- 需要完全独立修改副本。

但深拷贝成本更高。不要无脑使用，先确认是否真的需要。

## 防止函数修改原数据

```python
def add_score(scores, score):
    new_scores = scores.copy()
    new_scores.append(score)
    return new_scores
```

如果是嵌套结构，需要考虑深拷贝。

## 常见错误

### 以为 `b = a` 是复制

这是绑定同一个对象。

### 以为 `copy()` 能复制所有层级

`copy()` 是浅拷贝。

### 不知道函数是否会修改传入数据

函数设计要明确：

- 是修改原对象。
- 还是返回新对象。
