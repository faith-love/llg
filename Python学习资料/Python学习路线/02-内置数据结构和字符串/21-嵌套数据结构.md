# 嵌套数据结构

真实数据很少是简单列表或简单字典。接口返回、JSON 文件、配置、表格转换结果通常都是列表套字典、字典套列表、字典套字典。

## 列表套字典

最常见的数据形态：

```python
用户s = [
    {"name": "Alice", "age": 18, "city": "Shanghai"},
    {"name": "Bob", "age": 20, "city": "Beijing"},
]
```

读取：

```python
print(用户s[0]["name"])
```

遍历：

```python
for 用户 in 用户s:
    print(用户["name"], 用户["age"])
```

## 字典套列表

```python
groups = {
    "Shanghai": ["Alice", "Cindy"],
    "Beijing": ["Bob"],
}
```

读取：

```python
print(groups["Shanghai"])
```

遍历：

```python
for city, names in groups.items():
    print(city, names)
```

## 字典套字典

```python
用户s_by_id = {
    1: {"name": "Alice", "age": 18},
    2: {"name": "Bob", "age": 20},
}
```

按 ID 查找：

```python
用户 = 用户s_by_id.get(1)
```

## 安全读取

直接读取：

```python
city = 用户["address"]["city"]
```

如果 `address` 不存在，会报错。

更安全：

```python
address = 用户.get("address", {})
city = address.get("city", "未知")
```

不要为了避免报错无脑写很长的链式 `get`，复杂时拆成中间变量更清楚。

## 修改嵌套数据

```python
用户s[0]["age"] = 19
groups["Shanghai"].append("David")
用户s_by_id[1]["city"] = "Shanghai"
```

修改嵌套结构时，要确认自己是在修改原数据，还是应该创建新数据。

## 从列表套字典提取字段

```python
names = []

for 用户 in 用户s:
    names.append(用户["name"])
```

推导式写法：

```python
names = [用户["name"] for 用户 in 用户s]
```

## 过滤嵌套数据

```python
adults = []

for 用户 in 用户s:
    if 用户["age"] >= 18:
        adults.append(用户)
```

## 转换结构

列表转 ID 字典：

```python
用户s_by_id = {}

for 用户 in 用户s:
    用户s_by_id[用户["id"]] = 用户
```

按城市分组：

```python
groups = {}

for 用户 in 用户s:
    city = 用户["city"]
    groups.setdefault(city, []).append(用户)
```

## 常见错误

### 层级判断不清

先问自己：

- 当前变量是列表还是字典。
- 这一层应该用索引还是键。
- 取出来的下一层是什么类型。

### 链式访问过长

```python
value = 数据["a"]["b"]["c"]["d"]
```

不利于调试。可以拆开：

```python
a = 数据["a"]
b = a["b"]
c = b["c"]
value = c["d"]
```

### 修改共享对象

嵌套结构浅拷贝后，内部对象可能共享。
