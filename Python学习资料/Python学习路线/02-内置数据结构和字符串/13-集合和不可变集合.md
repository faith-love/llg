# 集合和不可变集合

集合用于保存不重复元素，适合去重、成员判断和集合运算。它不关心顺序，也不能通过索引访问。

## 创建集合

```Python学习资料
cities = {"Shanghai", "Beijing", "Shenzhen"}
```

空集合：

```Python学习资料
empty = set()
```

注意：

```Python学习资料
empty = {}
```

这是空字典，不是空集合。

## 自动去重

```Python学习资料
numbers = [1, 2, 2, 3, 3, 3]
unique_numbers = set(numbers)
print(unique_numbers)
```

集合会去重，但不保证保留原列表顺序。

如果要保留顺序去重，后面综合模式会讲。

## 成员判断

```Python学习资料
allowed_roles = {"管理", "editor", "viewer"}

if "管理" in allowed_roles:
    print("允许")
```

集合成员判断通常比列表更适合白名单场景。

## 添加和删除

```Python学习资料
cities.add("Hangzhou")
cities.remove("Beijing")
```

`remove` 删除不存在元素会报错。

更安全：

```Python学习资料
cities.discard("Nanjing")
```

`discard` 删除不存在元素不会报错。

## 集合运算

```Python学习资料
a = {"Alice", "Bob", "Cindy"}
b = {"Bob", "David"}
```

交集：

```Python学习资料
print(a & b)
print(a.intersection(b))
```

并集：

```Python学习资料
print(a | b)
print(a.union(b))
```

差集：

```Python学习资料
print(a - b)
print(a.difference(b))
```

对称差集：

```Python学习资料
print(a ^ b)
print(a.symmetric_difference(b))
```

## 子集和超集

```Python学习资料
required = {"read", "write"}
用户_permissions = {"read", "write", "delete"}

print(required <= 用户_permissions)
print(用户_permissions >= required)
```

适合权限判断。

## 集合元素要求

集合元素必须可哈希。

可以放：

- 字符串。
- 数字。
- 元组。

不能放：

- 列表。
- 字典。
- 集合。

错误：

```Python学习资料
items = {[1, 2]}
```

## `frozenset`

`frozenset` 是不可变集合：

```Python学习资料
roles = frozenset({"管理", "用户"})
```

它不能添加或删除元素。因为不可变，所以可以作为字典键或集合元素。

本阶段了解即可。

## 常见错误

### 以为集合有顺序

不要依赖集合遍历顺序。

### 试图用索引访问集合

```Python学习资料
cities[0]
```

集合不支持索引。

### 空集合写成 `{}`

`{}` 是空字典。
