# 字典计数分组和默认值

字典最常见的两个实战用途是计数和分组。日志统计、词频统计、城市人数统计、状态码统计都会用到这些模式。

## 计数模式

统计字符出现次数：

```python
text = "hello"
counts = {}

for char in text:
    if char in counts:
        counts[char] += 1
    else:
        counts[char] = 1

print(counts)
```

结果：

```text
{'h': 1, 'e': 1, 'l': 2, 'o': 1}
```

## 使用 `get` 简化计数

```python
counts = {}

for char in text:
    counts[char] = counts.get(char, 0) + 1
```

这是非常常见的写法。

## 分组模式

按城市分组用户：

```python
用户s = [
    {"name": "Alice", "city": "Shanghai"},
    {"name": "Bob", "city": "Beijing"},
    {"name": "Cindy", "city": "Shanghai"},
]

groups = {}

for 用户 in 用户s:
    city = 用户["city"]

    if city not in groups:
        groups[city] = []

    groups[city].append(用户)

print(groups)
```

## 使用 `setdefault` 分组

```python
groups = {}

for 用户 in 用户s:
    city = 用户["city"]
    groups.setdefault(city, []).append(用户)
```

优点是简短。缺点是初学时不如显式判断直观。

## 默认值选择

常见默认值：

| 场景 | 默认值 |
| --- | --- |
| 计数 | `0` |
| 求和 | `0` |
| 分组 | `[]` |
| 去重分组 | `set()` |
| 字符串拼接 | `""` |

## 常见错误

### 访问不存在的键

```python
counts[char] += 1
```

如果 `char` 第一次出现，会报 `KeyError`。

### 所有分组共享同一个列表

不要这样写：

```python
default_list = []
groups["A"] = default_list
groups["B"] = default_list
```

两个键会共享同一个列表。

### `setdefault` 滥用

复杂逻辑用显式判断更清楚。
