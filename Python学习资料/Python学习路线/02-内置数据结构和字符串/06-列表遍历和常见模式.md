# 列表遍历和常见模式

列表的价值不只是保存数据，更重要的是批量处理数据。基础阶段要熟练掌握遍历、累计、过滤、转换、查找这些常见模式。

## 直接遍历元素

```python
scores = [90, 85, 100]

for score in scores:
    print(score)
```

适合只需要元素值的场景。

## 遍历下标和值

```python
for 首页, score in enumerate(scores):
    print(首页, score)
```

适合需要位置的场景。

## 累计求和

```python
total = 0

for score in scores:
    total += score

print(total)
```

也可以使用：

```python
print(sum(scores))
```

学习阶段建议先手写循环，理解累计过程。

## 计数

统计及格人数：

```python
passed_count = 0

for score in scores:
    if score >= 60:
        passed_count += 1

print(passed_count)
```

## 过滤

筛选及格成绩：

```python
passed_scores = []

for score in scores:
    if score >= 60:
        passed_scores.append(score)

print(passed_scores)
```

## 转换

把分数转换成等级：

```python
levels = []

for score in scores:
    if score >= 90:
        levels.append("A")
    elif score >= 80:
        levels.append("B")
    elif score >= 60:
        levels.append("C")
    else:
        levels.append("D")
```

## 查找第一个匹配项

```python
target = None

for score in scores:
    if score >= 90:
        target = score
        break

print(target)
```

注意：如果没有找到，`target` 仍然是 `None`。

## 判断是否全部满足

手写方式：

```python
all_passed = True

for score in scores:
    if score < 60:
        all_passed = False
        break
```

内置方式：

```python
all_passed = all(score >= 60 for score in scores)
```

## 判断是否任意满足

```python
has_full_score = any(score == 100 for score in scores)
```

本阶段可以先会读，推导式后面会讲。

## 批量更新列表

如果要根据下标修改元素：

```python
for 首页, score in enumerate(scores):
    if score < 60:
        scores[首页] = 60
```

如果只是生成新列表，更推荐不要修改原列表：

```python
fixed_scores = []

for score in scores:
    if score < 60:
        fixed_scores.append(60)
    else:
        fixed_scores.append(score)
```

## 常见错误

### 遍历时删除元素

```python
numbers = [1, 2, 3, 4]

for number in numbers:
    if number % 2 == 0:
        numbers.remove(number)
```

这种写法容易跳过元素。更推荐生成新列表：

```python
odd_numbers = []

for number in numbers:
    if number % 2 != 0:
        odd_numbers.append(number)
```

### 只需要元素却使用下标

不必要：

```python
for i in range(len(scores)):
    print(scores[i])
```

更清晰：

```python
for score in scores:
    print(score)
```

## 验收标准

- 能手写累计、计数、过滤、转换。
- 能使用 `enumerate` 处理下标和值。

- 能选择“修改原列表”还是“生成新列表”。
