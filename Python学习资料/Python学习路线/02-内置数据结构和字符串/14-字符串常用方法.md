# 字符串常用方法

字符串是不可变文本序列。输入清洗、日志解析、文件处理、接口字段处理都离不开字符串方法。

## 去除空白

```python
text = "  hello Python学习资料  "

print(text.strip())
print(text.lstrip())
print(text.rstrip())
```

常见输入清洗：

```python
name = input("姓名：").strip()
```

## 大小写转换

```python
text = "Hello Python"

print(text.lower())
print(text.upper())
print(text.title())
print(text.c接口talize())
```

大小写无关比较：

```python
answer = input("yes/no：").strip().lower()
```

## 切分

```python
line = "Alice,18,Shanghai"
parts = line.split(",")
print(parts)
```

默认按空白切分：

```python
text = "hello   Python学习资料"
print(text.split())
```

限制切分次数：

```python
record = "name=Alice=extra"
print(record.split("=", maxsplit=1))
```

## 拼接

使用 `join`：

```python
items = ["Alice", "18", "Shanghai"]
line = ",".join(items)
print(line)
```

不要在大量循环里反复用 `+` 拼接字符串。更推荐先收集到列表，再 `join`。

## 替换

```python
text = "hello Java学习资料"
new_text = text.replace("Java学习资料", "Python学习资料")
```

注意字符串不可变，`replace` 返回新字符串。

## 分行

```python
text = "line1\nline2\nline3"
lines = text.splitlines()
```

适合处理多行文本。

## 去前缀和后缀

```python
filename = "report.csv"

print(filename.removesuffix(".csv"))
print("用户:alice".removeprefix("用户:"))
```

`removeprefix` 和 `removesuffix` 比手写切片更清楚。

## 填充和对齐

```python
text = "42"

print(text.zfill(5))
print(text.rjust(5))
print(text.ljust(5))
print(text.center(5))
```

常用于编号、表格输出。

## 字符串不可变

所有字符串方法都不会修改原字符串：

```python
text = " hello "
text.strip()
print(text)
```

需要重新赋值：

```python
text = text.strip()
```

## 常见错误

### 忘记接收返回值

```python
text = " hello "
text.strip()
```

`text` 没变。

### `split` 分隔符不对

```python
line = "Alice,18,Shanghai"
print(line.split(";"))
```

结果不会按逗号切分。

### `join` 的元素不是字符串

```python
items = ["Alice", 18]
print(",".join(items))
```

会报 `TypeError`。需要先转换：

```python
print(",".join(str(item) for item in items))
```
