# 02-内置数据结构和字符串

这一阶段的目标是掌握 Python 最常用的数据组织方式：字符串、列表、元组、字典、集合，以及它们背后的可变性、哈希、遍历、排序、去重、计数、分组和拷贝问题。

如果 01 阶段解决的是“程序怎么执行”，那么 02 阶段解决的是“数据怎么组织和处理”。后续文件处理、接口数据、数据库结果、Excel 清洗、Web 请求参数，都会大量使用这些内置数据结构。

## 本阶段不做什么

- 不深入算法复杂度证明，但要知道常见操作的大致成本。
- 不深入 pandas，先用内置结构完成基础数据处理。
- 不深入类和对象，先把字典、列表等结构用熟。
- 不追求写很短的“炫技代码”，优先清晰可读。
