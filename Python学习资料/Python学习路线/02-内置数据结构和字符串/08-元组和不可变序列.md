# 元组和不可变序列

元组是不可变序列。它常用于保存固定组合、函数返回多个值、表达一个不应该被修改的数据结构。

## 创建元组

```python
point = (3, 5)
colors = ("red", "green", "blue")
```

括号可以省略，但建议保留，提升可读性：

```python
point = 3, 5
```

## 单元素元组

单元素元组必须有逗号：

```python
value = (1,)
```

不是元组：

```python
value = (1)
```

这里 `value` 是整数 `1`。

## 访问元组

```python
point = (3, 5)

print(point[0])
print(point[1])
```

元组支持索引、切片、遍历、长度。

## 元组不可变

```python
point = (3, 5)
point[0] = 10
```

会报 `TypeError`。

不可变表示元组本身不能替换元素。

## 元组里包含可变对象

```python
数据 = ([1, 2], "ok")
数据[0].append(3)
print(数据)
```

这可以执行。因为元组第一个元素仍然是同一个列表对象，只是列表内容变了。

所以“元组不可变”不是“里面所有对象都不可变”。

## 解包

```python
point = (3, 5)
x, y = point
```

函数返回多个值时，本质上常见就是返回元组：

```python
def get_name_and_age():
    return "Alice", 18


name, age = get_name_and_age()
```

## 交换变量

```python
a = 1
b = 2

a, b = b, a
```

这里也用到了元组打包和解包思想。

## 元组和列表怎么选

| 场景 | 选择 |
| --- | --- |
| 数据长度固定，表示一个整体 | `tuple` |
| 数据会增删改 | `list` |
| 函数返回多个值 | `tuple` |
| 坐标、范围、固定配置 | `tuple` |
| 一批同类记录 | `list` |

示例：

```python
point = (3, 5)
scores = [90, 85, 100]
```

## 常见错误

### 单元素元组少逗号

```python
value = (1)
```

### 以为元组内部可变对象不能改

元组不可变限制的是元素引用，不是引用对象的内部状态。

### 用元组保存需要频繁修改的数据

如果后续要不断追加或删除，用列表。
