# 可变性身份和值

可变性是 Python 数据结构阶段最重要的基础。很多“为什么这个列表也变了”“为什么默认参数有问题”“为什么浅拷贝不够”的问题，都来自这里。

## 身份和值

对象有两个常见观察角度：

- 身份：是不是同一个对象，用 `is` 或 `id()` 观察。
- 值：内容是否相等，用 `==` 观察。

示例：

```Python学习资料
a = [1, 2]
b = [1, 2]

print(a == b)
print(a is b)
print(id(a))
print(id(b))
```

`a == b` 是 `True`，因为内容相等。

`a is b` 是 `False`，因为不是同一个对象。

## 可变对象

可变对象可以原地修改。

常见可变对象：

- `list`
- `dict`
- `set`

示例：

```Python学习资料
numbers = [1, 2]
numbers.append(3)
print(numbers)
```

`numbers` 仍然指向原来的列表对象，只是列表内容变了。

## 不可变对象

不可变对象不能原地修改。

常见不可变对象：

- `int`
- `float`
- `bool`
- `str`
- `tuple`
- `frozenset`
- `bytes`

示例：

```Python学习资料
text = "abc"
text = text.upper()
```

这里不是把原字符串改成大写，而是创建了新字符串，再让 `text` 绑定到新对象。

## 多个变量指向同一个可变对象

```Python学习资料
a = [1, 2]
b = a

b.append(3)

print(a)
print(b)
```

`a` 和 `b` 指向同一个列表，所以通过 `b` 修改后，`a` 也能看到变化。

## 函数参数里的可变对象

```Python学习资料
def add_item(items):
    items.append("new")


values = []
add_item(values)
print(values)
```

函数内部修改了传入的列表对象，外部也会看到变化。

这不是“函数返回了列表”，而是同一个对象被修改了。

## 原地修改和重新绑定

原地修改：

```Python学习资料
items = [1, 2]
items.append(3)
```

重新绑定：

```Python学习资料
items = [1, 2]
items = items + [3]
```

区别：

- `append` 修改原列表。
- `items + [3]` 创建新列表，再重新绑定变量。

## `==` 和 `is`

`==` 比较值：

```Python学习资料
[1, 2] == [1, 2]
```

`is` 比较身份：

```Python学习资料
a is b
```

常见规则：

- 判断内容相等，用 `==`。
- 判断是否为 `None`，用 `is None`。
- 不要用 `is` 比较字符串或数字值。

## 常见错误

### 误以为赋值会复制列表

```Python学习资料
a = [1, 2]
b = a
```

这不是复制，而是多一个名字指向同一对象。

### 修改函数参数导致外部数据变化

如果函数不应该修改原数据，可以先复制：

```Python学习资料
def add_item(items):
    new_items = items.copy()
    new_items.append("new")
    return new_items
```

### 把 `is` 当作 `==`

不建议：

```Python学习资料
if name is "Alice":
    print("ok")
```

应该：

```Python学习资料
if name == "Alice":
    print("ok")
```
