# 推导式

推导式用于从一个可迭代对象生成新的列表、字典或集合。它能让简单转换和过滤更简洁，但过度使用会降低可读性。

## 列表推导式

普通写法：

```python
numbers = [1, 2, 3, 4]
squares = []

for number in numbers:
    squares.append(number * number)
```

推导式写法：

```python
squares = [number * number for number in numbers]
```

## 带条件过滤

```python
numbers = [1, 2, 3, 4, 5]
even_numbers = [number for number in numbers if number % 2 == 0]
```

含义：

- 遍历 `numbers`。
- 只保留偶数。
- 生成新列表。

## 转换加过滤

```python
scores = [55, 60, 80, 90]
passed_levels = [score + 5 for score in scores if score >= 60]
```

## 字典推导式

```python
names = ["Alice", "Bob"]
name_lengths = {name: len(name) for name in names}
```

结果：

```python
{"Alice": 5, "Bob": 3}
```

## 集合推导式

```python
words = ["apple", "banana", "apple"]
first_letters = {word[0] for word in words}
```

集合推导式会自动去重。

## 条件表达式和过滤条件

过滤条件写在后面：

```python
even_numbers = [n for n in numbers if n % 2 == 0]
```

条件表达式写在前面：

```python
labels = ["even" if n % 2 == 0 else "odd" for n in numbers]
```

两者作用不同。

## 嵌套推导式

```python
pairs = [(x, y) for x in range(2) for y in range(3)]
```

嵌套推导式可读性容易下降。基础阶段能看懂即可，不要强行使用。

## 推导式的可读性边界

适合推导式：

- 简单转换。
- 简单过滤。
- 创建字典映射。
- 创建集合去重。

不适合推导式：

- 多层嵌套。
- 复杂分支。
- 需要异常处理。
- 需要多个中间步骤。

复杂时写普通循环更清楚。

## 常见错误

### 把过滤条件和条件表达式混淆

```python
[n if n > 0 for n in numbers]
```

这是错误语法。

如果只是过滤：

```python
[n for n in numbers if n > 0]
```

如果要替换：

```python
[n if n > 0 else 0 for n in numbers]
```

### 推导式太长

一行代码太复杂时，维护成本会很高。

## 练习

1. 用列表推导式生成 1-10 的平方。
2. 筛选偶数。
3. 把姓名列表全部转成小写。
4. 用字典推导式生成姓名长度映射。
5. 用集合推导式提取首字母。
6. 把复杂推导式改写成普通循环。
7. 把普通循环改写成清晰推导式。

## 验收标准

- 能写列表、字典、集合推导式。
- 能区分过滤条件和条件表达式。
- 能判断什么时候不该使用推导式。
- 能把推导式和普通循环互相转换。
