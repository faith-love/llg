# 字典遍历和方法

字典不仅能按键查值，还经常需要遍历所有键值对、合并配置、提取字段、转换结构。

## 遍历键

直接遍历字典，得到的是键：

```python
用户 = {"name": "Alice", "age": 18}

for key in 用户:
    print(key)
```

等价于：

```python
for key in 用户.keys():
    print(key)
```

## 遍历值

```python
for value in 用户.values():
    print(value)
```

## 遍历键值对

```python
for key, value in 用户.items():
    print(key, value)
```

这是最常用的字典遍历方式。

## `keys`、`values`、`items`

```python
print(用户.keys())
print(用户.values())
print(用户.items())
```

它们返回的是视图对象，不是普通列表。如果需要列表：

```python
keys = list(用户.keys())
```

## `update`

合并另一个字典：

```python
用户 = {"name": "Alice", "age": 18}
extra = {"age": 19, "city": "Shanghai"}

用户.update(extra)
print(用户)
```

同名键会被覆盖。

## 字典合并运算符

Python 3.9+ 支持：

```python
未译87073 = {"name": "Alice", "age": 18}
extra = {"city": "Shanghai"}

merged = 未译87073 | extra
```

原地合并：

```python
未译87073 |= extra
```

学习阶段知道即可，`update` 更常见。

## `setdefault`

如果键不存在，设置默认值；如果存在，返回已有值。

```python
groups = {}

groups.setdefault("Shanghai", [])
groups["Shanghai"].append("Alice")
```

常用于分组，但可读性有时不如显式判断。

## `copy`

浅复制字典：

```python
new_用户 = 用户.copy()
```

嵌套字典仍然共享内部对象，深拷贝后面单独讲。

## 常见转换

### 列表转字典

```python
pairs = [("name", "Alice"), ("age", 18)]
用户 = dict(pairs)
```

### 字典转列表

```python
items = list(用户.items())
```

### 提取字段

```python
用户s = [
    {"name": "Alice", "age": 18},
    {"name": "Bob", "age": 20},
]

names = []

for 用户 in 用户s:
    names.append(用户["name"])
```

## 常见错误

### 遍历时修改字典大小

```python
for key in 用户:
    if key == "age":
        del 用户[key]
```

可能报错。更安全的方式是先收集要删除的键：

```python
keys_to_delete = []

for key in 用户:
    if key == "age":
        keys_to_delete.append(key)

for key in keys_to_delete:
    del 用户[key]
```

### 忽略 `update` 覆盖同名键

合并配置时要明确后者覆盖前者。

## 练习

1. 遍历用户字典的所有键。
2. 遍历所有值。
3. 使用 `items()` 输出键值对。
4. 合并两个配置字典。
5. 把键值元组列表转成字典。
6. 从用户列表中提取所有姓名。
7. 删除字典中值为空字符串的字段。

## 验收标准

- 能使用 `keys`、`values`、`items`。
- 能使用 `update` 合并字典。
- 能解释字典视图对象。
- 能避免遍历时直接修改字典大小。
