# Python 详细学习路线

这份路线面向从零基础到能独立完成 Python 自动化脚本、Web API、数据处理和工程化项目的学习过程。主线不是“记住语法”，而是逐步形成可交付能力：能写、能调、能测、能部署、能解释取舍。

## 版本基线

截至 2026-05-09，Python 官方下载页显示最新稳定下载版本为 Python 3.14.4；Python Developer's Guide 显示 Python 3.14 处于 bugfix 阶段，Python 3.13 也处于 bugfix 阶段，Python 3.12 处于 安全 阶段。

新学习主线建议使用 Python 3.14；如果教程、公司项目或关键依赖暂未适配 3.14，可以使用 Python 3.13 或 3.12，但要记录原因。

## 学习原则

- 每个知识点都要形成“概念解释 + 可运行示例 + 常见错误 + 练习 + 验收标准”。
- 每周至少完成一个可运行产出，哪怕只是一个小脚本。
- 不把所有代码写在一个文件里，从第一阶段就养成目录、命名、提交记录和复盘习惯。
- 学 Python 不只学语法，还要学依赖管理、调试、测试、数据格式、网络、数据库和部署。
- 遇到错误先读报错第一行和最后一行，再做最小复现，不直接整段复制搜索。
