# 项目五：性能和安全加固项目

性能和安全加固项目不是从零写功能，而是对已有项目做诊断、优化和防护。它能体现你是否具备工程成熟度。

## 项目目标

选择一个已有项目，完成：

- 性能基准。
- profile 分析。
- 内存排查。
- 安全检查。
- 修复和对比。
- 加固报告。

## 性能部分

必须包含：

- 优化前耗时。
- cProfile 报告。
- 热点函数。
- 优化方案。
- 优化后耗时。
- 取舍说明。

可选：

- line profiler。
- tracemalloc。
- 并发调优。
- 数据库查询优化。

## 安全部分

检查：

- 输入校验。
- SQL 注入。
- 命令注入。
- 路径穿越。
- 文件上传。
- 反序列化。
- token 日志。
- CO未译25173S。
- 权限校验。
- 依赖漏洞。

```markdown
# 性能和安全加固报告

## 背景

## 性能基准

## 优化前后对比

## 安全风险清单

## 修复记录

## 剩余风险
```

## 常见优化方向

- list 成员测试改 set。
- 双重循环改 dict 索引。
- 全量读取改流式。
- 单条写入改批量。
- N+1 查询改批量查询。
- 无上限并发改限流。
- 无缓存或错误缓存策略修复。

## 常见安全修复

- SQL 参数化。
- subprocess 参数列表。
- 路径 resolve 检查。
- token 脱敏。
- 上传文件重命名。
- 限制 CO未译25173S。
- 增加权限校验。

## 验收标准

- 有优化前后数据。
- 有 profile 证据。
- 有安全风险清单。
- 至少修复 3 个性能或安全问题。
- 有剩余风险说明。
- 有测试覆盖关键修复。
