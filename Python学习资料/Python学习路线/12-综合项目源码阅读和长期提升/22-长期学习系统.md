# 长期学习系统

长期提升靠系统，而不是靠一时热情。学习系统要能持续输入、输出、反馈和复盘。

## 学习闭环

```text
目标 -> 学习 -> 练习 -> 项目 -> 反馈 -> 复盘 -> 调整
```

只输入不输出，容易忘。只做项目不复盘，经验无法沉淀。

## 周计划

每周固定：

- 一个学习主题。
- 一个实践任务。
- 一个输出文档。
- 一次复盘。

示例：

```markdown
## 本周目标

## 计划任务

## 完成结果

## 问题

## 下周调整
```

## 月复盘

每月回答：

- 完成了什么？
- 哪些任务拖延？
- 哪些问题重复出现？
- 哪个项目有进展？
- 哪个能力短板最明显？
- 下月重点是什么？

## 刻意练习

针对薄弱项重复训练：

- 类型注解。
- SQL。
- 测试。
- 并发。
- Docker。
- 性能分析。
- 安全检查。

练习要有反馈，不是重复做简单题。

## 输入来源

稳定来源：

- 官方文档。
- 标准库源码。
- 高质量开源项目。
- 技术书。
- 真实项目问题。
- 代码评审反馈。

少依赖碎片短视频和无上下文文章。

## 输出形式

- 项目。
- 文档。
- 源码笔记。
- 复盘。
- 分享。
- P未译25173。
- 未译25173eview。

## 常见错误

### 只收藏不实践

收藏不是学习。

### 频繁换方向

长期没有积累。

### 没有复盘

同样错误反复出现。

### 目标过大

无法执行。

## 练习

1. 写 4 周学习计划。
2. 写月复盘模板。
3. 选择 3 个薄弱项。
4. 为每个薄弱项设计练习。
5. 建立项目维护日程。
6. 建立源码阅读日程。
7. 建立技术写作日程。

## 验收标准

- 有固定周计划。
- 有月复盘。
- 有项目和文档输出。
- 能根据反馈调整学习路线。
