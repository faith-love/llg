# 12-综合项目源码阅读和长期提升

这一阶段的目标是把前 11 个阶段的知识转化为长期可展示、可复盘、可持续提升的能力体系。你不再只按知识点学习，而是通过综合项目、源码阅读、开源协作、面试复盘和长期维护来巩固能力。

如果前面阶段解决的是“学会具体能力”，第 12 阶段解决的是“如何持续证明、升级和迁移这些能力”。

## 本阶段产出

- 至少 3 个可运行、可演示、可测试的综合项目。
- 每个项目都有 说明、需求说明、技术方案、测试报告和复盘。
- 至少 1 个项目完成部署或Docker化运行。
- 至少 1 份源码阅读笔记。
- 至少 1 份代码评审记录。
- 至少 1 份项目面试讲解稿。
- 一份 Python 长期学习计划。
- 一份最终路线验收报告。

## 本阶段不做什么

- 不再堆零散练习而不形成作品。
- 不做无法运行、无法演示、无法验收的项目。
- 不只读源码不记录调用链和设计取舍。
- 不把面试准备等同于背题。
- 不追逐每个新框架，而是维护自己的技术雷达和迁移节奏。
