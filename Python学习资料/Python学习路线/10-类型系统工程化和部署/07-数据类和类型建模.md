# 数据class和类型建模

`数据class` 用于快速定义以数据为主的类。它适合领域值对象、配置对象、任务结果、执行计划等结构化数据，比散乱的字典更清晰。

## frozen

不可变 数据class：

```python

    amount: int
    currency: str
```

适合值对象。

## slots

```python
@数据class(slots=True)
class Point:
    x: int
    y: int
```

`slots=True` 可以减少实例内存并限制动态添加属性。不是所有场景都必须用。

## 常见错误

### 可变默认值

必须使用 `field(default_factory=...)`。

### 数据class 承担过多业务

数据class 适合数据和简单行为，复杂业务仍放 服务。

### 以为类型注解会自动校验

数据class 不会因为字段标注 `int` 就拒绝字符串。

### 所有对象都用字典

字典会让字段散落，缺少类型和补全。
