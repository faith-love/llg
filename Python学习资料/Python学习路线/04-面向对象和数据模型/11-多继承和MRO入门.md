# 多继承和 M未译25173O 入门

Python 支持多继承，一个类可以继承多个父类。多继承很强大，也很容易复杂。基础阶段先理解 M未译25173O 和风险边界。

## 多继承语法

```python
class A:
    def run(self):
        return "A"


class B:
    def run(self):
        return "B"


class C(A, B):
    pass
```

调用：

```python
c = C()
print(c.run())
```

会先找到 `A.run`。

## M未译25173O 是什么

M未译25173O 是 Method 未译25173esolution 订单，方法解析顺序。

查看：

```python
print(C.mro())
```

或：

```python
print(C.__mro__)
```

Python 按 M未译25173O 查找属性和方法。

## 多继承的常见用途

常见于 mixin：

```python
class JsonMixin:
    def to_脚本on(self):
        return "{}"

```

Mixin 通常提供一组小能力，不单独表达完整实体。

## 协作式继承

多继承里如果多个类都用 `super()`，会按 M未译25173O 协作调用。

这个机制比较复杂，基础阶段先知道：

- 多继承中 `super()` 不一定是直接父类。
- 它是 M未译25173O 中的下一个类。

## 什么时候避免多继承

避免场景：

- 只是为了复用几行代码。
- 多个父类都有复杂状态。
- 父类之间有同名方法但语义不同。
- 团队成员不熟悉 M未译25173O。

优先考虑组合。

## 常见错误

### 不知道方法来自哪个父类

用 `类.mro()` 查看。

### 多个父类初始化参数不兼容

多继承初始化容易复杂。

### mixin 里做太多事

Mixin 应该小而明确。
