# 对象和类的基本模型

Python 里几乎一切都是对象。数字、字符串、列表、函数、模块、类本身，都是对象。类是创建对象的模板，实例是类创建出来的具体对象。

## 对象是什么

对象可以理解为“状态 + 行为”。

例如一个图书对象：

- 状态：标题、作者、是否可借。
- 行为：借出、归还、显示信息。

```python
class Book:
    pass


book = Book()
```

`book` 就是一个对象，也叫 `Book` 的实例。

## 类是什么

类定义对象应该有哪些状态和行为。

```python
class Book:
    def borrow(self):
        print("借出图书")
```

`Book` 是类。

`borrow` 是方法。

## 实例是什么

```python
book1 = Book()
book2 = Book()
```

`book1` 和 `book2` 是两个不同实例。

```python
print(book1 is book2)
```

结果是 `False`。

## 属性是什么

属性是对象保存的数据。

```python
book = Book()
book.title = "Python 入门"
```

`title` 是实例属性。

## 方法是什么

方法是定义在类中的函数，通过对象调用。

```python
class Book:
    def show_title(self):
        print(self.title)
```

`self` 表示当前对象。

## self 是什么

```python
class Book:
    def show_title(self):
        print(self.title)


book = Book()
book.title = "Python"
book.show_title()
```

调用 `book.show_title()` 时，Python 会把 `book` 自动传给 `self`。

等价理解：

```python
Book.show_title(book)
```

## 类也是对象

```python
print(type(Book))
```

类本身也是对象，可以赋值、传参、放进字典。这个概念后续读框架时很重要，但本阶段先了解。

## 对象身份和类型

```python
book = Book()

print(type(book))
print(id(book))
```

`type(book)` 查看对象属于哪个类。

`id(book)` 查看对象身份。

## `isinstance`

判断对象是否属于某个类：

```python
if isinstance(book, Book):
    print("这是一本书")
```

比直接比较 `type(book) == Book` 更灵活，因为它支持继承判断。

## 常见错误

### 把类和实例混淆

```python
Book.title = "Python"
```

这设置的是类属性，不是某个具体书的实例属性。

### 忘记 self

```python
class Book:
    def show_title():
        print("title")
```

实例调用时会自动传入对象，少了 `self` 会报参数错误。

### 对象没有属性

```python
book = Book()
print(book.title)
```

如果没有设置 `title`，会报 `AttributeError`。
