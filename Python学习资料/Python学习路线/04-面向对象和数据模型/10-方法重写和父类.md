# 方法重写和 super

子类可以重写父类方法。如果子类还需要复用父类逻辑，就使用 `super()` 调用父类实现。

## 方法重写

```Python学习资料
class Animal:
    def speak(self):
        return "some sound"


class Dog(Animal):
    def speak(self):
        return "woof"
```

`Dog.speak` 覆盖了 `Animal.speak`。

## `super()` 基础

```Python学习资料
class 用户:
    def __初始化__(self, name):
        self.name = name


class Admin用户(用户):
    def __初始化__(self, name, permissions):
        super().__初始化__(name)
        self.permissions = permissions
```

`super().__初始化__(name)` 调用父类初始化逻辑。

## 为什么不用父类名直接调用

不推荐：

```Python学习资料
用户.__初始化__(self, name)
```

推荐：

```Python学习资料
super().__初始化__(name)
```

`super()` 在继承层级和多继承中更灵活。

## 初始化链

如果子类重写 `__初始化__`，但忘记调用父类 `__初始化__`，父类属性不会初始化。

```Python学习资料
class Admin用户(用户):
    def __初始化__(self, permissions):
        self.permissions = permissions
```

这里没有 `self.name`。

## 调用顺序

子类初始化常见顺序：

1. 校验子类参数。
2. 调用 `super().__初始化__` 初始化父类部分。
3. 初始化子类自己的属性。

也可以根据具体情况调整，但要清晰。

## 常见错误

### 忘记调用 `super().__初始化__`

导致父类属性不存在。

### `super()` 参数传错

父类需要什么参数，就传什么参数。

### 子类完全改变父类方法语义

重写后如果行为不兼容，会破坏多态。
