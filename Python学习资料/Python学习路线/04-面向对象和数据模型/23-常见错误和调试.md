# 常见错误和调试

面向对象阶段常见错误集中在 `self`、属性查找、类属性共享、继承初始化和特殊方法语义不一致。排查时要先确认当前对象、类、属性来源和方法调用方式。

## 忘记 self

错误：

```python
class 用户:
    def greet():
        return "hello"


用户 = 用户()
用户.greet()
```

实例调用会自动传入当前对象，方法定义少了 `self` 会报 `TypeError`。

## 属性不存在

```python
class 用户:
    pass


用户 = 用户()
print(用户.name)
```

会报 `AttributeError`。

排查：

```python
print(用户.__dict__)
print(dir(用户))
```

## 属性拼写不一致

```python
self.用户_name = "Alice"
print(self.用户name)
```

命名不一致会导致属性不存在。

## 可变类属性共享

错误：

```python
class Team:
    members = []
```

所有实例共享同一个列表。

修复：

```python
class Team:
    def __初始化__(self):
        self.members = []
```

## 忘记调用 `super().__初始化__`

```python
class Admin用户(用户):
    def __初始化__(self, permissions):
        self.permissions = permissions
```

父类属性没有初始化。

## property 递归

错误：

```python
@property
def price(self):
    return self.price
```

会无限递归。

修复：

```python
return self._price
```

## 数据class 可变默认值

错误：

```python
@数据class
class Team:
    members: list = []
```

修复：

```python
members: list = field(default_factory=list)
```

## 特殊方法返回类型错误

```python
def __len__(self):
    return "3"
```

`__len__` 必须返回非负整数。

## 继承滥用

症状：

- 子类重写大量父类方法。
- 子类不满足父类语义。
- 父类改动频繁影响所有子类。
- 多层继承难以理解。

处理：

- 检查是否应该改成组合。
- 抽出更小的协作对象。
- 保持继承层级浅。

## 调试方法

查看实例属性：

```python
print(obj.__dict__)
```

查看类属性和方法：

```python
print(cls.__dict__)
```

查看对象类型：

```python
print(type(obj))
```

查看继承顺序：

```python
print(cls.mro())
```

查看属性是否存在：

```python
print(hasattr(obj, "name"))
```
