# 类定义实例和属性

类定义了对象的结构和行为。实例属性保存每个对象自己的状态。掌握类定义和实例属性，是面向对象的第一步。

## 定义类

```Python学习资料
class 用户:
    pass
```

类名建议使用大驼峰命名：

```Python学习资料
class 用户Profile:
    pass
```

## 创建实例

```Python学习资料
用户 = 用户()
```

调用类名就会创建实例。

## 动态添加属性

```Python学习资料
用户.name = "Alice"
用户.age = 18
```

Python 允许动态添加属性，但实际项目中更推荐在 `__初始化__` 中统一初始化，避免属性不完整。

## 访问属性

```Python学习资料
print(用户.name)
```

如果属性不存在，会报 `AttributeError`。

## 修改属性

```Python学习资料
用户.age = 19
```

## 删除属性

```Python学习资料
del 用户.age
```

删除后再次访问会报错。

## 查看对象属性

```Python学习资料
print(用户.__dict__)
```

很多普通对象的实例属性保存在 `__dict__` 中。

示例：

```Python学习资料
{'name': 'Alice', 'age': 18}
```

## 属性命名

属性名建议：

- 小写加下划线。
- 表达业务含义。
- 避免和方法名冲突。

推荐：

```Python学习资料
用户_name
created_at
is_active
```

## 属性不完整的风险

```Python学习资料
用户1 = 用户()
用户1.name = "Alice"

用户2 = 用户()

print(用户2.name)
```

`用户2` 没有 `name`，会报错。

这就是为什么需要 `__初始化__`。

## 类体中的代码

```Python学习资料
class Demo:
    print("定义类时执行")
```

类体代码会在类定义时执行，不是创建实例时执行。不要在类体中放复杂业务逻辑。

## 常见错误

### 属性拼写不一致

```Python学习资料
用户.用户_name = "Alice"
print(用户.用户name)
```

两个名字不同。

### 动态属性导致对象不一致

不同实例有不同属性，后续代码很难保证安全访问。

### 类体代码误当实例初始化

实例初始化应该写在 `__初始化__`。
