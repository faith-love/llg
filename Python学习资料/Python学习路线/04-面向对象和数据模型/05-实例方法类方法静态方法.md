# 实例方法类方法静态方法

Python 类中常见三种方法：实例方法、类方法、静态方法。它们的区别在于第一个参数和适用场景。

## 实例方法

最常见的方法。

```python
class 用户:
    def __初始化__(self, name):
        self.name = name

    def greet(self):
        return f"你好，{self.name}"
```

调用：

```python
用户 = 用户("Alice")
print(用户.greet())
```

实例方法第一个参数是 `self`，表示当前实例。

## 类方法

类方法使用 `@classmethod`，第一个参数是 `cls`，表示当前类。

```python
class 用户:
    def __初始化__(self, name):
        self.name = name

    @classmethod
    def from_dict(cls, 数据):
        return cls(数据["name"])
```

调用：

```python
用户 = 用户.from_dict({"name": "Alice"})
```

类方法常用于：

- 替代构造器。
- 从字典、字符串、文件记录创建对象。
- 需要访问类本身的逻辑。

## 静态方法

静态方法使用 `@静态资源method`，不自动接收 `self` 或 `cls`。

```python
class 用户:
    @静态资源method
    def is_valid_name(name):
        return bool(name and name.strip())
```

调用：

```python
print(用户.is_valid_name("Alice"))
```

静态方法适合放和类相关、但不需要访问实例或类状态的工具函数。

## 什么时候用哪种

| 场景 | 方法类型 |
| --- | --- |
| 需要访问或修改实例属性 | 实例方法 |
| 需要创建实例或访问类 | 类方法 |
| 只是和类相关的工具函数 | 静态方法 |

## `self` 和 `cls` 只是约定名

技术上可以用别的名字，但强烈建议遵守约定：

- 实例方法第一个参数叫 `self`。
- 类方法第一个参数叫 `cls`。

## 常见错误

### 实例方法忘记 self

```python
class 用户:
    def greet():
        return "hello"
```

实例调用会报参数错误。

### 类方法忘记 `@classmethod`

```python
class 用户:
    def from_dict(cls, 数据):
        return cls(数据["name"])
```

没有装饰器时，它只是普通实例方法。

### 静态方法访问 self

静态方法没有 `self`。

如果需要访问实例属性，就应该用实例方法。
