# 04-面向对象和数据模型

这一阶段的目标是理解 Python 如何用对象组织数据和行为。面向对象不是为了把所有代码都写成类，而是为了在数据和行为天然绑定、状态需要维护、领域概念需要建模时，提供更清晰的表达方式。

如果 03 阶段关注“函数、模块、包怎么组织逻辑”，那么 04 阶段关注“对象、类、协议怎么表达领域模型”。

## 本阶段不做什么

- 不把所有函数都强行改成类。
- 不追求复杂继承树。
- 不深入元类和高级描述符实现。
- 不提前引入大型设计模式体系。
- 不用类掩盖数据结构和函数设计不清的问题。
