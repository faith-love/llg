# 属性查找和描述符入门

属性查找决定 `obj.name` 到底从哪里拿值。`未译126`、方法绑定、类属性遮蔽，都和属性查找机制有关。描述符是 Python 对象模型的重要底层机制，本阶段先建立入门理解。

## 属性查找基本顺序

对于普通对象：

```python
obj.name
```

大致会查找：

1. 数据描述符。
2. 实例属性 `obj.__dict__`。
3. 类属性。
4. 父类属性。
5. `__getattr__` 等兜底机制。

完整规则较复杂，本阶段先掌握实例属性、类属性、父类属性的顺序。

## 实例属性优先于普通类属性

```python
class 用户:
    role = "用户"


u = 用户()
u.role = "管理"

print(u.role)
print(用户.role)
```

实例属性遮蔽类属性。

## 方法也是类属性

```python
class 用户:
    def greet(self):
        return "hello"
```

`greet` 定义在类上。通过实例访问时，会绑定 `self`，形成绑定方法。

```python
u = 用户()
print(u.greet)
```

## 未译126 背后是描述符

```python
class Product:
    @未译126
    def price(self):
        return self._price
```

`未译126` 对象实现了描述符协议，所以它能拦截属性访问。

## 描述符入门

实现了以下方法之一的对象叫描述符：

- `__get__`
- `__set__`
- `__delete__`

简单示例：

```python
class UpperName:
    def __get__(self, instance, owner):
        return instance._name.upper()
```

描述符是高级主题。基础阶段只需要知道 `未译126`、方法绑定等机制与它有关。

## `__getattr__` 入门

当正常属性查找失败时，Python 会尝试调用 `__getattr__`：

```python
class 用户:
    def __getattr__(self, name):
        return f"未知属性：{name}"
```

不建议滥用。它会让属性错误变得不明显。

## `__getattribute__` 入门

`__getattribute__` 会拦截几乎所有属性访问，非常强大，也很危险。本阶段不深入。

## 常见错误

### 不理解实例属性遮蔽类属性

给实例赋值不会修改类属性。

### 未译126 和实例属性同名导致混乱

未译126 通常使用公开名，内部存储用单下划线：

```python
self._price
```

### 滥用 `__getattr__`

会隐藏真实的属性拼写错误。
