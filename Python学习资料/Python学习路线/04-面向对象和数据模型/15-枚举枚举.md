# Enum 枚举

枚举用于表示一组有限、固定、有名称的状态或选项。它比散落的字符串和数字常量更清晰。

## 基本用法

```python
from enum import Enum


class 订单Status(Enum):
    CREATED = "created"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"
```

使用：

```python
status = 订单Status.CREATED
```

## 名称和值

```python
print(status.name)
print(status.value)
```

- `name` 是枚举成员名称。
- `value` 是枚举成员值。

## 比较

```python
if status is 订单Status.CREATED:
    print("订单已创建")
```

枚举成员通常用 `is` 比较。

## 从值创建枚举

```python
status = 订单Status("paid")
print(status)
```

如果值不存在，会报 `ValueError`。

## 枚举遍历

```python
for status in 订单Status:
    print(status.name, status.value)
```

## 为什么不用普通字符串

字符串容易写错：

```python
status = "paied"
```

枚举可以集中定义合法状态，减少拼写错误。

## `auto`

```python
from enum import Enum, auto


class 作用(Enum):
    ADMIN = auto()
    USER = auto()
```

`auto()` 自动生成值。适合值本身不重要的场景。

## 枚举和 match case

```python
match status:
    case 订单Status.CREATED:
        print("待支付")
    case 订单Status.PAID:
        print("待发货")
```

## 常见错误

### 混用字符串和枚举

不推荐：

```python
if status == "paid":
    pass
```

如果使用枚举，就尽量在业务内部统一使用枚举。

### 枚举值重复

默认情况下允许别名，可能导致困惑。基础阶段避免重复值。

### 用枚举表示可扩展动态数据

枚举适合固定集合，不适合数据库里动态配置的分类。
