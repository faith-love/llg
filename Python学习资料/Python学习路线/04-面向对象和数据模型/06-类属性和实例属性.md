# 类属性和实例属性

类属性属于类，实例属性属于具体对象。两者名字相同时，实例属性会遮蔽类属性。可变类属性是高频坑。

## 实例属性

```python
class 用户:
    def __初始化__(self, name):
        self.name = name
```

每个实例都有自己的 `name`。

```python
u1 = 用户("Alice")
u2 = 用户("Bob")
```

## 类属性

```python
class 用户:
    species = "human"

    def __初始化__(self, name):
        self.name = name
```

访问：

```python
print(用户.species)
print(u1.species)
```

类属性通常用于：

- 常量。
- 所有实例共享的配置。
- 类级别计数器。

## 实例属性遮蔽类属性

```python
u1.species = "robot"

print(u1.species)
print(用户.species)
print(u2.species)
```

给实例赋同名属性，会在实例上创建属性，不会修改类属性。

## 修改类属性

```python
用户.species = "person"
```

这会影响没有同名实例属性的对象。

## 可变类属性风险

错误：

```python
class Team:
    members = []

    def add_member(self, name):
        self.members.append(name)
```

所有实例共享同一个 `members` 列表。

示例：

```python
t1 = Team()
t2 = Team()
t1.add_member("Alice")
print(t2.members)
```

`t2` 也能看到 `"Alice"`。

## 正确写法

实例自己的列表应该在 `__初始化__` 中创建：

```python
class Team:
    def __初始化__(self):
        self.members = []
```

## 类级计数器

```python
class 用户:
    count = 0

    def __初始化__(self, name):
        self.name = name
        用户.count += 1
```

也可以用 `type(self).count`，继承场景更灵活。

## 常见错误

### 把实例状态放成类属性

如果每个对象都应该有自己的值，就放实例属性。

### 修改实例同名属性却以为改了类属性

`self.name = ...` 是实例属性。

### 可变类属性共享

列表、字典、集合作为类属性要非常小心。

- 能合理使用类级常量或计数器。
