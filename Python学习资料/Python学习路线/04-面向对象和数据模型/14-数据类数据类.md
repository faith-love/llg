# 数据class 数据类

`数据class` 用于快速定义主要保存数据的类。它可以自动生成 `__初始化__`、`__repr__`、`__eq__` 等方法，减少样板代码。

## 基本用法

```python
from 数据classes import 数据class


@数据class
class 用户:
    name: str
    age: int
```

使用：

```python
用户 = 用户("Alice", 18)
print(用户)
```

自动生成：

- `__初始化__`
- `__repr__`
- `__eq__`

## 默认值

```python
@数据class
class 用户:
    name: str
    age: int = 0
    active: bool = True
```

有默认值的字段要放在无默认值字段后面。

## 可变默认值

不能直接写：

```python
@数据class
class Team:
    members: list = []
```

应该使用 `field(default_factory=...)`：

```python
from 数据classes import 数据class, field


@数据class
class Team:
    members: list[str] = field(default_factory=list)
```

这样每个实例都有自己的列表。

## 不可变数据类

```python
@数据class(frozen=True)
class Point:
    x: int
    y: int
```

创建后不能修改属性：

```python
point = Point(1, 2)
point.x = 3
```

会报错。

## 排序

```python
@数据class(order=True)
class Score:
    value: int
    name: str
```

可以比较和排序。

排序按字段定义顺序进行。实际项目中要谨慎，确保排序语义清晰。

## 字段配置

```python
from 数据classes import field


@数据class
class 用户:
    name: str
    password: str = field(repr=False)
```

`repr=False` 表示打印对象时不显示该字段。

适合隐藏敏感字段。

## `__post_初始化__`

初始化后校验：

```python
@数据class
class Product:
    name: str
    price: float

    def __post_初始化__(self):
        if self.price < 0:
            raise ValueError("价格不能小于 0")
```

## 数据class 适合什么

适合：

- 数据对象。
- 配置对象。
- 值对象。
- 简单领域实体。
- 减少样板代码。

不适合：

- 行为复杂的对象。
- 初始化过程很复杂。
- 属性大量动态变化。
- 需要精细控制对象生命周期。

## 常见错误

### 可变默认值直接写列表

使用 `default_factory`。

### 把所有类都写成 数据class

数据类适合数据为主的类，不是所有类都适合。

### 类型标注不准确

数据class 依赖类型标注定义字段。字段必须写标注。

## 验收标准

- 能定义 数据class。
- 能使用默认值和 `default_factory`。
- 能使用 `frozen=True`。

- 能判断 数据class 的适用边界。
