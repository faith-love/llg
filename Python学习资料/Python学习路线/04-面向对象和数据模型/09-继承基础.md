# 继承基础

继承用于表达“子类是父类的一种”。它可以复用父类行为，也可以扩展或重写行为。但继承会增加耦合，不能为了少写几行代码就滥用。

## 基本语法

```python
class Animal:
    def speak(self):
        return "some sound"


class Dog(Animal):
    pass
```

`Dog` 继承 `Animal`。

调用：

```python
dog = Dog()
print(dog.speak())
```

子类可以使用父类方法。

## 继承表达 is-a

适合：

- Dog 是 Animal 的一种。
- Circle 是 Shape 的一种。
- CsvExporter 是 Exporter 的一种。

不适合：

- 用户 有 Address。
- 订单 有 订单Item。
- ReportService 使用 FORMatter。

## 子类添加方法

```python
class Dog(Animal):
    def wag_tail(self):
        return "wagging"
```

子类可以在父类基础上扩展行为。

## 子类重写方法

```python
class Dog(Animal):
    def speak(self):
        return "woof"
```

子类方法同名时，会覆盖父类方法。

## `isinstance` 和继承

```python
dog = Dog()

print(isinstance(dog, Dog))
print(isinstance(dog, Animal))
```

两个都是 `True`。

## `issubclass`

```python
print(issubclass(Dog, Animal))
```

判断一个类是否是另一个类的子类。

## 继承的成本

继承会带来：

- 父类变化影响子类。
- 子类必须理解父类内部约定。
- 多层继承难排查。
- 错误抽象会让模型僵硬。

## 常见错误

### 为复用代码滥用继承

如果不是 is-a 关系，先考虑组合。

### 继承层级太深

超过 2-3 层就要警惕。

### 父类职责太多

父类越大，子类越难维护。
