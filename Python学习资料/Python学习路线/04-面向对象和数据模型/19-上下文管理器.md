# 上下文管理器

上下文管理器用于管理资源的进入和退出，最常见的例子是 `with open(...) as f`。它通过 `__enter__` 和 `__exit__` 实现。

## with 的作用

```Python学习资料
with open("数据.txt", encoding="utf-8") as f:
    content = f.read()
```

`with` 能保证代码块结束后资源被正确关闭。

## 自定义上下文管理器

```Python学习资料
class DemoContext:
    def __enter__(self):
        print("进入")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("退出")
```

使用：

```Python学习资料
with DemoContext() as demo:
    print("执行中")
```

## `__enter__`

进入 `with` 代码块前调用。

它的返回值会赋给 `as` 后面的变量。

```Python学习资料
def __enter__(self):
    return self
```

## `__exit__`

退出 `with` 代码块时调用，即使代码块里发生异常也会调用。

参数：

- `exc_type`：异常类型。
- `exc_value`：异常对象。
- `traceback`：调用栈。

如果 `__exit__` 返回 `True`，异常会被吞掉。通常不要随便返回 `True`。

## 适合使用的场景

- 文件打开和关闭。
- 锁的获取和释放。
- JDBC或事务。
- 临时修改环境。
- 计时。
- 资源清理。

## 常见错误

### `__exit__` 吞掉异常

如果返回 `True`，异常不会继续抛出。除非明确要吞异常，否则不要这么做。

### 忘记释放资源

上下文管理器的价值就在于集中清理。

### 在 `__enter__` 做太多复杂业务

保持进入和退出逻辑清晰。
