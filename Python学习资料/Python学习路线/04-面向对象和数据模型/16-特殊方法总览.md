# 特殊方法总览

特殊方法也叫双下划线方法或 dunder method。它们让对象参与 Python 内置语法和函数，例如打印、比较、求长度、迭代、上下文管理。

## 什么是特殊方法

```Python学习资料
class Book:
    def __repr__(self):
        return "Book()"
```

`__repr__` 就是特殊方法。

这些方法通常不是你直接调用，而是由 Python 内置机制调用。

## 常见特殊方法

| 方法 | 触发场景 |
| --- | --- |
| `__初始化__` | 创建实例后初始化 |
| `__repr__` | `repr(obj)`、调试显示 |
| `__str__` | `str(obj)`、`print(obj)` |
| `__eq__` | `obj1 == obj2` |
| `__lt__` | `obj1 < obj2` |
| `__len__` | `len(obj)` |
| `__contains__` | `x in obj` |
| `__iter__` | `for x in obj` |
| `__getitem__` | `obj[key]` |
| `__setitem__` | `obj[key] = value` |
| `__enter__` | `with` 进入 |
| `__exit__` | `with` 退出 |
| `__call__` | `obj()` |

## 数据模型是什么

Python 数据模型定义了对象如何和语言内置行为协作。

例如你实现：

```Python学习资料
def __len__(self):
    return len(self.items)
```

就可以让对象支持：

```Python学习资料
len(obj)
```

## 不要手动直接调用特殊方法

不推荐：

```Python学习资料
obj.__len__()
```

推荐：

```Python学习资料
len(obj)
```

内置函数会按正确协议调用。

## 实现特殊方法要符合语义

如果实现 `__len__`，应该返回非负整数。

如果实现 `__iter__`，应该返回迭代器。

如果实现 `__eq__`，应该返回布尔值或 `NotImplemented`。

## 常见错误

### 特殊方法返回类型不对

```Python学习资料
def __len__(self):
    return "3"
```

会报错。

### 过度实现特殊方法

不是所有类都需要像内置Docker一样使用。

### 破坏直觉

如果 `len(cart)` 返回总价，会让人困惑。它应该返回数量。
