# 条件分支

条件分支让程序根据不同情况执行不同代码。只会顺序执行的程序无法处理真实业务规则。

## 基本语法

```python
age = 18

if age >= 18:
    print("成年人")
```

结构：

- `if` 后面是条件表达式。
- 条件后面写冒号。
- 条件成立时执行缩进代码块。

## `if else`

```python
age = 16

if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

## `if elif else`

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

注意：分支从上到下判断，只会进入第一个满足条件的分支。

## 条件顺序

条件顺序很重要。

错误示例：

```python
score = 95

if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

`score >= 60` 已经成立，所以永远不会进入 `score >= 90`。

应该把更具体、更严格的条件放前面。

## 嵌套条件

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("需要购票")
else:
    print("未成年人不能入场")
```

嵌套过深会降低可读性。可以用逻辑运算简化：

```python
if age >= 18 and has_ticket:
    print("可以入场")
```

## 条件表达式

简单二选一可以写成条件表达式：

```python
status = "成年人" if age >= 18 else "未成年人"
```

适合简单赋值，不适合复杂逻辑。

## 防御式判断

处理用户输入时，先判断非法情况：

```python
age_text = input("年龄：").strip()

if not age_text:
    print("年龄不能为空")
elif not age_text.isdigit():
    print("年龄必须是整数")
else:
    age = int(age_text)
    print(f"年龄：{age}")
```

## 常见错误

### 忘记冒号

```python
if age >= 18
    print("成年人")
```

### 使用 `=` 而不是 `==`

```python
if name = "Alice":
    print("ok")
```

### 条件顺序错误

把宽泛条件放在前面，会挡住后面的具体条件。

### 判断空值不准确

需要区分：

```python
if value:
```

和：

```python
if value is not None:
```
