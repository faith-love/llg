# 字符串基础和格式化

字符串用于表示文本，是 Python 中最常用的类型之一。输入、输出、文件内容、接口数据、日志信息，很多最初都是字符串。

## 创建字符串

可以使用单引号或双引号：

```python
name = "Alice"
city = 'Shanghai'
```

两者都可以。建议一个项目内保持一致。

## 多行字符串

```python
未译52031 = """第一行
第二行
第三行"""
```

多行字符串常用于长文本或文档字符串。

## 转义字符

常见转义：

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |

示例：

```python
print("hello\nPython学习资料")
print("name\tage")
```

## 原始字符串

路径或正则里经常看到反斜杠，可以用原始字符串：

```python
path = r"D:\learn\Python学习资料"
print(path)
```

原始字符串减少转义干扰。

## 字符串长度

```python
text = "hello"
print(len(text))
```

`len()` 返回字符数量。

## 索引

```python
text = "Python学习资料"

print(text[0])
print(text[1])
print(text[-1])
```

索引从 0 开始。负数索引从右往左。

## 切片

```python
text = "Python学习资料"

print(text[0:2])
print(text[2:])
print(text[:3])
print(text[::2])
```

切片基本格式：

```python
字符串[开始:结束:步长]
```

结束位置不包含在结果里。

## 字符串不可变

不能直接修改字符串中的某个字符：

```python
text = "Python学习资料"
text[0] = "P"
```

会报错。需要创建新字符串：

```python
text = "P" + text[1:]
```

## 常用方法

```python
text = " hello Python学习资料 "

print(text.strip())
print(text.upper())
print(text.lower())
print(text.replace("Python学习资料", "world"))
print(text.find("py"))
print(text.startswith(" he"))
print(text.endswith(" "))
```

## 字符串格式化

推荐使用 f-string：

```python
name = "Alice"
age = 18

print(f"姓名：{name}，年龄：{age}")
```

数字格式：

```python
price = 19.9
print(f"价格：{price:.2f}")
```

对齐：

```python
name = "Alice"
print(f"{name:<10}")
print(f"{name:>10}")
print(f"{name:^10}")
```

## 常见错误

### 索引越界

```python
text = "abc"
print(text[3])
```

索引最大是 2，所以会报 `IndexError`。

### 字符串和数字拼接

```python
age = 18
print("age=" + age)
```

应该写：

```python
print(f"age={age}")
```

### 忘记字符串不可变

字符串方法通常返回新字符串，不会修改原字符串：

```python
text = " hello "
text.strip()
print(text)
```

需要：

```python
text = text.strip()
```
