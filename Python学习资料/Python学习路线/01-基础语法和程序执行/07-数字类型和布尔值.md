# 数字类型和布尔值

数字和布尔值是最基础的计算材料。写条件、循环、计数、统计、输入校验时都会用到。

## 整数

Python 的整数可以表示很大的数，不像某些语言有固定范围。

```Python学习资料
count = 100
big_number = 10 ** 100
```

常用运算：

```Python学习资料
a = 10
b = 3

print(a + b)   # 加
print(a - b)   # 减
print(a * b)   # 乘
print(a / b)   # 普通除法，结果是 float
print(a // b)  # 整除
print(a % b)   # 取余
print(a ** b)  # 幂
```

## 浮点数

浮点数用于表示小数：

```Python学习资料
price = 19.99
weight = 62.5
```

### 精度问题

```Python学习资料
print(0.1 + 0.2)
```

可能输出：

```text
0.30000000000000004
```

原因是二进制浮点数不能精确表示所有十进制小数。

学习阶段记住：

- 普通小数计算可以用 `float`。
- 金额等严肃精度场景后续要学习 `decimal.Decimal`。
- 不要直接用浮点数做严格相等比较。

不建议：

```Python学习资料
if 0.1 + 0.2 == 0.3:
    print("相等")
```

可以用误差范围：

```Python学习资料
if abs((0.1 + 0.2) - 0.3) < 1e-9:
    print("近似相等")
```

## 布尔值

布尔值只有两个：

```Python学习资料
True
False
```

注意首字母大写。

错误：

```Python学习资料
true
false
```

## 比较产生布尔值

```Python学习资料
age = 18

print(age >= 18)
print(age < 18)
```

比较结果就是布尔值。

## 布尔运算

```Python学习资料
is_adult = True
has_ticket = False

print(is_adult and has_ticket)
print(is_adult or has_ticket)
print(not is_adult)
```

含义：

- `and`：都为真才为真。
- `or`：至少一个为真就为真。
- `not`：取反。

## 布尔值和整数的关系

在 Python 中：

```Python学习资料
print(True == 1)
print(False == 0)
```

结果是：

```text
True
True
```

但实际代码里不要把布尔值当普通整数使用，否则可读性会变差。

## 常见错误

### 除法结果类型误判

```Python学习资料
result = 10 / 2
print(type(result))
```

结果是 `float`，不是 `int`。

如果需要整数，使用 `//` 或显式转换。

### 浮点数直接比较

不要依赖浮点数严格相等。

### 布尔值小写

`True` 和 `False` 必须首字母大写。
