# 阶段目标

基础语法阶段的核心目标是建立“能独立写小程序”的能力。不是背语法表，也不是把教程看完，而是能把一个小问题拆成输入、处理、输出，并写成可运行脚本。

## 你要达到的能力

完成本阶段后，应该能做到：

- 能创建 `.py` 文件并从命令行运行。
- 能解释 Python 代码从上到下的执行顺序。
- 能区分语法错误和运行时错误。
- 能使用变量保存数据。
- 能使用 `int`、`float`、`bool`、`str`、`None`。
- 能完成输入、计算、输出。
- 能写条件判断和循环。
- 能定义简单函数，把重复逻辑抽出来。
- 能处理最常见的类型转换和输入校验。
- 能读懂报错中的文件名、行号、异常类型和错误信息。

## 学习边界

本阶段只要求掌握基础语法，不要求一次掌握所有 Python 特性。

### 必须掌握

- Python 文件如何运行。
- 注释、缩进、代码块。
- 变量和对象引用。
- 基础数据类型。
- 类型转换。
- 运算符和表达式。
- `print` 和 `input`。
- `if/elif/else`。
- `for` 和 `while`。
- `break`、`continue`、循环 `else`。
- 函数定义、参数、返回值。
- `if __name__ == "__主__"`。
- 常见报错排查。

### 暂时了解

- `match case`。
- 命令行参数。
- 作用域和名称查找。
- 浅拷贝、深拷贝。
- 类型提示。

这些内容后面会继续深入，本阶段先建立概念。

### 暂时不深入

- 装饰器。
- 生成器。
- 类和对象。
- 异常体系。
- 模块和包结构。
- 第三方库。
- Web、数据库、爬虫、数据分析。

## 为什么先学执行模型

很多初学者的问题不是“不知道某个函数”，而是不知道代码到底怎么执行。

例如：

```Python学习资料
print("开始")

name = input("请输入姓名：")

if name:
    print("你好", name)
else:
    print("没有输入姓名")

print("结束")
```

你需要能说清楚：

1. 哪一行先执行。
2. 程序什么时候停下来等待输入。
3. `if name` 判断的是什么。
4. 哪些代码在条件内部。
5. 为什么最后总会输出“结束”。

## 阶段练习目标

本阶段建议完成至少 30 个小练习，覆盖：

- 数字计算。
- 字符串拼接和格式化。
- 输入校验。
- 条件判断。
- 循环累计。
- 简单菜单。
- 简单函数封装。
- 常见错误修复。

练习不是为了数量，而是为了覆盖不同语法组合。

## 阶段通过标准

满足以下条件，可以进入下一阶段：

- 不看教程能写一个 50-100 行的小脚本。
- 能解释脚本的输入、处理、输出。
- 能把重复代码拆成函数。
- 能处理用户输入为空、非数字、范围不合法等情况。
- 能修复 `SyntaxError`、`IndentationError`、`NameError`、`TypeError`、`ValueError` 中的常见问题。
- 能写出一份阶段复盘。
