# 验收标准和复盘

本阶段通过标准不是“看完文档”，而是能独立写基础脚本、能解释代码行为、能处理常见错误。

## 知识验收

你应该能回答：

- Python 脚本如何运行。
- 交互式运行和脚本运行有什么区别。
- 缩进为什么会影响程序含义。
- 变量为什么是名字绑定对象。
- `int`、`float`、`bool`、`str`、`None` 分别适合表示什么。
- `input()` 为什么要做类型转换。
- `/` 和 `//` 有什么区别。
- `==` 和 `is` 有什么区别。
- `if x` 和 `if x is not None` 有什么区别。
- `break` 和 `continue` 有什么区别。
- 没有 `return` 的函数返回什么。
- `if __name__ == "__主__"` 的作用是什么。

## 代码验收

必须完成：

- 至少 30 个基础练习。
- 至少 5 个错误复现和修复记录。
- 至少 3 个函数拆分练习。
- 至少 1 个菜单循环程序。
- 至少 1 个综合小程序。

综合小程序最低要求：

- 能从命令行运行。
- 使用 `主()`。
- 至少包含 2 个自定义函数。
- 有输入校验。
- 有清晰输出。
- 遇到非法输入不会直接崩溃。

## 推荐综合小程序

### 1. BMI 计算器

功能：

- 输入身高和体重。
- 校验输入是否为数字。
- 计算 BMI。
- 输出分类。

必须包含函数：

- `calculate_bmi(height, weight)`
- `get_bmi_level(bmi)`
- `主()`

### 2. 猜数字

功能：

- 固定一个目标数字。
- 用户循环输入。
- 输入不合法时提示。
- 猜大、猜小、猜中分别提示。
- 猜中退出。

必须包含：

- `while` 循环。
- `break`。
- 类型转换。
- 输入校验。

### 3. 简单成绩统计

功能：

- 循环输入成绩。
- 输入 `quit` 结束。
- 校验成绩范围。
- 输出数量、总分、平均分。

必须包含：

- 循环。
- 累计。
- 计数。
- 分支。
- 函数。

## 错误排查验收

你应该能独立处理：

- `SyntaxError`
- `IndentationError`
- `NameError`
- `TypeError`
- `ValueError`
- `IndexError`

每个错误至少记录：

- 报错原文。
- 出错代码。
- 根本原因。
- 修复方式。
- 下次如何避免。
