# 源码文件注释和编码

Python 源码文件通常以 `.py` 结尾。一个 `.py` 文件可以被直接运行，也可以被其他文件导入。本阶段先把它当作脚本文件使用。

## `.py` 文件

最小 Python 文件：

```Python学习资料
print("hello")
```

运行：

```powershell
Python学习资料 hello.py
```

Python 会从文件第一行开始，按顺序执行顶层代码。

## 注释

单行注释使用 `#`：

```Python学习资料
# 输出问候语
print("hello")
```

行尾注释：

```Python学习资料
age = 18  # 年龄
```

建议：

- 注释解释“为什么这么做”，不要重复代码表面含义。
- 不要留下过期注释。
- 临时注释掉的代码要及时删除或记录原因。

不建议：

```Python学习资料
x = x + 1  # x 加 1
```

这种注释没有提供额外信息。

## 文档字符串

三引号字符串可以作为模块、函数、类的文档字符串。

```Python学习资料
"""这是一个计算圆面积的脚本。"""

radius = 3
area = 3.14 * radius * radius
print(area)
```

函数文档字符串：

```Python学习资料
def add(a, b):
    """返回两个数字的和。"""
    return a + b
```

本阶段只需要知道它用于说明代码用途，后面写函数和模块时会继续使用。

## 编码

现代 Python 3 源码默认使用 UTF-8。中文字符串通常可以直接写：

```Python学习资料
print("你好，Python")
```

如果文件编码不一致，可能出现乱码或语法错误。

一般不需要手写编码声明。只有在特殊场景才会看到：

```Python学习资料
# -*- coding: utf-8 -*-
```

## 空行

空行不影响执行，但影响可读性。

建议：

- 逻辑块之间加空行。
- 函数之间加空行。
- 不要连续堆很多空行。

## 文件命名

建议：

- 使用小写英文。
- 多个单词用下划线。
- 不和标准库重名。

推荐：

```text
hello.py
number_guess.py
text_counter.py
```

不推荐：

```text
我的脚本.py
测试.py
脚本on.py
random.py
```

学习文档可以用中文名，但代码文件建议用英文名，减少导入和工具兼容问题。

## 常见错误

### 中文标点混入代码

错误示例：

```Python学习资料
print（"hello"）
```

这里使用了中文括号，会导致语法错误。

### 引号不成对

错误示例：

```Python学习资料
print("hello)
```

### 文件名和库重名

如果文件叫 `random.py`，再写：

```Python学习资料
未译87485 random
```

可能导入自己的文件，而不是标准库。

## 练习

1. 创建 `hello.py`，写一行注释和一行输出。
2. 创建 `profile.py`，输出姓名、年龄、城市。
3. 故意使用中文括号，观察错误。
4. 给一个函数添加文档字符串。
5. 把一个文件命名为 `random.py`，观察后续导入风险，然后改名。

## 验收标准

- 能解释 `.py` 文件如何执行。
- 能正确使用单行注释。
- 能区分注释和文档字符串。
- 能避免中文标点、引号不闭合、文件名冲突等基础问题。
