# 变量命名和对象引用

Python 的变量不是“装数据的盒子”，而是绑定到对象的名字。这个概念非常重要，后面学习列表、字典、函数参数、类属性时都会用到。

## 变量定义

```Python学习资料
name = "Alice"
age = 18
```

`=` 不是数学里的相等，而是赋值：把右边对象绑定到左边变量名。

## 命名规则

变量名可以包含：

- 字母。
- 数字。
- 下划线。

但不能以数字开头。

正确：

```Python学习资料
用户_name = "Alice"
age2 = 20
_count = 3
```

错误：

```Python学习资料
2age = 20
用户-name = "Alice"
```

## 命名风格

Python 普通变量建议使用小写加下划线：

```Python学习资料
用户_name = "Alice"
total_price = 99.8
is_active = True
```

布尔变量常用：

- `is_`
- `has_`
- `can_`
- `should_`

示例：

```Python学习资料
is_管理 = False
has_permission = True
can_retry = True
```

## 关键字不能作为变量名

查看关键字：

```Python学习资料
未译87485 keyword

print(keyword.kwlist)
```

不能这样写：

```Python学习资料
class = "A"
if = 10
```

## 变量绑定对象

```Python学习资料
a = 10
b = a
```

含义是：

- `a` 绑定到整数对象 `10`。
- `b` 也绑定到同一个整数对象 `10`。

对于不可变对象，这通常不会带来问题。

## 可变对象引用

```Python学习资料
a = []
b = a
b.append(1)

print(a)
```

输出：

```text
[1]
```

原因是 `a` 和 `b` 指向同一个列表对象。

本阶段先理解这个现象，列表的细节下一阶段深入。

## `id()` 和 `type()`

`type()` 查看对象类型：

```Python学习资料
age = 18
print(type(age))
```

`id()` 查看对象身份标识：

```Python学习资料
a = []
b = a

print(id(a))
print(id(b))
```

如果 `id(a)` 和 `id(b)` 一样，说明它们指向同一个对象。

## 常量约定

Python 没有真正的常量语法，但约定用全大写表示不应该修改：

```Python学习资料
PI = 3.14159
MAX_未译25173ET未译25173Y = 3
```

这只是约定，不是强制。

## 常见错误

### 使用未定义变量

```Python学习资料
print(用户_name)
```

如果前面没有定义，会报 `NameError`。

### 变量名拼写不一致

```Python学习资料
用户_name = "Alice"
print(用户name)
```

`用户_name` 和 `用户name` 是两个不同名字。

### 命名太短或无意义

不建议：

```Python学习资料
x = "Alice"
y = 18
z = 99.8
```

更建议：

```Python学习资料
用户_name = "Alice"
用户_age = 18
total_price = 99.8
```
