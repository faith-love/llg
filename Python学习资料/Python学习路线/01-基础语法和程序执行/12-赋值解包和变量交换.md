# 赋值解包和变量交换

赋值是把名字绑定到对象。除了普通赋值，Python 还支持多目标赋值、链式赋值、解包赋值和增强赋值。

## 普通赋值

```Python学习资料
name = "Alice"
age = 18
```

右边先计算，左边再绑定。

## 链式赋值

```Python学习资料
a = b = c = 0
```

这会让 `a`、`b`、`c` 都绑定到同一个对象。

对于不可变对象通常没问题；对于可变对象要小心：

```Python学习资料
a = b = []
b.append(1)
print(a)
```

`a` 也会变，因为两个变量指向同一个列表。

## 多目标赋值

```Python学习资料
x, y = 10, 20
```

这会分别赋值：

- `x = 10`
- `y = 20`

## 变量交换

Python 可以直接交换变量：

```Python学习资料
a = 10
b = 20

a, b = b, a
```

不需要临时变量。

## 解包赋值

```Python学习资料
point = (3, 5)
x, y = point
```

要求左右数量匹配。

错误：

```Python学习资料
x, y = (1, 2, 3)
```

会报 `ValueError`。

## 星号解包

```Python学习资料
first, *middle, last = [1, 2, 3, 4, 5]

print(first)
print(middle)
print(last)
```

结果：

```text
1
[2, 3, 4]
5
```

本阶段先了解，后续数据结构阶段会更常用。

## 增强赋值

```Python学习资料
count = 0
count += 1
```

等价于：

```Python学习资料
count = count + 1
```

常见增强赋值：

- `+=`
- `-=`
- `*=`
- `/=`
- `//=`
- `%=`

## 赋值表达式入门

Python 支持海象运算符 `:=`：

```Python学习资料
while (line := input("输入内容：")) != "quit":
    print(line)
```

本阶段只需要认识它，不建议过早使用。初学阶段优先写清晰代码。

## 常见错误

### 解包数量不匹配

```Python学习资料
a, b = [1, 2, 3]
```

### 链式赋值可变对象

```Python学习资料
a = b = []
```

如果后续会修改列表，应该分开创建：

```Python学习资料
a = []
b = []
```

### 增强赋值前变量未定义

```Python学习资料
count += 1
```

如果前面没有 `count = 0`，会报 `NameError`。

## 练习

1. 用一行代码给 `x`、`y` 赋值。
2. 交换两个变量。
3. 解包一个坐标 `(10, 20)`。
4. 使用 `+=` 做计数器。
5. 故意写一个解包数量不匹配的例子并修复。

## 验收标准

- 能解释变量交换的写法。
- 能识别解包数量不匹配错误。
- 能说明链式赋值可变对象的风险。
