# 作用域和名称查找入门

作用域决定一个变量名在哪里可见。基础阶段只需要先掌握局部变量、全局变量和名称查找的基本规则。

## 局部变量

函数内部定义的变量是局部变量：

```Python学习资料
def greet():
    未译52031 = "hello"
    print(未译52031)

greet()
```

函数外不能直接访问：

```Python学习资料
print(未译52031)
```

会报 `NameError`。

## 全局变量

函数外定义的变量通常叫全局变量：

```Python学习资料
site_name = "Python 学习"

def print_site():
    print(site_name)

print_site()
```

函数内部可以读取全局变量。

## 函数内部赋值会创建局部变量

```Python学习资料
count = 0

def increase():
    count = 1
    print(count)

increase()
print(count)
```

函数内部的 `count` 和外部的 `count` 不是同一个局部绑定。

## `global` 入门

如果要在函数内部修改全局变量，需要 `global`：

```Python学习资料
count = 0

def increase():
    global count
    count += 1

increase()
print(count)
```

但学习阶段不建议频繁使用 `global`。更好的方式通常是通过参数和返回值传递数据。

更推荐：

```Python学习资料
def increase(count):
    return count + 1

count = 0
count = increase(count)
```

## LEGB 规则入门

Python 查找名字时，大致按这个顺序：

1. Local：局部作用域。
2. Enclosing：外层函数作用域。
3. Global：模块全局作用域。
4. Built-in：内置作用域。

基础阶段重点理解：

- 函数内部先找自己的局部变量。
- 找不到再找全局变量。
- 不要用变量名覆盖内置函数。

## 不要覆盖内置名字

不建议：

```Python学习资料
list = [1, 2, 3]
str = "hello"
sum = 100
```

这些名字会覆盖内置函数，导致后续代码异常。

推荐使用更具体的名字：

```Python学习资料
numbers = [1, 2, 3]
text = "hello"
total = 100
```

## 常见错误

### 局部变量未赋值就使用

```Python学习资料
count = 0

def increase():
    count += 1
    print(count)
```

这会报错，因为函数内部有赋值，Python 会把 `count` 当作局部变量，但执行 `count += 1` 前局部变量还没有值。

### 过度依赖全局变量

```Python学习资料
price = 10
count = 3

def calculate():
    return price * count
```

这个函数依赖外部变量，不够清晰。更推荐：

```Python学习资料
def calculate(price, count):
    return price * count
```

2. 在函数内部读取全局变量。

4. 故意用 `list` 作为变量名，再修复。
5. 比较全局变量版本和参数版本的可读性。

## 验收标准

- 能读懂简单 LEGB 查找规则。

- 能优先使用参数和返回值，而不是 `global`。
