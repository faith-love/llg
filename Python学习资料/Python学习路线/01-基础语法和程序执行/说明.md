# 01-基础语法和程序执行

这一阶段的目标是掌握 Python 程序最小运行闭环：会创建脚本、会运行脚本、会读懂执行顺序、会使用变量和基础类型、会写判断和循环、会定义简单函数，并能定位最常见的语法和运行错误。

这一阶段不要急着学习 Web、爬虫、数据分析或第三方库。基础语法不稳时，后面所有方向都会变成复制代码。

## 本阶段产出

- 至少 30 个基础小程序。
- 一份变量、类型、判断、循环、函数的知识点笔记。
- 一份常见错误记录。
- 一个 `Python学习资料-basics-practice` 练习目录。
- 一份阶段复盘。

## 本阶段不做什么

- 不深入列表、字典、集合的高级操作，下一阶段单独学习。
- 不学习复杂面向对象设计。
- 不学习 Web 框架和数据库。
- 不追求算法题数量，先保证语法和执行模型稳定。
- 不安装大量第三方库。
