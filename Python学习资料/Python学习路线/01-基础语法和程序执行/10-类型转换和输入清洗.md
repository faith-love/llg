# 类型转换和输入清洗

用户输入、文件内容、接口参数最初通常都是字符串。写程序时必须明确把字符串转换成需要的类型，并处理转换失败的情况。

## 常见类型转换

```Python学习资料
int("18")
float("3.14")
str(100)
bool(1)
```

示例：

```Python学习资料
age_text = "18"
age = int(age_text)
print(age + 1)
```

## `input()` 得到的是字符串

```Python学习资料
age = input("请输入年龄：")
print(type(age))
```

即使输入 `18`，得到的也是字符串 `"18"`。

如果要计算：

```Python学习资料
age = int(input("请输入年龄："))
print(age + 1)
```

## 转换失败

```Python学习资料
age = int("abc")
```

会报 `ValueError`。

基础阶段先学会避免明显错误：

```Python学习资料
age_text = input("请输入年龄：").strip()

if age_text.isdigit():
    age = int(age_text)
    print(f"明年年龄：{age + 1}")
else:
    print("年龄必须是整数")
```

## 字符串清洗

常用方法：

```Python学习资料
text = "  Hello Python  "

print(text.strip())
print(text.lower())
print(text.upper())
```

用户输入通常要先 `strip()`：

```Python学习资料
name = input("请输入姓名：").strip()
```

## 数字字符串判断

`isdigit()` 可以判断字符串是否由数字组成：

```Python学习资料
print("123".isdigit())
print("12.3".isdigit())
print("-1".isdigit())
```

注意：

- `"123"` 返回 `True`。
- `"12.3"` 返回 `False`。
- `"-1"` 返回 `False`。

所以 `isdigit()` 只适合简单正整数判断。

## 布尔转换的坑

```Python学习资料
print(bool("False"))
```

结果是 `True`，因为非空字符串都是真值。

如果用户输入 `"yes"`、`"no"`，不要直接用 `bool()`：

```Python学习资料
answer = input("是否继续 yes/no：").strip().lower()

if answer == "yes":
    print("继续")
elif answer == "no":
    print("停止")
else:
    print("输入不合法")
```

## 显式转换优先

不要依赖“看起来能转换”的隐式理解。Python 不会自动把字符串数字当数字计算：

```Python学习资料
print("10" + "20")
```

输出：

```text
1020
```

如果要加法：

```Python学习资料
print(int("10") + int("20"))
```

## 常见错误

### 忘记转换输入

```Python学习资料
age = input("年龄：")
print(age + 1)
```

会报 `TypeError`。

### 空字符串转换整数

```Python学习资料
int("")
```

会报 `ValueError`。

### 用 `bool()` 解析用户输入

```Python学习资料
bool("False")
```

这个结果不是很多人预期的。

5. 输入分数，要求不能为空且必须是 0-100 的整数。

## 验收标准

- 能解释为什么 `input()` 返回字符串。
- 能正确使用 `int()`、`float()`、`str()`。
- 能处理空输入。
- 能避免 `bool("False")` 这类误判。
