# 函数入门

函数用于把一段逻辑封装成可复用单元。基础阶段学函数，不是为了写复杂架构，而是为了避免代码重复、让程序结构清晰、让逻辑可以单独测试。

## 定义函数

```python
def greet():
    print("hello")
```

调用函数：

```python
greet()
```

函数定义不会立即执行函数体，只有调用时才执行。

## 参数

```python
def greet(name):
    print(f"你好，{name}")

greet("Alice")
```

参数是函数的输入。

## 多个参数

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

## 返回值

`return` 用于返回结果：

```python
def add(a, b):
    return a + b
```

没有 `return` 的函数默认返回 `None`。

```python
def say_hello():
    print("hello")

value = say_hello()
print(value)
```

## 参数和返回值的关系

一个函数最好能清楚表达：

- 输入是什么。
- 输出是什么。
- 是否有副作用。

示例：

```python
def calculate_total_price(price, count):
    return price * count
```

这个函数只计算，不负责输入，也不负责输出。

## 默认参数

```python
def greet(name, prefix="你好"):
    return f"{prefix}，{name}"

print(greet("Alice"))
print(greet("Alice", "欢迎"))
```

注意：默认参数在函数定义时计算。不要在基础阶段使用可变对象作为默认参数。

不建议：

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

后续会详细解释这个坑。

## 关键字参数

```python
def introduce(name, age):
    print(f"{name} is {age}")

introduce(name="Alice", age=18)
introduce(age=18, name="Alice")
```

关键字参数可以提高可读性。

## 位置参数

```python
introduce("Alice", 18)
```

按位置传入参数。

## 函数命名

函数名建议使用动词或动宾结构：

推荐：

```python
calculate_total()
validate_age()
print_menu()
load_用户_input()
```

不推荐：

```python
do()
handle()
process()
测试()
```

除非上下文很明确，否则这些名字太模糊。

## 什么时候拆函数

适合拆函数的信号：

- 同一段逻辑重复出现。
- 一个脚本超过 50 行开始难读。
- 一段代码有明确输入和输出。
- 一段代码可以单独测试。
- 主流程里细节太多。

## 示例：把输入计算输出拆开

不推荐全部写在一起：

```python
price = float(input("单价："))
count = int(input("数量："))
total = price * count
print(f"总价：{total:.2f}")
```

拆成函数：

```python
def calculate_total(price, count):
    return price * count


def 主():
    price = float(input("单价："))
    count = int(input("数量："))
    total = calculate_total(price, count)
    print(f"总价：{total:.2f}")


主()
```

## 常见错误

### 定义了函数但没有调用

```python
def greet():
    print("hello")
```

这段代码不会输出任何内容。

### 忘记返回值

```python
def add(a, b):
    a + b

result = add(1, 2)
print(result)
```

结果是 `None`。

### 参数数量不匹配

```python
def add(a, b):
    return a + b

add(1)
```

会报 `TypeError`。

- 能定义和调用函数。
- 能区分参数和返回值。

- 能避免默认可变参数。
