# 缩进代码块和语句

Python 用缩进表达代码结构。缩进不是排版习惯，而是语法本身。缩进错了，程序含义就变了。

## 语句

一条语句通常是一行代码：

```python
name = "Alice"
print(name)
```

Python 从上到下执行语句。

## 简单语句和复合语句

简单语句：

```python
age = 18
print(age)
```

复合语句会引入代码块，常见有：

```python
if age >= 18:
    print("成年人")
```

复合语句特点：

- 以冒号 `:` 结尾。
- 下一行开始缩进。
- 缩进部分属于这个代码块。

## 缩进规则

建议统一使用 4 个空格。

正确：

```python
if True:
    print("第一行")
    print("第二行")
```

错误：

```python
if True:
    print("第一行")
  print("第二行")
```

## 代码块

代码块是一组缩进层级相同的语句。

```python
score = 90

if score >= 60:
    print("及格")
    print("继续努力")

print("程序结束")
```

这里：

- 两个 `print` 在 `if` 代码块内部。
- 最后一行 `print("程序结束")` 不在 `if` 里。

## 冒号

这些语句后面通常要写冒号：

- `if`
- `elif`
- `else`
- `for`
- `while`
- `def`
- `class`
- `try`
- `except`
- `finally`
- `with`
- `match`
- `case`

本阶段重点掌握 `if`、`for`、`while`、`def`。

## 一行多语句

Python 允许用分号写一行多语句：

```python
a = 1; b = 2; print(a + b)
```

但不建议这样写。学习阶段保持一行一条语句，更容易读懂和调试。

## 长表达式换行

括号内可以自然换行：

```python
total = (
    100
    + 200
    + 300
)
```

函数调用也可以换行：

```python
print(
    "hello",
    "Python学习资料",
)
```

## 常见错误

### 忘记冒号

```python
if age >= 18
    print("成年人")
```

### 缩进不一致

```python
if age >= 18:
    print("成年人")
        print("欢迎")
```

### 把代码写错代码块

```python
for i in range(3):
    print(i)
print("循环结束")
```

和：

```python
for i in range(3):
    print(i)
    print("循环结束")
```

这两个程序输出不同，因为第二个“循环结束”在循环内部。

## 练习

1. 写一个 `if` 判断，故意忘记冒号，观察错误。
2. 写一个循环，把输出放在循环内和循环外，比较结果。
3. 写一个嵌套 `if`，观察缩进层级。
4. 把一行很长的 `print` 改成多行写法。

## 验收标准

- 能解释冒号和缩进的关系。
- 能判断一行代码属于哪个代码块。
- 能修复 `IndentationError`。
- 能避免 Tab 和空格混用。
