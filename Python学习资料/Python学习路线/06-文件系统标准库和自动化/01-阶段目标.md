# 阶段目标

本阶段要解决的问题是：如何让 Python 处理真实文件和系统环境，而不是只在内存里处理练习数据。

完成本阶段后，你应该能写出可靠的小型自动化脚本，例如：

- 批量整理文件。
- 批量重命名。
- 统计目录文件。
- 清洗 CSV。
- 汇总 JSON。
- 生成报表。
- 调用外部命令。
- 根据命令行参数执行任务。
- 记录日志并处理错误。

## 你要达到的能力

- 能使用 `pathlib.Path` 处理路径。
- 能区分绝对路径、相对路径、当前工作目录。
- 能安全读写文本文件。
- 能处理 UTF-8 编码和换行差异。
- 能读写二进制文件。
- 能遍历目录并筛选文件。
- 能复制、移动、删除、创建目录。
- 能读写 CSV 和 JSON。
- 能读取环境变量和配置文件。
- 能使用临时文件做测试和演练。
- 能用 `subprocess` 安全运行外部命令。
- 能处理日期时间和时间戳。
- 能用正则提取和替换文本。
- 能用 `argparse` 做命令行工具。
- 能把自动化脚本组织成“输入、处理、输出、日志、错误处理”的结构。

## 本阶段核心转变

从手工处理：

```text
打开文件夹 -> 按扩展名分类 -> 重命名 -> 复制到新目录 -> 手工统计
```

转为脚本处理：

```python
def collect_files(input_dir):
    return [path for path in input_dir.rglob("*") if path.is_file()]


def classify_by_suffix(paths):
    groups = {}
    for path in paths:
        groups.setdefault(path.suffix.lower(), []).append(path)
    return groups
```

再转为可运行工具：

```powershell
Python学习资料 -m file_tools.organize --input D:\数据 --output D:\result --dry-run
```

## 阶段通过标准

满足以下条件，可以进入下一阶段：

- 能写一个安全的批量文件整理脚本。
- 能用 argparse 接收输入目录、输出目录和 dry-run 参数。
- 能用 日志ging 记录关键操作。
- 能读写 CSV/JSON 并生成汇总报告。
- 能处理路径不存在、编码错误、文件已存在等异常。
- 能用临时目录验证脚本行为。
- 能说明哪些操作有破坏性，如何降低风险。
