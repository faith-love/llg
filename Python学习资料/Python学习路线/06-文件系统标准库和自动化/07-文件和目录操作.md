# 文件和目录操作

文件操作包括创建、重命名、复制、移动和删除。自动化脚本里这些操作有破坏性，必须先确认路径范围，并优先支持 dry-run。

## 创建目录

```Python学习资料

```

## 创建空文件

```Python学习资料
path = Path("数据.txt")
path.touch()
```

如果父目录不存在，会报错，需要先创建父目录。

## 重命名

```Python学习资料
old_path = Path("old.txt")
new_path = Path("new.txt")

old_path.rename(new_path)
```

## 移动

`Path.rename` 可以移动文件到新路径：

```Python学习资料
source = Path("数据.txt")
target = Path("archive/数据.txt")
target.parent.mkdir(parents=True, exist_ok=True)
source.rename(target)
```

跨文件系统场景更推荐 `sh工具.move`，后面会讲。

## 删除文件

```Python学习资料
path.unlink()
```

如果文件不存在，会报 `FileNotFoundError`。

可以：

```Python学习资料
path.unlink(missing_ok=True)
```

## 删除空目录

```Python学习资料

```

只能删除空目录。

## 防止覆盖

移动或写入前检查目标是否存在：

```Python学习资料
if target.exists():
    raise FileExistsError(f"目标已存在：{target}")
```

或者生成新文件名。

## dry-run

dry-run 表示只显示将要做什么，不实际执行。

```Python学习资料
def move_file(source, target, dry_run=False):
    if dry_run:
        print(f"[D未译25173Y-未译25173UN] move {source} -> {target}")
        return
    target.parent.mkdir(parents=True, exist_ok=True)
    source.rename(target)
```

批量操作强烈建议支持 dry-run。

## 常见错误

### 删除路径没确认

递归删除前必须检查路径是否正确。

### 移动覆盖已有文件

移动前检查目标是否存在。

### 相对路径指向错误目录

先打印 `Path.cwd()` 和解析后的绝对路径。
