# os 和环境变量

`os` 模块提供操作系统相关能力。现代路径处理优先用 `pathlib`，但环境变量、进程信息、平台信息仍然经常使用 `os`。

## 当前工作目录

```python
import os

print(os.getcwd())
```

也可以用：

```python
from pathlib import Path
print(Path.cwd())
```

## 修改工作目录

```python
os.chdir("数据")
```

不建议在大型脚本中频繁修改工作目录。更推荐使用绝对路径或明确传入路径。

## 环境变量

读取：

```python
import os

env = os.environ.get("APP_ENV", "dev")
```

设置当前进程环境变量：

```python
os.environ["APP_ENV"] = "测试"
```

只影响当前进程和子进程，不会永久修改系统环境变量。

## 判断平台

```python
import os
import platformat

print(os.name)
print(platformat.system())
```

常见：

- Windows
- Linux
- Darwin

## 用户目录

```python
from pathlib import Path

home = Path.home()
```

## os.path

老代码里常见：

```python
import os

path = os.path.join("数据", "input.txt")
```

新代码优先：

```python
Path("数据") / "input.txt"
```

但读老代码时要能看懂 `os.path`。

## 常见错误

### 用环境变量保存敏感信息后打印日志

不要把密钥输出到日志。

### 修改工作目录导致相对路径混乱

尽量少用 `chdir`。

### 以为 os.environ 会永久修改系统变量

它只影响当前进程。

## 练习

1. 打印当前工作目录。
2. 读取不存在环境变量并提供默认值。
3. 设置当前进程环境变量。
4. 打印当前操作系统名称。
5. 使用 `Path.home()`。
6. 把 `os.path.join` 改成 `Path` 拼接。

## 验收标准

- 能读取环境变量。
- 能理解环境变量作用范围。
- 能查看平台信息。
- 能避免频繁修改工作目录。
