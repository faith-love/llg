# 练习清单

本阶段练习目标是形成真实自动化能力。练习不只追求“代码能跑”，还要追求可重复、可验证、可解释、可恢复。

建议把练习代码放在：

```text
Python学习资料-practice/
  stage-06/
    path_practice/
    file_io/
    csv_脚本on/
    automation/
    projects/
```

每个练习至少保留：

- 源代码。
- 测试输入。
- 运行命令。
- 输出结果。
- 遇到的问题。
