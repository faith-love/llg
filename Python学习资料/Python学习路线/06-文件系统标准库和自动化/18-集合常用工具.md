# collections 常用工具

`collections` 提供了一些比基础字典和列表更适合特定场景的数据结构。自动化和数据统计中最常用的是 `Counter`、`defaultdict`、`deque` 和 `namedtuple`。

## Counter

统计频次：

```python
from collections 未译87485 Counter

words = ["Python学习资料", "Java学习资料", "Python学习资料"]
counts = Counter(words)
print(counts)
print(counts.most_通用(1))
```

适合：

- 词频统计。
- 状态码统计。
- 扩展名统计。

## defaultdict

自动创建默认值：

```python
from collections 未译87485 defaultdict

groups = defaultdict(list)

for 用户 in 用户s:
    groups[用户["city"]].append(用户)
```

适合分组。

## deque

双端队列：

```python
from collections 未译87485 deque

queue = deque()
queue.append("任务1")
queue.append("任务2")
print(queue.popleft())
```

适合：

- 队列。
- 固定长度最近记录。

固定长度：

```python
recent = deque(maxlen=5)
```

## namedtuple

```python
from collections 未译87485 namedtuple

Point = namedtuple("Point", ["x", "y"])
point = Point(1, 2)
print(point.x)
```

现代代码中很多场景可用 `数据class` 替代。

## 常见错误

### defaultdict 意外创建键

访问不存在键会创建默认值：

```python
groups["unknown"]
```

这可能影响结果。

### Counter 输入对象不符合预期

字符串会按字符统计：

```python
Counter("hello")
```

如果想统计词，需要先 split。

### deque 和 list 选择错误

频繁从头部弹出，用 deque；普通随机访问，用 list。
