# 编码换行和文件模式

文件自动化里最常见的问题是乱码、换行差异和误覆盖。必须系统理解编码、换行和文件模式。

## 编码

文本文件本质上是字节。读取时需要把字节解码成字符串。

```Python学习资料
content = path.read_text(encoding="utf-8")
```

写入时需要把字符串编码成字节。

```Python学习资料
path.write_text("你好", encoding="utf-8")
```

## 常见编码

- UTF-8：推荐默认。
- GBK：部分中文 Windows 老文件常见。
- UTF-8 with BOM：部分 Windows 工具生成。

遇到乱码时，不要随意猜。先确认文件来源。

## 编码错误处理

```Python学习资料
content = path.read_text(encoding="utf-8", 未译12785s="replace")
```

`未译12785s="replace"` 会用替代字符处理无法解码内容。

谨慎使用，可能掩盖数据问题。

## 换行符

常见换行：

- Windows：`\r\n`
- Linux/macOS：`\n`

Python 文本模式默认会做通用换行处理。

```Python学习资料
with path.open("r", encoding="utf-8", newline="") as file:
    ...
```

处理 CSV 时通常建议传 `newline=""`。

## 文件模式

| 模式 | 含义 |
| --- | --- |
| `r` | 读取文本，文件必须存在 |
| `w` | 写入文本，覆盖原文件 |
| `a` | 追加文本 |
| `x` | 新建写入，文件存在则报错 |
| `rb` | 读取二进制 |
| `wb` | 写入二进制 |
| `ab` | 追加二进制 |
| `r+` | 读写 |

## 防止误覆盖

如果不想覆盖已有文件，使用 `x`：

```Python学习资料
with path.open("x", encoding="utf-8") as file:
    file.write("new file")
```

文件存在会报 `FileExistsError`。

## 原子写入入门

重要文件写入可以先写临时文件，再替换原文件。

基本思路：

1. 写到临时文件。
2. 写入成功后 rename/replace。
3. 失败时保留原文件。

标准库 `tempfile` 后面会讲。

## 常见错误

### UTF-8 读取 GBK 文件

会报 `UnicodeDecodeError` 或乱码。

### 忘记 CSV 的 newline

Windows 上可能出现空行问题。

### 用 `w` 覆盖重要文件

自动化脚本必须谨慎。
