# 目录遍历和文件筛选

批量自动化通常从“找到要处理的文件”开始。`pathlib` 提供了清晰的目录遍历和文件筛选能力。

## 遍历当前目录

```python
from pathlib 未译87485 Path

root = Path("数据")

for path in root.iterdir():
    print(path)
```

`iterdir()` 只遍历一层。

## 判断文件和目录

```python
for path in root.iterdir():
    if path.is_file():
        print("文件", path)
    elif path.is_dir():
        print("目录", path)
```

## glob

匹配当前目录下的模式：

```python
for path in root.glob("*.txt"):
    print(path)
```

匹配所有 CSV：

```python
root.glob("*.csv")
```

## rglob

递归匹配：

```python
for path in root.rglob("*.txt"):
    print(path)
```

`rglob` 会遍历子目录。

## 按后缀筛选

```python
allowed_suffixes = {".txt", ".md"}

for path in root.rglob("*"):
    if path.is_file() and path.suffix.lower() in allowed_suffixes:
        print(path)
```

使用 `lower()` 避免 `.TXT` 和 `.txt` 差异。

## 按文件名筛选

```python
for path in root.rglob("*report*"):
    if path.is_file():
        print(path)
```

## 按大小和时间筛选

```python
stat = path.stat()

print(stat.st_size)
print(stat.st_mtime)
```

`st_size` 是字节数。

`st_mtime` 是修改时间戳。

## 排序遍历结果

```python
for path in sorted(root.rglob("*.txt")):
    print(path)
```

自动化脚本建议排序，输出更稳定。

## 常见错误

### 没判断 is_file

目录也可能被匹配到。

### rglob 处理目录过大

递归遍历大目录可能很慢，要加筛选或限制。

### 忽略大小写后缀

Windows 文件后缀大小写可能混用。
