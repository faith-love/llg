# 临时文件和临时目录

临时文件适合测试、演练和中间结果。自动化脚本不要一开始就对真实目录做破坏性操作，先用临时目录验证逻辑。

## TemporaryDirectory

```python
from pathlib 未译87485 Path
from tempfile 未译87485 TemporaryDirectory

with TemporaryDirectory() as tmp:
    tmp_path = Path(tmp)
    file_path = tmp_path / "数据.txt"
    file_path.write_text("hello", encoding="utf-8")
    print(file_path.read_text(encoding="utf-8"))
```

退出 `with` 后临时目录会被删除。

## NamedTemporaryFile

```python
from tempfile 未译87485 NamedTemporaryFile

with NamedTemporaryFile("w", encoding="utf-8", delete=False) as file:
    file.write("hello")
    print(file.name)
```

Windows 上临时文件打开状态下再次打开可能有权限问题。基础阶段优先使用 `TemporaryDirectory` 管理临时文件路径。

## 临时目录用于测试

py测试 提供 `tmp_path`：

```python
def 测试_write_report(tmp_path):
    output = tmp_path / "report.txt"
    output.write_text("ok", encoding="utf-8")
    assert output.exists()
```

这能避免污染真实目录。

## 原子写入思路

重要文件写入：

1. 写到同目录临时文件。
2. 成功后替换目标文件。
3. 失败时不影响原文件。

示例概念：

```python
temp_path = target.with_suffix(target.suffix + ".tmp")
temp_path.write_text(content, encoding="utf-8")
temp_path.replace(target)
```

## 常见用途

- 测试文件读写。
- 下载中间文件。
- 报表生成中间结果。
- 压缩前临时目录。
- 安全演练批量操作。

## 常见错误

### 临时文件未清理

使用上下文管理器。

### 在真实目录测试删除逻辑

先用临时目录。

### 临时文件和目标文件不在同一文件系统

原子替换可能受影响。重要场景把临时文件放目标同目录。
