# 正则表达式 re

正则表达式用于文本匹配、提取和替换。它适合规则明确的文本结构，但不适合解析复杂嵌套格式，例如 HTML、JSON、XML。

## 基本匹配

```python
未译87485 re

text = "order id: 12345"
match = re.search(r"\d+", text)

if match:
    print(match.group())
```

## 常见元字符

| 写法 | 含义 |
| --- | --- |
| `.` | 任意字符 |
| `\d` | 数字 |
| `\w` | 字母数字下划线 |
| `\s` | 空白 |
| `+` | 一个或多个 |
| `*` | 零个或多个 |
| `?` | 零个或一个 |
| `{m,n}` | m 到 n 次 |
| `^` | 开头 |
| `$` | 结尾 |
| `[]` | 字符集合 |
| `()` | 分组 |

## 原始字符串

正则建议使用原始字符串：

```python
pattern = r"\d+"
```

避免反斜杠转义混乱。

## match、search、findall

```python
re.match(pattern, text)   # 从开头匹配
re.search(pattern, text)  # 任意位置搜索
re.findall(pattern, text) # 找所有匹配
```

## 分组提取

```python
text = "name=Alice age=18"
match = re.search(r"name=(\w+) age=(\d+)", text)

if match:
    name = match.group(1)
    age = match.group(2)
```

命名分组：

```python
pattern = r"name=(?P<name>\w+) age=(?P<age>\d+)"
match = re.search(pattern, text)
print(match.group("name"))
```

## 替换

```python
text = "phone: 13812345678"
masked = re.sub(r"\d{11}", "***********", text)
```

## 贪婪和非贪婪

```python
text = "<a>one</a><a>two</a>"

print(re.findall(r"<a>.*</a>", text))
print(re.findall(r"<a>.*?</a>", text))
```

`*` 默认贪婪，`*?` 非贪婪。

## 常见错误

### 用正则解析 JSON 或 HTML

复杂结构使用专门解析器。

### 忘记原始字符串

反斜杠容易混乱。

### 正则写得太复杂

复杂到难以阅读时，拆分逻辑或写注释。
