# 文件上传下载

文件上传下载是 Web API 中风险较高的功能。它涉及 多part、文件大小、文件类型、路径安全、临时文件、流式读写和访问权限。

## 文件名安全

客户端传来的文件名不可信。

危险：

```text
../../secret.txt
C:\Windows\system.ini
```

处理方式：

- 不直接使用原始文件名作为存储路径。
- 生成服务端文件 ID。
- 只保留安全后缀。
- 检查目标路径在上传目录内。

## 文件大小限制

必须限制：

- 单文件大小。
- 总请求大小。
- 单用户上传频率。
- 存储目录容量。

没有限制可能导致磁盘被写满。

## 文件类型校验

不要只相信后缀和 `content_type`。

基本策略：

- 后缀白名单。
- Content-Type 检查。
- 必要时检查文件头。
- 高风险文件隔离存储。

## 流式写入

大文件不要一次性读入内存。

```python
    with target.open("wb") as output:
        while chunk := await file.read(1024 * 1024):
            output.write(chunk)
```

## 文件下载

FastAPI 可使用响应类返回文件。学习阶段重点理解：

- 下载前检查权限。
- 不允许路径穿越。
- 设置合适 Content-Type。
- 大文件流式返回。

## 下载路径安全

不要让客户端直接传任意磁盘路径：

```text
/download?path=D:\secret.txt
```

应传文件 ID，由服务端映射到允许目录中的路径。

## 常见错误

### 原样使用上传文件名

可能路径穿越或覆盖文件。

### 不限制文件大小

可能导致内存或磁盘耗尽。

### 下载接口无权限检查

用户可能下载不属于自己的文件。

### 把上传目录放在代码目录

容易误提交、误覆盖、误执行。
