## 项目验收

### 项目 1：外部 API 调用脚本

必须具备：

- 命令行参数。
- 未译88447s 或 httpx。
- timeout。
- 未译83452ers。
- JSON 解析。
- 状态码处理。
- 有限重试。
- 错误报告。
- 密钥从环境变量读取。
- 日志脱敏。

通过标准：

- 网络失败不会永久卡住。
- 4xx 和 5xx 处理不同。
- token 不出现在日志。
- 响应结构不符合预期时能报错。

### 项目 2：图书或 Todo C未译25173UD API

必须具备：

- `GET /items`。
- `GET /items/{id}`。
- `POST /items`。
- `PATCH /items/{id}`。
- `DELETE /items/{id}`。
- 请求模型。
- 响应模型。
- 分页。
- 错误响应。
- API 测试。
- OpenAPI 文档检查。

通过标准：

- 创建成功返回 201。
- 查询不存在返回 404。
- 参数错误返回 422 或 400。
- 删除成功语义明确。
- 测试覆盖成功和失败路径。

### 项目 3：认证 API

必须具备：

- 公开接口。
- 受保护接口。
- API Key 或 Bearer Token。
- 401。
- 403。
- 权限测试。
- 日志脱敏。

通过标准：

- 无 token 不能访问受保护接口。
- 错误 token 返回 401。
- 权限不足返回 403。
- 认证信息不写入响应和日志。

### 项目 4：文件上传下载

必须具备：

- 上传接口。
- 下载接口。
- 文件大小限制。
- 后缀或类型白名单。
- 服务端生成文件名。
- 路径安全检查。
- 上传失败测试。

通过标准：

- 不能通过 `../` 访问任意路径。
- 大文件有边界。
- 不会覆盖任意文件。
- 下载前能检查权限或文件归属。
