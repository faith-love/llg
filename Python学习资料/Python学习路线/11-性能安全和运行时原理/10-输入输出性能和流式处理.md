# IO性能和流式处理

很多程序慢在 IO，而不是 CPU。文件、网络、数据库、磁盘都属于 IO 边界。优化 IO 的核心是减少等待、减少次数、批量处理、流式处理和控制资源。

## 一次性读取的问题

```Python学习资料
content = path.read_text(encoding="utf-8")
```

适合小文件。

大文件可能导致：

- 内存峰值高。
- 启动慢。
- 无法处理超大输入。

## 逐行处理

```Python学习资料
with path.open("r", encoding="utf-8") as file:
    for line in file:
        process(line)
```

适合日志、CSV、文本大文件。

## 分块处理

二进制文件：

```Python学习资料
with path.open("rb") as file:
    while chunk := file.read(1024 * 1024):
        process(chunk)
```

## 批量写入

不要频繁小写入。

可以：

- 收集一批再写。
- 使用缓冲。
- 使用 `writelines`。
- 数据库批量 insert。

## 网络 IO

网络请求要关注：

- timeout。
- 连接复用。
- 并发上限。
- 重试。
- 响应大小。
- 流式下载。

## 文件句柄

大量文件处理要避免同时打开太多文件。

策略：

- 每次打开一个文件。
- 用线程池限制并发。
- 使用上下文管理器及时关闭。

## 常见错误

### 大文件 read_text

一次性加载导致内存暴涨。

### 循环中每条记录写一次数据库

批量写入通常更快。

### 网络请求无 timeout

任务可能永久等待。

### 并发 IO 无上限

文件句柄、连接数、内存都可能耗尽。

## 练习

1. 逐行处理大文本文件。
2. 分块复制二进制文件。
3. 对比一次性读取和流式读取内存。
4. 批量写入 CSV。
5. 模拟每行写入和批量写入耗时差异。
6. 给网络请求设置 timeout。
7. 限制并发下载数量。
8. 写 IO 优化记录。

## 验收标准

- 能选择一次性读取、逐行读取和分块读取。
- 能减少小 IO 次数。
- 能控制文件和网络资源上限。
