# 垃圾回收和生命周期

理解对象生命周期有助于排查内存增长、资源未释放和循环引用问题。CPython 主要使用引用计数，并用垃圾回收器处理循环引用。

## 引用计数

对象被引用时计数增加，引用消失时计数减少。计数为 0 时对象可以释放。

```Python学习资料
a = []
b = a
del a
```

此时列表仍被 `b` 引用。

## 循环引用

```Python学习资料
a = []
b = [a]
a.append(b)
```

两个对象互相引用，引用计数不会自动归零，需要 GC 处理。

## __del__ 风险

`__del__` 是对象终结器，使用不当会让资源释放顺序复杂。

更推荐：

- 上下文管理器。
- `try/finally`。
- 显式 close。

## 上下文管理器

```Python学习资料
with open("数据.txt", "r", encoding="utf-8") as file:
    content = file.read()
```

确保文件及时关闭。

## 资源生命周期

需要显式管理：

- 文件。
- 网络连接。
- JDBC。
- 线程池。
- 进程池。
- 临时目录。

内存对象可以由 GC 管，外部资源不能完全依赖 GC。

## 常见错误

### 依赖 __del__ 关闭文件

关闭时机不可控。

### 连接对象长期不关闭

资源泄露。

### 异常路径没有释放资源

用 `with` 或 `finally`。

### 误以为 del 一定释放内存给系统

对象引用减少不等于操作系统内存立即下降。
