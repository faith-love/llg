# 字节码和解释执行

Python 源代码会被编译成字节码，再由解释器执行。你不需要每天读字节码，但理解它能帮助你认识函数调用、局部变量、循环和表达式的成本。

## dis 模块

```python
import dis


def add(a, b):
    return a + b


dis.dis(add)
```

`dis` 可以查看函数对应的字节码指令。

## 字节码能看什么

可以观察：

- 函数调用。
- 局部变量加载。
- 属性访问。
- 循环。
- 分支。
- 常量加载。

## 局部变量和全局变量

局部变量访问通常比全局查找更直接。

但不要为了微小差异牺牲可读性。只有热点循环里才值得关注。

## 函数调用成本

Python 函数调用有成本。

在极高频循环中：

- 过度拆小函数可能有开销。
- 但可读性通常更重要。
- 优先用 profile 判断。

## 列表推导

列表推导通常比手写 append 循环更简洁，也可能更快。

```python
squares = [x * x for x in values]
```

但如果数据很大且不需要完整列表，生成器更省内存。

## 常见错误

### 过早基于字节码优化

多数项目瓶颈不在单条字节码。

### 依赖字节码细节

不同 Python 版本字节码可能变化。

### 只看字节码不看 profile

字节码用于理解，不替代性能测量。

## 练习

6. 写一份字节码观察笔记。
