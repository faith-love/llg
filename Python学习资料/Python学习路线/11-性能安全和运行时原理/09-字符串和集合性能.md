# 字符串和集合性能

字符串、列表、集合和字典是 Python 高频数据结构。它们的性能特征会直接影响文本处理、日志分析、数据清洗和 API 参数处理。

## 字符串不可变

字符串是不可变对象。频繁拼接可能创建大量新字符串。

不推荐：

```Python学习资料
result = ""
for item in items:
    result += item
```

推荐：

```Python学习资料
result = "".join(items)
```

## join

`join` 适合把多个字符串合并。

```Python学习资料
lines = ["a", "b", "c"]
text = "\n".join(lines)
```

## 生成器表达式

```Python学习资料
total = sum(x * x for x in values)
```

生成器可以减少中间列表，但不是所有场景都更快。要测量。

常见拷贝：

- `list()`

大对象拷贝要谨慎。

## 正则性能

如果同一个正则反复使用，可以预编译：

```Python学习资料
未译87485 re


pattern = re.通用pile(r"\d+")
```

不要在大循环中重复编译同一正则。

## 常见错误

### 循环中字符串 +=

大量拼接用 join。

### list 做大量去重

用 set 或 dict。

### 不必要的中间列表

能流式处理时不要构造巨大中间结果。

### 过度正则

简单前缀后缀判断用 `startswith`、`endswith` 更清晰。
