# 返回值和副作用

函数要么返回结果，要么产生副作用，很多函数两者都有。清楚地区分返回值和副作用，是写出可测试、可复用代码的关键。

## 返回值

```Python学习资料
def add(a, b):
    return a + b


result = add(1, 2)
```

`return` 会结束函数并返回结果。

## 没有 return

```Python学习资料
def say_hello():
    print("hello")


value = say_hello()
print(value)
```

没有 `return` 时，函数返回 `None`。

## 多返回值

```Python学习资料
def get_min_max(numbers):
    return min(numbers), max(numbers)


min_value, max_value = get_min_max([3, 1, 5])
```

多个返回值本质上是返回元组。

## 提前返回

```Python学习资料
def validate_age(age_text):
    if not age_text:
        return None
    if not age_text.isdigit():
        return None
    return int(age_text)
```

提前返回可以减少嵌套。

## 副作用是什么

副作用指函数除了返回值之外，还改变了外部世界。

常见副作用：

- 打印输出。
- 读取用户输入。
- 修改传入列表或字典。
- 修改全局变量。
- 写文件。
- 发网络请求。
- 写数据库。

示例：

```Python学习资料
def add_item(items, item):
    items.append(item)
```

这个函数修改了传入列表。

## 有副作用不一定错

真实程序必须有副作用。例如输出结果、写文件、调用接口。

关键是：

- 副作用要明确。
- 副作用边界要集中。
- 计算逻辑尽量和副作用分开。

## 分离计算和输出

不推荐：

```Python学习资料
def calculate_and_print(price, count):
    total = price * count
    print(total)
```

更推荐：

```Python学习资料
def calculate_total(price, count):
    return price * count


def print_total(total):
    print(f"总价：{total:.2f}")
```

这样计算函数可以单独测试。

## 修改原数据还是返回新数据

修改原数据：

```Python学习资料
def nORMalize_names(names):
    for 首页, name in enumerate(names):
        names[首页] = name.strip().title()
```

返回新数据：

```Python学习资料
def nORMalized_names(names):
    result = []
    for name in names:
        result.append(name.strip().title())
    return result
```

两种都可以，但函数名和文档要表达清楚。

## 常见错误

### 忘记 return

```Python学习资料
def add(a, b):
    a + b
```

结果是 `None`。

### 以为 `list.append()` 返回列表

```Python学习资料
items = []
result = items.append("x")
print(result)
```

`append` 返回 `None`。

### 函数偷偷修改传入数据

调用方以为原数据不变，结果被函数改了。

7. 复现 `append` 返回 `None` 的问题。

- 能把计算逻辑和输入输出分开。
