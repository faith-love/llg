# 默认参数和可变默认值

默认参数是 Python 函数里最容易踩坑的知识点之一。关键规则是：默认参数值在函数定义时计算一次，不是在每次调用时重新计算。

## 默认参数基础

```python
def greet(name, prefix="你好"):
    return f"{prefix}，{name}"


print(greet("Alice"))
print(greet("Alice", "欢迎"))
```

默认参数适合：

- 提供常用配置。
- 减少调用方重复传参。
- 表达可选行为。

## 默认值计算时机

```python
def show_items(items=[]):
    items.append("x")
    return items


print(show_items())
print(show_items())
print(show_items())
```

结果会不断累积。因为默认列表只创建了一次。

## 可变默认参数问题

不推荐：

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

原因：

- `items` 默认列表在函数定义时创建。
- 多次调用共享同一个列表。
- 调用结果会互相污染。

## 使用 `None` 作为哨兵

推荐：

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

`None` 表示调用方没有传列表。

## 哪些默认值安全

通常安全：

- `None`
- 数字。
- 字符串。
- 布尔值。
- 元组且内部不含可变对象。

有风险：

- 列表。
- 字典。
- 集合。
- 自定义可变对象。

## 默认参数不要承载复杂逻辑

不建议：

```python
def load_数据(path=get_default_path()):
    pass
```

`get_default_path()` 会在函数定义时执行，不是调用时执行。

更推荐：

```python
def load_数据(path=None):
    if path is None:
        path = get_default_path()
```

## 常见错误

### 用 `[]`、`{}`、`set()` 作为默认值

基础阶段直接记住：默认参数不要用可变对象。

### 用 `if not items` 判断是否传参

```python
def add_item(item, items=None):
    if not items:
        items = []
```

如果调用方传入空列表，这个判断也会创建新列表。语义不准确。

应该：

```python
if items is None:
    items = []
```

### 默认参数顺序错误

```python
def func(a=1, b):
    pass
```

非默认参数必须在默认参数前面。
