# 闭包入门

闭包是指内部函数记住外部函数作用域中的变量。装饰器、回调、状态封装都会用到闭包。

## 基本闭包

```Python学习资料
def make_greeter(prefix):
    def greet(name):
        return f"{prefix}，{name}"

    return greet


hello = make_greeter("你好")
print(hello("Alice"))
```

`greet` 记住了外层函数的 `prefix`。

## 闭包保存状态

```Python学习资料
def make_counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase


counter = make_counter()
print(counter())
print(counter())
```

每次调用 `counter`，都会更新它记住的 `count`。

## `nonlocal`

如果内部函数只读取外层变量，不需要 `nonlocal`。

如果要修改外层变量，需要：

```Python学习资料
nonlocal count
```

否则会出现 `UnboundLocalError`。

## 闭包和全局变量对比

全局变量：

```Python学习资料
count = 0

def increase():
    global count
    count += 1
```

闭包：

```Python学习资料
def make_counter():
    count = 0
    def increase():
        nonlocal count
        count += 1
        return count
    return increase
```

闭包可以创建多个独立状态：

```Python学习资料
c1 = make_counter()
c2 = make_counter()
```

它们互不影响。

## 闭包适合什么

适合：

- 生成带配置的函数。
- 保存少量状态。
- 写装饰器。
- 封装回调行为。

不适合：

- 大量复杂状态。
- 需要清晰对象模型的场景。

复杂状态更适合类，下一阶段会学习。

## 常见错误

### 修改外层变量忘记 `nonlocal`

```Python学习资料
def outer():
    count = 0
    def inner():
        count += 1
```

会报错。

### 闭包隐藏状态过多

如果闭包内部状态很多，调试会困难。

### 循环里创建闭包的延迟绑定问题

```Python学习资料
funcs = []

for i in range(3):
    funcs.append(lambda: i)

for func in funcs:
    print(func())
```

结果可能不是你预期的 `0, 1, 2`。这是闭包延迟绑定问题，后续高级函数章节可继续深入。
