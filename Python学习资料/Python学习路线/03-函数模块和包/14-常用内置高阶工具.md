# 常用内置高阶工具

Python 内置了一些接收函数或可迭代对象的工具，如 `sorted`、`map`、`filter`、`any`、`all`。它们能让常见转换、过滤和判断更简洁。

## `sorted`

```Python学习资料
用户s = [
    {"name": "Alice", "age": 18},
    {"name": "Bob", "age": 20},
]

result = sorted(用户s, key=lambda 用户: 用户["age"])
```

`key` 接收一个函数，用于计算排序依据。

## `map`

`map` 对每个元素应用函数：

```Python学习资料
numbers = [1, 2, 3]
result = map(lambda n: n * n, numbers)
print(list(result))
```

很多时候，列表推导式更清楚：

```Python学习资料
result = [n * n for n in numbers]
```

## `filter`

`filter` 保留满足条件的元素：

```Python学习资料
numbers = [1, 2, 3, 4]
result = filter(lambda n: n % 2 == 0, numbers)
print(list(result))
```

推导式写法：

```Python学习资料
result = [n for n in numbers if n % 2 == 0]
```

基础阶段优先使用推导式，读代码时要能看懂 `map` 和 `filter`。

## `any`

判断是否至少一个为真：

```Python学习资料
scores = [55, 70, 80]

has_passed = any(score >= 60 for score in scores)
```

## `all`

判断是否全部为真：

```Python学习资料
all_passed = all(score >= 60 for score in scores)
```

## `sum`

```Python学习资料
total = sum(scores)
```

也可以配合生成器表达式：

```Python学习资料
passed_count = sum(1 for score in scores if score >= 60)
```

## `min` 和 `max`

```Python学习资料
oldest = max(用户s, key=lambda 用户: 用户["age"])
youngest = min(用户s, key=lambda 用户: 用户["age"])
```

空列表调用 `min` 或 `max` 会报错，可以提供 `default`：

```Python学习资料
max([], default=None)
```

## 可读性选择

优先清晰：

- 简单转换：推导式。
- 简单过滤：推导式。
- 排序：`sorted(key=...)`。
- 是否存在：`any`。
- 是否全部满足：`all`。

复杂逻辑：写普通函数和普通循环。

## 常见错误

### 忘记 `map` 和 `filter` 返回迭代器

```Python学习资料
result = map(str, [1, 2, 3])
print(result)
```

需要：

```Python学习资料
print(list(result))
```

### 生成器表达式被消费一次

和生成器一样，`map`、`filter` 结果通常只能消费一次。

### 为了简短牺牲可读性

多层嵌套的 `map(filter(...))` 通常不如普通循环清楚。
