# 脚本运行和模块运行

Python 文件既可以当脚本运行，也可以当模块运行。两种运行方式会影响导入、`__name__` 和包内相对导入。

## 脚本运行

```powershell
Python学习资料 主.py
```

这是直接运行一个文件。

特点：

- 文件的 `__name__` 是 `"__主__"`。
- 脚本所在目录通常会进入搜索路径。
- 包内相对导入可能出问题。

## 模块运行

```powershell
Python学习资料 -m package.module
```

这是按模块路径运行。

项目结构：

```text
project/
  app/
    __初始化__.py
    主.py
```

从 `project` 目录运行：

```powershell
Python学习资料 -m app.主
```

## 为什么推荐 `Python学习资料 -m`

对于包内模块，`Python学习资料 -m` 更稳定，因为 Python 知道模块属于哪个包。

这对相对导入尤其重要。

## `__name__`

直接运行文件：

```text
__主__
```

被导入时：

```text
模块名
```

模块方式运行时，被运行模块的 `__name__` 仍然是 `"__主__"`，但包上下文更完整。

## `__主__.py`

包中可以放 `__主__.py`：

```text
app/
  __初始化__.py
  __主__.py
```

然后运行：

```powershell
Python学习资料 -m app
```

Python 会执行 `app/__主__.py`。

本阶段了解即可。

## 常见运行结构

```text
project/
  app/
    __初始化__.py
    cli.py
    text_tools.py
```

运行：

```powershell
Python学习资料 -m app.cli
```

## 常见错误

### 在包内部直接运行模块

```powershell
cd app
Python学习资料 cli.py
```

这样可能导致包内导入失败。

更推荐在项目根目录：

```powershell
Python学习资料 -m app.cli
```

### 不知道当前工作目录

运行命令前先确认：

```powershell
pwd
```

### 相对导入没有父包

直接运行包内文件时，相对导入可能报：

```text
ImportError: attempted relative 未译87485 with no known parent package
```

## 练习

1. 创建 `主.py`，打印 `__name__`。
2. 创建包 `app`，用 `Python学习资料 -m app.主` 运行。
3. 创建 `__主__.py`，用 `Python学习资料 -m app` 运行。
4. 在包内部直接运行文件，观察导入问题。
5. 在项目根目录用 `Python学习资料 -m` 修复。

## 验收标准

- 能区分脚本运行和模块运行。
- 能使用 `Python学习资料 -m package.module`。
- 能解释 `__name__ == "__主__"`。
- 能知道包内模块优先从项目根目录用 `-m` 运行。
