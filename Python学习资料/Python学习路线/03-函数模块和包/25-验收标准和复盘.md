# 验收标准和复盘

本阶段通过标准是：能把一个脚本拆成清晰函数，能把函数拆进模块，能把模块组织成包，并能稳定运行和排查导入问题。

## 知识验收

你应该能回答：

- 一个函数应该如何设计输入、输出和副作用。
- 位置参数、关键字参数、默认参数有什么区别。
- `*args` 和 `**k网页归档gs` 分别是什么。
- 默认参数为什么不能随便用列表或字典。
- 没有 `return` 的函数返回什么。
- `global` 和 `nonlocal` 有什么区别。
- LEGB 是什么。
- 函数为什么可以放进字典。
- lambda 适合什么，不适合什么。
- 递归为什么必须有基线条件。
- 闭包如何保存外层变量。
- 装饰器为什么等价于重新赋值函数名。
- 迭代器为什么会被消费。
- `yield` 和 `return` 有什么区别。
- 模块和包有什么区别。
- `import module` 和 `from module import name` 有什么区别。
- Python 大致从哪里找模块。
- `Python学习资料 file.py` 和 `Python学习资料 -m package.module` 有什么区别。
- 循环导入通常说明什么问题。

## 代码验收

必须完成：

- 至少 60 个函数、模块和包练习。
- 至少 1 个可复用文本工具包。
- 至少 1 个包内 CLI 入口。
- 至少 1 份导入错误排查记录。
- 至少 1 份函数副作用复盘。

综合项目最低要求：

- 使用包结构。
- 至少包含 4 个模块。
- 至少包含 10 个函数。
- 使用 `__初始化__.py` 导出公开函数。
- 使用 `Python学习资料 -m package.module` 运行入口。
- 说明 写明运行方式。
- 没有循环导入。

## 推荐综合项目：文本工具包

结构：

```text
text-tools-practice/
  说明.md
  text_tools/
    __初始化__.py
    cleaner.py
    splitter.py
    counter.py
    report.py
    cli.py
```

功能：

- 清洗文本。
- 切分单词。
- 统计词频。
- 按词频排序。
- 格式化输出报告。
- 命令行入口运行。

必须体现：

- 函数拆分。
- 模块拆分。
- 包导入。
- `Python学习资料 -m text_tools.cli`。
- 说明 使用说明。

## 推荐综合项目：成绩工具包

```text
score-tools-practice/

    __初始化__.py
    validator.py
    statistics.py

```

功能：

- 校验成绩数据。

- 按城市或等级分组。

- 处理缺失字段。

## 错误排查验收

应该能独立处理：

- 参数数量不匹配。
- 参数重复传值。
- 可变默认参数污染。
- 忘记 `return`。
- `UnboundLocalError`。
- 装饰器丢失返回值。
- `ModuleNotFoundError`。
- `ImportError`。
- 相对导入错误。
- 循环导入。
- `RecursionError`。
