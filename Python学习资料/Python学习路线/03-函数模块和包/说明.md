# 03-函数模块和包

这一阶段的目标是从“会写脚本”推进到“会组织可复用代码”。函数解决局部复杂度，模块解决文件级组织，包解决项目级组织。学完这一阶段，代码不应该再是一个巨大的 `主.py`，而应该能拆成清晰的函数、模块和包。

如果 02 阶段关注数据怎么组织，那么 03 阶段关注逻辑怎么组织。

## 本阶段产出

- 至少 60 个函数、模块和包练习。
- 一个可复用文本处理工具包。
- 一个带命令行入口的小脚本项目。
- 一份导入错误排查笔记。
- 一份函数设计和副作用复盘。

## 本阶段不做什么

- 不深入面向对象设计，下一阶段单独学习。
- 不深入打包发布到 PyPI，只先掌握本地包结构。
- 不把装饰器、闭包、生成器学到源码级，先会读、会写基础用法。
- 不追求函数数量，追求边界清晰、输入输出明确。
