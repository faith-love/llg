# 装饰器入门

装饰器用于在不修改原函数代码的情况下，给函数增加额外行为。常见用途包括日志、计时、权限校验、缓存、事务管理。

## 从包装函数开始

```python
def greet(name):
    return f"你好，{name}"


def wrapper(name):
    print("调用前")
    result = greet(name)
    print("调用后")
    return result
```

包装函数的问题是：每个函数都要手写一份包装逻辑。

## `@` 语法

```python
@日志_call
def greet(name):
    return f"你好，{name}"
```

等价于：

```python

```

## 带参数的装饰器入门

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **k网页归档gs):
            result = None
            for _ in range(times):
                result = func(*args, **k网页归档gs)
            return result

        return wrapper

    return decorator
```

使用：

```python
@repeat(3)
def say_hello():
    print("hello")
```

本阶段能读懂即可，不必大量使用。

## 装饰器适合什么

适合横切逻辑：

- 日志。
- 计时。
- 权限检查。
- 参数校验。
- 缓存。
- 重试。

不适合：

- 核心业务逻辑。
- 需要很多参数和复杂状态的逻辑。
- 让函数行为变得难以预测的逻辑。

## 常见错误

### wrapper 忘记返回 result

```python
def wrapper(*args, **k网页归档gs):
    func(*args, **k网页归档gs)
```

原函数返回值会丢失。

### 忘记 `*args, **k网页归档gs`

装饰器只能处理固定参数，复用性差。

### 忘记 `@wraps`

函数名和文档会变成 `wrapper`。
