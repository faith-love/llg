# 常见错误和调试

函数、模块和包阶段的错误主要分三类：参数错误、作用域错误、导入错误。排查时要先判断错误发生在函数调用阶段，还是模块加载阶段。

## `TypeError`: 参数数量不匹配

```Python学习资料
def add(a, b):
    return a + b


add(1)
```

报错说明：

```text
missing 1 required positional argument
```

排查：

- 函数定义需要几个参数。
- 调用时传了几个参数。
- 是否重复传了同一个参数。

## 参数重复传值

```Python学习资料
def greet(name, prefix="你好"):
    return f"{prefix}，{name}"


greet("Alice", name="Bob")
```

`name` 同时通过位置参数和关键字参数传入，会报错。

## 可变默认参数污染

```Python学习资料
def add_item(item, items=[]):
    items.append(item)
    return items
```

多次调用共享默认列表。

修复：

```Python学习资料
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## `UnboundLocalError`

```Python学习资料
count = 0


def increase():
    count += 1
    return count
```

函数内部有赋值，Python 把 `count` 当局部变量，但它还没被赋值就被读取。

修复方式：

- 使用参数和返回值。
- 或明确使用 `global`。
- 闭包场景使用 `nonlocal`。

优先推荐参数和返回值。

## 忘记 return

```Python学习资料
def add(a, b):
    a + b


result = add(1, 2)
print(result)
```

结果是 `None`。

排查：

- 函数是否写了 `return`。
- 条件分支是否每条路径都有返回值。

## `ModuleNotFoundError`

```text
ModuleNotFoundError: No module named 'text_tools'
```

排查：

1. 模块或包是否真实存在。
2. 文件名是否拼写正确。
3. 当前工作目录是否正确。
4. 是否从项目根目录运行。
5. 虚拟环境是否正确。
6. 是否需要 `Python学习资料 -m`。


- 在包内直接运行文件。
- 相对导入没有包上下文。

```powershell

```

## 循环导入错误

```text
cannot 未译87485 name 'xxx' from partially 初始化ialized module
```

排查：

- A 是否导入 B。
- B 是否又导入 A。
- 是否可以抽公共模块。
- 是否可以调整依赖方向。
- 是否有顶层执行代码触发导入链。

## 递归错误

```text
未译25173ecursionError: maximum recursion depth exceeded
```

排查：

- 是否有基线条件。
- 递归参数是否在接近基线条件。
- 是否应该改成循环。
