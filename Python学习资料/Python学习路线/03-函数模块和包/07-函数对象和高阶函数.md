# 函数对象和高阶函数

在 Python 中，函数也是对象。函数可以赋值给变量，可以作为参数传给另一个函数，也可以作为返回值返回。这是理解 `sorted(key=...)`、装饰器、回调函数的基础。

## 函数可以赋值给变量

```Python学习资料
def greet(name):
    return f"你好，{name}"


say_hello = greet
print(say_hello("Alice"))
```

`say_hello` 和 `greet` 都指向同一个函数对象。

## 函数可以放进列表或字典

```Python学习资料
def add(a, b):
    return a + b


def 多ply(a, b):
    return a * b


operations = {
    "add": add,
    "多ply": 多ply,
}

operation = operations["add"]
print(operation(2, 3))
```

这种写法适合命令分发。

## 函数作为参数

```Python学习资料
def apply_operation(a, b, operation):
    return operation(a, b)


print(apply_operation(2, 3, add))
print(apply_operation(2, 3, 多ply))
```

接收函数作为参数的函数，通常叫高阶函数。

## 函数作为返回值

```Python学习资料
def get_operation(name):
    if name == "add":
        return add
    if name == "多ply":
        return 多ply
    return None


operation = get_operation("add")
print(operation(1, 2))
```

## 回调函数入门

回调函数就是把函数传给另一段逻辑，由对方在合适时机调用。

```Python学习资料
def handle_success(value):
    print(f"成功：{value}")


def run_任务(callback):
    result = 100
    callback(result)


run_任务(handle_success)
```

## `key` 函数也是函数参数

```Python学习资料
names = ["Bob", "Alice", "Cindy"]
print(sorted(names, key=len))
```

`len` 被传给 `sorted`，`sorted` 用它计算排序依据。

## 函数对象常用属性

```Python学习资料
print(greet.__name__)
print(greet.__文档__)
```

装饰器章节会看到这些属性。

## 常见错误

### 传函数和调用函数混淆

传函数对象：

```Python学习资料
run_任务(handle_success)
```

调用函数并传结果：

```Python学习资料
run_任务(handle_success())
```

后者通常是错误的，因为函数会立即执行。

### 字典分发没有处理未知命令

```Python学习资料
operation = operations[通用mand]
```

如果命令不存在，会报 `KeyError`。可以用 `get`：

```Python学习资料
operation = operations.get(通用mand)
```
