# 异常测试

异常分支必须测试。只测试正常路径，会让错误处理看起来存在，但实际可能完全不可用。

## py测试.raises 基础

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b


def 测试_divide_by_zero():
    with py测试.raises(ValueError):
        divide(1, 0)
```

## 断言错误信息

```python
def 测试_divide_by_zero_未译52031():
    with py测试.raises(ValueError, match="除数不能为 0"):
        divide(1, 0)
```

`match` 使用正则匹配错误信息。

## 捕获异常对象

```python
def 测试_未译12785_detail():
    with py测试.raises(ValueError) as exc_info:
        divide(1, 0)

    assert "除数" in str(exc_info.value)
```

## 测试自定义异常

```python
class InsufficientBalanceError(Exception):
    pass


def 测试_withdraw_insufficient_balance():
    account = Account(balance=100)

    with py测试.raises(InsufficientBalanceError):
        account.withdraw(200)
```

## 测试异常后状态不变

异常发生后，对象状态也要验证。

```python
def 测试_withdraw_failed_keeps_balance():
    account = Account(balance=100)

    with py测试.raises(InsufficientBalanceError):
        account.withdraw(200)

    assert account.balance == 100
```

这类测试很重要。

## 测试异常链

```python
def 测试_parse_age_未译12785_chain():
    with py测试.raises(用户InputError) as exc_info:
        parse_age("abc")

    assert isinstance(exc_info.value.__cause__, ValueError)
```

如果使用了 `raise from`，可以检查 `__cause__`。

## 常见错误

### 只测试抛出，不测试状态

业务对象失败后状态是否保持一致也要测试。

### match 文本太脆弱

如果完整匹配长错误信息，文案稍改测试就失败。匹配关键片段即可。

### 捕获太宽泛

不推荐：

```python
with py测试.raises(Exception):
    ...
```

应该捕获具体异常。

## 练习

1. 测试 `divide` 除零异常。
2. 使用 `match` 断言错误信息。
3. 捕获异常对象并检查内容。
4. 测试自定义领域异常。
5. 测试失败后对象状态不变。
6. 测试 `raise from` 异常链。
7. 把 `py测试.raises(Exception)` 改成具体异常。

## 验收标准

- 能使用 `py测试.raises`。
- 能断言异常信息。
- 能测试自定义异常。
- 能验证异常后状态。
- 能避免捕获过宽异常。
