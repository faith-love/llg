# 阶段目标

本阶段要解决的问题是：程序出错时能不能快速定位，代码修改后能不能知道是否破坏旧行为，项目变大后能不能保持一致质量。

## 你要达到的能力

完成本阶段后，应该能做到：

- 能读懂 traceback，定位出错文件、行号和调用链。
- 能区分语法错误、运行时异常、业务异常。
- 能用 `try/except/else/finally` 表达清晰错误边界。
- 能主动抛出异常，并保留异常链。
- 能设计自定义异常层级。
- 能使用断点调试和 `breakpoint()`。
- 能使用 日志ging 记录运行信息。
- 能用 unit测试 或 py测试 写基础测试。
- 能用 py测试 fixture 和参数化减少重复测试。
- 能测试异常场景。
- 能用 mock 或 monkeypatch 隔离外部依赖。
- 能组织 `测试s/` 目录。
- 能使用格式化和静态检查工具减少低级错误。

## 本阶段核心转变

从：

```python
def divide(a, b):
    return a / b
```

转为：

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b
```

再转为：

```python
def 测试_divide_by_zero():
    with py测试.raises(ValueError, match="除数不能为 0"):
        divide(1, 0)
```

也就是：明确错误，验证错误。

## 阶段通过标准

满足以下条件，可以进入下一阶段：

- 能为一个小型领域模型写自定义异常。
- 能为核心函数写 py测试 测试。
- 能为异常分支写测试。
- 能用断点或 traceback 定位问题。
- 能用 日志ging 替代长期 `print` 调试。
- 能运行格式化和静态检查工具。
- 能写阶段复盘，说明发现过哪些错误和如何避免。
