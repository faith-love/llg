# 05-异常调试测试和质量

这一阶段的目标是让代码从“能跑”变成“可定位、可验证、可维护”。异常处理负责让错误边界清晰，调试负责快速定位问题，测试负责固定行为，质量工具负责减少低级错误和风格漂移。

如果 04 阶段关注对象如何表达领域模型，那么 05 阶段关注如何证明这些模型和函数是可靠的。

## 本阶段不做什么

- 不追求 100% 覆盖率。
- 不把所有异常都捕获掉。
- 不用 mock 替代所有真实测试。
- 不为了工具而工具，先保证问题能定位、行为能验证。
- 不在日志里输出密码、令牌、身份证号等敏感信息。
