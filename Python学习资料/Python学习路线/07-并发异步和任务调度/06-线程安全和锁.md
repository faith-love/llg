# 线程安全和锁

线程安全是并发编程最重要的基础之一。只要多个线程访问共享可变状态，就要考虑竞态条件、同步和锁。

## 竞态条件

竞态条件是指程序结果取决于多个线程执行的先后顺序。

示例：

```python
counter = 0


def increase():
    global counter
    for _ in range(100000):
        counter += 1
```

多个线程同时执行时，结果可能小于预期。

## Lock

`Lock` 用于保护临界区。

```python
import threading


counter = 0
lock = threading.Lock()


def increase():
    global counter
    for _ in range(100000):
        with lock:
            counter += 1
```

临界区是不能被多个线程同时执行的代码区域。

## 锁的粒度

锁太大：

- 并发退化成串行。
- 任务等待时间变长。

锁太小：

- 仍可能漏掉共享状态。
- 代码复杂难检查。

原则：

- 只锁共享可变状态。
- 不在锁里做慢 IO。
- 不在锁里调用不可控外部函数。

## RLock

`RLock` 是可重入锁，同一个线程可以多次获取。

```python
lock = threading.RLock()
```

适合：

- 同一个对象的多个方法内部都需要锁。
- 一个加锁方法调用另一个加锁方法。

不要因为省事就默认用 `RLock`。如果不需要重入，`Lock` 更清晰。

## Event

`Event` 用于在线程之间传递状态信号。

```python
event = threading.Event()

event.set()
event.is_set()
event.wait(timeout=5)
```

常见用途：

- 通知线程停止。
- 等待初始化完成。
- 通知某个条件已经发生。

## Semaphore

`Semaphore` 用于限制同时进入某段代码的线程数量。

```python
import threading


semaphore = threading.Semaphore(3)


def worker():
    with semaphore:
        do_limited_work()
```

适合：

- 限制同时访问外部 API。
- 限制JDBC。
- 限制文件打开数量。

## Condition

`Condition` 用于更复杂的等待和通知。初学阶段了解即可，很多生产者消费者场景可以直接用 `queue.Queue`。

```python
condition = threading.Condition()
```

优先级：

1. 能用 `Queue` 就用 `Queue`。
2. 简单信号用 `Event`。
3. 限制并发用 `Semaphore`。
4. 复杂条件协调再考虑 `Condition`。

## 死锁

死锁是多个线程互相等待对方释放资源，导致都无法继续。

常见原因：

- 两把锁获取顺序不一致。
- 持有锁时等待另一个线程。
- 锁没有释放。
- 在锁内执行可能阻塞很久的操作。

预防：

- 固定锁获取顺序。
- 使用 `with lock` 自动释放。
- 缩小临界区。
- 避免嵌套锁。
- 给等待设置超时。

## 共享状态替代方案

优先级建议：

1. 不共享状态。
2. 每个线程处理独立数据。
3. 用队列传递消息。
4. 用锁保护共享状态。
5. 必要时封装线程安全对象。

## 常见错误

### 以为 list append 永远安全

某些单步操作看起来可用，但整体业务逻辑仍可能不安全。不要把实现细节当成线程安全设计。

### 锁保护不完整

写入加锁，读取不加锁，也可能看到中间状态。

### 在锁里做网络请求

这会让其他线程长时间等待。

### 捕获异常后没有释放锁

使用 `with lock`，避免手动 acquire/release 漏释放。

2. 用 `Lock` 修复计数器。
3. 演示锁粒度过大导致并发变慢。
4. 用 `Event` 停止后台线程。
5. 用 `Semaphore` 限制最多 3 个线程同时执行。
6. 构造一个简单死锁示例。
7. 修改死锁示例，固定锁顺序。
8. 把共享列表改成队列通信。

## 验收标准

- 能解释竞态条件。
- 能用 `Lock` 保护临界区。
- 能用 `Event` 传递停止信号。
- 能用 `Semaphore` 限制并发。
- 能识别死锁风险。
