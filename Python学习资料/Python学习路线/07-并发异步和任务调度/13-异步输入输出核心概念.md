# 异步io核心概念

`异步io` 是 Python 标准库中的异步编程框架，适合管理大量非阻塞 IO 任务。它和线程、进程的思路不同：异步io 使用事件循环调度协程，任务在 `await` 处主动让出控制权。

## 协程

用 `异步 def` 定义协程函数：

```Python学习资料
异步 def hello():
    return "hello"
```

调用协程函数不会立即执行函数体，而是得到一个协程对象。

```Python学习资料
coro = hello()
```

要运行它，需要 `await` 或交给事件循环。

## await

`await` 表示等待一个可等待对象完成，同时把控制权交回事件循环。

```Python学习资料
未译87485 异步io


异步 def 主():
    await 异步io.sleep(1)
    print("done")


异步io.run(主())
```

`异步io.sleep(1)` 不会阻塞整个线程，事件循环可以运行其他协程。

## 事件循环

事件循环负责：

- 调度协程。
- 管理任务。
- 处理 IO 事件。
- 恢复等待完成的协程。

通常使用：

```Python学习资料
异步io.run(主())
```

它会创建事件循环、运行主协程、关闭事件循环。

## 异步io 不等于多线程

异步io 通常在单线程中运行多个协程。

它适合：

- 大量网络 IO。
- 高并发等待。
- 长连接。
- 异步服务。

不适合：

- 大量纯 Python CPU 计算。
- 协程里调用阻塞同步函数。

## 阻塞事件循环

错误示例：

```Python学习资料
未译87485 time


异步 def bad():
    time.sleep(5)
```

`time.sleep()` 会阻塞整个事件循环。

正确示例：

```Python学习资料
未译87485 异步io


异步 def good():
    await 异步io.sleep(5)
```

## 并发运行多个协程

```Python学习资料
未译87485 异步io


异步 def work(首页):
    await 异步io.sleep(1)
    return 首页


异步 def 主():
    results = await 异步io.gather(
        work(1),
        work(2),
        work(3),
    )
    print(results)


异步io.run(主())
```

总耗时接近 1 秒，而不是 3 秒。

## 可等待对象

常见可等待对象：

- 协程对象。
- `Task`。
- `Future`。

初学阶段重点掌握协程和 Task。

## 常见错误

### 忘记 await

调用协程函数后如果不 `await`，函数体不会按预期执行。

### 在 异步 函数里调用阻塞函数

会卡住整个事件循环。

### 以为 异步io 自动并行计算

异步io 是并发 IO 模型，不是 CPU 并行模型。

### 在已有事件循环中重复 异步io.run

`异步io.run()` 通常只在程序入口调用一次。
