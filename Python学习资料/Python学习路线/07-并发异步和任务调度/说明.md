# 07-并发异步和任务调度

这一阶段的目标是让你能把“一个一个执行”的 Python 程序升级成“有控制地同时处理多个任务”的程序。重点不是盲目追求快，而是学会判断任务类型、选择并发模型、控制资源、处理取消超时、记录日志，并让任务调度长期稳定运行。

如果 06 阶段关注“单个自动化脚本能否可靠处理文件和数据”，那么 07 阶段关注“多个任务同时运行时，程序是否仍然可靠、可控、可恢复”。

## 本阶段产出

- 至少 100 个并发、异步和调度练习。
- 一个多线程批量下载或批量 IO 脚本。
- 一个进程池 CPU 密集计算脚本。
- 一个 异步io 并发请求脚本。
- 一个带限流、重试、超时和日志的任务执行器。
- 一个本地定时任务或周期调度脚本。
- 一份死锁、取消、超时、任务泄漏的错误记录。
- 一份阶段复盘。

## 本阶段不做什么

- 不把所有任务都并发化。先判断瓶颈，再选择模型。
- 不在不理解线程安全前共享可变状态。
- 不在 异步io 事件循环里直接执行长时间同步阻塞代码。
- 不为了“快”无限开线程、进程或协程。
- 不把调度器当作可靠消息队列或工作流引擎。
- 不在没有日志、超时、重试和退出机制的情况下长期运行后台任务。
