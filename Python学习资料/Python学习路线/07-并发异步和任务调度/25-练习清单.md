# 练习清单

本阶段练习目标是形成可控并发能力。每个练习都要关注：并发数量、耗时、错误、超时、退出和报告。

建议目录：

```text
Python学习资料-practice/
  stage-07/
    concepts/
    threading/
    多processing/
    异步io/
    scheduling/
    projects/
```
