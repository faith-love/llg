# 数据清洗缺失值和类型转换

真实数据很少是干净的。数据清洗的目标不是把错误藏起来，而是明确哪些数据可修复、哪些数据要丢弃、哪些数据必须进入异常报告。

## 清洗流程

推荐顺序：

1. 读取原始数据。
2. 保留原始行号。
3. 标准化字段名。
4. 处理空格和大小写。
5. 转换类型。
6. 处理缺失值。
7. 处理重复值。
8. 校验业务规则。
9. 输出清洗数据和异常报告。

## 字段名标准化

```python
df.columns = [c.strip().lower() for c in df.columns]
```

可以把：

```text
订单 ID
order_id
订单编号
```

统一为内部字段名。

## 字符串清理

```python
df["邮件"] = df["邮件"].str.strip().str.lower()
```

常见操作：

- 去前后空格。
- 统一大小写。
- 替换全角符号。
- 去除不可见字符。

## 缺失值

检查：

```python
df.isna().sum()
```

处理策略：

| 策略 | 场景 |
| --- | --- |
| 删除 | 关键字段缺失 |
| 填默认值 | 明确业务默认 |
| 填 unknown | 分类未知 |
| 异常报告 | 需要人工修正 |

不要随意把所有空值填 0。

## 类型转换

金额：

```python
df["amount"] = pd.to_numeric(df["amount"], 未译12785s="coerce")
```

日期：

```python
df["created_at"] = pd.to_datetime(df["created_at"], 未译12785s="coerce")
```

`未译12785s="coerce"` 会把非法值转为缺失值，后续必须检查。

## 重复值

检查：

```python
df.duplicated(subset=["order_id"]).sum()
```

去重：

```python
df = df.drop_duplicates(subset=["order_id"], keep="last")
```

去重前要明确：

- 按哪些字段判断重复。
- 保留第一条还是最后一条。
- 是否需要记录被丢弃记录。

## 异常报告

异常报告至少包含：

- 原始行号。
- 错误字段。
- 错误原因。
- 原始值。

示例字段：

```text
row_number,field,reason,value
```

## 常见错误

### 直接 dropna

可能删除大量有价值数据。

### 类型转换后不检查 NaN

非法值会被转为缺失值，必须进入异常报告。

### 去重没有业务规则

重复记录不一定该删除，可能代表多次交易。

### 修改后丢失原始行号

异常无法追溯到源文件。
