# 阶段目标

第 09 阶段要建立数据工程的基础能力：能理解数据库结构，能用 Python 安全访问数据库，能用 pandas 清洗常见数据，能设计可重复运行的 ETL 流程，并能通过日志和质量报告解释每一次数据处理结果。

这一阶段不是只学 SQL 或 pandas，而是把“数据读取、校验、转换、入库、复盘”连成闭环。

## 本阶段要解决的问题

你需要能回答：

- 表、主键、外键、索引、约束分别解决什么问题？
- Python 连接数据库时 connection 和 cursor 的职责是什么？
- 为什么必须使用参数化查询？
- 事务何时提交，何时回滚？
- 索引为什么能加速查询，又为什么会拖慢写入？
- pandas 的 DataFrame 和数据库表有什么相似和不同？
- 数据清洗时如何处理缺失、重复、类型错误？
- ETL 重复执行时如何避免重复写入？
- 如何记录每次处理了多少行、跳过多少行、失败多少行？
- 如何让数据任务可测试、可追踪、可恢复？

## 难点

### 难点 1：SQL 安全

SQL 注入不是高级安全问题，而是数据库访问的基本底线。任何外部输入进入 SQL，都必须参数化。

### 难点 2：事务边界

事务太大，会长时间占用锁；事务太小，可能导致中间状态暴露。你要能说明一次业务写入为什么放在一个事务里。

### 难点 3：数据类型

文件里的数据都是字符串居多，但数据库和 pandas 需要明确类型。日期、金额、空值、布尔值、分类值都要显式处理。

### 难点 4：幂等性

ETL 不是只跑一次。重复运行、失败重跑、部分成功后恢复，都是常态。必须设计主键、去重、upsert 和水位线。
