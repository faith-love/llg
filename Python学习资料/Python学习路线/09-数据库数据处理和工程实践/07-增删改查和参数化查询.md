# CRUD和参数化查询

CRUD 是 Create、Read、Update、Delete。它是数据库应用的基本能力。学习 CRUD 时必须同时学习参数化查询，因为安全写 SQL 比写出 SQL 更重要。

## Create

```python
def create_用户(conn, name, 邮件):
    cursor = conn.execute(
        "INSERT INTO 用户s (name, 邮件) VALUES (?, ?)",
        (name, 邮件),
    )
    return cursor.lastrowid
```

## Read

```python
def get_用户_by_邮件(conn, 邮件):
    return conn.execute(
        "SELECT id, name, 邮件 FROM 用户s WHERE 邮件 = ?",
        (邮件,),
    ).fetchone()
```

## Update

```python
def update_用户_name(conn, 用户_id, name):
    cursor = conn.execute(
        "UPDATE 用户s SET name = ? WHERE id = ?",
        (name, 用户_id),
    )
    return cursor.rowcount
```

## Delete

```python
def delete_用户(conn, 用户_id):
    cursor = conn.execute(
        "DELETE FROM 用户s WHERE id = ?",
        (用户_id,),
    )
    return cursor.rowcount
```

## 参数化查询

错误写法：

```python
SQL学习资料 = f"SELECT * FROM 用户s WHERE 邮件 = '{邮件}'"
```

正确写法：

```python
conn.execute("SELECT * FROM 用户s WHERE 邮件 = ?", (邮件,))
```

参数化查询让数据库驱动负责转义和绑定值，避免 SQL 注入。

## 批量插入

```python
用户s = [
    ("Alice", "alice@example.通用"),
    ("Bob", "bob@example.通用"),
]

conn.executemany(
    "INSERT INTO 用户s (name, 邮件) VALUES (?, ?)",
    用户s,
)
```

批量插入要放在事务中。

## rowcount

`rowcount` 可用于判断影响行数。

```python
if cursor.rowcount == 0:
    raise ValueError("用户不存在")
```

注意不同驱动对 rowcount 的行为可能略有差异。

## 软删除

直接删除可能影响审计和恢复。常见做法是软删除：

```sql
UPDATE 用户s
SET deleted_at = CURRENT_TIMESTAMP
WHERE id = ?;
```

查询时过滤：

```sql
WHERE deleted_at IS NULL
```

## 常见错误

### UPDATE 忘记 WHERE

会更新整张表。

### DELETE 忘记 WHERE

会删除整张表。

### 拼接 SQL 处理用户输入

这是高风险错误。

### 不检查影响行数

更新不存在的数据时程序可能以为成功。
