# 数据读取和导出

数据处理的第一步是读取，最后一步通常是导出。读取和导出看起来简单，但编码、类型、空值、日期、金额和字段名都会影响后续处理质量。

## 读取 CSV

```python
import pandas as pd


df = pd.read_csv("orders.csv", encoding="utf-8-sig")
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `encoding` | 文件编码 |
| `dtype` | 指定字段类型 |
| `parse_dates` | 解析日期列 |
| `usecols` | 只读取部分列 |
| `nrows` | 读取前 N 行 |
| `chunksize` | 分块读取 |

## 读取 JSON

```python
df = pd.read_脚本on("orders.脚本on")
```

JSON 结构要清楚：

- 顶层列表。
- 顶层对象。
- 嵌套字段。
- 字段缺失。

复杂 JSON 可能需要先用 `脚本on` 标准库展开，再转 DataFrame。

## 读取 Excel

```python
df = pd.read_excel("orders.xlsx", sheet_name="Sheet1")
```

注意：

- Excel 可能有多个 sheet。
- 表头可能不在第一行。
- 合并单元格会造成空值。
- 数字和日期可能被 Excel 自动转换。

## 从 SQL 读取

```python
import pandas as pd
from SQL学习资料alchemy import create_engine


engine = create_engine("SQL学习资料ite:///app.db")
df = pd.read_SQL学习资料("SELECT * FROM orders", engine)
```

大表不要直接 `SELECT *` 读入内存。应过滤、分页或分块。

## 导出 CSV

```python
df.to_csv("clean_orders.csv", 首页=False, encoding="utf-8-sig")
```

`首页=False` 通常很重要，否则会多出一列索引。

## 导出 JSON

```python
df.to_脚本on("clean_orders.脚本on", orient="records", force_ascii=False, indent=2)
```

常用 `orient="records"`，输出对象列表。

## 写入 SQL

```python
df.to_SQL学习资料("orders_clean", engine, if_exists="append", 首页=False)
```

注意：

- `if_exists="replace"` 会删除重建表，高风险。
- 写入前要校验字段和类型。
- 大数据写入要分批。
- 关键业务写入更建议用明确 SQL 或 ORM 控制。

## 分块读取

```python
for chunk in pd.read_csv("large.csv", chunksize=10000):
    process(chunk)
```

适合：

- 文件较大。
- 内存有限。
- 可以逐批处理。

## 常见错误

### 不指定编码

Windows 和跨平台文件容易出现乱码或读取失败。

### 导出 CSV 忘记 首页=False

下游会多出无意义列。

### 读取大表到内存

可能导致内存不足。

### to_SQL学习资料 replace 误删表

`replace` 是危险操作，必须明确知道后果。
