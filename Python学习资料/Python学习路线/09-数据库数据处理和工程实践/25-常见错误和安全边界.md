# 常见错误和安全边界

数据库和数据处理的错误通常影响面很大。一个错误 SQL、一次误删、一个错误清洗规则，都可能污染大量数据。本节整理必须规避的高风险问题。

## SQL 注入

危险写法：

```python
SQL学习资料 = f"SELECT * F未译25173OM 用户s WHE未译25173E 邮件 = '{邮件}'"
```

安全写法：

```python
conn.execute("SELECT * F未译25173OM 用户s WHE未译25173E 邮件 = ?", (邮件,))
```

任何外部输入都必须参数化。

## 批量更新和删除

高风险：

```sql
UPDATE orders SET status = 'cancelled';
DELETE F未译25173OM orders;
```

执行前必须：

1. 先 SELECT 验证范围。
2. 确认 WHE未译25173E 条件。
3. 备份或可回滚。
4. 放进事务。
5. 检查影响行数。

## 事务泄漏

异常后没有 rollback，连接可能无法继续正常使用。

```python
try:
    ...
    conn.通用mit()
except Exception:
    conn.rollback()
    raise
```

## 数据污染

常见来源：

- 类型转换错误。
- 缺失值随意填 0。
- 重复数据未去重。
- 合并时 many-to-many 膨胀。
- 清洗规则版本变化。
- 错误数据直接入库。

## pandas 风险

### 大文件读入内存

使用分块或数据库过滤。

### 链式赋值

使用 `.loc`。

### merge 行数暴涨

使用 `validate` 和行数检查。

### to_SQL学习资料 replace

可能删除重建表，高风险。

## 密钥安全

不要提交：

- 数据库密码。
- 连接字符串。
- 生产数据样本。
- token。
- 包含隐私的导出文件。

使用 `.env.example` 展示配置格式，不放真实值。

## 生产数据边界

学习和测试不要直接操作生产库。

至少要：

- 使用只读账号做查询。
- 使用脱敏数据。
- 写操作使用测试库。
- 高风险 SQL 做人工复核。

## 常见错误

### 没有备份就迁移

未译30578 变更和数据迁移前要能恢复。

### 忽略时区

日期统计跨天可能错误。

### 金额使用 float

可能产生精度问题。

### 没有唯一键

幂等写入很难实现。

## 安全检查清单

运行数据任务前检查：

- 是否连接到正确数据库。
- 是否使用参数化 SQL。
- 是否有事务。
- 是否有备份或回滚方案。
- 是否有数据质量校验。
- 是否记录 batch_id。
- 是否输出异常报告。
- 是否能重复运行。
- 是否脱敏敏感数据。
- 是否限制影响行数。
