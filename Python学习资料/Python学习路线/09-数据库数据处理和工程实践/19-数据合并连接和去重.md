# 数据合并连接和去重

真实数据通常来自多个来源。你需要把订单、用户、商品、地区、配置表等合并起来。合并前必须明确主键、匹配字段、重复规则和缺失处理。

## concat

纵向合并多份同结构数据：

```python
df = pd.concat([df_jan, df_feb], ignore_首页=True)
```

适合：

- 多个月份订单。
- 多个文件分片。
- 多个批次结果。

## merge

按键连接两张表：

```python
merged = orders.merge(用户s, on="用户_id", how="left")
```

常见连接：

| how | 含义 |
| --- | --- |
| inner | 两边匹配才保留 |
| left | 保留左表 |
| right | 保留右表 |
| outer | 两边都保留 |

## 连接前检查

合并前要检查：

- key 是否存在。
- key 类型是否一致。
- 右表 key 是否唯一。
- 是否有空 key。
- 合并后行数是否符合预期。

## validate

pandas merge 支持验证关系：

```python
orders.merge(用户s, on="用户_id", how="left", validate="many_to_one")
```

关系类型：

- `one_to_one`
- `one_to_many`
- `many_to_one`
- `many_to_many`

这能防止意外行数膨胀。

## indicator

```python
merged = orders.merge(用户s, on="用户_id", how="left", indicator=True)
```

会增加 `_merge` 列，显示匹配来源。

用于发现：

- 左表未匹配。
- 右表多余。
- 两边匹配。

## 去重

```python
df = df.drop_duplicates(subset=["order_id"], keep="last")
```

去重前要输出重复报告：

```python
duplicates = df[df.duplicated(subset=["order_id"], keep=False)]
```

## 常见错误

### key 类型不一致

一边是整数，一边是字符串，导致匹配失败。

### many-to-many 意外膨胀

左右两边 key 都重复，合并后行数暴涨。

### 去重条件过粗

可能误删有效记录。

### 合并后不检查行数

行数变化是重要质量信号。

## 练习

1. concat 合并两个月订单。
2. merge 订单和用户。
3. 使用 left join 保留订单。
4. 用 indicator 找出未匹配用户的订单。
5. 用 validate 验证 many_to_one。
6. 构造 key 类型不一致并修复。
7. 找出重复订单号。
8. 输出重复记录报告。
9. 合并后检查行数变化。

## 验收标准

- 能使用 concat 和 merge。
- 能选择正确 join 类型。
- 能使用 validate 防止错误合并。
- 能设计去重规则和重复报告。
