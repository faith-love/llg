# 版本选择

版本选择要服务于学习和项目稳定性。不要盲目追新，也不要长期停留在过旧版本。

## 当前建议

截至 2026-05-09：

- Python 官方下载页显示最新稳定下载版本为 Python 3.14.4。
- Python 3.14 处于 bugfix 阶段，适合作为新学习主线。
- Python 3.13 处于 bugfix 阶段，仍然适合新项目和兼容性要求较高的学习。
- Python 3.12 处于 安全 阶段，适合依赖生态或公司项目还没升级时使用。
- Python 3.10 仍处于 安全 阶段，但计划在 2026-10 结束支持，不建议作为新学习主线。
- Python 3.9 已结束支持，不建议新建项目使用。

## 推荐策略

| 场景 | 建议版本 | 原因 |
| --- | --- | --- |
| 全新学习 | Python 3.14 | 当前稳定主线，能接触最新语言和标准库能力 |
| 跟随多数教程 | Python 3.13 或 3.12 | 教程和第三方库兼容性通常更稳 |
| 公司项目基线是 3.12 | Python 3.12 | 学习时贴近项目环境，减少版本差异 |
| 维护旧项目 | 先使用项目指定版本 | 不先升级，先复现和理解当前行为 |
| 新建长期项目 | Python 3.14 或 3.13 | 支持周期更长，后续维护成本更低 |

## 学习时必须理解的版本概念

### 1. CPython 是默认实现

通常说的 Python 指 CPython。它是官方默认实现，也是绝大多数教程、库、框架默认支持的运行时。

需要知道：

- CPython 使用字节码解释执行。
- CPython 有 GIL，这会影响多线程 CPU 密集任务。
- 很多性能、内存、扩展库行为都和 CPython 实现有关。

暂时不需要深入：

- 自己编译 CPython。
- 写 C 扩展。
- 修改解释器源码。

### 2. 小版本会影响语法和标准库

Python 3.10、3.11、3.12、3.13、3.14 之间不是完全一样。

会影响：

- 语法是否可用。
- 标准库模块是否存在。
- 第三方依赖是否支持。
- 类型提示写法是否兼容。
- 错误信息和性能表现是否变化。

学习文档里必须记录运行版本，例如：

```powershell
Python学习资料 --version
```

### 3. bugfix、安全、end-of-life 的区别

- `bugfix`：稳定发布后仍接收 bug 修复和安全修复，通常会发布新的二进制安装包。
- `安全`：只接收安全修复，通常不再发布完整二进制安装包。
- `end-of-life`：停止支持，不再修复问题。

学习新项目时，优先选择 bugfix 阶段的版本。

## Windows 环境建议

在 Windows 上建议固定这些习惯：

- 使用官方安装器或 Python install manager。
- 确认 `py --version` 和 `Python学习资料 --version` 的实际指向。
- 每个项目使用独立 `.venv`。
- 不在系统 Python 里长期安装项目依赖。
- 项目 说明 记录 Python 版本和依赖安装命令。

常用命令：

```powershell
py -0p
Python学习资料 --version
Python学习资料 -m venv .venv
.\.venv\Scripts\Activate.ps1
Python学习资料 -m pip install -U pip
```

## 依赖兼容策略

学习时可能遇到“教程能跑，我这里不能跑”的情况。优先按下面顺序排查：

1. Python 版本是否一致。
2. 是否激活了正确虚拟环境。
3. 依赖版本是否一致。
4. 操作系统路径和命令是否不同。
5. 教程代码是否使用了旧 API。

不要一开始就怀疑自己语法没学会。很多问题本质是版本和环境不一致。
