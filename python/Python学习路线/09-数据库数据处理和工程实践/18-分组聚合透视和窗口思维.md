# 分组聚合透视和窗口思维

数据分析和报表经常需要按维度汇总。pandas 的 `groupby`、`agg`、`pivot_table`、`rolling` 和排序排名能力，是从明细数据得到业务指标的基础。

## groupby

```python
summary = df.groupby("status")["amount"].sum()
```

含义：

```text
按 status 分组，对 amount 求和
```

## 多字段分组

```python
summary = df.groupby(["created_date", "category"])["amount"].sum()
```

用于按日期和分类汇总。

## agg

```python
summary = df.groupby("category").agg(
    order_count=("order_id", "count"),
    total_amount=("amount", "sum"),
    avg_amount=("amount", "mean"),
)
```

`agg` 能一次生成多个指标。

## reset_index

groupby 后结果可能把分组字段放到索引中。

```python
summary = summary.reset_index()
```

导出 CSV 前通常需要 reset_index。

## pivot_table

```python
table = pd.pivot_table(
    df,
    values="amount",
    index="created_date",
    columns="category",
    aggfunc="sum",
    fill_value=0,
)
```

适合做二维报表。

## rolling

滚动窗口：

```python
df["rolling_7d_amount"] = df["amount"].rolling(7).sum()
```

注意：时间窗口前通常要先排序，并设置合适索引。

## rank

```python
df["rank"] = df["amount"].rank(ascending=False)
```

可用于排名。

## SQL 窗口思维

pandas 的分组和窗口思维与 SQL 很接近：

- `groupby` 对应 `GROUP BY`。
- `rank` 对应窗口排名。
- `rolling` 对应滑动窗口。
- `transform` 可把组内统计回填到每一行。

## 常见错误

### 分组前没有清洗类型

金额是字符串时求和会出错或拼接。

### 日期未排序就 rolling

滚动结果没有业务意义。

### pivot 后缺失值未填充

报表出现 NaN，影响导出和计算。

### groupby 后索引混乱

导出前检查列和索引。
