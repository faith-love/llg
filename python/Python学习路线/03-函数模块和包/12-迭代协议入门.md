# 迭代协议入门

Python 的 `for` 循环背后依赖迭代协议。理解可迭代对象和迭代器，可以帮助你读懂生成器、文件遍历、`map`、`filter` 等惰性对象。

## 可迭代对象

可以被 `for` 遍历的对象，通常叫可迭代对象。

常见可迭代对象：

- 字符串。
- 列表。
- 元组。
- 字典。
- 集合。
- `range`。
- 文件对象。
- 生成器。

示例：

```python
for char in "abc":
    print(char)
```

## 迭代器

迭代器是可以被 `next()` 逐个取值的对象。

```python
items = [1, 2, 3]
iterator = iter(items)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

取完后再取，会抛出 `StopIteration`。

## `for` 循环背后的过程

大致等价于：

```python
items = [1, 2, 3]
iterator = iter(items)

while True:
    try:
        item = next(iterator)
    except StopIteration:
        break
    print(item)
```

本阶段不需要手写这种代码，但要理解 `for` 是不断取下一个值。

## 可迭代对象和迭代器的区别

列表是可迭代对象，但不是迭代器：

```python
items = [1, 2, 3]
next(items)
```

会报错。

需要先：

```python
iterator = iter(items)
```

## 迭代器会消耗

```python
iterator = iter([1, 2, 3])

for item in iterator:
    print(item)

for item in iterator:
    print(item)
```

第二个循环不会输出，因为迭代器已经被消耗完。

## 惰性计算

很多迭代器不会一次性生成所有数据，而是用到时才生成。

好处：

- 节省内存。
- 适合处理大数据流。
- 可以表示无限序列。

代价：

- 只能消费一次。
- 调试时需要小心。

## 常见错误

### 以为迭代器可以反复遍历

迭代器通常只能消费一次。

### 把列表和迭代器混为一谈

列表保存所有元素，迭代器按需取值。

### 直接 `next()` 可迭代对象

先用 `iter()`。

4. 比较列表和迭代器的区别。
5. 用 `for` 遍历字典、集合、字符串。
