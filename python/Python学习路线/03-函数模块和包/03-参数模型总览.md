# 参数模型总览

Python 函数参数非常灵活。基础阶段只会普通参数还不够，需要系统理解位置参数、关键字参数、默认参数、可变参数、仅位置参数和仅关键字参数。

## 普通位置参数

```python
def add(a, b):
    return a + b


add(1, 2)
```

调用时按位置匹配：

- `a = 1`
- `b = 2`

## 关键字参数

```python
def introduce(name, age):
    return f"{name}: {age}"


introduce(name="Alice", age=18)
introduce(age=18, name="Alice")
```

关键字参数按名字匹配，顺序可以变化。

## 混合调用

```python
introduce("Alice", age=18)
```

规则：

- 位置参数要放在关键字参数前面。
- 同一个参数不能重复传值。

错误：

```python
introduce(name="Alice", 18)
introduce("Alice", name="Bob")
```

## 默认参数

```python
def greet(name, prefix="你好"):
    return f"{prefix}，{name}"
```

默认参数必须放在非默认参数后面。

错误：

```python
def greet(prefix="你好", name):
    return f"{prefix}，{name}"
```

## 可变位置参数 `*args`

接收任意数量的位置参数：

```python
def add_all(*numbers):
    total = 0
    for number in numbers:
        total += number
    return total


print(add_all(1, 2, 3))
```

`numbers` 是一个元组。

## 可变关键字参数 `**kwargs`

接收任意数量的关键字参数：

```python
def print_user(**fields):
    for key, value in fields.items():
        print(key, value)


print_user(name="Alice", age=18)
```

`fields` 是一个字典。

## 参数解包

列表或元组解包成位置参数：

```python
values = [1, 2]
print(add(*values))
```

字典解包成关键字参数：

```python
data = {"name": "Alice", "age": 18}
print(introduce(**data))
```

## 仅关键字参数

`*` 后面的参数必须用关键字传入：

```python
def create_user(name, *, age, city):
    return {"name": name, "age": age, "city": city}


create_user("Alice", age=18, city="Shanghai")
```

这样可以提高调用可读性。

## 仅位置参数

`/` 前面的参数只能按位置传入：

```python
def divide(a, b, /):
    return a / b
```

基础阶段了解即可。很多内置函数会使用这种签名。

## 参数顺序完整形式

完整顺序大致是：

```python
def func(pos_only, /, normal, *args, keyword_only, **kwargs):
    pass
```

学习阶段不用强行写复杂签名，但要能读懂。

## 常见错误

### 参数数量不匹配

```python
add(1)
```

会报 `TypeError`。

### 默认参数顺序错误

非默认参数不能放在默认参数后面。

### 传参重复

```python
introduce("Alice", name="Bob")
```

`name` 被传了两次。
