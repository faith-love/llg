# 递归入门

递归是函数调用自己。它适合处理树形结构、嵌套结构、分治问题。基础阶段不要求大量刷递归题，但要理解基线条件和递归调用。

## 最小递归

```python
def countdown(n):
    if n <= 0:
        return
    print(n)
    countdown(n - 1)


countdown(3)
```

输出：

```text
3
2
1
```

## 基线条件

递归必须有停止条件，也叫基线条件。

```python
if n <= 0:
    return
```

没有停止条件会无限递归，最终报 `RecursionError`。

## 递归计算阶乘

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

调用过程：

```text
factorial(3)
3 * factorial(2)
3 * 2 * factorial(1)
3 * 2 * 1 * factorial(0)
3 * 2 * 1 * 1
```

## 递归处理嵌套列表

```python
def flatten(items):
    result = []

    for item in items:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)

    return result
```

示例：

```python
print(flatten([1, [2, 3], [4, [5]]]))
```

## 递归的成本

递归每次调用都会占用调用栈。Python 有递归深度限制。

```python
def loop():
    loop()
```

会触发 `RecursionError`。

基础阶段不要用递归替代所有循环。

## 递归适合什么

适合：

- 树形目录。
- 嵌套列表。
- 嵌套字典。
- 分治算法。
- 语法树或菜单树。

不适合：

- 普通计数循环。
- 简单列表遍历。
- 数据量很大且深度不可控的场景。

## 常见错误

### 没有基线条件

函数永远调用自己。

### 递归参数没有变化

```python
def countdown(n):
    countdown(n)
```

### 递归过深

嵌套层级太深时，可能触发递归深度限制。
