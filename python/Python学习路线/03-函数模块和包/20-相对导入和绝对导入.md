# 相对导入和绝对导入

包内模块之间可以使用绝对导入或相对导入。导入方式不清楚时，很容易遇到 `ModuleNotFoundError` 或 “attempted relative import” 错误。

## 绝对导入

从项目包根路径写完整导入：

```python
from text_tools.cleaner import clean_text
```

优点：

- 来源清晰。
- 不依赖当前文件层级理解。
- 推荐优先使用。

## 相对导入

在包内部，使用点表示相对位置：

```python
from .cleaner import clean_text
from .counter import count_words
```

一个点表示当前包。

两个点表示上一级包：

```python
from ..config import DEFAULT_ENCODING
```

本阶段先掌握一个点的用法。

## 示例结构

```text
project/
  text_tools/
    __init__.py
    cleaner.py
    counter.py
    report.py
```

`report.py`：

```python
from .cleaner import clean_text
from .counter import count_words
```

从项目根目录运行：

```powershell
python -m text_tools.report
```

## 相对导入的运行要求

相对导入要求模块知道自己属于哪个包。

如果直接运行：

```powershell
python text_tools/report.py
```

可能报：

```text
ImportError: attempted relative import with no known parent package
```

使用：

```powershell
python -m text_tools.report
```

## 什么时候用绝对导入

优先使用绝对导入：

- 主流程模块。
- 跨包导入。
- 项目结构比较清晰时。

## 什么时候用相对导入

可以使用相对导入：

- 同一个包内部模块互相引用。
- 包名较长。
- 明确要表达包内关系。

## 常见错误

### 在包内文件直接运行相对导入

使用 `python -m`。

### 相对导入层级写错

点的数量和目录层级要一致。

### 混用运行方式

同一项目不要一会儿直接运行文件，一会儿模块运行，否则导入问题会混乱。

## 排查建议

1. 确认是否在项目根目录运行。
2. 确认包目录有 `__init__.py`。
3. 优先尝试绝对导入。
4. 包内相对导入配合 `python -m`。
5. 不要靠随意改 `sys.path` 解决。

## 练习

1. 用绝对导入引用包内函数。
2. 用相对导入引用同包模块。
3. 直接运行相对导入文件，观察错误。
4. 用 `python -m` 修复。
5. 把相对导入改成绝对导入，比较可读性。

## 验收标准

- 能区分绝对导入和相对导入。
- 能使用一个点的相对导入。
- 能解释相对导入为什么需要包上下文。
- 能用 `python -m` 运行包内模块。
