# 作用域和名称查找

作用域决定变量名在哪里可见。Python 的名称查找遵循 LEGB 规则。理解作用域可以避免很多 `NameError`、`UnboundLocalError` 和全局变量污染问题。

## LEGB 规则

Python 查找名字时大致按顺序：

1. Local：当前函数局部作用域。
2. Enclosing：外层函数作用域。
3. Global：当前模块全局作用域。
4. Built-in：内置作用域。

## 局部作用域

```python
def greet():
    message = "hello"
    print(message)


greet()
```

`message` 只在函数内部可见。

## 全局作用域

```python
site_name = "Python 学习"


def print_site():
    print(site_name)
```

函数内部可以读取全局变量。

## 函数内部赋值会创建局部变量

```python
count = 0


def increase():
    count = count + 1
    return count
```

这会报 `UnboundLocalError`。因为函数内有赋值，Python 把 `count` 判断为局部变量，但右侧读取时它还没有值。

## `global`

```python
count = 0


def increase():
    global count
    count += 1
```

`global` 表示函数内使用模块级变量。

不建议频繁使用。更推荐：

```python
def increase(count):
    return count + 1
```

## 外层函数作用域

```python
def outer():
    message = "hello"

    def inner():
        print(message)

    inner()
```

`inner` 可以读取 `outer` 的变量。

## `nonlocal`

如果内层函数要修改外层函数变量，使用 `nonlocal`：

```python
def make_counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase
```

本阶段先会读懂即可。

## 内置作用域

内置函数来自 Built-in 作用域：

```python
len([1, 2, 3])
print("hello")
```

不要覆盖内置名字：

```python
list = [1, 2, 3]
str = "hello"
sum = 100
```

## 作用域设计建议

- 函数优先通过参数接收数据。
- 函数优先通过返回值输出结果。
- 少用全局变量。
- 常量可以放模块顶部。
- 不要在函数里隐式依赖大量外部状态。

## 常见错误

### 局部变量未绑定

`UnboundLocalError` 常来自函数内既读取又赋值同名变量。

### 覆盖内置函数

```python
sum = 10
sum([1, 2, 3])
```

会报错。

### 全局变量让函数难测试

函数依赖全局配置时，测试和复用都会变困难。
