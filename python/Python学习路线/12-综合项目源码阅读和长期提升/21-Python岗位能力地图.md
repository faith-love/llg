# Python岗位能力地图

Python 可以走多个方向。长期提升要结合目标岗位，而不是所有方向平均用力。

## 自动化和脚本方向

核心能力：

- 文件处理。
- Excel/CSV/JSON。
- CLI。
- 批处理。
- 日志。
- 调度。
- 错误报告。

作品：

- 自动化工具平台。
- 报表生成工具。
- 运维脚本集合。

## 后端开发方向

核心能力：

- HTTP。
- FastAPI/Flask。
- 数据库。
- ORM。
- 认证授权。
- 测试。
- Docker。
- CI。

作品：

- Web API 服务。
- 后台管理 API。
- 任务系统。

## 数据处理方向

核心能力：

- SQL。
- pandas。
- ETL。
- 数据质量。
- 增量同步。
- 报表。
- 可视化基础。

作品：

- 数据清洗管道。
- 业务报表系统。
- 数据质量检查工具。

## 测试开发方向

核心能力：

- pytest。
- 接口测试。
- mock。
- 自动化测试框架。
- CI。
- 测试数据管理。

作品：

- API 测试框架。
- 数据驱动测试工具。
- 测试报告系统。

## 平台和工具方向

核心能力：

- CLI。
- 插件系统。
- 包管理。
- Docker。
- CI/CD。
- 监控。
- 性能和安全。

作品：

- 内部开发者工具。
- 任务调度平台。
- 质量检查工具链。

## 选择路径

问自己：

- 我更喜欢业务服务还是工具自动化？
- 我是否喜欢数据分析和清洗？
- 我是否愿意深入部署和平台？
- 当前工作机会需要什么？
- 我的项目组合能证明哪个方向？

## 常见错误

### 所有方向都浅尝

很难形成竞争力。

### 只学框架不学基础

框架变化快，基础迁移能力更重要。

### 项目和岗位方向不匹配

想做后端却只有数据清洗脚本，证明力不足。

## 练习

1. 选择 1 个主方向。
2. 选择 1 个辅助方向。
3. 列出目标岗位要求。
4. 对照当前能力打分。
5. 设计 3 个匹配项目。
6. 写 3 个月提升计划。

## 验收标准

- 能区分 Python 常见岗位方向。
- 能选择自己的主线。
- 能让项目组合匹配目标岗位。
