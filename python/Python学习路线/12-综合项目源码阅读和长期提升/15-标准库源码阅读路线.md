# 标准库源码阅读路线

标准库源码是学习 Python 设计风格的重要材料。不要一开始读最复杂的模块，先从你用过、边界清晰、能写最小示例的模块开始。

## 推荐顺序

1. `pathlib`
2. `json`
3. `csv`
4. `logging`
5. `argparse`
6. `dataclasses`
7. `functools`
8. `asyncio`

## pathlib

阅读目标：

- Path 对象如何封装路径操作。
- Windows 和 Posix 差异如何处理。
- 方法如何返回新 Path。

问题：

- `Path("a") / "b"` 如何实现？
- `resolve()` 做了什么？
- `glob()` 如何工作？

## json

阅读目标：

- dumps/load 的入口。
- encoder/decoder 分工。
- default 参数如何处理。

问题：

- 不可序列化对象如何报错？
- `ensure_ascii=False` 如何影响输出？

## csv

阅读目标：

- reader 和 DictReader。
- dialect 概念。
- newline 处理边界。

问题：

- DictReader 如何使用表头？
- 为什么建议 `newline=""`？

## logging

阅读目标：

- logger、handler、formatter。
- 日志级别判断。
- propagation。

问题：

- 为什么重复日志会出现？
- handler 如何决定输出位置？

## argparse

阅读目标：

- parser。
- argument。
- action。
- help 生成。

问题：

- required 参数如何校验？
- subcommand 如何实现？

## dataclasses

阅读目标：

- 装饰器如何生成方法。
- field/default_factory。
- frozen。

问题：

- 为什么可变默认值危险？
- `__post_init__` 何时调用？

## asyncio

阅读目标：

- event loop。
- Task。
- Future。
- Queue。

注意：asyncio 复杂，先读文档和小片段，不要一口吃完。

## 常见错误

### 一开始读 asyncio 全部源码

难度过高。

### 不结合使用场景

源码要和自己的代码示例配合。

### 不记录版本

源码随版本变化。

## 练习

1. 阅读 pathlib 的一个方法。
2. 阅读 json.dumps 调用链。
3. 阅读 DictReader 初始化。
4. 阅读 logging handler 流程。
5. 阅读 argparse 子命令示例。
6. 阅读 dataclass default_factory 相关逻辑。
7. 写 3 篇标准库源码笔记。

## 验收标准

- 能选择合适标准库阅读目标。
- 能写最小示例和调用链。
- 能总结标准库设计风格。
