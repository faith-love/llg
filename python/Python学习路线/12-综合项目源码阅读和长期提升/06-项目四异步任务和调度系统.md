# 项目四：异步任务和调度系统

异步任务和调度系统适合展示并发、asyncio、队列、限流、重试、调度、日志、监控和优雅退出能力。

## 项目目标

实现一个任务执行器：

- 从输入源读取任务。
- 按并发上限执行。
- 失败后有限重试。
- 输出结果报告。
- 支持周期调度。
- 支持优雅退出。

## 示例场景

- URL 状态巡检。
- API 批量同步。
- 文件转换任务。
- 定时目录扫描。
- 周期报表生成。

## 必备功能

- 任务队列。
- worker。
- 并发上限。
- timeout。
- retry。
- backoff。
- 失败报告。
- 运行日志。
- 停止信号。

## 推荐模型

```text
producer -> queue -> workers -> result collector -> report
```

队列必须有 maxsize，避免任务堆积。

## asyncio 示例方向

使用：

- `asyncio.Queue`。
- `asyncio.create_task`。
- `asyncio.Semaphore`。
- `asyncio.wait_for`。
- `task.cancel()`。

## 调度要求

周期任务要处理：

- 上次未结束是否跳过。
- 单次任务超时。
- 错过执行是否补跑。
- Ctrl+C 退出。
- 下次运行时间日志。

## 测试要求

至少测试：

- 成功任务。
- 失败任务。
- 超时任务。
- 重试次数。
- 并发上限。
- 队列 maxsize。
- 取消任务。
- 报告输出。

## 常见错误

### 无限创建任务

必须限制并发。

### 没有 timeout

worker 可能永久卡住。

### 失败后无限重试

必须有限重试和退避。

### 退出时不取消任务

后台任务泄漏。

## 验收标准

- 能并发执行任务。
- 能限制并发。
- 能处理超时、重试和取消。
- 能输出任务报告。
- 能周期运行并优雅退出。
