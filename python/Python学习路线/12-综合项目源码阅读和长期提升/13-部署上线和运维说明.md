# 部署上线和运维说明

部署说明用于保证项目从本地开发走向可运行环境。即使只是学习项目，也应该能说明配置、启动、日志、健康检查、备份和回滚。

## 部署说明结构

```markdown
# 部署说明

## 环境要求

## 配置项

## 启动命令

## 健康检查

## 日志

## 数据持久化

## 备份恢复

## 回滚

## 常见问题
```

## 环境要求

说明：

- Python 版本。
- 操作系统。
- 依赖服务。
- 数据库。
- 端口。
- 磁盘目录。

## 配置项

列出：

- 环境变量名。
- 是否必填。
- 示例值。
- 是否敏感。
- 默认值。

## 启动命令

本地：

```powershell
uvicorn app.main:app --reload
```

容器：

```powershell
docker run --rm -p 8000:8000 my-api:0.1.0
```

## 健康检查

```text
GET /health
```

说明健康检查验证哪些依赖。

## 日志

说明：

- 日志输出位置。
- 日志级别。
- request_id。
- 错误日志。
- 敏感信息脱敏。

## 备份和回滚

即使学习项目，也要说明：

- 数据在哪里。
- 如何备份。
- 如何恢复。
- 发布失败如何回滚到上一个版本。

## 常见错误

### 部署命令和 README 不一致

新环境跑不起来。

### 配置项没有说明是否敏感

容易泄露。

### 无健康检查

无法判断服务是否可用。

### 无回滚方案

上线失败无法恢复。

## 练习

1. 写环境要求。
2. 写配置项表。
3. 写本地启动命令。
4. 写 Docker 启动命令。
5. 增加健康检查说明。
6. 写日志说明。
7. 写备份恢复说明。
8. 写回滚步骤。

## 验收标准

- 部署说明能复现运行环境。
- 配置项清晰。
- 有健康检查、日志和回滚说明。
