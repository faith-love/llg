# 列表排序和反转

排序是数据处理中最常见的操作之一。Python 提供 `list.sort()` 和 `sorted()` 两种主要方式。

## `sort()` 原地排序

```python
numbers = [3, 1, 2]
numbers.sort()
print(numbers)
```

`sort()` 会修改原列表，返回 `None`。

常见错误：

```python
numbers = [3, 1, 2]
result = numbers.sort()
print(result)
```

`result` 是 `None`。

## `sorted()` 返回新列表

```python
numbers = [3, 1, 2]
new_numbers = sorted(numbers)

print(numbers)
print(new_numbers)
```

`sorted()` 不修改原数据，返回排序后的新列表。

## 降序排序

```python
numbers = [3, 1, 2]

print(sorted(numbers, reverse=True))
```

或：

```python
numbers.sort(reverse=True)
```

## 字符串排序

```python
names = ["Bob", "Alice", "Cindy"]
print(sorted(names))
```

按字符顺序排序。中文排序涉及拼音或本地化规则，后续再深入。

## 按 key 排序

按字符串长度排序：

```python
names = ["Bob", "Alice", "Cindy"]
print(sorted(names, key=len))
```

按字典字段排序：

```python
users = [
    {"name": "Alice", "age": 18},
    {"name": "Bob", "age": 20},
    {"name": "Cindy", "age": 17},
]

users_by_age = sorted(users, key=lambda user: user["age"])
print(users_by_age)
```

本阶段先会使用简单 `lambda`，函数和高级用法后续继续深入。

## 多条件排序

```python
users = [
    {"name": "Alice", "age": 18, "score": 90},
    {"name": "Bob", "age": 18, "score": 85},
    {"name": "Cindy", "age": 17, "score": 95},
]

result = sorted(users, key=lambda user: (user["age"], -user["score"]))
```

含义：

- 先按年龄升序。
- 年龄相同再按分数降序。

## 稳定排序

Python 排序是稳定的。稳定排序意味着：如果两个元素排序键相同，它们原来的相对顺序会保留。

这在多轮排序时很有用。

## 反转

原地反转：

```python
items = [1, 2, 3]
items.reverse()
```

返回反向迭代器：

```python
items = [1, 2, 3]
for item in reversed(items):
    print(item)
```

切片反转：

```python
items = [1, 2, 3]
print(items[::-1])
```

## 常见错误

### 把 `sort()` 的返回值当新列表

`sort()` 返回 `None`。

### 对混合类型排序

```python
items = [1, "2", 3]
print(sorted(items))
```

数字和字符串不能直接比较。

### 字典字段不存在

```python
sorted(users, key=lambda user: user["score"])
```

如果某个用户没有 `score`，会报 `KeyError`。

可以先清洗数据，或使用：

```python
sorted(users, key=lambda user: user.get("score", 0))
```
