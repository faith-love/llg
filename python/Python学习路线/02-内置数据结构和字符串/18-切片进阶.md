# 切片进阶

切片是序列处理中非常高频的语法。基础阶段已经见过 `start:stop`，这一节补齐步长、反转、复制、边界和可变序列切片赋值。

## 基本格式

```python
序列[start:stop:step]
```

- `start`：开始位置，包含。
- `stop`：结束位置，不包含。
- `step`：步长。

## 省略规则

```python
items = [0, 1, 2, 3, 4, 5]

print(items[:3])
print(items[3:])
print(items[:])
```

含义：

- `[:3]`：从开头到索引 3 前。
- `[3:]`：从索引 3 到结尾。
- `[:]`：复制整个序列。

## 步长

```python
items = [0, 1, 2, 3, 4, 5]

print(items[::2])
print(items[1::2])
```

`step=2` 表示每隔一个取一个。

## 反转

```python
items = [1, 2, 3]
print(items[::-1])
```

字符串也可以：

```python
text = "python"
print(text[::-1])
```

## 负数索引切片

```python
items = [0, 1, 2, 3, 4, 5]

print(items[-3:])
print(items[:-1])
```

常用场景：

- 取最后 N 个元素。
- 去掉最后一个元素。

## 切片越界

```python
items = [1, 2, 3]

print(items[100:200])
```

不会报错，结果是空列表。

索引越界会报错：

```python
print(items[100])
```

## 切片复制

```python
items = [1, 2, 3]
new_items = items[:]
```

这是浅拷贝。对于一层列表通常够用；嵌套列表会共享内部对象。

## 列表切片赋值

列表是可变序列，支持切片赋值：

```python
items = [1, 2, 3, 4]
items[1:3] = [20, 30]
print(items)
```

也可以改变长度：

```python
items[1:3] = [99]
```

本阶段先了解，实际项目里不要过度使用复杂切片赋值。

## 删除切片

```python
items = [1, 2, 3, 4]
del items[1:3]
```

## 常见错误

### 忘记 stop 不包含

`items[1:3]` 取索引 1 和 2，不包含 3。

### 负步长边界混乱

复杂负步长切片可读性差，必要时拆成更清楚的代码。

### 以为切片深拷贝

```python
matrix = [[1], [2]]
new_matrix = matrix[:]
new_matrix[0].append(99)
print(matrix)
```

内部列表仍然共享。

## 练习

1. 取列表前三个元素。
2. 取列表后三个元素。
3. 每隔一个元素取一个。
4. 反转字符串。
5. 去掉字符串首尾字符。
6. 使用切片复制列表。
7. 复现嵌套列表切片浅拷贝问题。

## 验收标准

- 能熟练使用 `start:stop:step`。
- 能解释 stop 不包含。
- 能用切片反转和复制。
- 能说明切片复制是浅拷贝。
