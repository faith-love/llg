# 阶段目标

这一阶段要从“能写基础语法”推进到“能组织和处理一批数据”。Python 之所以适合自动化、数据清洗、接口处理，很大程度上是因为内置数据结构好用。

## 你要达到的能力

完成本阶段后，应该能做到：

- 根据场景选择 `list`、`tuple`、`dict`、`set`、`str`。
- 熟练使用索引、切片、遍历、成员判断。
- 使用列表完成批量存储、过滤、转换、排序。
- 使用字典表达键值关系、查找表、计数和分组。
- 使用集合完成去重、交集、并集、差集。
- 使用字符串方法完成文本清洗、切分、拼接和判断。
- 理解可变对象和不可变对象的区别。
- 理解浅拷贝和深拷贝为什么影响嵌套结构。
- 能处理列表套字典、字典套列表等常见嵌套数据。
- 能写出 100 行以内的数据处理脚本。

## 为什么这一阶段重要

真实任务很少只处理单个数字或字符串。更多时候是：

- 一批文件路径。
- 一批用户记录。
- 一段日志文本。
- 一个 JSON 对象。
- 一张表格里的多行数据。
- 一个接口返回的列表和字典。

例如：

```python
users = [
    {"name": "Alice", "age": 18, "city": "Shanghai"},
    {"name": "Bob", "age": 20, "city": "Beijing"},
    {"name": "Cindy", "age": 17, "city": "Shanghai"},
]

adult_names = []

for user in users:
    if user["age"] >= 18:
        adult_names.append(user["name"])

print(adult_names)
```

这里同时用到了：

- 列表保存多条记录。
- 字典表示单个用户。
- 字符串作为键和值。
- 循环遍历。
- 条件过滤。
- 列表追加。

这就是后续大量项目的基本数据形态。
