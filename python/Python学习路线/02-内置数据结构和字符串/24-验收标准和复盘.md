# 验收标准和复盘

本阶段通过标准是：能用 Python 内置数据结构完成常见小型数据处理任务，并能解释可变性、拷贝、排序、去重、计数、分组这些核心机制。

## 知识验收

你应该能回答：

- 列表、元组、字典、集合分别适合什么场景。
- 可变对象和不可变对象有什么区别。
- `==` 和 `is` 有什么区别。
- 为什么 `b = a` 不是复制列表。
- 浅拷贝和深拷贝有什么区别。
- `append` 和 `extend` 有什么区别。
- `sort()` 和 `sorted()` 有什么区别。
- 字典的 `get` 和 `[]` 访问有什么区别。
- `set` 为什么能去重。
- 空字典和空集合怎么写。
- `split` 和 `join` 分别做什么。
- 字符串为什么是不可变的。
- UTF-8 编码和 bytes 的基本关系是什么。
- 推导式什么时候适合用，什么时候不适合用。

## 代码验收

必须完成：

- 至少 60 个练习。
- 至少 1 个词频统计脚本。
- 至少 1 个成绩统计脚本。
- 至少 1 个用户分组脚本。
- 至少 1 个文本清洗脚本。
- 至少 5 个数据结构错误复现和修复记录。

综合脚本最低要求：

- 使用列表保存多条数据。
- 使用字典表达一条记录或计数结果。
- 使用集合完成去重或成员判断。
- 使用字符串方法做文本清洗。
- 使用函数拆分主要逻辑。
- 能处理空输入或缺失字段。

## 推荐综合项目：学生成绩统计

数据示例：

```python
students = [
    {"name": "Alice", "city": "Shanghai", "score": 90},
    {"name": "Bob", "city": "Beijing", "score": 58},
    {"name": "Cindy", "city": "Shanghai", "score": 76},
]
```

功能要求：

- 输出最高分、最低分、平均分。
- 输出及格人数。
- 按城市分组学生。
- 按分数降序排序。
- 筛选不及格学生。
- 处理缺失 `score` 的记录。

必须使用：

- 列表遍历。
- 字典读取。
- `get` 默认值。
- `sorted(key=...)`。
- 分组逻辑。
- 函数拆分。

## 推荐综合项目：文本词频统计

功能要求：

- 输入一段英文文本。
- 转小写。
- 去掉简单标点。
- 按空白切分单词。
- 统计每个单词出现次数。
- 按出现次数降序输出。

必须使用：

- 字符串方法。
- 列表。
- 字典计数。
- 排序。
