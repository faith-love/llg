# 内置数据结构总览

数据结构是组织数据的方式。选择合适的数据结构，会让代码更简单、性能更稳定、错误更少。

## 常用内置结构

| 类型 | 示例 | 适合场景 | 是否可变 |
| --- | --- | --- | --- |
| `str` | `"hello"` | 文本 | 不可变 |
| `list` | `[1, 2, 3]` | 有序、可变、可重复的一组数据 | 可变 |
| `tuple` | `(1, 2, 3)` | 有序、不可变的一组数据 | 不可变 |
| `dict` | `{"name": "Alice"}` | 键值映射、快速查找 | 可变 |
| `set` | `{1, 2, 3}` | 去重、集合运算、快速成员判断 | 可变 |
| `frozenset` | `frozenset({1, 2})` | 不可变集合 | 不可变 |
| `bytes` | `b"abc"` | 二进制数据 | 不可变 |

## 按用途选择

### 保存一批有顺序的数据

使用 `list`：

```python
scores = [90, 85, 100]
```

适合：

- 成绩列表。
- 文件路径列表。
- 用户记录列表。
- 待处理任务列表。

### 保存固定组合

使用 `tuple`：

```python
point = (3, 5)
```

适合：

- 坐标。
- 函数返回多个值。
- 不希望被修改的一组值。

### 按键查找值

使用 `dict`：

```python
user = {"name": "Alice", "age": 18}
```

适合：

- 用户信息。
- 配置。
- 计数器。
- 查找表。
- JSON 数据。

### 去重或集合运算

使用 `set`：

```python
cities = {"Shanghai", "Beijing", "Shenzhen"}
```

适合：

- 去重。
- 判断是否存在。
- 求交集、并集、差集。

### 保存文本

使用 `str`：

```python
text = "hello python"
```

适合：

- 用户输入。
- 文件内容。
- 日志行。
- 接口字段。

## 有序和无序

有序结构：

- `str`
- `list`
- `tuple`

可以使用索引：

```python
names = ["Alice", "Bob"]
print(names[0])
```

映射结构：

- `dict`

按键访问：

```python
user = {"name": "Alice"}
print(user["name"])
```

集合结构：

- `set`

关注成员是否存在，不关注位置：

```python
allowed = {"admin", "user"}
print("admin" in allowed)
```

## 可重复和不可重复

列表允许重复：

```python
items = ["apple", "apple", "banana"]
```

集合自动去重：

```python
items = {"apple", "apple", "banana"}
print(items)
```

## 可变和不可变

可变对象可以原地修改：

```python
numbers = [1, 2]
numbers.append(3)
```

不可变对象不能原地修改：

```python
text = "abc"
text[0] = "A"
```

会报错。

## 快速选择规则

| 需求 | 优先选择 |
| --- | --- |
| 保存多条同类数据 | `list` |
| 保存一条记录的多个字段 | `dict` |
| 根据名称快速查值 | `dict` |
| 去重 | `set` |
| 判断是否在白名单里 | `set` |
| 保存固定坐标或多返回值 | `tuple` |
| 处理文本 | `str` |
| 处理二进制文件内容 | `bytes` |

## 常见错误

### 用列表查找大量唯一项

如果只是判断成员是否存在，集合通常更合适：

```python
allowed = {"admin", "editor", "viewer"}

if role in allowed:
    print("允许")
```

### 用多个列表表达一条记录

不推荐：

```python
names = ["Alice", "Bob"]
ages = [18, 20]
```

更推荐：

```python
users = [
    {"name": "Alice", "age": 18},
    {"name": "Bob", "age": 20},
]
```
