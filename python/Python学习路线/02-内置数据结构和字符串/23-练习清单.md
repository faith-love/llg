# 练习清单

本阶段至少完成 60 个练习，覆盖列表、元组、字典、集合、字符串、推导式、排序、去重、计数、分组和嵌套结构。

## A. 序列和切片

1. 创建一个数字列表并输出长度。
2. 访问列表第一个、最后一个元素。
3. 对列表做前三个、后三个、隔一个取一个的切片。
4. 反转一个字符串。
5. 判断某个元素是否在列表中。
6. 使用 `sum`、`max`、`min` 处理成绩列表。
7. 复现索引越界错误并修复。
8. 复现嵌套列表 `[[]] * 3` 的共享引用问题。

## B. 列表操作

9. 创建成绩列表，添加一个成绩。
10. 修改指定位置成绩。
11. 删除最后一个成绩。
12. 删除指定值。
13. 统计某个值出现次数。
14. 比较 `append` 和 `extend`。
15. 筛选所有及格成绩。
16. 把所有低于 60 的成绩修正为 60。
17. 找到第一个满分。
18. 判断是否所有成绩都及格。

## C. 排序和反转

19. 对数字列表升序排序。
20. 对数字列表降序排序。
21. 对姓名按长度排序。
22. 对用户列表按年龄排序。
23. 对用户列表先按城市、再按年龄排序。
24. 比较 `sort()` 和 `sorted()` 的区别。
25. 反转一个列表。

## D. 元组和解包

26. 创建坐标元组并解包。
27. 创建单元素元组并查看类型。
28. 写函数返回姓名和年龄。
29. 使用元组交换两个变量。
30. 复现元组里列表可以修改的例子。

## E. 字典

31. 创建用户字典。
32. 添加、修改、删除字段。
33. 使用 `get` 读取不存在字段。
34. 遍历字典的键、值、键值对。
35. 合并两个配置字典。
36. 把键值元组列表转成字典。
37. 从用户列表提取所有姓名。
38. 删除字典中值为空的字段。

## F. 计数和分组

39. 统计字符串字符出现次数。
40. 统计单词出现次数。
41. 统计城市出现次数。
42. 按城市分组用户。
43. 按分数等级分组成绩。
44. 找出每个城市年龄最大的人。
45. 使用 `get` 改写计数逻辑。
46. 使用 `setdefault` 改写分组逻辑。

## G. 集合

47. 用集合给列表去重。
48. 保留原顺序去重。
49. 求两个班级共同学生。
50. 求两个班级所有学生。
51. 求只在 A 班不在 B 班的学生。
52. 判断用户权限是否包含必需权限。
53. 比较 `remove` 和 `discard`。

## H. 字符串

54. 清洗输入两侧空格。
55. 把输入统一转成小写。
56. 切分 CSV 风格文本。
57. 使用 `join` 拼接字段。
58. 替换敏感词。
59. 判断文件名是否以 `.csv` 或 `.xlsx` 结尾。
60. 找出字符串中某个字符的所有位置。
61. 比较中文字符串字符长度和 UTF-8 字节长度。

## I. 推导式

62. 用列表推导式生成平方列表。
63. 用列表推导式筛选偶数。
64. 用字典推导式生成姓名长度映射。
65. 用集合推导式提取单词首字母。
66. 把复杂推导式改写成普通循环。

## J. 综合练习

67. 词频统计：输入一段文本，输出每个词出现次数。
68. 成绩统计：输出最高分、最低分、平均分、及格人数。
69. 用户分组：按城市分组用户，并统计每组人数。
70. 商品清单：按分类统计商品总价。
71. 日志过滤：筛选包含关键字的日志行。
72. 数据清洗：清洗用户输入列表，去空格、去空值、去重、排序。

## 每个练习的要求

- 能从命令行运行。
- 输入输出清晰。
- 变量命名表达数据含义。
- 关键步骤有必要的中间变量。
- 出错时能定位数据类型和数据内容。
