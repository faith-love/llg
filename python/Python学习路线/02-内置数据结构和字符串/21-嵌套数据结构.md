# 嵌套数据结构

真实数据很少是简单列表或简单字典。接口返回、JSON 文件、配置、表格转换结果通常都是列表套字典、字典套列表、字典套字典。

## 列表套字典

最常见的数据形态：

```python
users = [
    {"name": "Alice", "age": 18, "city": "Shanghai"},
    {"name": "Bob", "age": 20, "city": "Beijing"},
]
```

读取：

```python
print(users[0]["name"])
```

遍历：

```python
for user in users:
    print(user["name"], user["age"])
```

## 字典套列表

```python
groups = {
    "Shanghai": ["Alice", "Cindy"],
    "Beijing": ["Bob"],
}
```

读取：

```python
print(groups["Shanghai"])
```

遍历：

```python
for city, names in groups.items():
    print(city, names)
```

## 字典套字典

```python
users_by_id = {
    1: {"name": "Alice", "age": 18},
    2: {"name": "Bob", "age": 20},
}
```

按 ID 查找：

```python
user = users_by_id.get(1)
```

## 安全读取

直接读取：

```python
city = user["address"]["city"]
```

如果 `address` 不存在，会报错。

更安全：

```python
address = user.get("address", {})
city = address.get("city", "未知")
```

不要为了避免报错无脑写很长的链式 `get`，复杂时拆成中间变量更清楚。

## 修改嵌套数据

```python
users[0]["age"] = 19
groups["Shanghai"].append("David")
users_by_id[1]["city"] = "Shanghai"
```

修改嵌套结构时，要确认自己是在修改原数据，还是应该创建新数据。

## 从列表套字典提取字段

```python
names = []

for user in users:
    names.append(user["name"])
```

推导式写法：

```python
names = [user["name"] for user in users]
```

## 过滤嵌套数据

```python
adults = []

for user in users:
    if user["age"] >= 18:
        adults.append(user)
```

## 转换结构

列表转 ID 字典：

```python
users_by_id = {}

for user in users:
    users_by_id[user["id"]] = user
```

按城市分组：

```python
groups = {}

for user in users:
    city = user["city"]
    groups.setdefault(city, []).append(user)
```

## 常见错误

### 层级判断不清

先问自己：

- 当前变量是列表还是字典。
- 这一层应该用索引还是键。
- 取出来的下一层是什么类型。

### 链式访问过长

```python
value = data["a"]["b"]["c"]["d"]
```

不利于调试。可以拆开：

```python
a = data["a"]
b = a["b"]
c = b["c"]
value = c["d"]
```

### 修改共享对象

嵌套结构浅拷贝后，内部对象可能共享。
