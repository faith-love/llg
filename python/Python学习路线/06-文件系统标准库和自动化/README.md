# 06-文件系统标准库和自动化

这一阶段的目标是把 Python 用到真实工作流里：读写文件、遍历目录、处理路径、解析常见数据格式、调用系统命令、读取环境变量、处理时间日期、用标准库完成批量自动化任务。

如果 05 阶段关注“代码是否可靠”，那么 06 阶段关注“如何让 Python 可靠地处理真实文件、系统环境和批量任务”。

## 本阶段产出

- 至少 80 个文件、系统、标准库和自动化练习。
- 一个批量文件整理脚本。
- 一个 CSV/JSON 报表生成脚本。
- 一个带 argparse、logging、dry-run 的自动化工具。
- 一份路径、编码、命令执行的错误记录。
- 一份阶段复盘。

## 本阶段不做什么

- 不直接操作真实重要目录做删除和移动，先用临时目录和测试数据。
- 不用字符串拼接 shell 命令处理用户输入。
- 不引入 pandas，先掌握标准库 CSV/JSON 和基础数据流。
- 不追求 GUI 工具，先做稳定命令行脚本。
