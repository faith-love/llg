# 文件读写基础

文件读写是自动化脚本最常见的能力。基础原则是：明确编码、使用上下文管理器、区分读写模式、处理文件不存在和权限错误。

## 读取文本文件

```python
from pathlib import Path

path = Path("data.txt")

with path.open("r", encoding="utf-8") as file:
    content = file.read()
```

`with` 会在代码块结束后自动关闭文件。

## 写入文本文件

```python
from pathlib import Path

path = Path("output.txt")

with path.open("w", encoding="utf-8") as file:
    file.write("hello\n")
```

`w` 模式会覆盖原文件。

## 追加文本

```python
with path.open("a", encoding="utf-8") as file:
    file.write("new line\n")
```

`a` 模式在文件末尾追加。

## 逐行读取

```python
with path.open("r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```

适合大文件，不需要一次性读入内存。

## 读取所有行

```python
lines = path.read_text(encoding="utf-8").splitlines()
```

小文件可以这样处理。

## 便捷方法

```python
content = path.read_text(encoding="utf-8")
path.write_text("hello\n", encoding="utf-8")
```

适合小文件。

大文件优先使用流式读写。

## 文件不存在

```python
if not path.exists():
    raise FileNotFoundError(f"文件不存在：{path}")
```

也可以直接读取，让异常暴露给调用方。

## 写文件前创建目录

```python
output_path = Path("result/report.txt")
output_path.parent.mkdir(parents=True, exist_ok=True)
output_path.write_text("report", encoding="utf-8")
```

## 常见错误

### 忘记指定编码

不同系统默认编码可能不同，建议明确 `encoding="utf-8"`。

### 写模式覆盖原文件

`w` 会覆盖原内容。重要文件写入前要确认。

### 一次性读入大文件

大文件用逐行读取。

### 忘记关闭文件

使用 `with`。

## 练习

3. 逐行读取文件。
4. 追加一行内容。
5. 写文件前自动创建父目录。
6. 读取不存在文件，观察异常。
7. 比较 `read_text` 和 `open` 逐行读取。

## 验收标准

- 能读写文本文件。
- 能使用 `with` 自动关闭文件。
- 能区分读取、写入、追加模式。
- 能处理小文件和大文件的不同读法。
- 能明确使用 UTF-8 编码。
