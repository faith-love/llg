# 任务调度基础

任务调度是让任务在未来某个时间、延迟一段时间或按周期运行。它和并发不同：并发关注“同时处理多个任务”，调度关注“什么时候运行任务”。

## 调度类型

| 类型 | 示例 |
| --- | --- |
| 延迟执行 | 10 秒后运行 |
| 固定间隔 | 每 5 分钟运行一次 |
| 固定时间 | 每天 9:00 运行 |
| 条件触发 | 文件出现后运行 |
| 周期扫描 | 每小时检查一次 |

## 简单延迟

同步：

```python
from time import sleep

sleep(10)
do_work()
```

异步：

```python
await asyncio.sleep(10)
await do_work()
```

## threading.Timer

```python
from threading import Timer


timer = Timer(10, do_work)
timer.start()
```

适合简单延迟任务，不适合复杂长期调度。

## sched 标准库

`sched` 是标准库调度模块，适合了解调度基本思想。

```python
import sched
import time


scheduler = sched.scheduler(time.time, time.sleep)


def task():
    print("run")


scheduler.enter(5, 1, task)
scheduler.run()
```

真实长期任务通常会选择更成熟的调度方式。

## 简单周期循环

```python
import time


while True:
    start = time.monotonic()
    do_work()
    elapsed = time.monotonic() - start
    sleep_seconds = max(0, 60 - elapsed)
    time.sleep(sleep_seconds)
```

注意：

- 用 `time.monotonic()` 计算间隔更稳。
- 任务耗时要从间隔中扣除。
- 任务失败要记录。
- 要有退出机制。

## 防止任务重叠

如果任务每分钟执行一次，但单次任务耗时 90 秒，就会重叠。

策略：

- 跳过本轮。
- 等上轮结束后立即执行。
- 允许并发但限制数量。
- 直接报警。

初学阶段建议：默认不允许重叠，记录跳过原因。

## 错过执行

程序暂停、机器休眠、任务超时，都可能错过计划时间。

需要决定：

- 补跑所有错过任务。
- 只跑最近一次。
- 跳过并记录。

不同业务选择不同。报表类任务可能要补跑，监控类任务通常只跑当前。

## 时区和日期

固定时间任务要明确：

- 使用本地时间还是 UTC。
- 夏令时是否影响。
- 任务日期如何计算。
- 文件名日期使用哪个时区。

学习阶段建议先使用本地时间，并在 README 中写明。

## 常见错误

### while True 没有退出机制

程序无法优雅停止。

### 周期任务没有超时

单次任务卡住后，整个调度停止。

### 上一轮没结束又启动下一轮

可能导致任务堆积和数据冲突。

### 没有记录下次运行时间

日志无法判断调度是否正常。

## 练习

1. 写一个 10 秒后执行的任务。
2. 用 `threading.Timer` 延迟执行。
3. 用 `sched` 安排两个任务。
4. 写一个每 5 秒执行一次的循环。
5. 记录每次任务开始、结束、耗时。
6. 防止上一轮未结束时启动下一轮。
7. 增加最大运行次数，便于测试。
8. 增加 Ctrl+C 退出处理。

## 验收标准

- 能区分延迟、间隔和固定时间调度。
- 能写简单周期任务。
- 能处理任务耗时超过间隔的情况。
- 能给调度任务增加日志和退出机制。
