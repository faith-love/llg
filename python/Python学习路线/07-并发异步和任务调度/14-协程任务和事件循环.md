# 协程任务和事件循环

协程是可以被等待的执行单元，Task 是事件循环中被调度运行的协程包装。理解协程、Task 和事件循环的关系，是写 asyncio 程序的基础。

## 协程对象

```python
async def work():
    return 1


coro = work()
```

此时 `work()` 的函数体还没有真正运行。

## Task

使用 `asyncio.create_task()` 把协程提交给事件循环调度。

```python
import asyncio


async def work():
    await asyncio.sleep(1)
    return 1


async def main():
    task = asyncio.create_task(work())
    result = await task
    print(result)


asyncio.run(main())
```

创建 Task 后，它会被事件循环安排运行。

## create_task 的用途

如果你想让多个协程同时开始，需要创建 Task。

```python
async def main():
    task1 = asyncio.create_task(work(1))
    task2 = asyncio.create_task(work(2))

    result1 = await task1
    result2 = await task2
```

如果直接：

```python
result1 = await work(1)
result2 = await work(2)
```

两个任务会顺序等待。

## asyncio.run

程序入口：

```python
asyncio.run(main())
```

它负责：

- 创建事件循环。
- 运行主协程。
- 关闭事件循环。
- 清理异步生成器等资源。

不要在普通业务函数里到处调用 `asyncio.run()`。

## 获取当前任务

```python
task = asyncio.current_task()
```

可以用于调试和日志，但不要过度依赖。

## Task 命名

较新 Python 版本中可以给任务命名：

```python
task = asyncio.create_task(work(), name="worker-1")
```

任务名有助于日志排查。

## 后台任务

创建后不立即 await 的任务就是后台任务。

```python
task = asyncio.create_task(background())
```

注意：

- 必须保存引用。
- 必须处理异常。
- 程序退出前要取消或等待。

错误做法：

```python
asyncio.create_task(background())
```

创建后不保存引用，异常和生命周期都难管理。

## Task 异常

如果 Task 抛出异常但没有被 await 或检查，可能出现“Task exception was never retrieved”。

正确方式：

```python
try:
    await task
except Exception as exc:
    ...
```

或者统一收集任务结果。

## 顺序和并发对比

顺序：

```python
await work(1)
await work(2)
await work(3)
```

并发：

```python
tasks = [asyncio.create_task(work(i)) for i in range(3)]
results = await asyncio.gather(*tasks)
```

## 常见错误

### 创建任务但不等待

程序可能在任务完成前退出。

### 后台任务异常没有处理

需要保存任务并检查结果。

### 到处调用 asyncio.run

通常只在入口调用一次。

### 以为 create_task 会开新线程

Task 仍由事件循环调度，通常在同一个线程内运行。

## 练习

1. 创建协程对象，观察它不会自动执行。
2. 用 `create_task` 创建任务。
3. 比较顺序 await 和 create_task 并发耗时。
4. 给 Task 命名。
5. 创建后台任务并保存引用。
6. 让后台任务抛异常并处理。
7. 程序退出前取消后台任务。

## 验收标准

- 能区分协程对象和 Task。
- 能用 `create_task` 启动并发任务。
- 能管理后台任务生命周期。
- 能处理 Task 异常。
