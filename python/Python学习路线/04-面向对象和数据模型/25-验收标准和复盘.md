# 验收标准和复盘

本阶段通过标准是：能设计小型领域模型，理解对象状态和行为，能正确选择组合、继承、多态、dataclass、Enum 和常见特殊方法。

## 知识验收

你应该能回答：

- 类、实例、对象、属性、方法分别是什么。
- `self` 是什么。
- `__init__` 做什么，为什么不能返回非 `None`。
- 实例属性和类属性有什么区别。
- 为什么可变类属性危险。
- `@property` 适合什么场景。
- 实例方法、类方法、静态方法有什么区别。
- 组合和继承如何选择。
- `super()` 的作用是什么。
- MRO 是什么。
- 鸭子类型和抽象基类有什么区别。
- dataclass 适合什么，不适合什么。
- Enum 适合表达什么。
- `__repr__` 和 `__str__` 有什么区别。
- 如何让对象支持 `len()`、`in`、遍历。
- 上下文管理器如何工作。
- 描述符和 `property` 有什么关系。

## 代码验收

必须完成：

- 至少 70 个面向对象练习。
- 至少 1 个图书馆领域模型。
- 至少 1 个购物车或订单模型。
- 至少 1 个使用 dataclass 的数据对象。
- 至少 1 个使用 Enum 的状态模型。
- 至少 1 个自定义异常层级。
- 至少 1 个实现特殊方法的容器对象。

综合项目最低要求：

- 至少 5 个类。
- 至少 1 个组合关系。
- 至少 1 个继承或抽象基类关系。
- 至少 1 个枚举。
- 至少 1 个 dataclass。
- 至少 1 个领域异常。
- 至少实现 `__repr__` 或 `__str__`。
- 有 README 说明对象关系和运行方式。

## 推荐综合项目：图书馆模型

建议类：

- `Book`
- `Member`
- `Loan`
- `Library`
- `BookStatus`
- `LibraryError`
- `BookUnavailableError`

功能：

- 添加图书。
- 注册会员。
- 借书。
- 还书。
- 查询可借图书。
- 防止重复借出。

必须体现：

- 组合关系。
- 领域异常。
- Enum 状态。
- 清晰 `repr`。
- 对象自己维护规则。

建议类：

- `Product`
- `CartItem`
- `ShoppingCart`

- `OrderStatus`
- `InsufficientStockError`

功能：

- 添加商品到购物车。
- 修改数量。

- 取消订单。

## 错误排查验收

应该能独立处理：

- 忘记 `self`。
- 属性不存在。
- 类属性共享可变对象。
- 忘记调用 `super().__init__`。
- property 递归。
- dataclass 可变默认值错误。
- Enum 值转换失败。
- 特殊方法返回类型错误。
- 继承关系不合理。
