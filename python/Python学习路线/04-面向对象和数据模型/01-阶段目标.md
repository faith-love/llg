# 阶段目标

本阶段要解决的问题是：当数据和行为天然属于同一个概念时，如何用类和对象表达它；当多个对象协作时，如何避免代码散乱；当对象需要参与 Python 内置操作时，如何实现数据模型协议。

## 你要达到的能力

完成本阶段后，应该能做到：

- 能定义类并创建实例。
- 能使用实例属性保存对象状态。
- 能使用实例方法表达对象行为。
- 能区分类属性和实例属性。
- 能写清晰的 `__init__` 初始化逻辑。
- 能使用 `@property` 做只读属性或属性校验。
- 能判断什么时候用组合，什么时候用继承。
- 能使用 `super()` 正确调用父类逻辑。
- 能理解多态和鸭子类型。
- 能使用 `dataclass` 表达数据对象。
- 能使用 `Enum` 表达有限状态。
- 能实现常见特殊方法，如 `__repr__`、`__str__`、`__eq__`、`__len__`。
- 能设计一个小型领域模型。

## 为什么学习面向对象

函数适合表达过程和转换：

```python
def calculate_total(items):
    return sum(item["price"] * item["count"] for item in items)
```

类适合表达有状态、有行为、有约束的领域概念：

```python
class Cart:
    def __init__(self):
        self.items = []

    def add_item(self, name, price, count):
        self.items.append({"name": name, "price": price, "count": count})

    def total_price(self):
        return sum(item["price"] * item["count"] for item in self.items)
```

这里购物车有状态 `items`，也有行为 `add_item` 和 `total_price`，用类表达更自然。

## 本阶段核心转变

从字典堆数据：

```python
book = {"title": "Python", "available": True}
```

转为有行为的对象：

```python
class Book:
    def __init__(self, title):
        self.title = title
        self.available = True

    def borrow(self):
        if not self.available:
            raise ValueError("图书已借出")
        self.available = False
```

对象不只是数据容器，它可以维护自己的规则。
