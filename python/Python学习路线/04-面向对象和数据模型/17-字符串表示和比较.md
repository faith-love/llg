# 字符串表示和比较

对象需要有清晰的字符串表示，方便调试、日志和输出。对象之间也经常需要比较相等或排序。

## `__repr__`

`__repr__` 面向开发者，目标是清晰、可调试。

```python
class Book:
    def __init__(self, title):
        self.title = title

    def __repr__(self):
        return f"Book(title={self.title!r})"
```

调用：

```python
book = Book("Python")
print(repr(book))
```

## `__str__`

`__str__` 面向用户，目标是友好显示。

```python
class Book:
    def __init__(self, title):
        self.title = title

    def __str__(self):
        return self.title
```

`print(book)` 会优先使用 `__str__`。

如果没有 `__str__`，会退回使用 `__repr__`。

## `!r`

```python
f"{self.title!r}"
```

`!r` 会使用 `repr` 格式，字符串会带引号，调试更清晰。

## `__eq__`

定义相等：

```python
class Book:
    def __init__(self, isbn, title):
        self.isbn = isbn
        self.title = title

    def __eq__(self, other):
        if not isinstance(other, Book):
            return NotImplemented
        return self.isbn == other.isbn
```

两个书对象是否相等，可以按 ISBN 判断。

## `NotImplemented`

当无法和另一个类型比较时，返回 `NotImplemented`，让 Python 尝试其他比较逻辑。

不要直接返回 `False` 掩盖不兼容类型。

## 排序比较

可以实现 `__lt__`：

```python
class Score:
    def __init__(self, value):
        self.value = value

    def __lt__(self, other):
        return self.value < other.value
```

然后可以排序：

```python
scores = [Score(90), Score(80)]
print(sorted(scores))
```

更常见的方式是用 `key` 排序：

```python
sorted(scores, key=lambda score: score.value)
```

## dataclass 自动生成

`dataclass` 可以自动生成 `__repr__` 和 `__eq__`：

```python
from dataclasses import dataclass


@dataclass
class Book:
    isbn: str
    title: str
```

## 常见错误

### `__repr__` 不包含关键信息

`<Book object at ...>` 对调试价值低。

### `__eq__` 不检查类型

直接访问 `other.isbn` 可能导致 `AttributeError`。

### 排序语义不清

对象排序应该有明确业务含义。否则使用 `key` 更清楚。
