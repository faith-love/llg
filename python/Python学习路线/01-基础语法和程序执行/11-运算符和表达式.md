# 运算符和表达式

表达式会产生一个值，运算符用于把值组合成新的值。条件判断、循环控制、计算逻辑都离不开表达式。

## 表达式

表达式是能计算出结果的代码片段：

```python
1 + 2
age >= 18
name.strip()
```

语句是完整执行单位：

```python
age = 18
print(age)
```

## 算术运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加 | `1 + 2` |
| `-` | 减 | `5 - 3` |
| `*` | 乘 | `2 * 3` |
| `/` | 除 | `5 / 2` |
| `//` | 整除 | `5 // 2` |
| `%` | 取余 | `5 % 2` |
| `**` | 幂 | `2 ** 3` |

## 比较运算符

| 运算符 | 含义 |
| --- | --- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

示例：

```python
score = 80
print(score >= 60)
```

## 链式比较

Python 支持链式比较：

```python
age = 20

if 18 <= age <= 60:
    print("工作年龄段")
```

比下面写法更清晰：

```python
if age >= 18 and age <= 60:
    print("工作年龄段")
```

## 逻辑运算符

```python
and
or
not
```

示例：

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以入场")
```

## 短路求值

`and` 和 `or` 会短路。

```python
name = ""

if name and name[0] == "A":
    print("A 开头")
```

如果 `name` 是空字符串，后面的 `name[0]` 不会执行，避免索引错误。

## 成员运算符

```python
text = "hello python"

print("python" in text)
print("java" not in text)
```

常用于字符串、列表、字典等容器。

## 身份运算符

```python
is
is not
```

主要用于判断 `None`：

```python
if result is None:
    print("没有结果")
```

不要用 `is` 比较普通数值或字符串内容。

## 运算符优先级

常见优先级从高到低：

1. 括号。
2. 幂运算。
3. 乘除取余。
4. 加减。
5. 比较。
6. `not`。
7. `and`。
8. `or`。

不确定时，用括号提高可读性：

```python
if (age >= 18) and (has_ticket or is_vip):
    print("可以入场")
```

## 常见错误

### 把 `=` 当比较

```python
if age = 18:
    print("18")
```

比较要用 `==`。

### `and` 和 `or` 混用不加括号

复杂条件建议显式加括号。

### 用 `is` 比较值

不建议：

```python
if name is "Alice":
    print("ok")
```

应该：

```python
if name == "Alice":
    print("ok")
```

## 练习

1. 判断一个数是否在 1-100 之间。
2. 判断字符串是否包含某个关键词。
3. 输入年龄和是否有票，判断能否入场。
4. 判断一个数是否能被 3 或 5 整除。
5. 写 5 个复杂条件，并用括号提升可读性。

## 验收标准

- 能区分 `=`、`==`、`is`。
- 能使用算术、比较、逻辑、成员运算符。
- 能解释短路求值。
- 能写出清晰的复合条件。
