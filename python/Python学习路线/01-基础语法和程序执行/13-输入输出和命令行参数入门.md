# 输入输出和命令行参数入门

程序通常要接收输入、处理数据、输出结果。基础阶段先掌握 `print()`、`input()` 和简单命令行参数。

## 输出：`print()`

```python
print("hello")
print(1 + 2)
```

多个值输出：

```python
name = "Alice"
age = 18

print(name, age)
```

默认用空格分隔。

## `sep` 参数

```python
print("2026", "05", "09", sep="-")
```

输出：

```text
2026-05-09
```

## `end` 参数

```python
print("hello", end=" ")
print("python")
```

默认 `end="\n"`，表示输出后换行。

## 输入：`input()`

```python
name = input("请输入姓名：")
print(f"你好，{name}")
```

注意：

- `input()` 会暂停程序等待用户输入。
- 返回值永远是字符串。
- 通常需要 `.strip()` 去掉两侧空格。

```python
name = input("请输入姓名：").strip()
```

## 输入数字

```python
age_text = input("请输入年龄：").strip()

if age_text.isdigit():
    age = int(age_text)
    print(f"明年 {age + 1} 岁")
else:
    print("请输入整数")
```

## 命令行参数入门

命令行参数可以让脚本从终端接收参数。

脚本：

```python
import sys

print(sys.argv)
```

运行：

```powershell
python hello.py Alice 18
```

`sys.argv` 是参数列表：

- 第 0 个是脚本路径。
- 后面才是用户传入的参数。

示例：

```python
import sys

if len(sys.argv) < 2:
    print("请提供姓名")
else:
    name = sys.argv[1]
    print(f"你好，{name}")
```

更复杂的命令行参数后续会学习 `argparse`。

## 输出格式建议

用户可读输出：

```python
print(f"总价：{total_price:.2f} 元")
```

调试输出：

```python
print(f"debug: age_text={age_text}")
```

不要把调试输出长期留在正式脚本里，后面会学习日志。

## 常见错误

### 忘记输入是字符串

```python
number = input("数字：")
print(number + 1)
```

### 参数数量不检查

```python
import sys

name = sys.argv[1]
```

如果没有传参数，会报 `IndexError`。

### 输出信息不清楚

不建议：

```python
print("error")
```

建议：

```python
print("错误：年龄必须是整数")
```
