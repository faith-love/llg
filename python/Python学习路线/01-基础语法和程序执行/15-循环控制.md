# 循环控制

循环用于重复执行代码。只要涉及批量处理、累计统计、菜单交互、重试逻辑，都会用到循环。

## `for` 循环

遍历一组值：

```python
for i in range(5):
    print(i)
```

输出：

```text
0
1
2
3
4
```

`range(5)` 表示从 0 到 4。

## `range()`

```python
range(结束)
range(开始, 结束)
range(开始, 结束, 步长)
```

示例：

```python
for i in range(1, 6):
    print(i)

for i in range(10, 0, -1):
    print(i)
```

结束值不包含在结果里。

## 遍历字符串

```python
text = "python"

for char in text:
    print(char)
```

## `while` 循环

当条件成立时重复执行：

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

`while` 适合：

- 不确定循环次数。
- 等待用户输入。
- 重试操作。

## 避免死循环

错误示例：

```python
count = 0

while count < 3:
    print(count)
```

`count` 没有变化，循环永远不会结束。

## `break`

立即结束循环：

```python
while True:
    command = input("请输入命令：").strip()

    if command == "quit":
        break

    print(f"执行：{command}")
```

## `continue`

跳过本次循环，进入下一次：

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

## 循环 `else`

循环正常结束时执行 `else`；如果被 `break` 打断，则不执行。

```python
for i in range(3):
    if i == 5:
        print("找到了")
        break
else:
    print("没找到")
```

这个语法不常用，但读代码时要能看懂。

## 嵌套循环

```python
for row in range(1, 4):
    for col in range(1, 4):
        print(row, col)
```

嵌套循环容易复杂，基础阶段只要求能读懂和写简单乘法表。

## 常见模式

### 累计求和

```python
total = 0

for i in range(1, 101):
    total += i

print(total)
```

### 计数

```python
count = 0

for char in "hello":
    if char == "l":
        count += 1

print(count)
```

### 菜单循环

```python
while True:
    print("1. 查询")
    print("2. 退出")

    choice = input("请选择：").strip()

    if choice == "1":
        print("执行查询")
    elif choice == "2":
        break
    else:
        print("无效选择")
```

## 常见错误

### 循环边界差一

`range(1, 10)` 不包含 10。

### 忘记更新 while 条件变量

导致死循环。

### `break` 和 `continue` 混淆

- `break` 结束整个循环。
- `continue` 只跳过本次。
