# 脚本入口和程序组织

随着代码变多，需要把主流程和函数定义分开。`if __name__ == "__main__"` 是 Python 脚本常见入口写法。

## 顶层代码会立即执行

```python
print("开始")

def add(a, b):
    return a + b

print(add(1, 2))
```

运行文件时，顶层 `print` 会按顺序执行。

## `__name__` 是什么

每个 Python 文件运行时都有一个特殊变量 `__name__`。

直接运行文件时：

```python
print(__name__)
```

输出：

```text
__main__
```

如果文件被其他文件导入，`__name__` 通常是模块名。

## 标准入口写法

```python
def main():
    print("程序开始")


if __name__ == "__main__":
    main()
```

含义：

- 定义 `main()` 函数保存主流程。
- 只有当文件被直接运行时，才调用 `main()`。
- 如果以后被导入，主流程不会自动执行。

## 为什么要写 `main()`

好处：

- 主流程更清晰。
- 函数定义和执行入口分开。
- 方便以后导入复用。
- 方便写测试。

不推荐大量顶层代码：

```python
name = input("姓名：")
age = int(input("年龄："))
print(name, age)
```

更推荐：

```python
def main():
    name = input("姓名：")
    age = int(input("年龄："))
    print(name, age)


if __name__ == "__main__":
    main()
```

## 基础脚本结构

推荐本阶段使用：

```python
def read_age():
    age_text = input("年龄：").strip()
    if not age_text.isdigit():
        return None
    return int(age_text)


def is_adult(age):
    return age >= 18


def main():
    age = read_age()
    if age is None:
        print("年龄输入不合法")
        return

    if is_adult(age):
        print("成年人")
    else:
        print("未成年人")


if __name__ == "__main__":
    main()
```

## 文件内代码顺序

建议：

1. 模块说明。
2. 导入。
3. 常量。
4. 函数定义。
5. `main()`。
6. 入口判断。

示例：

```python
"""年龄判断脚本。"""

MIN_ADULT_AGE = 18


def is_adult(age):
    return age >= MIN_ADULT_AGE


def main():
    age = 20
    print(is_adult(age))


if __name__ == "__main__":
    main()
```

## 常见错误

### 把入口判断写错

正确：

```python
if __name__ == "__main__":
    main()
```

常见错误：

```python
if name == "main":
    main()
```

### 忘记调用 `main()`

```python
if __name__ == "__main__":
    main
```

少了括号，函数不会执行。

### 顶层代码太多

顶层代码太多会导致导入时自动执行，后续难测试。
