# 基础数据类型总览

本阶段先掌握最常用的基础类型：`int`、`float`、`bool`、`str`、`None`。列表、元组、字典、集合下一阶段系统学习。

## 基础类型表

| 类型 | 示例 | 用途 |
| --- | --- | --- |
| `int` | `18` | 整数 |
| `float` | `3.14` | 小数 |
| `bool` | `True`、`False` | 判断结果 |
| `str` | `"hello"` | 文本 |
| `NoneType` | `None` | 表示没有值 |

## 查看类型

```python
print(type(18))
print(type(3.14))
print(type(True))
print(type("hello"))
print(type(None))
```

## 整数 `int`

```python
age = 18
count = 100
```

常见操作：

```python
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 // 3)
print(10 % 3)
print(10 ** 3)
```

## 浮点数 `float`

```python
price = 19.99
rate = 0.08
```

注意浮点数精度：

```python
print(0.1 + 0.2)
```

结果可能不是精确的 `0.3`。

## 布尔值 `bool`

```python
is_active = True
is_deleted = False
```

布尔值常用于条件判断：

```python
if is_active:
    print("可用")
```

## 字符串 `str`

```python
name = "Alice"
message = "你好"
```

字符串用于表示文本。

常见操作：

```python
print(len(name))
print(name.upper())
print(name.lower())
```

## 空值 `None`

```python
result = None
```

`None` 表示当前没有值。它不是空字符串，也不是 0。

判断是否为 `None`：

```python
if result is None:
    print("没有结果")
```

## 类型不是变量固定属性

Python 是动态类型语言。变量名可以重新绑定到不同类型对象：

```python
value = 10
value = "hello"
```

这可以运行，但不代表推荐随意改变变量含义。实际项目里应该保持变量语义稳定。

## 常见错误

### 字符串和数字直接相加

```python
age = 18
print("年龄：" + age)
```

会报 `TypeError`。需要转换：

```python
print("年龄：" + str(age))
```

或使用 f-string：

```python
print(f"年龄：{age}")
```

### 把 `None` 当成字符串

```python
name = None
print(name.upper())
```

会报错，因为 `None` 没有 `upper()` 方法。
