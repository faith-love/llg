# 基础错误排查

学习编程一定会遇到报错。基础阶段最重要的不是“不报错”，而是能读懂常见错误，并知道从哪里开始修。

## 报错信息怎么读

典型报错：

```text
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(age + 1)
TypeError: can only concatenate str (not "int") to str
```

重点看：

- 文件名：`main.py`
- 行号：`line 3`
- 出错代码：`print(age + 1)`
- 异常类型：`TypeError`
- 错误说明：不能把字符串和整数相加

## `SyntaxError`

语法错误，代码还没开始正常执行。

常见原因：

- 忘记冒号。
- 引号不闭合。
- 括号不匹配。
- 使用中文标点。

示例：

```python
if age >= 18
    print("成年人")
```

## `IndentationError`

缩进错误。

常见原因：

- 应该缩进的地方没有缩进。
- 不该缩进的地方多缩进。
- Tab 和空格混用。

示例：

```python
if True:
print("hello")
```

## `NameError`

使用了不存在的名字。

常见原因：

- 变量没定义。
- 变量名拼写错误。
- 作用域不对。

示例：

```python
user_name = "Alice"
print(username)
```

## `TypeError`

类型不支持当前操作。

常见原因：

- 字符串和数字直接相加。
- 函数参数数量不对。
- 对 `None` 调用方法。

示例：

```python
age = "18"
print(age + 1)
```

## `ValueError`

值的格式不合法。

常见原因：

- `int("abc")`
- `float("")`

示例：

```python
age = int("abc")
```

## `IndexError`

索引越界。

示例：

```python
text = "abc"
print(text[3])
```

## 排查顺序

遇到错误按这个顺序处理：

1. 看最后一行异常类型。
2. 看最后一段错误说明。
3. 找到自己写的文件和行号。
4. 检查这一行涉及的变量类型和值。
5. 缩小代码，只保留能复现错误的最小片段。
6. 修复后记录到错误笔记。

## 最小复现

不要在 200 行脚本里盲目改。先把错误缩小：

```python
age = input("年龄：")
print(age + 1)
```

这样很快能看出 `input()` 返回字符串。

## 调试输出

基础阶段可以临时打印类型和值：

```python
print(type(age), age)
```

后续会学习断点调试和日志。
