# 学习目标

Python 学习目标要按能力定义，而不是按“看完多少教程”定义。真正有用的目标是：遇到一个明确问题时，能拆解需求、选择工具、写出可运行代码、验证结果，并把代码整理成以后还能维护的形式。

## 总目标

完成这条路线后，应具备以下能力：

- 能独立编写 Python 脚本，处理文件、文本、表格、接口和批量任务。
- 能理解 Python 基础语法、数据结构、函数、模块、类、异常和标准库。
- 能使用虚拟环境和依赖管理工具维护项目环境。
- 能使用测试、日志、调试器和类型提示提升代码可靠性。
- 能开发基础 Web API，理解请求、响应、参数校验、错误处理和数据库访问。
- 能处理 CSV、Excel、JSON、日志等常见数据，并做清洗、统计和导出。
- 能把项目组织成清晰目录，写 README、运行说明、验收说明和复盘笔记。
- 能定位常见性能、安全、并发和部署问题，不只停留在语法层面。

## 能力分层

| 层级 | 能力描述 | 判断标准 |
| --- | --- | --- |
| 入门 | 能运行脚本，理解变量、判断、循环、函数和基本数据结构 | 能写 30 个基础小程序，并解释每行代码的作用 |
| 初级 | 能完成文件处理、文本处理、命令行参数和小型自动化任务 | 能做一个可复用脚本，支持参数、日志和错误提示 |
| 中级 | 能组织模块、写测试、处理异常、读写数据库和调用接口 | 能完成一个带测试的 CLI 或 API 项目 |
| 高级 | 能做工程化拆分、类型约束、部署、性能分析和安全加固 | 能维护多人可读的项目结构，并定位线上问题 |
| 精通 | 能理解运行时机制、设计取舍、库源码和复杂系统边界 | 能解释技术选择，读懂关键库源码，并形成稳定的方法论 |

## 主线方向

这份路线以“通用 Python 工程能力”为主线，覆盖四类高频使用场景。

### 1. 自动化和脚本

需要掌握：

- 文件遍历、路径处理、批量重命名。
- 文本解析、正则表达式、日志分析。
- CSV、Excel、JSON、YAML 等数据格式读写。
- 命令行参数、配置文件、环境变量。
- 定时任务、批处理、错误重试和执行记录。

验收方式：

- 写一个文件整理工具。
- 写一个 Excel/CSV 批量处理脚本。
- 写一个日志统计脚本。
- 所有脚本都能通过命令行参数控制输入和输出路径。

### 2. Web API 和后端

需要掌握：

- HTTP 基础、状态码、请求头、Cookie、Session。
- Flask、FastAPI 或 Django 的定位和基本结构。
- 路由、请求参数、响应模型、错误响应。
- 数据校验、认证授权、分页、过滤和排序。
- 数据库访问、事务、连接池、ORM、迁移。

验收方式：

- 写一个 CRUD API。
- 支持参数校验、统一错误响应和分页。
- 接入数据库。
- 提供 README、接口文档和测试用例。

### 3. 数据处理和分析

需要掌握：

- pandas、NumPy 的基础使用。
- 缺失值、重复值、异常值处理。
- 类型转换、分组聚合、排序、透视表。
- 大文件分块读取和内存控制。
- 数据校验、对账、导出和可视化基础。

验收方式：

- 完成一次原始表格到清洗结果的转换。
- 输出处理规则说明。
- 输出校验统计，例如总行数、缺失数、重复数、异常记录数。

### 4. 工程化和长期维护

需要掌握：

- 项目目录结构。
- 虚拟环境和依赖锁定。
- 测试、格式化、静态检查和类型检查。
- 日志、配置、异常和错误码。
- Docker、CI、部署脚本和健康检查。

验收方式：

- 一个项目可以在新机器按 README 跑起来。
- 依赖可复现。
- 测试可以一键运行。
- 关键配置不写死在代码里。

## 不作为主线的内容

以下内容可以后续扩展，但不放在入门到精通的第一主线里：

- 深度学习算法推导。
- 大规模分布式计算平台。
- CPython C 扩展开发。
- 复杂爬虫对抗。
- 游戏开发和桌面 GUI 深入。

原因很简单：这些方向都有独立路线。先把 Python 的通用工程能力打稳，再分方向深入，效率更高。

## 每个知识点的学习闭环

后续每个知识点都按同一个闭环学习：

1. 它解决什么问题。
2. 最小可运行例子是什么。
3. 常见错误是什么。
4. 在真实项目里怎么用。
5. 有哪些边界和替代方案。
6. 用什么练习证明自己掌握了。
