# 00-总览与版本基线

这一阶段不急着写大量代码，而是先把学习路线的边界固定下来：学到什么程度、用哪个版本、文件怎么放、每周怎么推进、怎么判断自己真的掌握了。

如果没有这个基线，后续很容易出现几个问题：

- 今天看基础语法，明天跳到爬虫，后天又学 Web，最后没有一个完整闭环。
- 代码能跑，但没有虚拟环境、依赖记录、测试和复盘，无法复用。
- 只追新特性，忽略企业项目里常见的 3.12/3.13 兼容问题。
- 学习资料越堆越多，却没有明确的阶段产出和验收标准。

## 本阶段产出

完成这一阶段后，应该固定下来：

- Python 学习主线和阶段边界。
- Python 版本选择原则。
- 文档目录和练习项目目录规范。
- 每周学习节奏、复盘节奏和提交节奏。
- 每个阶段的验收方式。
- 后续学习中最容易卡住的重点和难点清单。

## 不建议做的事

- 不要一开始就同时学爬虫、Web、数据分析、AI、自动化办公。
- 不要用系统全局 Python 装一堆依赖。
- 不要只看视频或文章，不写练习。
- 不要把“看懂了”当作“会用了”。
- 不要在还不会调试、测试、依赖管理时直接做复杂项目。
