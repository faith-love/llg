# 目录规范

目录规范的目标不是形式整齐，而是让学习资料、练习代码、项目复盘都能长期复用。

## 学习资料目录

Python 学习资料放在：

```text
D:\learn\python
```

推荐结构：

```text
python/
  README.md
  Python学习路线/
    README.md
    00-总览与版本基线/
      README.md
      01-学习目标.md
      02-版本选择.md
      03-目录规范.md
      04-每周节奏.md
      05-阶段验收标准.md
      06-重点和难点.md
    01-基础语法和程序执行/
    02-内置数据结构和字符串/
    03-函数模块和包/
    04-面向对象和数据模型/
    05-异常调试测试和质量/
    06-文件系统标准库和自动化/
    07-并发异步和任务调度/
    08-网络Web和API开发/
    09-数据库数据处理和工程实践/
    10-类型系统工程化和部署/
    11-性能安全和运行时原理/
    12-综合项目源码阅读和长期提升/
  practice/

  notes/
```

## 文档命名规范

文档命名使用：

- 两位数字排序。
- 英文短横线命名。
- 文件名表达主题，不使用模糊词。

示例：

```text
01-variables-and-types.md
02-control-flow.md
03-functions.md
```

不建议：

```text
笔记1.md
python学习.md
new.md
总结.md
```

原因是后续文件变多后，模糊命名会很难检索。

## 每个知识点文档的固定结构

后续阶段的每个知识点文档都建议使用同一结构：

```markdown
# 标题

## 它解决什么问题

## 核心概念

## 最小示例

## 常见用法

## 常见错误

## 练习

## 验收标准
```

重点知识点可以增加：

```markdown
## 底层机制

## 与其他方案的区别

## 面试表达

## 项目实践
```

## 练习项目目录

每个练习项目单独放一个目录，不要把所有练习塞进一个文件。

推荐结构：

```text
practice/
  01-foundation-syntax/
    hello_python/
      README.md
      main.py
    number_guess/
      README.md
      main.py
  02-built-in-data-structures/
    word_counter/
      README.md
      main.py
      sample.txt
```

每个练习至少包含：

- `README.md`：说明练习目标、运行方式、输入输出。
- `main.py`：主程序入口。
- 示例数据：如果需要处理文件或表格。
- 复盘记录：记录遇到的错误和修复方式。

## 正式项目目录

综合项目建议从一开始就按工程结构放置：

```text
projects/
  task_api/
    README.md
    pyproject.toml
    src/
      task_api/
        __init__.py
        main.py
        config.py
    tests/
      test_main.py
    docs/
      api.md
```

关键原则：

- 源码放 `src/`。
- 测试放 `tests/`。
- 文档放 `docs/`。
- 配置集中管理。
- 不把临时数据、缓存、密钥提交进仓库。

## README 规范

每个目录的 `README.md` 至少说明：

- 这个目录是什么。
- 推荐阅读顺序。
- 当前完成状态。
- 运行或使用方式。
- 后续要补充什么。

项目 README 至少说明：

- 项目目标。
- 环境要求。
- 安装依赖。
- 运行命令。
- 测试命令。
- 目录结构。
- 已知限制。

## 提交和复盘规范

建议每完成一个小练习就提交一次。

提交信息可以使用：

```text
learn(python): add variables practice
learn(python): add list and dict exercises
docs(python): add version baseline
```

每周复盘记录：

- 本周完成了哪些文档。
- 写了哪些练习。
- 遇到哪些错误。
- 哪些概念还不稳。
- 下周要补什么。
