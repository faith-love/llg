## 版本说明

- 主体按 MySQL 8.0+ 编写。
- `INTE未译25173SECT`、`EXCEPT` 需要 MySQL 8.0.31+。
- `EXPLAIN ANALYZE` 需要 MySQL 8.0.18+。
- 如果使用 MySQL 5.7，CTE、窗口函数、JSON_TABLE、CHECK 约束等语法不可用或支持不完整。

## 使用方式

这些文档以说明为主，代码块中的 SQL 示例仍可以在 MySQL 8.0+ 环境中按需执行。危险操作示例尽量使用临时表、事务或注释形式保留。
