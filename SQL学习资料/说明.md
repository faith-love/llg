# SQL 学习资料

当前目录用于沉淀 MySQL 语法参考和数据库设计方法论。内容以 Markdown 文档为主，适合查阅、复习和整理项目中的数据库设计决策。

## 目录

- [数据库语法参考](数据库语法参考/说明.md)：按主题拆分的 MySQL Markdown 文档，每个文件包含用途、学习目标、核心语法、关键注意点和 SQL 示例。
- [数据库表拆分方法论](数据库表拆分方法论/说明.md)：从拆分判断、拆分类型、设计方法、最佳实践到真实业务案例的成套文档。

## 使用方式

1. 学语法时先进入 `数据库语法参考/说明.md`，按查询、DDL、事务、索引、函数、窗口函数等主题查找。
2. 做项目设计或性能复盘时进入 `数据库表拆分方法论/说明.md`，按决策标准和案例模板判断是否需要拆表。
