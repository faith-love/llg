# 04-6 个月学习计划

## 计划怎么用

这个 6 个月计划不是死规定。它的作用是帮你判断当前应该学什么，不要今天看集合，明天跳到微服务，后天又去背 JVM 面试题。

如果你每天学习时间多，可以压缩周期；如果工作或上学很忙，可以拉长到 9-12 个月。

## 总体节奏

| 月份 | 重点 | 每周建议投入 | 最终产出 |
| --- | --- | ---: | --- |
| 第 1 月 | Java 基础、OOP、集合、异常 | 10-15 小时 | 基础练习 30 个以上 |
| 第 2 月 | 泛型、IO、Stream、反射、注解 | 10-15 小时 | 命令行图书管理系统 |
| 第 3 月 | JVM、并发、数据库、HTTP | 12-18 小时 | JDBC/MyBatis 小项目 |
| 第 4 月 | Spring、Spring Boot、REST API | 12-18 小时 | CRUD 后端项目 |
| 第 5 月 | 安全、缓存、测试、部署 | 12-18 小时 | 带登录、Redis、Docker 的项目 |
| 第 6 月 | 综合项目、优化、面试复盘 | 12-18 小时 | 可演示项目和复盘文档 |

## 第 1 月：打基础

目标：

- 会写基础 Java 程序。
- 理解类、对象、方法、构造器。
- 掌握常用集合和异常。

不要做：

- 不要直接学微服务。
- 不要直接背线程池参数。
- 不要一上来就复制 Spring Boot 项目。

产出：

- 30 个基础练习。
- 每个练习至少有一个提交记录。
- 一份基础错题清单。

## 第 2 月：能组织小程序

目标：

- 能把多个类组织成一个小系统。
- 会用泛型、IO、Stream。
- 初步理解注解和反射。

产出：

- 命令行图书管理系统。
- 文件保存和加载功能。
- README 写清运行方式。

## 第 3 月：进入后端基础

目标：

- 理解 JVM 基础。
- 理解并发问题。
- 会使用数据库。
- 理解 HTTP 和 REST。

产出：

- JDBC 或 MyBatis 小项目。
- 一个线程池练习。
- 一份 JVM 和并发笔记。

## 第 4 月：Spring Boot 主线

目标：

- 能搭建 Spring Boot 项目。
- 能写 Controller、Service、Mapper。
- 能处理异常、校验、分页和事务。

产出：

- 图书馆 REST API。
- 数据库初始化脚本。
- 接口示例。
- 基础测试。

## 第 5 月：工程化

目标：

- 添加登录鉴权。
- 使用 Redis。
- 写测试。
- 用 Docker 启动项目依赖。

产出：

- 带登录和缓存的后端项目。
- `docker compose` 启动文件。
- 测试覆盖核心业务。
- 日志和配置说明。

## 第 6 月：综合项目和复盘

目标：

- 做一个能展示的项目。
- 梳理面试高频知识。
- 写项目复盘。

产出：

- 一个完整项目。
- 项目复盘文档。
- 面试问答清单。
- 未来深入方向计划。

## 如果时间不够怎么办

优先级如下：

1. Java 基础和 OOP。
2. 集合、异常、泛型、IO。
3. 数据库和 HTTP。
4. Spring Boot CRUD、事务、异常、校验。
5. 测试和部署。
6. JVM、并发深入。
7. Redis、MQ、微服务。

不要为了赶进度跳过 1-4。基础不稳时，后面的框架只会越学越虚。

## 本节练习

写一个自己的 `six-month-plan.md`，至少包含：

- 每周能学几天。
- 每天能学多久。
- 第 1 个月要完成哪些练习。
- 第 3 个月前要完成哪个小项目。
- 第 6 个月要拿出什么项目。

## 本节通过标准

- 能说清 6 个月每个月的重点。
- 能根据自己的时间调整计划。
- 能判断哪些内容必须先学，哪些内容可以后学。
