# 00-阶段导读：总览与版本基线

## 这一阶段解决什么问题

很多小白学 Java 会直接打开视频，从“变量、if、for”开始看。这样不是不行，但容易出现三个问题：

- 不知道最终要学到什么程度。
- 学到一半被 JDK、IDE、Maven、Spring Boot 版本搞乱。
- 看了很多内容，但不知道自己是否真的能写项目。

所以第 00 阶段先做学习地图。它不是代码最多的阶段，但决定后面学习是否顺畅。

## 小白需要先记住的结论

- Java 后端不是只学 Java 语法，还要学数据库、HTTP、Spring Boot、测试、部署和排查问题。
- 新学习主线可以用 JDK 25 LTS；企业项目里 Java 17/21 也很常见。
- Spring Boot 当前主线要求 Java 17+，不要拿 Java 8 老教程直接套现代 Spring Boot 项目。
- 每个阶段都要有代码产出。只看视频、只抄笔记，不算完成。
- 学习目标不是“背完所有知识点”，而是“能解释、能写、能排查”。

## 本阶段产出

完成本阶段后，至少产出这些东西：

- 一份自己的 Java 学习时间安排。
- 本机安装好的 JDK、IDE、Maven、Git。
- 一个专门存放 Java 练习代码的目录。
- 一个学习记录文件，例如 `learning-log.md`。
- 一个阶段验收表，后续每周复盘时使用。
