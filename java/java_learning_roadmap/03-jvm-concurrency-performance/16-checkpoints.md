# 16-通过标准和复盘清单

## 阶段通过标准

完成这一阶段后，你应该能做到：

- 能解释 `.java -> .class -> JVM` 的执行链路。
- 能说明堆、栈、方法区分别关注什么。
- 能复现 `StackOverflowError` 和堆 OOM。
- 能看懂简单 GC 日志中的次数、耗时、回收前后容量。
- 能解释线程安全三要素。
- 能使用锁、原子类、并发集合修复基础并发问题。
- 能显式创建线程池，并说明核心参数。
- 能使用 `CompletableFuture` 做简单并发调用。
- 能按流程排查慢、卡、CPU 高、内存涨。

## 知识点深挖检查

每个知识点都要能回答：

- 作用：它解决什么问题？
- 痛点：没有它会遇到什么麻烦？
- 优点：它比简单写法好在哪里？
- 技巧：项目里怎么用更稳？
- 难点：小白最容易误解哪里？
- 重点：必须记住哪一句核心结论？
- 错误示例：常见错误代码长什么样？
