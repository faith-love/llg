# 02-知识图谱和复习系统

## 知识图谱解决什么问题

Java 后端知识点很多，如果只按视频顺序记，很容易碎片化。知识图谱的作用是把知识按模块、关系和应用场景组织起来。

## 推荐知识图谱

```text
Java 后端
  Java 基础
  集合和泛型
  异常和 IO
  JVM
  并发
  数据库
  MyBatis
  Spring Boot
  缓存和消息队列
  工程化
  项目
```

## 复习层级

每个知识点按 4 层复习：

| 层级 | 问题 |
| --- | --- |
| 作用 | 它解决什么问题 |
| 原理 | 它大致怎么工作 |
| 使用 | 项目里怎么用 |
| 坑点 | 容易错在哪里 |

## 复习频率

建议：

- 每天复盘 5 个问题。
- 每周整理 1 次错题。
- 每月重画一次知识图谱。
- 每做完项目补充项目相关问题。

## 容易出错的示例

### 错误示例：只收藏面试题

收藏了 200 道题，但没有分类、没有自己的答案、没有复习记录。

### 为什么错

收藏不等于掌握。没有主动回答和复盘，很快会忘。

### 正确做法

每道题至少记录：

```text
题目
我的错误回答
正确思路
项目例子
下次复习时间
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 知识图谱 | 串联知识 | 防止碎片化 | 按模块画树 | 重点是补关系 |
| 四层复习 | 从会背到会用 | 只背定义不够 | 作用、原理、使用、坑点 | 难点是项目例子 |
| 错题复习 | 修补薄弱点 | 不会的问题会反复出现 | 定期回看 | 重点是写自己的错误原因 |
| 输出训练 | 检查掌握程度 | 看懂不等于会讲 | 录音或写答案 | 难点是表达清楚 |

## 本节练习

- 画一份自己的 Java 后端知识图谱。
- 选 10 个知识点按四层复习法整理。
- 建一个错题表。

## 本节通过标准

- 能把知识点按模块归类。
- 能说明每个模块解决什么问题。
- 能给知识点补项目例子。
- 能建立可持续复习机制。
