# 01-面试准备原则

## 面试准备解决什么问题

面试准备不是临时背答案，而是把学习成果整理成别人能听懂、能验证、能继续追问的表达。

小白常见痛点：

- 会写但讲不清。
- 背了定义但不会举例。
- 项目能跑但说不出难点。
- 简历写了技术栈但被追问就卡住。
- 不会的问题看完答案很快又忘。

## 三类材料

你需要沉淀三类材料：

| 材料 | 作用 |
| --- | --- |
| 知识图谱 | 把 Java、JVM、并发、数据库、Spring 串起来 |
| 项目复盘 | 把项目讲成问题、方案、取舍和结果 |
| 错题清单 | 把不会的问题变成可复习条目 |

## 回答原则

回答问题时按这个顺序：

```text
先给结论 -> 解释作用 -> 说明原理 -> 举项目例子 -> 说注意点
```

例如问事务：

```text
事务用来保证一组数据库操作要么都成功，要么都失败。在我的图书借阅项目里，新增借阅记录和扣减库存必须在一个事务中，否则可能出现借阅记录存在但库存没扣的问题。实现时事务放在 Service 层，因为它围绕的是完整业务动作。
```

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| 面试表达 | 证明你理解问题 | 只会背定义很容易被追问穿 | 结论先行 | 重点是结合项目 |
| 知识图谱 | 防止知识碎片化 | 学过但串不起来 | 按模块画树 | 难点是建立联系 |
| 项目复盘 | 展示真实能力 | 不复盘就只剩代码 | 背景、流程、难点、结果 | 重点是问题和取舍 |
| 错题本 | 反复修补弱点 | 看答案容易忘 | 记录错误原因 | 重点是定期复习 |

## 本节练习

- 选择 5 个自己最怕被问的问题。
- 每个问题按“结论、作用、原理、例子、注意点”写一版答案。
- 把一个项目写成 3 分钟讲法。

## 本节通过标准

- 能解释面试不是单纯背题。
- 能用结构化方式回答问题。
- 能把知识点和项目经历绑定。
- 能建立错题复习机制。
