# 01-阶段目标和版本基线

## 总目标

这一阶段要能独立完成一个规范的 Spring Boot 后端项目。

项目至少包含：

- REST CRUD。
- 参数校验。
- 统一响应。
- 统一异常。
- 分页查询。
- 数据库事务。
- 登录鉴权。
- Redis 缓存。
- 基础测试。
- 日志和健康检查。

## 版本基线

当前官方 Spring Boot 4.0.6 要求 Java 17+。如果你学习 Spring Boot 3.x 或 4.x，主线就不要使用 Java 8。

建议：

- JDK：17、21、25 都可以作为现代学习环境，具体看项目依赖兼容性。
- Spring Boot：优先跟随官方当前稳定文档。
- Maven：使用官方要求的最低版本以上。
- 老教程：只借鉴思路，不直接照搬配置。

## 知识点深挖

| 知识点 | 作用 | 痛点或优点 | 技巧 | 难点和重点 |
| --- | --- | --- | --- | --- |
| Spring Boot | 快速构建生产级 Spring 应用 | 减少大量手动配置 | 先理解 Spring，再理解 Boot | 重点是 Boot 是约定和整合，不是替代基础 |
| 版本基线 | 保证依赖兼容 | 版本混用会导致启动失败 | 新建项目前先查官方要求 | 难点是教程版本和当前版本差异 |
| 项目目标 | 防止只会 Hello World | 用完整功能串起知识 | 按功能清单逐步完成 | 重点是工程闭环 |

## 本节练习

- 查看本机 `java -version`。
- 查看 Maven 版本。
- 在 Spring Initializr 或 IDE 中创建一个最小 Spring Boot 项目。
- 记录 Spring Boot、JDK、Maven 版本。

## 本节通过标准

- 能说明 Spring Boot 当前主线为什么要求 Java 17+。
- 能创建并启动一个空项目。
- 能写出本阶段项目功能清单。
