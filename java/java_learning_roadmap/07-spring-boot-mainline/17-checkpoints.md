# 17-通过标准和复盘清单

## 阶段通过标准

完成这一阶段后，你应该能做到：

- 能解释 IoC、DI、Bean。
- 能使用构造器注入。
- 能说明 Bean 生命周期和组件扫描。
- 能解释 AOP 和事务代理。
- 能搭建 Spring Boot REST API。
- 能处理参数校验和统一异常。
- 能用 MyBatis 完成数据访问。
- 能实现登录鉴权基础流程。
- 能使用 Redis 缓存热点数据。
- 能理解 MQ、定时任务和异步处理基本风险。
- 能启用 Actuator 和写关键日志。
- 能写单元测试、Web 测试和集成测试。
