# 00-章节导读：项目路线和验收标准

## 为什么项目路线要单独讲

Java 学习最后必须落到项目。项目不是把知识点堆在一起，而是训练你把需求变成可运行、可维护、可解释的后端系统。

项目阶段解决的问题：

- 学过的知识点怎么串起来。
- 什么项目适合小白。
- 功能要做到什么程度才算完成。
- 数据库、接口、事务、权限、测试怎么验收。
- 项目怎么复盘成面试能讲的话。

## 小白先记住的主线

- 先做小项目，把基础语法和 OOP 跑通。
- 再做 REST API，把数据库、接口和事务跑通。
- 再做一个业务内容型项目，把权限、文件、缓存和查询优化跑通。
- 最后做订单简化版，把事务、并发、幂等、状态流转跑通。
- 每个项目都要留下 README、接口示例、数据库脚本、测试和复盘。
