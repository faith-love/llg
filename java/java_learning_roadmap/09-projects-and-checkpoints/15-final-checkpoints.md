# 15-总验收清单

## 一个合格 Java 项目的最低标准

一个能放进简历的 Java 项目至少满足：

- 有清晰 README。
- 能本地一条命令启动依赖。
- 有数据库初始化脚本。
- 有接口文档或接口示例。
- 有统一异常和统一响应。
- 有认证和权限控制。
- 有至少 10 个关键测试。
- 有日志和错误排查说明。
- 有 2-3 个能讲清楚的技术难点。
- 有性能、事务或并发方面的真实思考。

## 面试验收

你必须能回答：

- 项目解决什么问题？
- 你负责哪些模块？
- 核心业务流程是什么？
- 数据库为什么这样设计？
- 哪些地方用了事务？
- 如何防止重复提交或并发问题？
- 权限怎么控制？
- 遇到过什么 bug，怎么定位？
- 项目如何测试和部署？
- 如果继续优化，你会改哪里？

## 通过标准

满足下面条件，可以认为项目阶段合格：

- 至少完成 1 个完整 Spring Boot 项目。
- 项目能独立启动和演示。
- 有数据库脚本、接口文档、测试和 README。
- 能讲清 2 个以上真实难点。
- 能把项目讲给别人听，而不是只给别人看代码。
