# 15-通过标准和复盘清单

## 阶段通过标准

完成这一章后，你的项目至少应该满足：

- 能执行 `mvn clean test`。
- 能执行 `mvn clean package`。
- 有 Service 层核心测试。
- 有 Controller 成功和失败响应测试。
- 有独立测试配置。
- 日志能定位一次业务失败。
- 配置不包含真实密码或 Token。
- Docker Compose 能启动必要依赖。
- README 写清本地启动步骤。
- 能用 Linux 基础命令排查日志、端口、磁盘。

## 面试要能讲清的问题

- Git 分支和提交你是怎么管理的？
- Maven 依赖冲突你怎么排查？
- 单元测试和集成测试有什么区别？
- 你的项目测了哪些失败场景？
- 日志里不能打印哪些内容？
- Profile 和环境变量解决什么问题？
- Docker Compose 里服务之间为什么不能用 `localhost`？
- 部署后你怎么确认服务真的可用？

## 进入下一阶段前

进入综合项目阶段前，至少完成：

- 一个能启动的 Spring Boot 项目。
- 一份可执行 README。
- 一组关键测试。
- 一套本地 Docker 依赖。
- 一次完整问题排查记录。
