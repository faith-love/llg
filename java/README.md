# Java 学习资料

这个目录用于存放 Java 相关学习资料、练习项目和源码示例。

## 推荐入口

- [Java 详细学习路线](java_learning_roadmap/README.md)
- [Spring Boot 示例项目](spring-boot-demo/README.md)

## 使用方式

1. 先读 `java_learning_roadmap/README.md`，明确整体路线、版本选择和阶段目标。
2. 按阶段学习专题文档，每一阶段都要完成对应练习和验收项。
3. 学到 Spring Boot 阶段后，再结合 `spring-boot-demo` 中的示例模块拆解真实项目结构。
