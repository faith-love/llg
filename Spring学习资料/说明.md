# Spring 学习资料

这个目录用于存放 Spring 体系的学习路线、专题笔记和项目练习。这里的 Spring 指 Spring Framework、Spring Boot 以及常用的 Spring Data、Spring Security、Spring Cloud 等项目组合。

## 推荐入口

- [Spring 详细学习路线](Spring详细学习路线/说明.md)

## 和 Java 路线的关系

Spring 不是 Java 基础的替代品。建议先具备下面这些基础，再进入本目录：

- Java 面向对象、接口、多态、泛型、异常、集合。
- 注解、反射、Lambda、Stream 的基本使用。
- Maven 或 Gradle 的依赖管理和项目结构。
- HTTP、REST、JSON、数据库、事务、MyBatis 或 JPA 的基础概念。

如果这些基础还不稳，先回到 [Java 详细学习路线](../Java学习资料/Java学习路线/说明.md) 补齐第 2、4、5、6 阶段，再进入 Spring 主线。

## 使用方式

1. 先读 `Spring详细学习路线/说明.md`，明确版本基线、学习顺序和阶段产出。
2. 每个阶段都要写一个可运行示例，不能只看概念。
3. 学 Spring Boot 时同步拆解 `../Java学习资料/Spring-Boot示例/` 中已有示例，理解依赖、配置、分层和启动流程。
4. 每阶段保留一份问题清单，记录“为什么这样配置、错了会报什么、如何定位”。
