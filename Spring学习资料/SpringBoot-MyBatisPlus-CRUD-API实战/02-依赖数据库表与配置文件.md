# 依赖、数据库表与配置文件

这一节搭项目底座：`pom.xml`、启动类、数据库表、`application.yml`。这些文件决定项目能不能启动、能不能连上数据库、MyBatis-Plus 能不能工作。

## pom.xml

根目录 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <!-- Spring Boot 父工程：统一管理 Spring 相关依赖版本 -->
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.3.4</version>
        <relativePath/>
    </parent>

    <groupId>com.example</groupId>
    <artifactId>spring-mp-crud-demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>

    <properties>
        <!-- Spring Boot 3 推荐 Java 17 起步 -->
        <java.version>17</java.version>
    </properties>

    <dependencies>
        <dependency>
            <!-- Web API 能力：Controller、JSON、Tomcat 等 -->
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <dependency>
            <!-- 参数校验能力：@NotBlank、@Email、@Valid 等 -->
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

        <dependency>
            <!-- MyBatis-Plus Spring Boot 3 Starter -->
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
            <version>3.5.7</version>
        </dependency>

        <dependency>
            <!-- MySQL 驱动，运行时连接 MySQL 需要它 -->
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <scope>runtime</scope>
        </dependency>

        <dependency>
            <!-- 测试依赖，后面写接口测试会用到 -->
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <!-- 让 Maven 可以打包 Spring Boot 应用 -->
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

注意事项：

- Spring Boot 3 用 `mybatis-plus-spring-boot3-starter`。
- Spring Boot 2 项目才用旧的 `mybatis-plus-boot-starter`。
- `mysql-connector-j` 是运行时依赖，不需要自己写版本，交给 Spring Boot 管理。

## 启动类

`src/main/java/com/example/crud/CrudDemoApplication.java`：

```java
package com.example.crud;

import org.mybatis.spring.annotation.MapperScan;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

/**
 * Spring Boot 启动类。
 *
 * 作用：
 * 1. 启动内置 Tomcat。
 * 2. 扫描 com.example.crud 包下面的 Spring Bean。
 * 3. 通过 @MapperScan 扫描 MyBatis Mapper 接口。
 */
@MapperScan("com.example.crud.**.mapper")
@SpringBootApplication
public class CrudDemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(CrudDemoApplication.class, args);
    }
}
```

注意事项：

- 启动类尽量放在根包 `com.example.crud` 下。
- `@MapperScan` 要能扫描到 `UserMapper` 所在包。
- 不加 `@MapperScan` 时，也可以在每个 Mapper 上加 `@Mapper`，但项目里统一扫描更方便。

## 数据库表

`src/main/resources/db/schema.sql`：

```sql
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键 id',
  username VARCHAR(50) NOT NULL COMMENT '登录名，要求唯一',
  nickname VARCHAR(50) NOT NULL COMMENT '展示昵称',
  email VARCHAR(100) NOT NULL COMMENT '邮箱',
  status TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1 启用，0 禁用',
  deleted TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0 未删除，1 已删除',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  UNIQUE KEY uk_users_username (username),
  KEY idx_users_status (status),
  KEY idx_users_created_at (created_at)
) COMMENT = '用户表';
```

字段说明：

- `id`：主键，MyBatis-Plus 可以自动回填到 Entity。
- `username`：唯一字段，用来演示重复检查。
- `status`：业务状态，不等于删除。
- `deleted`：逻辑删除字段，删除时不真的删记录。
- `created_at`、`updated_at`：审计字段，后端自动填充。

## application.yml

`src/main/resources/application.yml`：

```yaml
server:
  # 本地开发端口
  port: 8080

spring:
  datasource:
    # 数据库连接地址，crud_demo 是数据库名
    url: jdbc:mysql://localhost:3306/crud_demo?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    # 本地数据库用户名
    username: root
    # 本地数据库密码，真实项目不要提交明文密码
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis-plus:
  configuration:
    # 开发阶段打印 SQL，方便你知道 MyBatis-Plus 到底执行了什么
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
    # 数据库字段 user_name 可以映射到 Java 字段 userName
    map-underscore-to-camel-case: true
  global-config:
    db-config:
      # 主键自增策略，和表里的 AUTO_INCREMENT 对应
      id-type: auto
      # 逻辑删除字段配置
      logic-delete-field: deleted
      logic-delete-value: 1
      logic-not-delete-value: 0
```

注意事项：

- 密码不要在真实项目里写死，可以用环境变量或配置中心。
- 开发阶段可以打印 SQL，生产环境要谨慎。
- `serverTimezone` 建议明确，避免时间差问题。
- 逻辑删除字段名要和 Entity 里的字段一致。

## 启动命令

```bash
mvn spring-boot:run
```

启动成功后能看到类似：

```text
Tomcat started on port 8080
Started CrudDemoApplication
```

## 练习

1. 创建数据库 `crud_demo`。
2. 执行 `schema.sql`。
3. 修改 `application.yml` 里的数据库用户名和密码。
4. 启动项目，确认没有数据库连接错误。

## 验收

- 项目能启动。
- 应用能连接 MySQL。
- `users` 表存在。
- 控制台能打印 MyBatis-Plus 执行的 SQL。
