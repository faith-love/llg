# 16-阶段总验收

## 这一阶段结束前，至少确认这些点

- 能解释 `@SpringBootApplication` 的大致组成。
- 能说明 Starter、自动配置和条件注解的关系。
- 能建立 `dev/test/prod` 三套配置。
- 能用 `@ConfigurationProperties` 管理结构化配置。
- 能打开并解释基本 Actuator 端点。
- 能通过启动日志和依赖树定位基础问题。
- 能理解环境变量和命令行参数的覆盖作用。

## 通过标准

能把一个 Boot 项目从“会启动”推进到“能解释它为什么这样启动、为什么这样配置、为什么这样装配”，这个阶段就算真正吃透了。
