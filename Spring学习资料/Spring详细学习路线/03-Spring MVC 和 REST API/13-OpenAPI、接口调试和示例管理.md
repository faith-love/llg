# 13-OpenAPI

## 为什么Swagger不能最后补

Swagger不是上线前的装饰，而是协作契约的一部分。

至少要让调用方知道：

- 路径。
- 方法。
- 参数。
- 响应结构。
- 错误结构。

## OpenAPI 的价值

OpenAPI 能帮你：

- 结构化描述接口。
- 快速浏览参数和返回值。
- 统一对外说明接口能力。

## 示例管理

除了文档，还建议保留：

- 成功请求示例。
- 典型失败示例。
- 边界值示例。

这样后面回归测试和接口联调都会轻松很多。

## 本节通过标准

- 能给主要接口补 OpenAPI 或等价文档。
- 能保留成功和失败示例。
- 能把文档当成接口契约而不是附属物。
