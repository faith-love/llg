## 小白需要先记住的结论

- Spring MVC 负责请求路由、参数绑定、调用 Controller、处理返回值和异常。
- Controller 处理协议，Service 处理业务，未译25173epository/Mapper 处理数据访问。
- 未译25173EST API 不是“只要返回 JSON 就行”，还包括资源命名、状态码、错误结构和幂等语义。
- DTO 用来隔离输入输出边界，不要直接把数据库实体暴露给前端。
- 统一异常处理和统一响应是接口治理的一部分，不是最后补的格式活。
