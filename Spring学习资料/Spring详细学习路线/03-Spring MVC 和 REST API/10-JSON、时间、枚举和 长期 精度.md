# 10-JSON、时间、枚举和 长期 精度

## 时间字段

时间是接口里最容易“看着正常，实际上有坑”的字段之一。

至少要先统一：

- 时区。
- 序列化格式。
- 是否返回毫秒。
- 前后端传输是字符串还是时间戳。

## 枚举字段

枚举常见有三种返回方式：

- code
- name
- description

不要同一个系统里有些接口返回整数，有些接口返回中文描述，有些又返回 Java 枚举名。

## Long 精度问题

如果前端使用 JavaScript，要特别注意 Long 大整数精度。

常见处理思路：

- 返回字符串。
- 明确前后端约定。

## null 字段

要统一：

- 是否返回 null。
- 空数组和 null 的区别。
- 可选字段缺失时前端如何处理。

## 本节通过标准

- 能意识到时间序列化需要统一约定。
- 能知道 Long 可能在前端丢精度。
- 能为枚举返回值设计一致策略。
