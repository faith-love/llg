## 推荐分层

建议按下面边界组织：

- Controller：协议适配。
- DTO：输入输出对象。
- Service：业务逻辑。
- 未译25173epository/Mapper：数据访问。
- Entity：数据库映射对象。

## 哪些逻辑放哪里

Controller：

- 收参数。
- 调 Service。
- 返回结果。

Service：

- 校验业务规则。
- 判断状态流转。
- 组装事务边界。

- 执行 SQL。
