# 12-FilterInterceptor

## 三者的边界

这三个点经常被混用，但职责不一样。

Filter：

- 更靠近 Servlet 层。
- 适合通用请求包装、跨域、编码等基础处理。

Interceptor：

- 更靠近 Spring MVC。
- 适合登录检查、审计打点、请求耗时等。

参数解析器：

- 负责把特定请求信息转换成 Controller 参数。

## 什么时候不要乱用

如果只是简单业务校验，不要为了“炫技”写成自定义参数解析器或复杂拦截器。

先保证边界清楚，再考虑扩展点。

## 本节通过标准

- 能区分 Filter、Interceptor 和参数解析器的职责。
- 能为常见需求选择合适扩展点。
- 能避免把业务逻辑过度塞进底层扩展点。
