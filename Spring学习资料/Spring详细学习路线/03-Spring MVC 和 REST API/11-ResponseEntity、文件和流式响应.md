# 11-ResponseEntity、文件和流式响应

## 为什么不是所有接口都返回统一包装

统一响应适合大多数业务 JSON 接口，但不适合一切场景。

常见例外：

- 文件下载。
- 图片或二进制流。
- 流式输出。
- 某些标准协议响应。

## ResponseEntity 的作用

`ResponseEntity` 适合显式控制：

- 状态码。
- 响应头。
- 响应体。

当你需要比“直接返回对象”更精细的控制时，它很有用。

## 文件下载要注意

至少要处理：

- `Content-Type`
- `Content-Disposition`
- 文件名编码
- 大文件流式输出

## 本节通过标准

- 能说明为什么统一响应不是绝对规则。
- 能在需要时用 `ResponseEntity` 做精细控制。
- 能意识到文件和流式场景与普通 JSON 接口不同。
