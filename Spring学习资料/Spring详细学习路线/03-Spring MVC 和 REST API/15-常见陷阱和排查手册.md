# 15-常见陷阱和排查手册

## 常见问题

- `404`：路由不匹配或 Controller 没被扫描。
- `400`：参数绑定或格式错误。
- DTO 校验不生效：少了 `@Valid` 或入口位置不对。
- 返回时间格式混乱：序列化约定没统一。
- 前端拿不到大整数：Long 精度问题没处理。
- 文件下载异常：响应头没配好。

## 排查顺序

建议先按这条线看：

1. 路由有没有命中。
2. 参数有没有正确绑定。
3. 校验有没有触发。
4. 业务异常有没有被统一处理。
5. 返回结构是不是调用方预期的。

## 本节通过标准

- 能快速判断 404、400、校验失效等问题的大方向。
- 能把常见坑整理成自己的排查清单。
