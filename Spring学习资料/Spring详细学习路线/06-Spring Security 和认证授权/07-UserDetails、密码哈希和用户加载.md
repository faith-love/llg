# 07-UserDetails、密码哈希和用户加载

## 用户加载在解决什么

安全框架最终需要知道：

- 当前用户是谁。
- 用户密码是什么。
- 用户拥有哪些角色或权限。

这就离不开用户加载逻辑。

## 密码为什么必须哈希

密码不能明文保存，也不应该可逆加密。

更合理的方式是：

- 使用哈希算法。
- 使用带盐或适合密码场景的编码器。

## 认证不是查表这么简单

除了查用户，还要考虑：

- 用户是否存在。
- 是否禁用。
- 密码是否匹配。
- 权限是否加载完整。

## 本节通过标准

- 能解释为什么密码必须哈希。
- 能理解用户加载逻辑在认证里的位置。
- 能避免把密码安全当成普通字符串比较。
