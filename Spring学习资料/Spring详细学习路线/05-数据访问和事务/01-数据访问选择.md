# 01-数据访问选择

## 常见方案

常见选择：

- Spring JDBC
- MyBatis / MyBatis-Plus
- Spring Data JPA

## 怎么选

Spring JDBC：

- 轻量。
- SQL 可控。
- 适合你想清楚掌握 SQL 和事务时使用。

MyBatis：

- 企业项目常见。
- SQL 控制强。
- 适合复杂查询和分页场景。

JPA：

- 对象建模强。
- 适合领域模型比较稳定的项目。
- 也更容易出现懒加载、N+1 等额外问题。

## 学习顺序建议

先把 SQL、连接池、事务和分页做明白，再补 JPA。

## 本节通过标准

- 能说出三种主流方案的定位差异。
- 能解释为什么先学 SQL 和事务主线更稳。
