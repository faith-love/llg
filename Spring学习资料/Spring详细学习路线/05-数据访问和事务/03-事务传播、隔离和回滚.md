# 03-事务传播、隔离和回滚

## 事务的核心问题

事务解决的是：

```text
一组操作要么一起成功，要么一起失败
```

## 默认回滚规则

Spring 默认更关注运行时异常。

你必须通过实验理解：

- 什么异常会回滚。
- 什么异常不会自动回滚。
- 显式指定回滚规则时会发生什么。

## 传播行为

先掌握最常见的几个：

- `REQUIRED`
- `REQUIRES_NEW`
- `NESTED`

不要一开始背所有传播行为，先把这几个典型场景吃透。

## 隔离级别

隔离级别和数据库并发问题有关，例如：

- 脏读。
- 不可重复读。
- 幻读。

学习时要知道这些概念和典型后果，但不要脱离数据库实际行为空背定义。

## 本节通过标准

- 能解释事务默认回滚行为。
- 能说明 `REQUIRED` 和 `REQUIRES_NEW` 的常见区别。
- 能知道隔离级别和并发读写问题相关。
