# 02-DataSource

## 数据源是什么

数据源负责提供JDBC。连接池负责复用连接、控制并发和降低创建成本。

常见连接池配置至少要关注：

- 最大连接数。
- 最小空闲连接。
- 连接超时。
- 空闲超时。

## SQL 边界

不管你用 JDBC、MyBatis 还是 JPA，最终都绕不开数据库执行。

你至少要知道：

- 一条查询最后大概是什么 SQL。
- 分页 SQL 长什么样。
- 哪些字段需要索引。
- 为什么会慢。

框架只是帮你组织访问，不会替你理解 SQL。

## 本节通过标准

- 能解释数据源和连接池的作用。
- 能从框架层回到 SQL 层看问题。
- 能列出几项最基本的连接池配置。
