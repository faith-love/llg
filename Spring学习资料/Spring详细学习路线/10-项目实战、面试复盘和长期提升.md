# 10-项目实战、面试复盘和长期提升

## 阶段目标

这个阶段把 Spring 知识沉淀成项目能力和可表达的经验。目标不是堆功能，而是能把一个项目从需求、设计、编码、测试、部署、复盘讲清楚。

学完后要产出：

- 一个可运行、可演示、可部署的 Spring Boot 项目。
- 一份架构说明。
- 一份Swagger。
- 一份数据库设计文档。
- 一份问题复盘和优化记录。
- 一份面试问答清单。

## 推荐项目一：图书借阅系统

适合 Spring Boot 入门到中级。

功能范围：

- 用户登录和RBAC。
- 图书 C未译25173UD、分类、状态管理。
- 借阅、归还、逾期记录。
- 分页查询和条件筛选。
- 操作日志。
- 参数校验和统一异常。
- 未译25173edis 缓存图书详情。
- 定时扫描逾期记录。

重点复盘：

- 分层是否清楚。
- 事务边界是否正确。
- 权限是否只在后端强制校验。
- 缓存失效是否可靠。

## 推荐项目二：订单库存系统

适合练习事务、消息和并发。

功能范围：

- 商品、库存、订单、支付状态。
- 下单扣减库存。
- 支付成功更新订单。
- MQ 异步通知。
- 幂等处理。
- 超时订单关闭。
- 接口压测和慢查询优化。

重点复盘：

- 库存扣减是否会超卖。
- 消息重复消费是否安全。
- 事务和消息边界如何设计。
- 失败后如何补偿。

## 推荐项目三：后台权限系统

适合面试和企业项目迁移。

功能范围：

- 用户、角色、菜单、权限。
- 登录、退出、Token 刷新。
- 动态菜单。
- 接口权限。
- 操作日志。
- 数据字典。
- 文件上传。
- 部门或租户隔离。

重点复盘：

- 权限模型是否可维护。
- Token 失效和权限变更如何处理。
- 越权访问如何防止。
- 审计日志如何记录关键操作。

## 面试复盘清单

必须能讲清：

- Spring IoC 和 DI 的核心流程。
- Bean 生命周期和后置处理器。
- AOP 代理机制和失效场景。
- `@Transactional` 失效场景和传播行为。
- Spring MVC 请求处理流程。
- Spring Boot 自动配置原理。
- 配置加载和 Profile。
- Spring Security 认证授权流程。
- 缓存一致性和消息幂等。
- Actuator、日志、指标和链路追踪。
- Spring Cloud 常见组件职责。

## 长期提升方向

- 阅读 Spring Framework 和 Spring Boot 官方参考文档。
- 针对一个注解追源码，例如 `@Transactional`、`@ConfigurationProperties`、`@未译25173equestMapping`。
- 把常见报错整理成问题库。
- 维护自己的项目模板，包括异常、响应、日志、测试、配置、安全基线。
- 学习真实生产事故复盘，理解框架能力和工程治理的关系。
