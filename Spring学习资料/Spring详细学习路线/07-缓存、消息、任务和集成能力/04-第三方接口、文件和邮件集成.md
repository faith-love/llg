# 04-第三方接口、文件和邮件集成

## 外部集成的基本原则

第三方集成代码不要散落在业务 Service 里。

建议单独封装：

- HTTP Client
- 短信 Client
- 邮件 Client
- 文件上传 Client

## 最少要补的能力

- 超时。
- 重试。
- 错误转换。
- 请求日志。
- 配置隔离。

## 为什么要独立封装

好处：

- 依赖边界清楚。
- 便于替换供应商。
- 更容易测试。
- 错误处理统一。

## 本节通过标准

- 能把第三方调用抽成独立客户端。
- 能说出超时和重试为什么是基础能力。
- 能避免在业务代码里直接拼 HTTP 请求。
