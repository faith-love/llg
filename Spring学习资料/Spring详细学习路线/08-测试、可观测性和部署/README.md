## 小白需要先记住的结论

- 不是所有测试都要 `@SpringBootTest`。
- 日志、指标和健康检查是后端交付物的一部分。
- 本地能跑，不代表能上线。
- 配置隔离、依赖准备和回滚思路都属于部署范畴。

## 本阶段产出

完成本阶段后，至少产出：

- 单元测试、Web 测试、数据层测试各一组。
- Actuator 健康检查和指标。
- 一份最小 Dockerfile。
- 一份启动、配置、部署 README。
