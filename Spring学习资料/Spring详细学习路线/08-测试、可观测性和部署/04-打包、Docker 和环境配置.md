# 04-打包、Docker 和环境配置

## 最小部署链路

一个最小部署链路通常包括：

1. 构建 jar。
2. 生成 Docker 镜像。
3. 注入环境配置。
4. 启动Docker。
5. 检查健康状态。

## 为什么本地能跑不够

部署时还要考虑：

- 环境变量。
- JDBC。
- 端口。
- 文件权限。
- 外部依赖地址。

## 说明 也是交付物

你至少要把下面内容写清楚：

- 环境依赖。
- 启动方式。
- 配置项。
- 健康检查地址。
- 常见错误。

## 本节通过标准

- 能写一个最小 Docker构建文件。
- 能通过环境变量覆盖配置。
- 能把启动和部署步骤写进 说明。
