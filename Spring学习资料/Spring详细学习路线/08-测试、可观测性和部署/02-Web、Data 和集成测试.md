# 02-Web、Data 和集成测试

## Web 测试

Web 测试主要验证：

- 路由。
- 参数绑定。
- 状态码。
- 响应结构。

常见工具：

- `MockMvc`
- `TestRestTemplate`
- `WebTestClient`

## Data 测试

数据层测试关注：

- SQL 是否正确。
- 映射是否正确。
- 事务和数据库行为是否符合预期。

## 集成测试

集成测试验证完整流程：

- 应用启动。
- 依赖可用。
- 多层调用链可跑通。

## 本节通过标准

- 能为 Controller、Repository 和完整流程分别设计测试。
- 能避免所有测试都堆到一个层级。
