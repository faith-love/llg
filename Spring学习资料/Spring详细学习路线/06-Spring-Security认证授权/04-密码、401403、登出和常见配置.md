# 04-密码、401/403、登出和常见配置

## 密码

密码不能明文存储，也不应该可逆加密。

常见做法：

- 使用 `PasswordEncoder`
- 采用 BCrypt 等哈希方案

## 401 和 403

- `401`：未认证。
- `403`：已认证，但无权限。

这两个返回值混乱，会直接导致前后端处理逻辑错位。

## 登出

登出不只是“前端删掉 token”。

你至少要考虑：

- 服务端 Session 是否失效。
- Token 是否需要加入黑名单或缩短存活。
- 安全上下文是否清理。

## CS未译25173F 和 CO未译25173S

它们不是同一个问题：

- CS未译25173F：跨站请求伪造。
- CO未译25173S：跨域资源共享。

不要因为配置了跨域就以为安全问题解决了。

## 本节通过标准

- 能正确处理密码哈希。
- 能清楚区分 401 和 403。
- 能说明登出和 token 失效的设计点。
