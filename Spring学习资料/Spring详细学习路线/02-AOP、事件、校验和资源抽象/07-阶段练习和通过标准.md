# 07-阶段练习和通过标准

## 阶段练习项目

建议创建：

```text
D:\learn\Spring学习资料\practice\spring-aop-event-validation-practice
```

这个项目围绕用户注册场景，练习 AOP、事件、参数校验、统一异常和配置读取。

## 练习一：耗时日志切面

要求：

- 定义 `@LogCost` 注解。
- 定义 `LogCostAspect`。
- 使用 `@Around` 统计方法耗时。
- 正常返回和抛出异常时都能打印耗时。
- 不吞掉业务异常。

验收：

- 能看到方法名和耗时。
- 能解释 `joinPoint.proceed()` 的作用。

## 练习二：权限入口切面

要求：

- 定义 `@RequirePermission("user:create")`。
- 切面中模拟当前用户权限。
- 权限不足时抛出业务异常。
- 统一异常处理返回 `403` 风格错误。

验收：

- 能解释这只是权限入口练习，不是完整安全体系。
- 能说明完整认证授权后续应学习 Spring Security。

## 练习三：用户注册事件

要求：

- 创建 `UserRegisteredEvent`。
- 注册成功后发布事件。
- 监听器一：发送欢迎消息。
- 监听器二：写审计日志。
- 分别观察同步和异步执行差异。

验收：

- 能说出默认事件是否同步。
- 能说明监听器异常对主流程的影响。
- 能解释什么时候使用 `@TransactionalEventListener`。

## 练习四：参数校验和统一异常

要求：

- 创建 `CreateUserRequest`。
- 字段包含用户名、邮箱、手机号、年龄。
- 添加 Bean Validation 注解。
- Controller 使用 `@Valid`。
- 统一处理校验异常。

验收：

- 错误响应包含错误码、错误消息和字段信息。
- 能区分格式校验和业务校验。

## 练习五：资源读取和配置绑定

要求：

- 读取 classpath 下的欢迎语模板。
- 使用 `Environment` 打印应用名。
- 使用 `@ConfigurationProperties` 绑定短信配置。
- 在欢迎消息监听器中使用短信配置。

验收：

- 配置项集中在一个 properties 类。
- 能通过 Profile 或环境变量覆盖配置。

## 阶段自测问题

进入下一阶段前，回答：

1. AOP 适合处理哪些横切逻辑？
2. 切点、通知、切面分别是什么？
3. `@Around` 为什么必须调用 `proceed()`？
4. 同类内部调用为什么可能导致 AOP 不生效？
5. Spring 事件和 MQ 的区别是什么？
6. 默认事件监听器是同步还是异步？
7. 什么时候需要 `@TransactionalEventListener`？
8. `@Valid` 放在哪里才会触发请求体校验？
9. `@NotNull` 和 `@NotBlank` 有什么区别？
10. `@Value` 和 `@ConfigurationProperties` 怎么选？

## 阶段通过标准

能做到下面这些，就可以进入 03 阶段：

- 能写一个可运行的耗时日志切面。
- 能解释 Spring AOP 基于代理的限制。
- 能发布和监听 Spring 事件。
- 能处理同步、异步、事务事件的基本差异。
- 能完成 DTO 参数校验和统一错误响应。
- 能读取 classpath 资源。
- 能用 `@ConfigurationProperties` 管理结构化配置。
