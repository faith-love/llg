# 阅读路线与工程能力地图

高级前端工程化要从“我会配置工具”升级到“我能设计一套长期可维护的交付系统”。工具只是手段，真正的主线是把代码从开发者电脑稳定推到用户浏览器，并且能在出问题时快速定位、止血、复盘和改进。

## 核心心智模型

```text
需求
  -> 架构边界
  -> 代码规范
  -> 类型与测试
  -> 构建产物
  -> CI/CD
  -> 发布灰度
  -> 性能与监控
  -> 事故复盘
  -> 规范和平台能力反哺
```

这条链路里任何一段弱，都会转化为交付风险。例如目录没有边界会导致改动影响面不可控，依赖没有治理会导致构建不可复现，缺少监控会导致线上问题只能靠用户反馈。

## 学习阶段

| 阶段 | 重点 | 产出 |
| --- | --- | --- |
| 基础工程能力 | 目录、依赖、构建、环境变量、规范 | 能维护一个稳定单仓项目 |
| 多项目协作能力 | monorepo、任务编排、代码生成、共享配置 | 能治理多个应用和多个包 |
| 交付质量能力 | 类型、测试、CI/CD、发布策略、回滚 | 能把质量门禁接入流水线 |
| 线上运营能力 | 性能、监控、安全、灰度、事故复盘 | 能对线上结果负责 |
| 组织治理能力 | 指标、技术债、RFC、平台化、组件库 | 能推动团队工程效率持续提升 |

如果你正在搭建中大型项目：

1. 先定目录边界和依赖规则。
2. 再选包管理器和 monorepo 方案。
3. 然后统一构建、环境配置、Lint、TypeScript 和测试。
4. 最后接入 CI/CD、发布、性能预算和监控。

如果你正在准备面试或晋升：

1. 先把一个真实项目拆成“问题、方案、落地、效果、复盘”。
2. 用工程指标说明收益，例如构建时间、发布失败率、包体体积、线上错误率、恢复时间。
3. 能讲清楚取舍，不要只罗列工具名。

## 工程能力自检

| 问题 | 初级回答 | 高级回答 |
| --- | --- | --- |
| 为什么要 monorepo | 因为流行 | 为了解决共享包、版本一致性、影响范围分析和批量重构 |
| 为什么要 CI | 自动跑命令 | 把类型、测试、构建、安全和发布审批变成可追溯门禁 |
| 为什么要性能预算 | 页面更快 | 把包体、LCP、INP、CLS 变成发布前和发布后的约束 |
| 为什么要监控 | 看错误 | 建立 release、source map、用户影响、告警和复盘闭环 |
| 为什么要组件库 | 复用 UI | 用设计 token、API 规范、测试、文档和版本策略降低协作成本 |

## 最小实战目标

学完这个专题后，至少应该能搭建一个这样的项目：

```text
apps/
  web/
  admin/
packages/
  ui/
  config-eslint/
  config-ts/
  shared/
tooling/
  generators/
  scripts/
```

它应该具备：

- 统一包管理器和 lockfile。
- 统一 TypeScript、ESLint、Prettier、测试和构建配置。
- 按包缓存任务结果，支持只构建受影响项目。
- 应用和组件库分别有构建产物、发布策略和变更日志。
- CI 中能跑类型检查、单测、构建、产物分析、安全扫描。
- 线上能关联版本、错误、source map、性能指标和用户影响范围。

## 学习方法

不要只看概念。每读一个主题，都要问三个问题：

1. 这个能力解决什么实际风险？
2. 这个能力接入到开发、构建、发布还是线上运行阶段？
3. 如果它失效，应该怎么发现、止血和修复？

## 深入展开：按全链路建立知识索引

深入学习时不要按工具孤立记忆，而要按交付链路建立索引：

| 链路位置 | 必须深入的问题 | 对应专题 |
| --- | --- | --- |
| 开发前 | 业务边界、目录分层、依赖方向怎么定 | 架构治理、目录治理 |
| 开发中 | 代码怎么生成、规范怎么自动执行 | 脚手架、Lint、TypeScript |
| 构建时 | Babel、TS、bundler、minifier 分别做什么 | 构建体系、Babel 子章节 |
| 合并前 | 哪些检查阻断 PR，哪些只报警 | 测试体系、CI 门禁 |
| 发布时 | 产物如何推进环境，如何灰度和回滚 | CI/CD、Feature Flag |
| 运行时 | 怎么知道用户是否白屏、卡顿、报错 | 性能、监控、可观测性 |
| 复盘后 | 问题如何变成规范、工具和指标 | 技术债、事故复盘 |

Babel 的学习位置在“构建时”，但它会影响后面的 source map、polyfill、产物体积、兼容性和线上排障，所以不能只当成一段配置。
