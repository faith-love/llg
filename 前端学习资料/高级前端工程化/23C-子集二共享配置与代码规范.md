# 子集二：共享配置与代码规范

这一节把 TypeScript、ESLint、Prettier 和包边界规则沉淀成共享配置。目标是让每个应用和包继承统一规则，而不是复制粘贴配置。

## 步骤一：TypeScript 配置包

`packages/config-ts/package.json`：

```json
{
  "name": "@acme/config-ts",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "exports": {
    "./base": "./base.json",
    "./react-app": "./react-app.json",
    "./library": "./library.json"
  }
}
```

`packages/config-ts/base.json`：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "skipLibCheck": true,
    "resolveJsonModule": true
  }
}
```

`packages/config-ts/react-app.json`：

```json
{
  "extends": "./base.json",
  "compilerOptions": {
    "jsx": "react-jsx",
    "noEmit": true
  }
}
```

`packages/config-ts/library.json`：

```json
{
  "extends": "./base.json",
  "compilerOptions": {
    "declaration": true,
    "emitDeclarationOnly": true,
    "outDir": "dist"
  }
}
```

应用使用：

```json
{
  "extends": "@acme/config-ts/react-app",
  "include": ["src", "vite.config.ts"]
}
```

库包使用：

```json
{
  "extends": "@acme/config-ts/library",
  "include": ["src"]
}
```

## 步骤二：ESLint 配置包

`packages/config-eslint/package.json`：

```json
{
  "name": "@acme/config-eslint",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "exports": {
    ".": "./index.js"
  },
  "peerDependencies": {
    "eslint": ">=9"
  }
}
```

`packages/config-eslint/index.js`：

```javascript
export default [
  {
    ignores: ['dist/**', 'coverage/**']
  },
  {
    files: ['**/*.{ts,tsx}'],
    rules: {
      'no-restricted-imports': [
        'error',
        {
          patterns: [
            {
              group: ['apps/*'],
              message: 'packages must not import app code'
            },
            {
              group: ['@acme/*/src/*'],
              message: 'do not deep import package internals'
            }
          ]
        }
      ]
    }
  }
]
```

根 `eslint.config.js`：

```javascript
import acme from '@acme/config-eslint'

export default acme
```

## 步骤四：包边界检查脚本

`tooling/scripts/check-package-boundaries.ts`：

```typescript
type Rule = {
  from: string
  disallow: string[]
}

const rules: Rule[] = [
  { from: 'packages/shared', disallow: ['react', 'react-dom', 'apps/'] },
  { from: 'packages/ui', disallow: ['apps/'] },
  { from: 'packages/api-client', disallow: ['react', 'apps/'] }
]

for (const rule of rules) {
  console.log(`check ${rule.from}: disallow ${rule.disallow.join(', ')}`)
}
```

根脚本：

```json
{
  "scripts": {
    "check:boundaries": "tsx tooling/scripts/check-package-boundaries.ts"
  }
}
```

## 步骤五：统一 package scripts

每个 app/package 至少提供：

```json
{
  "scripts": {
    "lint": "eslint .",
    "typecheck": "tsc --noEmit",
    "test": "vitest run --passWithNoTests",
    "build": "tsc --emitDeclarationOnly"
  }
}
```

应用包的 `build` 用 `vite build`，库包可以先用 `tsc --emitDeclarationOnly`，后续再接 Vite library mode。

## 验收命令

```bash
pnpm lint
pnpm typecheck
pnpm check:boundaries
```

## 验收标准

- app 和 package 都继承 `@acme/config-ts`。
- ESLint 禁止 packages 引用 apps。
- ESLint 禁止深层引用 `@acme/*/src/*`。
- `@acme/shared` 不允许出现 React 依赖。
- 新增 `any` 会被 TypeScript 或 ESLint 发现。
