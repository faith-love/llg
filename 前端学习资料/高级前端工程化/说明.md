# 高级前端工程化

这个专题面向已经能独立开发前端业务、但想把项目做成“多人协作、长期演进、稳定交付”的前端工程师。它不只讲某一个工具，而是把架构、依赖、构建、质量、发布、性能、监控、安全和团队治理放到同一条工程链路里理解。

## 先说结论

前端工程化不是只会配置 Vite、Webpack 或 Babel。

```text
高级前端工程化 = 架构边界 + 依赖治理 + 构建体系 + 质量门禁 + 发布回滚 + 性能预算 + 可观测性 + 安全治理 + 持续改进
```

它真正解决的是：多人、多应用、多环境、多版本、多运行时下，如何让前端系统可维护、可构建、可测试、可发布、可回滚、可观测、可治理。

## 学习目标

- 能设计中大型前端项目的目录分层、模块边界和依赖方向。
- 能治理 npm 依赖、锁文件、版本升级、peer dependencies 和安全风险。
- 能搭建 monorepo、任务编排、缓存、增量构建和 affected 流水线。
- 能统一 Vite、Webpack、Rollup、Rspack、Babel、SWC、TypeScript 等构建职责。
- 能深入理解 Babel 的 parse、transform、generate、AST、plugin、preset、polyfill 和 runtime。
- 能建立 ESLint、Prettier、Stylelint、commitlint、测试和 CI 质量门禁。
- 能设计多环境配置、Feature Flag、灰度发布、回滚和发布审计。
- 能分析产物体积、分包、缓存策略和构建性能瓶颈。
- 能用 Core Web Vitals、RUM、错误监控、日志和 trace 做前端可观测性。
- 能判断微前端、SSR、SSG、ISR、组件库和设计系统的适用场景。
- 能建立安全工程化、供应链治理、技术债管理和工程指标体系。

## 推荐阅读顺序

1. 先读 `00-02`，建立工程化的业务目标、系统边界和架构分层意识。
2. 再读 `03-07`，掌握依赖、monorepo、脚手架、构建、Babel 编译链路和环境配置。
3. 接着读 `08-11`，建立规范、类型、测试和 CI/CD 质量闭环。
4. 然后读 `12-16`，补齐产物优化、Web 性能、监控、微前端和渲染模式。
5. 最后读 `17-23`，沉淀组件库、安全、灰度、治理指标、事故复盘和项目表达。
6. 要按真实项目动手练习时，继续按 `23A1-23I2` 逐页完成工程化交付项。
