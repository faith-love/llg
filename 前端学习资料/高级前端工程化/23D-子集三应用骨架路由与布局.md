# 子集三：应用骨架、路由与布局

这一节创建 `admin` 和 `portal` 的最小可运行应用骨架。目标是练习应用层只做业务编排，不沉淀通用能力。

## admin 入口

`apps/admin/src/main.tsx`：

```typescript
import React from 'react'
import { createRoot } from 'react-dom/client'
import { App } from './app/App'

createRoot(document.getElementById('root') as HTMLElement).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
```

`apps/admin/src/app/App.tsx`：

```typescript
import { AdminRoutes } from './routes'

export function App() {
  return (
    <div>
      <header>
        <h1>ACME Admin</h1>
        <nav>
          <a href="/users">Users</a>
          <a href="/tickets">Tickets</a>
          <a href="/flags">Feature Flags</a>
        </nav>
      </header>
      <main>
        <AdminRoutes />
      </main>
    </div>
  )
}
```

`apps/admin/src/app/routes.tsx`：

```typescript
import { UsersPage } from '../pages/users/UsersPage'
import { TicketsPage } from '../pages/tickets/TicketsPage'
import { FlagsPage } from '../pages/flags/FlagsPage'

export function AdminRoutes() {
  const path = window.location.pathname

  if (path.startsWith('/tickets')) return <TicketsPage />
  if (path.startsWith('/flags')) return <FlagsPage />
  return <UsersPage />
}
```

## admin 页面

`apps/admin/src/pages/users/UsersPage.tsx`：

```typescript
import { DataTable, StatusBadge } from '@acme/ui'

type User = {
  id: string
  name: string
  status: 'active' | 'disabled'
}

const users: User[] = [
  { id: 'u1', name: 'Ada', status: 'active' },
  { id: 'u2', name: 'Linus', status: 'disabled' }
]

export function UsersPage() {
  return (
    <section>
      <h2>Users</h2>
      <DataTable
        rows={users}
        columns={[
          { key: 'name', title: 'Name', render: (row) => row.name },
          { key: 'status', title: 'Status', render: (row) => <StatusBadge status={row.status} /> }
        ]}
      />
    </section>
  )
}
```

## portal 入口

`apps/portal/src/app/App.tsx`：

```typescript
import { PortalRoutes } from './routes'

export function App() {
  return (
    <div>
      <header>
        <h1>ACME Portal</h1>
        <nav>
          <a href="/">Home</a>
          <a href="/tickets">My Tickets</a>
        </nav>
      </header>
      <main>
        <PortalRoutes />
      </main>
    </div>
  )
}
```

`apps/portal/src/app/routes.tsx`：

```typescript
import { HomePage } from '../pages/home/HomePage'
import { MyTicketsPage } from '../pages/tickets/MyTicketsPage'

export function PortalRoutes() {
  if (window.location.pathname.startsWith('/tickets')) {
    return <MyTicketsPage />
  }

  return <HomePage />
}
```

`apps/portal/src/pages/home/HomePage.tsx`：

```typescript
export function HomePage() {
  return (
    <section>
      <h2>Welcome</h2>
      <p>View your tickets and account information.</p>
    </section>
  )
}
```

`apps/portal/src/pages/tickets/MyTicketsPage.tsx`：

```typescript
import { DataTable } from '@acme/ui'

const tickets: Ticket[] = [

  )
}
```

## 验收命令

```bash
pnpm --filter admin dev
pnpm --filter portal dev
pnpm --filter admin build
pnpm --filter portal build
```

## 验收标准

- `admin` 和 `portal` 都能启动。
- 两个应用都使用 `@acme/ui` 的 `DataTable`。
- 页面层只做组合，不实现通用组件。
- 应用之间没有互相 import。
