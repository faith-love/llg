# 面试题与项目表达

高级前端工程化能力在面试和晋升中不能只背工具名。你需要讲清楚真实问题、约束条件、方案取舍、落地过程、结果指标和复盘。面试官更关心你是否能对复杂项目的长期交付负责。

## 项目表达结构

推荐结构：

```text
背景：项目规模、团队规模、痛点
问题：具体风险和影响
方案：为什么这么设计，替代方案是什么
落地：怎么拆阶段、怎么接入工具和流程
结果：指标变化和业务收益
复盘：还有什么不足，下一步怎么做
```

不要只说“我搭了 monorepo”。要说为什么需要它，以及它降低了什么成本。

## 高频问题

### 你如何设计一个中大型前端工程体系？

回答要点：

- 先明确业务形态和团队协作方式。
- 设计目录分层和模块边界。
- 统一包管理器、依赖和 Node 版本。
- 选择构建工具和配置复用方式。
- 接入规范、类型、测试和 CI。
- 设计发布、灰度、回滚和监控。
- 用指标持续治理。

### monorepo 的收益和成本是什么？

收益：

- 共享代码更容易。
- 跨包变更同 PR 完成。
- 统一规范和配置。
- affected 构建降低 CI 成本。

成本：

- 工具链复杂。
- 权限和 ownership 需要治理。
- 缓存和任务配置要维护。
- 仓库规模变大。

### 如何治理包体变大？

回答路径：

1. 先用分析工具确认哪些 chunk 变大。
2. 区分业务代码、第三方依赖、重复依赖和 CSS。
3. 对首屏和异步 chunk 设置预算。
4. 用路由懒加载、大组件异步、依赖替换、tree-shaking、缓存优化处理。
5. 把包体 diff 接入 CI，避免回归。

### 如何设计前端发布和回滚？

回答要点：

- 构建一次产物，多环境推进。
- 产物带 release、commit、manifest。
- 静态资源 hash 长缓存，HTML 短缓存。
- source map 上传并关联 release。
- 灰度或 Feature Flag 控制风险。
- 回滚 HTML 或配置，必要时关闭 flag。

### 你如何处理线上白屏？

回答顺序：

- 看是否新版本集中出现。
- 查 JS 异常、资源 404、chunk 加载失败。
- 查 runtime config 和接口。
- 用 source map 定位源码。
- 判断影响用户数和浏览器分布。
- 先回滚或关闭开关。
- 复盘补监控、测试或发布门禁。

## 项目亮点表达

普通表达：

```text
我配置了 ESLint、Prettier、Vite、CI。
```

更好的表达：

```text
我负责把三个前端应用迁移到统一工程体系。先统一 pnpm 和 Node 版本，再抽出 ESLint、TS、Vite 配置包，接入 PR 阶段 lint、typecheck、unit test 和 build。迁移后新应用初始化时间从半天降到十分钟，CI 能只构建受影响项目，主流程构建时间下降约 40%。
```

关键是讲出前后对比和指标。

## 面试追问准备

面试官可能追问：

- 为什么不用多仓库？
- 缓存怎么判断命中？
- source map 怎么保证不泄露？
- Feature Flag 失败怎么办？
- 如何避免组件库 breaking change？
- CI 太慢怎么优化？
- 类型治理如何处理老代码？
- 微前端 shared 依赖冲突怎么解决？

回答时不要绝对化。高级工程化强调取舍，不是“某工具最好”。

## 自检清单

- 是否能讲出一个真实问题，而不是工具堆叠？
- 是否能说明替代方案和取舍？
- 是否有指标证明收益？
- 是否知道方案的成本和失败场景？
- 是否能说出后续改进？
- 是否能把工程化和业务交付联系起来？

## 深入展开：工程化项目要讲出技术链路

讲高级工程化项目时，不要只说“我做了构建优化”。要能展开链路：

```text
问题：CI 构建慢，发布反馈超过 30 分钟
定位：依赖安装、TypeScript 检查、Babel 转换、打包压缩分别耗时多少
方案：pnpm store 缓存、monorepo affected、Babel 缓存、拆分 typecheck 和 build
门禁：PR 跑基础任务，main 跑完整任务
结果：CI P95 从 30 分钟降到 12 分钟
复盘：后续继续治理 flaky test 和包体预算
```

面试官追问 Babel 时，可以按这条线回答：

```text
Babel 是语法和 AST 转换层
它不负责打包和类型检查
preset-env 根据 targets 决定语法转换
polyfill 负责运行时 API
transform-runtime 处理 helper 复用和运行时隔离
排障要区分语法、API、插件顺序、配置命中和 sourcemap
```
