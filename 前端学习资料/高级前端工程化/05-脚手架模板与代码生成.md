# 脚手架模板与代码生成

脚手架和代码生成的价值，是把团队约定变成自动化能力。只写文档很容易失效，因为开发者会忘记步骤、复制旧代码、漏掉配置。生成器可以让新项目、新页面、新组件、新接口从第一行代码开始就符合规范。

## 可以生成什么

| 类型 | 示例 |
| --- | --- |
| 应用模板 | React/Vue 应用、管理后台、移动端 H5、组件库 |
| 模块模板 | 页面、路由、业务 feature、store、API、测试 |
| 组件模板 | 组件文件、样式、测试、Story、导出入口 |
| 配置模板 | ESLint、TypeScript、Vite、Vitest、Playwright |
| 文档模板 | README、变更日志、API 文档、设计说明 |
| 迁移脚本 | 批量改 import、替换 API、升级组件写法 |

## 一个好模板应该包含什么

不要只生成空文件。模板应该体现团队最佳实践：

```text
Button/
  Button.tsx
  Button.test.tsx
  Button.stories.tsx
  index.ts
```

还应该包含：

- 清晰命名。
- 稳定导出入口。
- 基础测试。
- 类型定义。
- 文档或 Story。
- 样式和设计 token 使用方式。
- 可选配置开关。

## CLI 设计

一个内部脚手架可以提供这些命令：

```bash
repo create app admin
repo create package ui
repo generate page user/list
repo generate component Button --with-test --with-story
repo migrate react-query-v4-to-v5
```

CLI 要做参数校验，不要让用户生成不合规结构。例如包名必须符合命名规范，模块路径不能越过约定目录。

## 生成器不是复制粘贴

生成器要把“规范”固化下来：

- 文件位置符合分层。
- import 路径符合别名规则。
- 测试文件自动生成。
- 组件自动导出。
- README 自动带使用示例。
- package.json 自动补脚本和依赖。
- monorepo 任务配置自动注册。

如果生成后还需要手工改大量配置，说明模板抽象还不够。

## 模板版本管理

模板本身也要版本化。否则旧项目和新项目会越来越不一致。

推荐做法：

- 模板放在仓库内，和工程配置一起 review。
- 每次模板变更写变更说明。
- 提供迁移脚本，把旧结构升级到新结构。
- 模板不要绑定过多业务默认值。
- 模板要有最小可运行验证。

## codemod

代码迁移不要完全靠人工搜索替换。可以用 AST 或专用工具做结构化修改。

适合 codemod 的场景：

- API 改名。
- import 路径迁移。
- 组件属性重命名。
- React class 组件迁移部分生命周期。
- 路由配置升级。
- 设计系统 token 替换。

字符串替换容易误伤，AST 迁移可以识别语法结构。

## 常见反模式

| 反模式 | 后果 |
| --- | --- |
| 模板长期不维护 | 新项目带着旧技术债出生 |
| 模板过度复杂 | 新人不知道哪些文件能删 |
| 只生成代码不注册配置 | 生成后还要手动接路由、导出、测试 |
| 生成器不校验命名 | 目录和包名混乱 |
| 无迁移脚本 | 规范升级只能靠人工改 |

## 落地清单

- 是否有统一创建应用、包、页面、组件的命令？
- 模板是否包含测试、文档和导出入口？
- 生成器是否会校验命名和目标路径？
- 模板是否能随工程规范升级？
- 是否有 codemod 处理批量迁移？
- 新人是否能只靠脚手架创建合规模块？

## 深入展开：脚手架要覆盖创建、升级和废弃

脚手架不应该只负责“生成第一版代码”。它还要覆盖模块生命周期：

| 阶段 | 脚手架能力 |
| --- | --- |
| 创建 | 生成目录、测试、文档、导出入口、路由注册 |
| 修改 | 增加子模块、补测试、注册权限、注册埋点 |
| 升级 | codemod 批量迁移 API、配置和 import |
| 废弃 | 标记 deprecated、迁移引用、删除死代码 |

一个成熟生成器应该有 dry-run：

```bash
repo generate component UserCard --dry-run
```

让开发者先看到会创建哪些文件、修改哪些入口。对会改多个文件的生成器，dry-run 能显著降低误操作风险。

模板还要能表达团队标准。例如创建页面时同时生成 loading、empty、error、permission denied 状态，而不是只生成一个空组件。
