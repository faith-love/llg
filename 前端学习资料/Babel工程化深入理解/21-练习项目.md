# 练习项目

这些练习用于把 Babel 和打包流程跑通。建议每个练习都查看输入源码、转换后代码和最终产物。

## 练习一：Babel CLI 转换单文件

要求：

- 新建 `src/index.js`。
- 使用箭头函数、可选链、class fields。
- 配置 `@babel/preset-env`。
- 用 Babel CLI 输出到 `lib`。
- 对比转换前后代码。

目标：理解 Babel 处理的是单文件语法转换。

## 练习二：写一个 Babel 插件

要求：

- 删除 `console.log`。
- 只在 production 环境启用。
- 用测试输入输出验证。

目标：理解 AST、visitor、path.remove。

## 练习三：preset-env 和 targets

要求：

- 分别配置现代 Chrome 和 IE 11。
- 开启 `debug: true`。
- 对比启用的转换插件。
- 解释为什么产物不同。

目标：理解 targets 决定转换范围。

## 练习四：polyfill 验证

要求：

- 使用 `Promise`、`Array.from`、`Array.prototype.includes`。
- 配置 `useBuiltIns: usage` 和 `core-js`。
- 查看输出中注入了哪些 polyfill。

目标：区分语法转换和 API polyfill。

## 练习五：Webpack + babel-loader

要求：

- 配置 Webpack entry。
- 配置 `babel-loader`。
- 加入 CSS loader。
- 打包输出 dist。
- 画出 module graph。

目标：理解 Webpack 如何调用 Babel。

## 练习六：动态导入和分包

要求：

- 新建两个页面模块。
- 使用 `import('./Admin')`。
- 构建后观察 chunk。
- 解释哪个 chunk 首屏加载，哪个按需加载。

目标：理解 dynamic import 和 chunk。

## 练习七：tree-shaking

要求：

- 写一个导出多个函数的模块。
- 只导入其中一个。
- 构建生产产物。
- 检查未使用函数是否被删除。
- 修改 Babel modules 配置，观察差异。

目标：理解 ESM、sideEffects、minify 对 tree-shaking 的影响。

## 练习八：库项目构建

要求：

- 用 Rollup 构建一个小工具库。
- 输出 ESM 和 CJS。
- 使用 `@babel/plugin-transform-runtime`。
- 生成 `.d.ts`。
- 配置 `exports`、`types`、`sideEffects`。

目标：理解库项目和应用项目构建差异。

## 练习九：source map 排障

要求：

- 开启 source map。
- 构建压缩产物。
- 制造运行时报错。
- 在浏览器中定位回源码。

目标：理解 source map 链路。

## 验收标准

- 能说明 Babel 在构建链路中的位置。
- 能画出 parse、transform、generate。
- 能解释 preset-env、core-js、transform-runtime。
- 能说明 Webpack/Rollup/Vite 打包流程。
- 能解释 tree-shaking 和 code splitting。
- 能定位一个构建问题属于 Babel、bundler、polyfill、TypeScript 还是部署路径。
