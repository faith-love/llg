# 声明、表达式、提升与作用域

`class` 有声明和表达式两种写法。它们看起来像函数声明和函数表达式，但作用域、提升和暂时性死区更接近 `let` 和 `const`。

## class 声明

```javascript
class User {
  constructor(name) {
    this.name = name
  }
}

const user = new User('Ada')
```

`User` 是当前块级作用域中的绑定。

```javascript
{
  class User {}
}

console.log(User) // ReferenceError
```

class 声明是块级作用域，不会像 `var` 一样提升到函数作用域。

## class 声明有暂时性死区

```javascript
new User()

class User {}
```

会抛错：

```text
ReferenceError: Cannot access 'User' before initialization
```

class 声明会创建绑定，但在执行到 class 定义之前不可访问。这一点和 `let`、`const` 类似。

对比函数声明：

```javascript
run()

function run() {
  console.log('ok')
}
```

函数声明通常可以在声明前调用，而 class 不行。

## class 表达式

```javascript
const User = class {
  constructor(name) {
    this.name = name
  }
}
```

也可以命名：

```javascript
const User = class InternalUser {
  static getClassName() {
    return InternalUser.name
  }
}

console.log(User.getClassName()) // 'InternalUser'
console.log(typeof InternalUser) // 'undefined'
```

命名 class 表达式的内部名字主要用于类体内部引用和调试栈信息，外部通常访问不到。

## class 名称是只读的吗

类名绑定本身取决于声明方式：

```javascript
class User {}
User = 1 // 在模块或严格模式中通常会报错
```

```javascript
let User = class {}
User = class Admin {}
```

如果用 `let` 保存 class 表达式，变量当然可以重新赋值。不要把“类名”和“保存类的变量”混在一起。

## class 体内部的名字

```javascript
class User {
  static create() {
    return new User()
  }
}
```

`User` 在类体方法中可用。但写可继承的静态工厂时，经常更推荐用 `this`：

```javascript
class Model {
  static create() {
    return new this()
  }
}

class User extends Model {}

console.log(User.create() instanceof User) // true
```

这里的 `this` 指调用静态方法的构造函数，更利于子类复用。

## 计算属性名的求值时机

class 成员名可以是计算属性：

```javascript
const key = 'sayHi'

class User {
  [key]() {
    return 'hi'
  }
}
```

计算属性名会在 class 定义求值时执行，不是每次实例化时执行：

```javascript
let i = 0

class Demo {
  [`m${++i}`]() {}
}

new Demo()
new Demo()

console.log(i) // 1
```

这和实例字段初始化不同。字段初始化发生在每次创建实例时。

## class 是一等值

class 可以像函数一样作为值传递：

```javascript
function createStore(StoreClass) {
  return new StoreClass()
}

class MemoryStore {}

const store = createStore(MemoryStore)
```

也可以动态生成：

```javascript
function withName(name) {
  return class {
    getName() {
      return name
    }
  }
}

const Named = withName('cache')
console.log(new Named().getName()) // 'cache'
```

这也是 mixin、测试替身、插件系统和框架内部常见的写法。
