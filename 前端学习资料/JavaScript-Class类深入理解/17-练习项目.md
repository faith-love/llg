# 练习项目

这些练习用于把 class 的细节落实到代码里。建议每个练习都先写最小实现，再用 `Object.getPrototypeOf`、`Object.getOwnPropertyNames`、`Object.getOwnPropertyDescriptors` 验证运行时结构。

## 练习一：实现 Counter

要求：

- `count` 是实例字段。
- `inc`、`dec`、`reset` 是原型方法。
- `value` 是 getter。
- 用 `Object.keys` 验证只有字段可枚举。

参考骨架：

```javascript
class Counter {
  count = 0

  get value() {
    return this.count
  }

  inc() {
    this.count += 1
  }

  dec() {
    this.count -= 1
  }

  reset() {
    this.count = 0
  }
}
```

验证：

```javascript
const counter = new Counter()
console.log(Object.keys(counter))
console.log(Object.getOwnPropertyNames(Counter.prototype))
```

## 练习二：实现私有余额账户

要求：

- 使用 `#balance` 真私有字段。
- 提供 `deposit`、`withdraw`、`getBalance`。
- 禁止余额变成负数。
- 使用 `#balance in obj` 写一个静态检查方法。

参考骨架：

```javascript
class Account {
  #balance = 0

  static isAccount(obj) {
    return #balance in obj
  }

  deposit(amount) {
    if (amount <= 0) throw new RangeError('amount must be positive')
    this.#balance += amount
  }

  withdraw(amount) {
    if (amount > this.#balance) throw new RangeError('insufficient balance')
    this.#balance -= amount
  }

  getBalance() {
    return this.#balance
  }
}
```

验证：

```javascript
const account = new Account()
account.deposit(100)
console.log(account.getBalance())
console.log(Account.isAccount(account))
console.log(Account.isAccount({}))
```

## 练习四：实现 LRUCache

要求：

- 构造器接收容量。
- `get` 命中后刷新顺序。
- `set` 超过容量时移除最久未使用项。
- 使用 `#cache` 保存内部 Map。
- 使用 getter 暴露 `size`。

骨架：

```javascript
class LRUCache {
  #cache = new Map()

  constructor(limit) {
    this.limit = limit
  }

  get size() {
    return this.#cache.size
  }

  get(key) {}

  set(key, value) {}
}
```

验收：

```javascript
const cache = new LRUCache(2)
cache.set('a', 1)
cache.set('b', 2)
cache.get('a')
cache.set('c', 3)

console.log(cache.get('b')) // undefined
console.log(cache.get('a')) // 1
console.log(cache.get('c')) // 3
```

## 练习五：实现可继承的 Model

要求：

- `Model.create(data)` 返回当前子类实例。
- `Model.fromList(list)` 返回当前子类实例数组。
- 子类 `User` 继承 `Model`。
- 使用静态方法中的 `this`，不要写死父类名。

参考：

```javascript
class Model {
  constructor(data = {}) {
    Object.assign(this, data)
  }

  static create(data) {
    return new this(data)
  }

  static fromList(list) {
    return list.map((item) => this.create(item))
  }
}

class User extends Model {}

const users = User.fromList([{ name: 'Ada' }])
console.log(users[0] instanceof User) // true
```

## 练习七：观察字段和 setter 的差异

写父类 setter：

```javascript
class Base {
  set value(v) {
    console.log('setter', v)
  }
}
```

分别测试：

```javascript
class A extends Base {
  value = 1
}
```

和：

```javascript
class B extends Base {
  constructor() {
    super()
    this.value = 1
  }
}
```

解释为什么一个不触发 setter，一个触发 setter。
