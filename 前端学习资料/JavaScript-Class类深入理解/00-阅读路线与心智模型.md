# 阅读路线与心智模型

学习 `class` 最容易走偏的地方，是把它当成 Java、C# 那种传统类系统。JavaScript 的 `class` 当然提供了更清晰的类语法，但它运行时依然建立在函数对象、普通对象、原型链、属性描述符和词法作用域之上。

## 先建立三层对象模型

任何一个 class 都可以先拆成三层：

```javascript
class Counter {
  static type = 'counter'

  count = 0

  inc() {
    this.count += 1
  }
}

const counter = new Counter()
```

对应运行时结构：

```text
Counter
  类型：函数对象
  作用：被 new 调用，承载 static 成员

Counter.prototype
  类型：普通对象
  作用：承载实例共享方法，例如 inc

counter
  类型：普通对象
  作用：承载每个实例自己的字段，例如 count
```

可以用代码验证：

```javascript
console.log(typeof Counter) // 'function'
console.log(Counter.type) // 'counter'
console.log(Counter.prototype.inc === counter.inc) // true
console.log(Object.hasOwn(counter, 'count')) // true
console.log(Object.hasOwn(counter, 'inc')) // false
```

## 学习顺序

建议按这个顺序推进：

| 顺序 | 主题 | 要解决的问题 |
| --- | --- | --- |
| 1 | `class` 与构造函数 | class 是什么，不是什么 |
| 2 | `new` 和 `constructor` | 实例如何被创建，this 什么时候可用 |
| 3 | 原型方法 | 方法为什么能共享，为什么不可枚举 |
| 4 | 实例字段 | 字段什么时候初始化，和构造器赋值有什么不同 |
| 5 | 私有成员 | `#x` 为什么是真私有，不是命名约定 |
| 6 | 静态成员 | 哪些东西属于类本身，不属于实例 |
| 7 | 继承与 `super` | 继承链如何建立，派生类构造器为什么特殊 |
| 8 | `this` 绑定 | 方法引用为什么会丢 this，箭头字段有什么代价 |
| 9 | TypeScript | 编译期约束和运行时行为如何区分 |

## 一张总图

```text
class Sub extends Base

静态链：
Sub.[[Prototype]] ----------> Base
Sub.staticMethod()           Base.staticMethod()

实例原型链：
new Sub()
  [[Prototype]] ------------> Sub.prototype
                                [[Prototype]] -> Base.prototype
                                                   [[Prototype]] -> Object.prototype
```

`extends` 不只是让实例继承方法，也会让子类构造函数继承父类构造函数上的静态成员。

## 阅读 class 代码的固定步骤

看到一个 class，按下面顺序拆：

1. 看 `extends`，确认它有没有父类。
2. 看 `static`，找类级别状态和类级别工具方法。
3. 看实例字段，确认每个实例会拥有哪些自有属性。
4. 看 `#private`，确认哪些状态只能在类体内部访问。
5. 看 `constructor`，确认参数如何转成实例状态。
6. 看普通方法，确认哪些行为被所有实例共享。
7. 看方法里是否依赖 `this`，判断传参、回调和事件绑定是否安全。
8. 看字段和访问器是否同名，判断覆盖关系和副作用。

## 最小验证工具

学 class 时不要只靠读文档。每个细节都可以用这些 API 验证：

```javascript
Object.getOwnPropertyNames(obj)
Object.getOwnPropertyDescriptors(obj)
Object.getPrototypeOf(obj)
Object.hasOwn(obj, 'name')
Reflect.ownKeys(obj)
obj instanceof Constructor
```

例如：

```javascript
class Demo {
  x = 1

  method() {}

  static create() {
    return new Demo()
  }
}

const demo = new Demo()

console.log(Object.getOwnPropertyNames(demo)) // ['x']
console.log(Object.getOwnPropertyNames(Demo.prototype)) // ['constructor', 'method']
console.log(Object.getOwnPropertyNames(Demo)) // ['length', 'name', 'prototype', 'create']
```
