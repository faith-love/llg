# JavaScript Class 类深入理解

这个专题面向已经会写前端业务代码、但想真正理解 `class` 细节的工程师。重点不是背语法，而是把 `class` 放回 JavaScript 的对象模型里理解：它是一套更结构化的原型语法，同时又引入了字段初始化、私有品牌、静态块、严格模式和派生类构造等新语义。

## 学习目标

- 能解释 `class` 和构造函数、原型对象、实例对象之间的关系。
- 能判断一个成员是在实例上、原型上，还是构造函数本身上。
- 能说清楚 `constructor`、公共字段、私有字段、静态字段、静态块的执行时机。
- 能理解 `extends` 同时建立了实例继承链和静态继承链。
- 能排查 `this` 丢失、`super` 使用错误、字段覆盖、私有字段访问失败等常见问题。
- 能区分 JavaScript 运行时私有成员和 TypeScript 编译期 `private`。
- 能读懂 React class 组件、老代码、组件库、SDK、状态机和工具库中的 class 写法。

## 总体心智模型

一段 class 代码：

```javascript
class User {
  static role = 'member'
  #token

  constructor(name, token) {
    this.name = name
    this.#token = token
  }

  login() {
    return `${this.name} logged in`
  }
}
```

需要拆成三层看：

```text
User                 -> 构造函数对象，也承载 static 成员
User.prototype       -> 原型对象，承载普通方法
new User(...)        -> 实例对象，承载实例字段和私有槽
```

不要把 class 当成“模板文件”。在运行时，它仍然会产生对象、函数、属性描述符和原型链。理解这些运行时结构，比记住语法更重要。

## 推荐阅读顺序

1. 先读 `00-04`，建立 class、constructor、prototype、new 的核心模型。
2. 再读 `05-10`，把字段、私有成员、静态成员、继承和 this 的坑补齐。
3. 已经写 TypeScript 或 React 的同学，再读 `12-14`，理解编译期语法和框架代码。
4. 最后用 `15-17` 做排障、面试复盘和练习。
