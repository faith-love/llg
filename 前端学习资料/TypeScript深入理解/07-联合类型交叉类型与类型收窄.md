# 联合类型、交叉类型与类型收窄

联合类型表达“可能是这些类型之一”。交叉类型表达“同时满足这些类型”。前端复杂状态建模离不开它们。

## 联合类型

```typescript
type ID = string | number

function findById(id: ID) {}
```

使用联合类型时，只能直接访问所有成员共有的能力：

```typescript
function print(value: string | number) {
  value.toUpperCase() // 类型错误
}
```

需要先收窄：

```typescript
function print(value: string | number) {
  if (typeof value === 'string') {
    return value.toUpperCase()
  }

  return value.toFixed(2)
}
```

## 类型收窄

常见收窄方式：

```typescript
typeof value === 'string'
value instanceof Date
'id' in value
Array.isArray(value)
value !== null
switch (value.status)
```

TypeScript 会根据控制流分析缩小类型。

## 可辨识联合

```typescript
type RequestState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; data: T }
  | { status: 'error'; error: Error }
```

`status` 是判别字段：

```typescript
function render<T>(state: RequestState<T>) {
  switch (state.status) {
    case 'success':
      return state.data
    case 'error':
      return state.error.message
    default:
      return null
  }
}
```

这是前端 UI 状态建模最实用的模式之一。

## 穷尽检查

```typescript
function assertNever(value: never): never {
  throw new Error(`Unexpected value: ${value}`)
}

function render<T>(state: RequestState<T>) {
  switch (state.status) {
    case 'idle':
      return null
    case 'loading':
      return 'loading'
    case 'success':
      return state.data
    case 'error':
      return state.error.message
    default:
      return assertNever(state)
  }
}
```

如果以后新增状态但没有处理，`assertNever(state)` 会提示类型错误。

## 交叉类型

```typescript
type WithId = {
  id: string
}

type WithTimestamp = {
  createdAt: string
}

type Entity = WithId & WithTimestamp
```

`Entity` 同时拥有 `id` 和 `createdAt`。

## 交叉类型不是对象合并那么简单

```typescript
type A = {
  value: string
}

type B = {
  value: number
}

type C = A & B
```

`C['value']` 会变成 `never`，因为一个值不可能同时是 `string` 和 `number`。

不要用交叉类型强行合并冲突字段。

## 自定义类型守卫

```typescript
function isUser(value: unknown): value is User {
  return (
    typeof value === 'object' &&
    value !== null &&
    'id' in value &&
    'name' in value
  )
}
```

使用：

```typescript
if (isUser(input)) {
  console.log(input.name)
}
```

类型守卫适合处理外部输入边界。

## 收窄常见误区

不要只判断 truthy：

```typescript
if (value) {}
```

它会排除 `''`、`0`、`false`，可能不符合业务。

更明确：

```typescript
if (value !== undefined) {}
if (value !== null) {}
if (typeof value === 'string') {}
```
