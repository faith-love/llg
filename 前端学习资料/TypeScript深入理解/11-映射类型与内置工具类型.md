# 映射类型与内置工具类型

映射类型可以遍历对象类型的键，生成新对象类型。TypeScript 的很多内置工具类型都基于它。

## 映射类型基础

```typescript
type User = {
  id: string
  name: string
}

type OptionalUser = {
  [K in keyof User]?: User[K]
}
```

`OptionalUser` 等价于：

```typescript
{
  id?: string
  name?: string
}
```

## Partial

```typescript
type Partial<T> = {
  [K in keyof T]?: T[K]
}
```

用法：

```typescript
type UserPatch = Partial<User>
```

适合更新接口、表单草稿、局部配置。

## Required

```typescript
type Required<T> = {
  [K in keyof T]-?: T[K]
}
```

`-?` 表示移除可选修饰符。

## Readonly

```typescript
type Readonly<T> = {
  readonly [K in keyof T]: T[K]
}
```

注意它是浅层 readonly。

## Pick

```typescript
type Pick<T, K extends keyof T> = {
  [P in K]: T[P]
}
```

用法：

```typescript
type UserPreview = Pick<User, 'id' | 'name'>
```

## Omit

```typescript
type UserWithoutPassword = Omit<User, 'password'>
```

常用于从完整模型中去掉敏感字段。

## Record

```typescript
type StatusMap = Record<'idle' | 'loading' | 'success', string>
```

等价于：

```typescript
{
  idle: string
  loading: string
  success: string
}
```

适合枚举值到配置的映射。

## Exclude 和 Extract

```typescript
type Status = 'idle' | 'loading' | 'success' | 'error'

type DoneStatus = Exclude<Status, 'idle' | 'loading'>
type ErrorStatus = Extract<Status, 'error'>
```

`Exclude` 从联合类型中排除成员。

`Extract` 从联合类型中提取成员。

## NonNullable

```typescript
type Value = string | null | undefined
type SafeValue = NonNullable<Value>
```

`SafeValue` 是 `string`。

## Parameters 和 ReturnType

```typescript
function createUser(name: string, age: number) {
  return { name, age }
}

type Args = Parameters<typeof createUser>
type Result = ReturnType<typeof createUser>
```

适合从已有函数派生类型，避免重复维护。

## Awaited

```typescript
type Data = Awaited<Promise<Promise<User>>>
```

结果是 `User`。

适合提取异步函数返回值：

```typescript
async function getUser() {
  return { id: '1', name: 'Ada' }
}

type User = Awaited<ReturnType<typeof getUser>>
```

## 键重映射

```typescript
type Getters<T> = {
  [K in keyof T as `get${Capitalize<K & string>}`]: () => T[K]
}
```

例如：

```typescript
type UserGetters = Getters<{
  name: string
  age: number
}>
```

会得到：

```typescript
{
  getName: () => string
  getAge: () => number
}
```

## 使用原则

工具类型适合减少重复，但不要为了少写类型而牺牲可读性。公共业务类型建议优先显式清楚，复杂工具类型要配注释和示例。
