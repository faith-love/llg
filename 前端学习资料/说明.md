## 学习方式

1. 学 JavaScript class 时，先读 Class 专题总纲，建立 `class -> constructor function -> prototype -> instance` 的对象模型。
2. 学 TypeScript 时，先读 TypeScript 专题总纲，建立 `类型空间 -> 值空间 -> 类型边界 -> 工程治理` 的主线。
3. 每个专题按编号阅读，配合浏览器控制台、Node.js 或 TS Playground 验证。
4. 学 Babel 和打包工程化时，先读 Babel 专题总纲，建立 `源码 -> AST -> transform -> module graph -> chunk -> dist` 的主线。
5. 遇到框架代码、组件库代码、SDK 代码时，回到对应专题查 `this`、继承、泛型、声明文件、Babel 配置和打包流程。
6. 新增前端专题时优先放入本目录；如果形成独立路线，再在本页补充入口。
