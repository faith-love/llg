## 学习方式

1. 学 JavaScript class 时，先读 Class 专题总纲，建立 `class -> constructor function -> prototype -> instance` 的对象模型。
2. 学 JS 库设计时，先读库架构专题总纲，建立 `定位 -> API -> core -> plugin -> runtime -> types -> build -> docs` 的主线。
3. 学 TypeScript 时，先读 TypeScript 专题总纲，建立 `类型空间 -> 值空间 -> 类型边界 -> 工程治理` 的主线。
4. 每个专题按编号阅读，配合浏览器控制台、Node.js 或 TS Playground 验证。
5. 学 Babel 和打包工程化时，先读 Babel 专题总纲，建立 `源码 -> AST -> transform -> module graph -> chunk -> dist` 的主线。
6. 学高级前端工程化时，先读高级工程化总纲，建立 `架构 -> 依赖 -> 构建 -> 质量 -> 发布 -> 性能 -> 监控 -> 治理` 的主线。
7. 遇到框架代码、组件库代码、SDK 代码时，回到对应专题查 `this`、继承、泛型、声明文件、库架构、Babel 配置、打包流程和工程治理方案。
8. 新增前端专题时优先放入本目录；如果形成独立路线，再在本页补充入口。
