# 01 命令行效率与文件搜索工具

这一类工具的目标是提高日常排障和部署效率：更快找到文件、更快搜索文本、更安全地保留远程会话、更直观看清目录和磁盘占用。它们多数不是生产服务依赖，适合安装在个人开发机、跳板机、测试机，生产服务器按需安装。

## 选型原则

- 基础命令先掌握：`find`、`grep`、`du`、`less`、`tail`。
- 增强工具用于提效，不要让核心脚本强依赖冷门工具。
- 生产服务器少装插件和主题，避免影响排障一致性。
- 搜索命令历史和日志时注意不要泄露密码、Token、连接串。

## zsh 与 oh-my-zsh

### 作用

`zsh` 是增强 Shell，`oh-my-zsh` 是常用配置框架，提供主题、插件、补全和更好的历史体验。

### 适合场景

- 个人开发机。
- 跳板机。
- 测试环境。
- 经常输入 Git、Docker、kubectl、ssh 命令的用户。

### 安装

Ubuntu/Debian：

```bash
sudo apt install zsh
```

RHEL 系：

```bash
sudo dnf install zsh
```

切换默认 Shell：

```bash
chsh -s "$(which zsh)"
```

### 使用技巧

- 开启命令自动补全和历史搜索。
- 只启用必要插件，例如 `git`、`docker`。
- root 用户尽量保持默认 Shell，减少插件对生产排障的影响。

### 注意事项

- 不要在生产服务器 root 环境安装过多主题和插件。
- 插件可能改变命令提示或补全行为，排障时要能回到 Bash。
- 不要把带密码的命令留在历史记录中。

## tmux

### 作用

`tmux` 是终端复用工具，可以在一个 SSH 会话中管理多个窗口和面板。网络断开后，tmux 会话仍可保留。

### 适合场景

- 长时间部署。
- 数据迁移。
- 远程看日志。
- 同时编辑配置、执行命令、观察服务状态。

### 常用命令

```bash
tmux new -s deploy
tmux ls
tmux attach -t deploy
tmux kill-session -t deploy
```

常用快捷键默认前缀是 `Ctrl+b`：

| 操作 | 快捷键 |
| --- | --- |
| 新窗口 | `Ctrl+b c` |
| 切换窗口 | `Ctrl+b n` / `Ctrl+b p` |
| 左右分屏 | `Ctrl+b %` |
| 上下分屏 | `Ctrl+b "` |
| 分离会话 | `Ctrl+b d` |

### 注意事项

- tmux 适合保护人工操作会话，不适合管理长期服务。
- 长期服务仍应使用 systemd、Docker Compose 或专门编排系统。
- 重要操作前给 session 起清晰名称，例如 `deploy-demo-api`。

## fzf

### 作用

`fzf` 是模糊查找工具，可快速查找历史命令、文件、目录、进程。

### 适合场景

- 从历史命令中找部署命令。
- 快速进入深层目录。
- 配合 `rg` 搜索内容后选择文件。

### 示例

查找文件并编辑：

```bash
vim "$(find . -type f | fzf)"
```

配合历史命令搜索通常由 Shell 插件提供，例如 `Ctrl+r`。

### 注意事项

- 搜索历史命令时可能看到敏感命令。
- 生产服务器上不要把 fzf 配置得过于复杂，避免影响基础操作。

## tree

### 作用

`tree` 用树形结构展示目录，适合说明部署结构和检查目录层级。

### 安装

```bash
sudo apt install tree
sudo dnf install tree
```

### 示例

```bash
tree -L 2 /opt/apps/demo-api
tree -L 3 -a /opt/apps/demo-api
```

常用于查看：

```text
current -> releases/版本
releases/
shared/config
shared/logs
shared/uploads
```

### 注意事项

- 目录很大时限制层级，例如 `-L 2`。
- 不要把包含密钥的目录结构随意截图外发。

## fd

### 作用

`fd` 是更现代的文件名查找工具，比 `find` 更易用，默认忽略 `.gitignore` 中的内容。

### 示例

```bash
fd nginx /etc
fd -e log . /var/log
fd application /opt/apps
```

与 `find` 对比：

```bash
find /opt/apps -name "*application*"
fd application /opt/apps
```

### 使用建议

- 交互排障可优先用 `fd`。
- 脚本里优先使用 `find`，因为系统默认更可能存在。
- 需要搜索隐藏文件时加 `-H`。

## ncdu

### 作用

`ncdu` 是交互式磁盘占用分析工具，适合快速定位大目录和大文件。

### 安装

```bash
sudo apt install ncdu
sudo dnf install ncdu
```

### 示例

```bash
sudo ncdu /var
sudo ncdu /opt/apps
sudo ncdu /
```

### 注意事项

- 它适合定位，不等于可以直接删除。
- 删除前确认文件归属、业务影响、是否有进程仍占用。
- 数据库目录、上传目录、证书目录不要随手删。

## ripgrep：rg

### 作用

`rg` 是非常快的全文搜索工具，适合在代码、配置、日志中查关键字。

### 示例

搜索配置项：

```bash
rg -n "server.port" /opt/apps/demo-api
```

搜索日志错误：

```bash
rg -n "ERROR|Exception" /opt/apps/demo-api/shared/logs
```

搜索隐藏文件：

```bash
rg -n -H "DB_PASSWORD" /opt/apps/demo-api
```

只搜索某类文件：

```bash
rg -n "proxy_pass" /etc/nginx -g "*.conf"
```

### 使用建议

- 日常搜索优先 `rg`，比递归 `grep` 更舒服。
- 脚本兼容性要求高时仍可使用 `grep`。
- 搜索日志时注意脱敏输出。

## 推荐组合

| 场景 | 推荐工具 |
| --- | --- |
| 长时间远程部署 | `tmux` |
| 快速找文件 | `fd` |
| 快速搜文本 | `rg` |
| 看部署目录 | `tree` |
| 查磁盘大目录 | `ncdu` |
| 找历史命令 | `fzf` |

## 练习

1. 用 `tree -L 3` 输出一个项目部署目录结构。
2. 用 `fd` 找出 `/var/log` 下所有 `.log` 文件。
3. 用 `rg` 在 Nginx 配置中搜索 `proxy_pass`。
4. 用 `ncdu` 分析 `/opt/apps` 占用最大的目录。
5. 创建一个 tmux 会话，在里面同时打开日志观察和服务状态检查。
